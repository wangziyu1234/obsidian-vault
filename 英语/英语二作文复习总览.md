# 英语二作文复习总览

> [!abstract] 本讲定位
> **作文重点背与写，其他题型只掌握基础。**
> 小作文约 **100 词、10 分**；大作文约 **150 词、15 分**。先按你手写本的习惯背熟整篇，再换题填空。

> [!tip] 先背这两页：整篇固定骨架＋中文空位
> [[04-2 小作文 整篇背诵模板|小作文：建议信、倡议信、邀请信]]。
> [[06-2 大作文 整篇背诵模板|大作文：动态、静态，以及多项调查首段]]。
> **固定英文连着背，粗体 [中文] 换成具体英文。** 完整三段默认展开，备用句和填空说明放在后面。

> **整篇读熟 → 看中文提纲默写 → 用真题填空 → 展开核对 → 重写错句。**

## ✉️ 小作文：先背功能，再组合

> [!tip] 默写前先说出这三段
> **首段：为什么写。**
>
> **中段：题目要我做什么，就具体写什么。**
>
> **尾段：询问、请求、致谢或祝福，按任务收束。**

| 题目要求 | 本轮背什么 | 去哪里核对 |
| :-- | :-- | :-- |
| 提建议 | 一个建议句 + 一个用途或理由 | [[03 小作文 分类与句型]] |
| 邀请或介绍活动 | 目的 + 安排 + 参与方式 | [[03 小作文 分类与句型]] |
| 感谢、道歉、投诉 | 具体事实 + 影响 + 后续行动 | [[04 小作文 九类模板]] |
| 推荐 | 明确选谁或选什么 + 理由 | [[04 小作文 九类模板]] |
| 介绍、反馈、询问 | 指定信息 + 一句明确询问 | [[03 小作文 分类与句型]] |

**先把一套整篇背顺，再换人物、对象和行动。** 建议、倡议、邀请先用 [[04-2 小作文 整篇背诵模板]]；其他信件再从 [[04 小作文 九类模板]] 查相应功能。

## 📊 大作文：三段各完成一个任务

> [!tip] 默写前先说出这三句中文
> **图里最突出的事实是什么？**
>
> **为什么会这样，或者它说明什么？**
>
> **据此可以得出什么结论、提出什么建议？**

| 段落 | 先记住的内容 | 默写时最容易漏的事 |
| :-- | :-- | :-- |
| 第一段 | 主题 + 关键数据 | 对象、年份、单位；动态还是静态 |
| 第二段 | 两条贴题的解释或评论 | 解释必须接回前段的数据 |
| 第三段 | 一条总结或具体建议 | 谁做什么、有什么作用 |

用 [[06-2 大作文 整篇背诵模板]] 连着背三段。动态换起终点和趋势，静态换占比与排序；多项调查换受访者比例句。原因和结尾随本题内容填入。

**起步两题**：2023 健康素养折线图 → 2024 劳动实践课调查。
在 [[06-1 大作文 动静态真题拆解]] 直接看原图练写；两题分别训练时间变化与类别比较。
完整成文：[[英语/作文真题/2023年英语二大作文参考范文|2023 完整范文]] · [[英语/作文真题/2024年英语二大作文参考范文|2024 完整范文]]。

## ✍️ 每次练习如何闭环

1. **回忆**：看中文提纲，说出整篇三段分别做什么。
2. **默写**：收起英文，连续写出本轮整篇模板，再填本题内容。
3. **核对**：展开答案，只标拼写、搭配、时态与任务遗漏。
4. **重写**：合上答案，把错句完整再写一遍。
5. **换题**：从 [[英语二作文真题训练索引]] 换一道题，用同一功能完成新内容。

> [!note] 默写和真题写作的检查标准不同
> **句型默写**核对核心结构和搭配；**真题写作**核对任务完成、数据准确与表达清楚，不要求与范文逐字相同。
> 若只有换数、换名字而方法完全相同，不另抄一套模板。
