# 翻译 被动、时态与否定基础

> [!abstract] 本讲定位
> 翻译时最后检查三件事：**谁对谁做了什么、事情何时发生、到底否定什么**。下面的短例用于辨认结构，不是新增真题。

## 12.1 被动：先分清执行者与承受者

常见形式为 **be + 过去分词**；完成时被动为 **have / has been + 过去分词**。

1. 找到动作和动作承受者。
2. 有 by 短语时，判断它是否给出了执行者。
3. 选择自然的中文表达：主动句、“被 / 受到”句，或无主句。

| 英文 | 可用译文 |
| :-- | :-- |
| She was given a new pen by her father. | 她父亲送给她一支新钢笔。 |
| He was praised by his teacher. | 他受到了老师的表扬。 |
| Measures have been taken to prevent the disease from spreading. | 已采取措施防止疾病传播。 |

**不用每个被动句都加“被”，但动作关系不能颠倒。** 原文没有交代执行者时，不随意补成“我们”或“政府”。

> [!note]- 不是见到过去分词就判被动
> be 后的过去分词也可能描述状态；介词短语也不一定表示动作执行者。先看整句意思，再判断结构。

## 12.2 时态：保留时间关系

| 形式 | 主要意思 | 中文提示 |
| :-- | :-- | :-- |
| do / does | 习惯、常态或事实 | 通常直接译；必要时加“经常” |
| did | 过去发生 | 过去、当时；按语境表达 |
| will do | 将来 | 将、会 |
| am / is / are doing | 正在进行 | 正在 |
| have / has done | 与现在相关的完成、经历或持续 | 已经、曾经、一直；依语境选择 |
| had done | 在另一过去事件之前 | 当时已经、此前已经 |

**英文有时态，中文不必句句加“了”。** 时间词已经说明关系时，可直接顺译。

> [!example] ✏️ 完成时：看参照时间
> Technology has changed the way we communicate.
>
> 技术已经改变了我们的交流方式。
>
> The plan had been completed before the meeting began.
>
> 会议开始之前，方案就已完成。

> [!note]- 完成时不只表示“做完了”
> He has lived here for ten years. → 他在这里已经住了十年。
> 这里是持续到现在；不能机械译成“过去住过十年”，暗示已经离开。

## 12.3 否定：分清范围与程度

| 表达 | 准确理解 |
| :-- | :-- |
| no / none / never | 没有 / 一个也没有 / 从不 |
| hardly / rarely | 几乎不 / 很少；不等于绝对没有 |
| not all | 并非所有；不是“全都不” |
| not necessarily | 不一定；不是“一定不” |
| not impossible | 并非不可能；不要直接加强成“必然可行” |
| far from easy | 远非易事 / 一点也不容易 |

> [!example] ✏️ 否定范围
> Not all students agreed.
>
> 并非所有学生都同意。
>
> I don't think he agrees.
>
> 我认为他并不同意。

> [!note]- 双重否定保留原来的分寸
> not unusual 可译“并不罕见”，不必加强成“极其常见”。否定句可以调整成自然的中文，但不能把可能变必然、把部分变全部。

## 12.4 解题套路

**被动看关系，时态看先后，否定看范围。**

1. 执行者、动作承受者有没有译反？
2. 已完成、正在发生、持续到现在有没有混淆？
3. not 否定的是全句、某个词，还是某个范围？
4. may、some、rarely 等限制语是否保留？
5. 完成检查后再按 [[10 翻译 概述与真题]] 的流程润色中文。
