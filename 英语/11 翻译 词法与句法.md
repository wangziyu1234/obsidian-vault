# 翻译 词义与基础从句

> [!abstract] 本讲定位
> 只掌握最常用的词义判断和三类从句。看到长句先找主干，再判断其余部分是**一件事、修饰名词，还是说明时间原因条件**。

## 11.1 词义：看词性、搭配和语境

1. **定词性**：句中位置表明它是名词、动词还是形容词。
2. **看搭配**：把短语作为整体理解，不逐词硬拼。
3. **回语境**：同一个词在本文讨论的事情中是什么意思？

| 表达 | 基础理解 |
| :-- | :-- |
| monitor efficiency | monitor 作动词：监测效率 |
| a computer monitor | monitor 作名词：电脑显示器 |
| carry goods | 运输货物；若主语是商店，可指经销商品 |
| feel down | 情绪低落，不译“感觉向下” |

> [!note]- 人名、地名怎么处理
> 熟悉的专有名词使用通行译名；陌生姓名可音译。先认清这是人、地点还是机构，同一对象前后译法保持一致，不靠拼写臆造身份信息。

## 11.2 代词：先找它指谁

- 遇到 he、she、it、they、this、that，回看相关句子。
- **单复数、人物关系、上下文意思**都应吻合，不能只选距离最近的名词。
- 中文直接用“他、它、这”会含混时，重复对应名词。

> [!example] ✏️ 基础示例（非真题）
> I bought a book yesterday. It was very useful.
>
> it 指 a book。可译：我昨天买了一本书。这本书很有用。

## 11.3 名词性从句：把“一件事”放进句子

这类从句可作主语、宾语、表语，或说明某个名词的具体内容。**先识别整块在句中做什么，再译内容。**

| 常见形式 | 译法与基础示例（非真题） |
| :-- | :-- |
| I think that ... | 我认为……；that 引出所想的内容 |
| What he said matters. | 他说的话很重要；What he said 整体作主语 |
| The fact is that he left. | 事实是他离开了；that 从句作表语 |
| the news that he won | 他获胜的消息；that 从句说明消息内容 |

> [!note]- 形式主语 it 不必译成“它”
> It is important to read carefully. → 仔细阅读很重要。
> 这里真正被评价的是 to read carefully；it 只占据语法位置。

## 11.4 定语从句：说明“哪个 / 什么样的”

**先找它修饰的名词。** who、which、that 等可引导定语从句。

- **短修饰**：放到名词前，译成“……的”。
- **长修饰或补充说明**：先说主句，再拆成一句补充。
- which 有时指前面整件事，要结合意思判断。

> [!example] ✏️ 基础示例（非真题）
> I need a course that includes writing.
>
> that includes writing 修饰 course。
> 译文：我需要一门包含写作内容的课程。

## 11.5 状语从句：交代关系

| 关系 | 常见词 | 中文通常怎样说 |
| :-- | :-- | :-- |
| 时间 | when, before, after | 当……时、在……之前 / 之后 |
| 原因 | because, since | 因为…… |
| 条件 | if, unless | 如果……、除非…… |
| 让步 | although, even though | 虽然……，但是…… |

> [!example] ✏️ 基础示例（非真题）
> Although he was tired, he kept working.
>
> 译文：虽然他很累，但仍继续工作。

> [!note]- 关系词也要看语境
> since 可表“自从”或“因为”；while 可表“当……时”或对比。先判断两部分之间的关系，不只背一个固定译法。

## 11.6 解题套路

**主干在哪里 → 从句管哪一块 → 关系是什么 → 中文怎样排。**

1. 圈谓语，确定主干；检查否定是否属于这个谓语。
2. 给从句标作用：内容、修饰、时间 / 原因 / 条件等。
3. 调整语序，补清指代；只补原句已经包含的意思。
4. 回看 [[10 翻译 概述与真题]] 的检查清单，防止拆句后漏信息。
