# 新题型 多项对应与小标题基础

> [!abstract] 本讲定位
> 英语二阅读新题型：**5 题，每题 2 分，共 10 分**。基础掌握两类：**多项对应找对象与观点，小标题对应找段落主旨**。约 450–550 词、7 选 5，具体要求以题干为准。

## 15.1 先认清在匹配什么

| 题型 | 原文中找什么 | 选项中比什么 |
| :-- | :-- | :-- |
| 多项对应 | 指定人物或主题的相关信息 | 判断、观点或概括是否吻合 |
| 小标题对应 | 指定语段主要在讲什么 | 标题是否覆盖该段中心 |

**两类都要找意思一致，不能见到相同单词就选。**

## 15.2 多项对应：对象 → 定位 → 观点

### 第一步：浏览题干和选项

- 圈出五个指定对象，如人物、机构或主题。
- 浏览七个选项，标出各自的核心意思和否定、比较等限制。

### 第二步：回原文定位

- 用人名、专有名词、数字等明显线索找相关句段。
- 读定位句的前后文，确认代词和引语属于谁。
- 同一人物多次出现时，把相关信息联系起来判断。

### 第三步：核对观点

- 谁持有什么观点？是在赞成、反对，还是转述别人？
- 选项与原文是同义改写，还是换了主体、范围或程度？
- 有原文依据后再确定答案。

### 第四步：回看五组对应

确认每项都能回到相关句段说明理由，尤其检查相似的人物观点有没有放错位置。

> [!note]- 定位不是“答案一定紧贴人名”
> 观点可能由后面的代词、引语或补充解释展开。人名只是入口，不能只抄人名后第一个句子的关键词。

## 15.3 小标题：整段 → 主旨 → 概括

### 第一步：浏览七个标题

用简短中文记下每个标题的核心：是建议、原因、问题，还是解决办法。

### 第二步：读段落，概括一句话

- 先读首句与尾句，再看中间内容怎样支持它们。
- 找反复出现的主题，以及 but、however 等词后强调的信息。
- 用一句中文回答：**这一段主要想告诉我什么？**

### 第三步：选能覆盖整段的标题

标题应概括主体内容；只对应一个例子或一个细节的选项，通常覆盖不足。

### 第四步：比较相近标题

把两个候选标题各自代入，检查哪一个与全段的对象、目的和重点更一致。

> [!note]- 首句、尾句是线索，不是固定答案位
> 有的段落先举例再总结，有的先承认一种看法再转折。遇到首尾不一致，要读完中间的论述再判断主旨。

## 15.4 同义替换：对意思，不只对单词

| 需要核对的内容 | 常见误选 |
| :-- | :-- |
| 主体相同 | 把甲的观点换成乙的观点 |
| 动作或观点相同 | 原文只是讨论，选项变成支持 |
| 范围与程度相同 | some 变 all，可能变必然 |
| 逻辑方向相同 | 原因与结果倒置，建议与现状混淆 |
| 概括层次合适 | 用局部例子代替整段中心 |

> [!example] ✏️ 基础示例（非真题）
> reduce costs ↔ spend less money：都可表达“减少开支”。
>
> 但 reduce costs 与 improve quality 不是同义关系，即使它们出现在同一句话中。

## 15.5 解题套路

**多项对应：找对象 → 读相关句段 → 对观点 → 查限制。**

**小标题对应：读整段 → 写一句主旨 → 比概括范围 → 排细节干扰。**

复盘只记三样：定位在哪里、发生了什么同义替换、错误选项错在什么地方。
