# 小作文 分类与句型

> [!abstract] 本讲定位
> **一类任务背一组句子，一道题组合几组功能。** 中文提示常显，英文折叠；每次只练一组。通用六组表达见 [[02 小作文 写作方法]]，三段成文见 [[04 小作文 九类模板]]。

> [!tip] 背诵顺序
> 先掌握 **建议 → 活动 → 询问**，再补感谢、道歉、投诉、推荐。每组先背带 **★** 的句子，其余按题目需要补。

> [!note]- 资料来源与使用边界
> [[英语/作文资料/27英二强化大小作文讲义.pdf#page=10|《强化讲义》PDF 第 10–12 页]]；原题核对用《真题汇总》PDF 第 2–18 页。表达已整理、纠错，完整资料见 [[英语二作文复习总览]]。
> 讲义的“三个建议、三个原因”是扩展思路，不是每题的硬要求；分类不能替代题干任务。

## 3.1 先认任务，再选功能

| 功能 | 中文提纲 |
| :-- | :-- |
| 建议 | 具体做法 + 用处 |
| 活动 | 目的 + 安排 + 参加方式 |
| 理由 | 具体事情 + 影响 / 理由 + 必要行动 |
| 介绍与反馈 | 指定内容 / 个人感受 + 题目要求的询问 |

**同一封信可以用几类功能，文体另看题干。**

> [!note]- 混合题速查
> - 2011 / 2016：祝贺 / 致谢 + 建议。
> - 2018：道歉 + 解释 + 另约时间。
> - 2019：具体辩题 + 理由 + 安排。
> - 2020：古迹介绍 + 参观提示。
> - 2024：调查计划 + 询问意见。
> - 2025：短剧介绍 + 邀请参演。
> - 2026：视频观感 + 希望进一步了解旅行。
>
> **2013 年义卖写 email，2015 年夏令营写 notice。** 不因内容都有“通知活动”就写同一种格式。完整历年任务见 [[01 小作文 概述与真题]]。

## 3.2 建议类：做什么，有什么用

**中文默写提示**

1. **★** 做……是个好办法。
2. 你应该……。
3. 请记得……。

> [!example]- ✏️ 展开核对：建议 3 句
> 1. **It is a good idea to ...**
> 2. You should ...
> 3. Remember to ...
>
> 三句后面都接动词原形。给出建议后，补一条用途或理由；不必为凑数固定写三个建议。

**落题时填具体动作**：读什么、练什么、带什么、怎样准备，不能只写“努力、认真、积极”。

> [!note]- 语气与备用写法
> - You could ... 比 You should ... 更柔和。
> - It is advisable to ... 是较正式的建议。
> - are supposed to / are expected to 常含职责、要求或预期。
> - You'd better ... 常带“最好这样，否则可能不好”的意味，对教授等对象慎用。

## 3.3 活动类：目的、安排、参与

**中文默写提示**

1. **★** 本活动旨在……。
2. **★** 活动将于［日期］在［地点］举行。
3. 我们先……，然后……。
4. 请在［截止时间］前联系我们。

> [!example]- ✏️ 展开核对：活动 4 句
> 1. **The activity aims to ...**
> 2. **The event will be held at [place] on [date].**
> 3. We will first [do A] and then [do B].
> 4. Please contact us by [deadline].

**默写后填一遍空**：活动名称、目的、主要流程、时间地点。题目不需要的项目可删；线上会议也不必硬写实体会场。

> [!note]- 时间介词与使用提醒
> - at + 时刻；on + 日期 / 星期；in + 月份 / 年份。
> - 地点依具体搭配选 at / in / on。
> - aims to do / aims at doing，不能混搭。
> - 嘉宾致辞、报名和附件不是每个活动必有的内容。
> - 若要求志愿者，可用 Participants / Volunteers are required to ... 写职责或必要要求。

## 3.4 理由类：每种功能先背一句

**中文默写提示**

1. **感谢**：你的帮助使我能够……。
2. **道歉**：为了弥补这件事，我想……。
3. **投诉**：如果你能……，我将不胜感激。
4. **推荐**：我推荐……，因为……。
5. **祝贺**：你的努力终于得到了回报。

> [!example]- ✏️ 展开核对：5 类功能各 1 句
> 1. Your help enabled me to ...
> 2. To make up for this, I would like to ...
> 3. I would appreciate it if you could ...
> 4. I recommend ... because ...
> 5. Your hard work has finally paid off.

**先记逻辑，再填句子。**

| 类型 | 中段怎么组织 |
| :-- | :-- |
| 感谢 | 对方做了什么 → 对我有什么帮助 |
| 道歉 | 什么没做到 → 为什么 → 怎样补救 |
| 投诉 | 什么问题 → 什么影响 → 要求怎样解决 |
| 推荐 | 选哪一个 → 有什么特点 → 为什么适合对方 |
| 祝贺 | 取得什么成就 → 肯定付出 → 题目要求的建议或祝愿 |

> [!warning]- 理由要贴着题目写
> 道歉不能只解释而不补救，投诉不能只抱怨而不提诉求。推荐展览要写“为什么适合这个人”，不搬大作文的“经济发展、社会进步”。

## 3.5 介绍、反馈与询问

**中文默写提示**

1. **★** 你觉得这个计划怎么样？
2. **★** 我还想进一步了解……。
3. 你能就……给我一些建议吗？
4. 我尤其喜欢……。
5. 报告将重点介绍……。

> [!example]- ✏️ 展开核对：介绍与询问 5 句
> 1. **What do you think of this plan?**
> 2. **I would love to know more about ...**
> 3. Could you give me some advice on ...?
> 4. I particularly enjoyed ...
> 5. The presentation will focus on ...

**填空方向**：计划写“具体做法”，视频写“具体观感”，进一步了解写“还想知道哪方面”。不要一律改成活动的时间地点。

> [!warning] 必须问得具体
> “期待回信”只是收尾；题目要求询问意见或建议时，还要有真正的询问。2024 年可以练①，2026 年可以练②与④。

## 3.6 解题套路

1. **圈任务动词**：建议、介绍、邀请、解释、询问。
2. **看中文默写**：每个功能先写一句，展开后核对。
3. **填本题信息**：加入具体内容，删掉不适用的套话。
4. **组合成文**：按文体写格式，再查每项任务是否完成。
