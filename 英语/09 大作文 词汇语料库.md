# 大作文 词汇语料库

> [!abstract]
> 图表作文必备词汇：图表类型、数量单位、时间表达、趋势（升/降/波动/平稳）、变化程度、极值、占比、逻辑连接词；以及社会/精神/生活三大主题语料库（中英对照）。

## 9.1 图表词汇

### 1. 图表类型

柱状图 bar chart / 饼状图 pie chart / 曲线图 line chart / 表格 table

### 2. 数量单位

dozen / hundred / thousand / million / billion

### 3. 时间点/段

| 表达 | 用法 |
| :-- | :-- |
| in 2008 | 在某年 |
| since 2017 | 自从 2017 |
| after 2020 | 2020 之后 |
| from 2008 to 2010 | 从 2008 到 2010 |
| between 2010 and 2020 | 2010 与 2020 之间 |
| during the period from... to... | 在...到...期间 |
| ten years = a decade | 十年 |

### 4. 趋势：上升 ↑

- 动词：increase, grow, climb, rise, jump, ascend, go up, surge, boom, soar, leap, shoot up
- 名词：an increase, a growth, a climb, a rise, a jump, a surge, a boom, an upward trend in

### 5. 趋势：下降 ↓

- 动词：decrease, decline, descend, fall, drop, sink (sank), shrink, diminish, dwindle, slump, plunge
- 名词：a decrease, a decline, a reduction, a fall, a drop, a slump, a downward trend in

### 6. 变化程度：明显/剧烈

- 副词：fast, rapidly, dramatically, sharply, drastically, considerably, remarkably, extremely, strikingly, substantially, enormously, significantly, greatly, steeply
- 形容词：speedy, sharp, significant, dramatic

### 7. 变化程度：逐步/适度

- 副词：slowly, gradually, slightly, steadily, moderately, marginally, fractionally, step by step, little by little
- 形容词：slow, gradual, slight, steady

### 8. 波动

- 名词：fluctuation
- 动词：fluctuate / wave between... and...; fluctuate around

### 9. 平稳/不变

- 动词：level out/off, remain unchanged
- 形容词：remain stable/steady/constant; stay at the same level

### 10. 到达极值

- 最高值：the highest point; the peak; the top
- 最低值：the lowest point; the bottom
- 达到：reach; attain; arrive at

### 11. 约 / 正好

- 约：about, almost, over, some, more than, less than
- 正好：exactly, nicely

### 12. 占比

occupy / account for / take up / make up

### 13. 逻辑连接词

| 变化趋势 | 连接词 |
| :-- | :-- |
| 相同变化趋势 | meanwhile, likewise, similarly |
| 不同变化趋势 | however, yet, while, ironically, on the contrary, in contrast, by contrast, conversely |
