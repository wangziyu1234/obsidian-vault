# 完形填空 基础搭配与逻辑关系

> [!abstract] 本讲定位
> 配合 [[13 完型 大纲与技巧]]，练习讲义的三条主线：**搭配、逻辑、语义一致**。
> 下列四个短例均节选自柴荣讲义中的真题；先判断再展开答案，不新增自编练习。

## 14.1 搭配：词组要与语境一起判断

先记讲义例题实际用到的几组：

| 搭配 | 本文中的意思 |
| :-- | :-- |
| cope with security issues | 处理安全问题 |
| roll … into one | 将……合为一体 |
| run on infrastructure | 依托基础设施运行 |
| sweep across the Web | 席卷网络 |
| be associated with … | 与……相关 |
| turn to one's phone | 转向手机以寻求慰藉 |

来源：[[英语/专项资料/27英二强化完型讲义.pdf#page=5|讲义第 5–6 页]]。不把介词单独死记，要同时看动作与对象。

#### ✏️ 例14.1（2013 年第 19 题）：搭配与对象

语境在讨论电子支付的安全问题。原句节选：

> … a new field of computer science is developing to **____** security issues.

选项：A. cope with　B. fight against　C. adapt to　D. call for

> [!example]- ✏️ 展开核对
> **A. cope with。**
> 新领域是为了“处理安全问题”。cope with 与 issues 搭配自然，也符合解决问题的语境。
> adapt to 是适应，call for 是呼吁或需要，不能代替此处的“处理”；选择依据不是哪个词最眼熟。
> 原题：[[英语/专项资料/27英二强化完型讲义.pdf#page=5|第 5 页]]；课堂解释：[[英语/专项资料/27英二完型强化技巧课堂笔记.pdf#page=7|第 7 页]]。

## 14.2 逻辑：先找连接的两层意思

| 关系 | 基础表达 | 先问自己 |
| :-- | :-- | :-- |
| 并列、补充 | and, also, moreover | 是否同方向增加信息？ |
| 相似 | similarly, likewise | 两个情况是否相似？ |
| 转折、对比 | but, however, while | 是否改变预期或比较双方？ |
| 让步 | although, even though, despite | 承认某事，结果仍如此吗？ |
| 原因、结果 | because, since, therefore, so | 哪个是原因，哪个是结果？ |
| 目的 | in order to, so that | 行动是为了什么？ |
| 条件 | if, unless, as long as | 结果需要什么条件？ |
| 举例 | for example, such as | 是否以具体情况说明上文？ |
| 时间 | before, after, when, until | 先后或持续关系是什么？ |

来源：[[英语/专项资料/27英二强化完型讲义.pdf#page=7|讲义第 7–9 页]]。表格是基础归纳，同一个词仍须结合句法和语境判断。

#### ✏️ 例14.2（2013 年第 13 题）：句内因果

前文说纸质支票有几天浮存期。接着写：

> **____** electronic payments are immediate, they eliminate the float for the consumer.

选项：A. Unless　B. Until　C. Because　D. Though

> [!example]- ✏️ 展开核对
> **C. Because。**
> 本句连接的是“电子支付即时完成”与“消除了浮存期”，前者是后者的原因。
> 纸质支票与电子支付在全文中形成对比，不代表本句内部也应填转折或让步。
> 原题：[[英语/专项资料/27英二强化完型讲义.pdf#page=10|第 10 页]]；课堂解释：[[英语/专项资料/27英二完型强化技巧课堂笔记.pdf#page=15|第 15 页]]。

> [!note]- 另一个基础区别：相似不是因果
> 同页 2014 年第 3 题，先谈较重女性不易缺钙，再谈老年人稍超重与健康的关系，用 **Likewise** 表相似。
> 不能因为两个例子方向一致就选 Therefore，也不能因 However 属于所谓“红花词”就优先选它。

## 14.3 语义一致：后文可能给出答案线索

先找三种对应：

1. **同义或改述**：例如 average guy 与 common man 在该文中相互说明。
2. **反义对比**：rather than 后的反面信息，帮助确定前面应是什么含义。
3. **人物与场景照应**：同一段中的 train commuters 与 fellow passengers 对应。

这些是上下文中的对应，不是说所有相关词都能互换。来源：[[英语/专项资料/27英二强化完型讲义.pdf#page=11|讲义第 11–13 页]]。

#### ✏️ 例14.3（2016 年第 16 题）：后文的反义线索

原文节选：

> … places where happiness was spread more **____**.
> Firms seem to invest more in places where most people are relatively happy, rather than in places with happiness inequality.

选项：A. rapidly　B. regularly　C. directly　D. equally

> [!example]- ✏️ 展开核对
> **D. equally。**
> 后句比较“大多数人相对幸福”与“幸福程度不均”，因此前面讨论的是分布更均衡，而非传播速度快、规律或直接。
> 线索：**rather than + inequality → equally**。
> 原题：[[英语/专项资料/27英二强化完型讲义.pdf#page=11|第 11 页]]；课堂解释：[[英语/专项资料/27英二完型强化技巧课堂笔记.pdf#page=17|第 17 页]]。

## 14.4 语法辅助：把结构看清，再判断搭配

这是为三条主线补充的基础检查，不是另加一类必须先做的语法题。

| 结构 | 基础区别 |
| :-- | :-- |
| because / although | 后接完整从句 |
| because of / despite | 后接名词或动名词等成分 |
| 介词 + which | 可还原从句，找介词与哪个词搭配 |
| 过去分词作后置定语 | 不要误认成句子的新谓语 |

#### ✏️ 例14.4（2011 年第 15 题）：还原从句

原文节选：

> … the infrastructure **____** which the transaction runs.

选项：A. on　B. after　C. beyond　D. across

> [!example]- ✏️ 展开核对
> **A. on。**
> 将关系从句还原：the transaction runs **on** the infrastructure。
> 先用语法看清介词服务于 run，再按“依托基础设施运行”的搭配与语义选 on。
> 原题：[[英语/专项资料/27英二强化完型讲义.pdf#page=5|第 5 页]]；课堂解释：[[英语/专项资料/27英二完型强化技巧课堂笔记.pdf#page=8|第 8–9 页]]。

> [!note]- 一个词可能有不同作用
> since 可表示原因或“自从”；while 可表示时间或对比；so that 可按语境表示目的或结果。
> however 通常为连接副词，不能不看结构就当作 but 使用。上述句法区别为整理时补充的基础提示。

## 14.5 解题套路

**搭配是否自然 → 逻辑是否成立 → 意思是否照应；需要时用语法看清结构。**

- 不确定逻辑时，先各用一句中文说出两层意思。
- 实词都像能填时，寻找能排除另一个选项的原文证据。
- 看不到线索时，向后读，再回到该空。
- 选完放回整句、整段复读，而不是只看局部是否通顺。
