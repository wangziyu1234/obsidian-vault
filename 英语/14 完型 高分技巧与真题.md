# 完形填空 基础搭配与逻辑关系

> [!abstract] 本讲定位
> 配合 [[13 完型 大纲与技巧]] 使用。只保留常用搭配、关系词和上下文照应；先辨认意思，再选择表达。短例用于说明方法，不是新增真题。

## 14.1 搭配：整组记，放回句中验

| 搭配 | 常见意思 |
| :-- | :-- |
| cope with a problem | 应对问题 |
| adapt to changes | 适应变化 |
| depend on ... | 依靠…… / 取决于…… |
| be associated with ... | 与……有关 |
| turn to someone for help | 向某人求助 |
| pay attention to ... | 注意…… |
| in the absence of ... | 在缺少……的情况下 |
| result in / result from | 导致…… / 由……引起 |

**动词、介词、对象一起看。** 不要见到 problem 就直接套某个熟词，也不要把 result in 和 result from 的因果方向弄反。

## 14.2 逻辑：先用中文判断关系

| 关系 | 常见表达 | 读句时的提示 |
| :-- | :-- | :-- |
| 并列、补充 | and, also, moreover | 同方向增加一层内容 |
| 转折、对比 | but, however, yet, while | 后文与前文预期不同，或比较双方 |
| 让步 | although, even though, despite | 承认某事，结果仍如此 |
| 原因 | because, since, because of | 回答“为什么” |
| 结果 | so, therefore, as a result | 回答“因此怎样” |
| 举例 | for example, for instance, such as | 用具体事例说明前面的观点 |
| 条件 | if, unless, as long as | 某条件成立时才怎样 |
| 时间 | before, after, when, until | 判断先后或持续到何时 |

> [!example] ✏️ 基础示例（非真题）
> The task was difficult, but she finished it.
>
> “任务很难”与“仍完成了”形成转折，不能仅因为两句都是事实就判成并列。

## 14.3 关系相近，还要检查句法

| 表达 | 后面接什么 |
| :-- | :-- |
| because / although | 完整从句 |
| because of / despite | 名词或动名词短语 |
| such as | 具体例子，如名词或短语 |
| for example | 引出举例说明，可修饰一个完整句子 |

- because he was ill → 因为他生病了。
- because of his illness → 因为他的病。
- although he was tired → 虽然他很累。
- despite being tired → 尽管很累。

> [!note]- 一个词可能表达不同关系
> since 可表示原因，也可表示“自从”；while 可表示时间或对比；so that 可表示目的，也可结合语境表示结果。
> however 通常是连接副词，不能把它当作 but，在任意位置直接连接两个分句。

## 14.4 语义照应：答案可能在前后文

1. **原词复现**：同一事物再次出现，但要确认指的是同一个对象。
2. **同义替换**：不同词表达同一层意思。
3. **上下义关系**：上文说类别，下文列具体例子，或反过来。
4. **反义关系**：前后人物、阶段或态度形成对比。

> [!example] ✏️ 基础示例（非真题）
> The train was crowded. Many passengers had to stand.
>
> train、crowded 与 passengers 共同构成乘车场景；判断人物身份要依照这个场景。

## 14.5 解题套路

**搭配是否自然 → 关系是否成立 → 句法是否匹配 → 意思是否照应。**

- 连接词题：先给两部分写出简短中文意思，再判断关系。
- 实词题：比较词义、搭配对象和全文场景。
- 相近选项：寻找能排除另一个的具体信息，不只凭眼熟。
- 做完复读整段，确认选项没有破坏前后意思。
