# 完形填空 基础做题流程

> [!abstract] 本讲定位
> 英语二完形填空：约 **350 词**的文章，**20 题，每题 0.5 分，共 10 分**。基础抓四类依据：**语法、搭配、逻辑、语义**。

## 13.1 先读懂文章在说什么

第一遍不急着填满所有空，先确定：

- **对象**：文章在谈谁或什么？
- **话题**：发生了什么，或要解释什么问题？
- **方向**：作者是在支持、反对、解释，还是提出办法？
- **转折**：后文有没有改变前面的预期？

首句常提供背景，但**全文主旨要结合各段确定**，不能只看一句就定结论。

## 13.2 填空按四类依据判断

| 依据 | 问自己什么 | 看哪里 |
| :-- | :-- | :-- |
| 语法 | 需要什么词性、形式或连接结构？ | 空格所在句 |
| 搭配 | 哪个词与前后词构成自然短语？ | 空前、空后 |
| 逻辑 | 两部分是递进、转折、原因还是结果？ | 相邻句、上下段 |
| 语义 | 哪个选项符合文章在讲的事情？ | 对应细节与全文主题 |

**语法能排除不合形式的选项；最后仍要把意思放回原文。** 熟悉的搭配也可能在当前语境中不成立。

## 13.3 实际做题的四遍顺序

### 第一遍：通读大意

把各段连起来，知道故事或论述怎样推进。不因一两个生词中断整篇。

### 第二遍：先填有把握的空

- 明确的搭配、语法形式先处理。
- 逻辑词先判断关系，再比较选项。
- 暂时无法确定的空做标记，继续往下读。

### 第三遍：带着后文回看难空

- 后文是否解释了前面的词或事件？
- 有没有原词复现、同义替换或相反意思？
- 人物、时间和因果是否一致？

### 第四遍：把答案全部代回

通读完整句段，检查句子是否通顺、逻辑是否连贯、词义是否前后一致。

## 13.4 两个选项犹豫时

1. **先排语法不成立的。** 看动词形式、介词和从句连接方式。
2. **再比搭配与语义。** 不只比较中文近义词，要看动作对象和使用场景。
3. **向前后多读一句。** 看哪一个与上下文的信息最吻合。
4. **保留证据更充分的。** 不能只因为某个选项看起来“高级”就选它。

> [!note]- 不按固定选词名单作答
> 同一个连接词能否使用，取决于这道题的句法和逻辑。however、since、unless 等都可能是正确答案；答题依据来自文章。

## 13.5 复盘只记必要内容

| 错因 | 留下什么 |
| :-- | :-- |
| 搭配不会 | 完整短语 + 本句中的意思 |
| 逻辑看反 | 相连的两层意思 + 正确关系 |
| 词义误判 | 本文词义 + 一个容易混淆的选项 |
| 漏看照应 | 支持答案的前后文位置 |

基础关系词与常用搭配见 [[14 完型 高分技巧与真题]]。

## 13.6 解题套路

**读大意 → 看结构 → 查搭配 → 判关系 → 对语义 → 全文回读。**

做对一道题时也能说出依据；做错一道题时能指出是哪一步判断出了问题。
