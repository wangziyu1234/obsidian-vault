# 拉普拉斯变换（数学基础）

## 📖 定义

$$
\boxed{F(s) = \mathcal{L}[f(t)] = \int_0^\infty f(t)e^{-st}\,dt,\qquad s=\sigma+\mathrm{j}\omega}
$$

反变换（梅林公式，实际计算几乎不用，用下文部分分式法查表）：

$$
f(t) = \mathcal{L}^{-1}[F(s)] = \frac{1}{2\pi \mathrm{j}}\int_{c-\mathrm{j}\infty}^{c+\mathrm{j}\infty}F(s)e^{st}\,ds
$$

存在条件：$f(t)$ 分段连续且为指数阶函数（$\lvert f(t)\rvert\le Me^{ct}$，积分在 $\operatorname{Re}s>c$ 收敛）。

---

## 📝 常用变换对

| 时域$f(t)$ | 复频域$F(s)$ |
|:--|:--|
| 单位脉冲$\delta(t)$                      | $1$                                    |
| 单位阶跃$1(t)$                           | $\dfrac{1}{s}$                         |
| 斜坡$t$                                  | $\dfrac{1}{s^{2}}$                     |
| $t^{n}\ (n=1,2,\dots)$                   | $\dfrac{n!}{s^{n+1}}$                  |
| 指数$e^{-at}$                            | $\dfrac{1}{s+a}$                       |
| $te^{-at}$                               | $\dfrac{1}{(s+a)^2}$                   |
| $t^ne^{-at}$                             | $\dfrac{n!}{(s+a)^{n+1}}$              |
| $1-e^{-at}$                              | $\dfrac{a}{s(s+a)}$                    |
| $\dfrac{e^{-at}-e^{-bt}}{b-a}\ (a\ne b)$ | $\dfrac{1}{(s+a)(s+b)}$                |
| $\sin\omega t$                           | $\dfrac{\omega}{s^{2}+\omega^{2}}$     |
| $\cos\omega t$                           | $\dfrac{s}{s^{2}+\omega^{2}}$          |
| $e^{-at}\sin\omega t$                    | $\dfrac{\omega}{(s+a)^{2}+\omega^{2}}$ |
| $e^{-at}\cos\omega t$                    | $\dfrac{s+a}{(s+a)^{2}+\omega^{2}}$    |

## 🔷 基本定理与重要性质

| 性质 | 公式 |
|:--|:--|
| 线性                   | $\mathcal{L}[af_1+bf_2] = aF_1(s)+bF_2(s)$                                        |
| 微分定理               | $\mathcal{L}[\dot f] = sF(s)-f(0)$                                                |
| $n$ 阶微分           | $\mathcal{L}[f^{(n)}] = s^nF(s)-s^{n-1}f(0)-s^{n-2}\dot f(0)-\cdots-f^{(n-1)}(0)$ |
| 积分定理               | $\mathcal{L}\left[\displaystyle\int_0^t f\,d\tau\right] = \dfrac{F(s)}{s}$        |
| 延迟定理（时域平移）   | $\mathcal{L}[f(t-\tau)\cdot1(t-\tau)] = e^{-\tau s}F(s)$                          |
| 复位移定理（s 域平移） | $\mathcal{L}[e^{-at}f(t)] = F(s+a)$                                               |
| 相似定理（尺度变换）   | $\mathcal{L}[f(at)] = \dfrac{1}{a}F\!\left(\dfrac{s}{a}\right)\ (a>0)$            |
| 复微分                 | $\mathcal{L}[tf(t)] = -\dfrac{dF(s)}{ds}$                                         |
| 除以 $t$（复积分）     | $\mathcal{L}\left[\dfrac{f(t)}{t}\right] = \displaystyle\int_s^{+\infty}F(\sigma)\,d\sigma$ |
| 卷积定理               | $\mathcal{L}[f_1*f_2] = F_1(s)F_2(s)$                                             |
| 初值定理               | $f(0^{+}) = \lim\limits_{s\to\infty}sF(s)$                                        |
| 终值定理               | $\lim\limits_{t\to\infty}f(t) = \lim\limits_{s\to 0}sF(s)$                        |

**典型应用（除以 $t$，$s$ 在 $F$ 的收敛域内）**：

$$
\mathcal{L}\left[\frac{\sin t}{t}\right]=\int_s^{+\infty}\frac{1}{1+\sigma^2}\,d\sigma
=\arctan\sigma\Big|_s^{+\infty}=\frac{\pi}{2}-\arctan s=\arctan\frac{1}{s}\qquad(s>0)
$$

其中 $\dfrac{\pi}{2}-\arctan s=\arctan\dfrac{1}{s}$ 由 $s>0$ 时 $\tan\left(\frac{\pi}{2}-\arctan s\right)=\dfrac{1}{s}$ 得到（数值验证：$s=1$ 时 $\int_0^{+\infty}\dfrac{\sin t}{t}e^{-t}\,dt=\dfrac{\pi}{4}$ ✓）。

> [!warning] ⚠️ 终值定理的使用条件
> 仅当 $sF(s)$ 的极点全部位于左半平面（$f(t)$ 有终值）时才能用。反例：$F(s)=\dfrac{\omega}{s^2+\omega^2}$（正弦无终值），套公式会得到错误结果 0。
> 微分定理在**零初始条件**下简化为 $\mathcal{L}[f^{(n)}]=s^nF(s)$——传递函数定义正是基于此。

## 💡 拉氏反变换——部分分式展开法

设 $F(s)=\dfrac{B(s)}{A(s)}$（$B$ 阶次低于 $A$），先将 $A(s)$ 因式分解，按极点类型展开：

**① 单实极点** $p_1,\dots,p_n$：

$$
\boxed{F(s)=\sum_i \frac{c_i}{s-p_i},\qquad
c_i = \big[(s-p_i)F(s)\big]\Big|_{s=p_i},\qquad
f(t)=\sum_i c_ie^{p_it}}
$$

例：$F(s)=\dfrac{s+3}{(s+1)(s+2)}$，$c_1=\dfrac{s+3}{s+2}\Big|_{s=-1}=2$，$c_2=\dfrac{s+3}{s+1}\Big|_{s=-2}=-1$

$$
F(s)=\frac{2}{s+1}-\frac{1}{s+2}\ \Rightarrow\ f(t)=2e^{-t}-e^{-2t}
$$

**② $r$ 重极点** $p_1$：展开含 $\dfrac{c_{r}}{(s-p_1)^{r}}+\cdots+\dfrac{c_{1}}{s-p_1}$ 各项，

$$
\boxed{c_{r-j} = \frac{1}{j!}\frac{d^{j}}{ds^{j}}\big[(s-p_1)^rF(s)\big]\Big|_{s=p_1}},\qquad
\mathcal{L}^{-1}\left[\frac{1}{(s-p_1)^{k}}\right]=\frac{t^{k-1}}{(k-1)!}e^{p_1t}
$$

例：$F(s)=\dfrac{1}{s(s+1)^2}=\dfrac{1}{s}-\dfrac{1}{s+1}-\dfrac{1}{(s+1)^2}\ \Rightarrow\ f(t)=1-e^{-t}-te^{-t}$

**③ 共轭复极点**：不必展开成复数项，直接**配方**成 $(s+a)^2+\omega^2$ 形式，套用 $e^{-at}\sin\omega t$、$e^{-at}\cos\omega t$ 变换对。
例：$F(s)=\dfrac{1}{s^2+2s+5}=\dfrac{1}{(s+1)^2+2^2}=\dfrac{1}{2}\cdot\dfrac{2}{(s+1)^2+2^2}\ \Rightarrow\ f(t)=\dfrac{1}{2}e^{-t}\sin2t$

每个极点 $p_i$ 对应一个时域模态 $e^{p_it}$——极点位置决定响应形态：

## 🔍 用拉氏变换解线性微分方程

```mermaid
flowchart LR
    A["线性微分方程<br/>+ 初始条件"] -- "拉氏变换<br/>微分定理代入初值" --> B["s 域代数方程"]
    B -- "解出 Y(s)" --> C["部分分式展开"]
    C -- "查表逐项反变换" --> D["时域解 y(t)"]
```

优点：微分方程化为**代数方程**求解；初始条件经微分定理**自动进入**方程，一并得到全解（自由分量 + 强迫分量）。

> [!example] ✏️ **例**
> **例**：$\ddot y+3\dot y+2y=1(t)$，$y(0)=\dot y(0)=0$。
> 取拉氏变换：
>
> $$
> (s^2+3s+2)Y(s)=\frac{1}{s}\ \Rightarrow\
> Y(s)=\frac{1}{s(s+1)(s+2)}
> $$
>
> 部分分式（单实极点，用 ① 的留数公式）：
>
> $$
> Y(s)=\frac{1/2}{s}-\frac{1}{s+1}+\frac{1/2}{s+2}
> $$
>
> 反变换得
>
> $$
> y(t)=\frac{1}{2}-e^{-t}+\frac{1}{2}e^{-2t}\quad(t\ge0)
> $$
>
> 验证：$y(0)=\frac12-1+\frac12=0$（满足）；$y(\infty)=\frac12$（等于系统直流增益 $\frac{1}{2}$）。
> 其中 $-e^{-t}+\frac12e^{-2t}$ 为暂态（自由）分量，由极点 $-1,-2$ 决定；$\frac12$ 为稳态（强迫）分量，由输入决定。
> 若初始条件非零，微分定理会引入 $sf(0)$ 等项，解法不变。
