# 第 4 章 能控性和能观测性

## ⚖️ 4.1 能控性与能观测性——秩判据

### 4.1.1 能控性

$$
\boxed{Q_c = [B\ \ AB\ \ A^2B\ \ \cdots\ \ A^{n-1}B]},\qquad
\text{完全能控} \ \Leftrightarrow\ \operatorname{rank}Q_c = n
$$

- 对角型直接法：$B$ 中对应行全零 ⇔ 该模态**不能控**
- **输出能控性**：$\operatorname{rank}[CB\ CAB\ \cdots\ CA^{n-1}B\ D]=q$ ⇔ 输出完全能控；与状态能控性无必然联系

### 4.1.2 能观测性

$$
\boxed{Q_o = \begin{bmatrix}C\\ CA\\ \vdots\\ CA^{n-1}\end{bmatrix}},\qquad
\text{完全能观} \ \Leftrightarrow\ \operatorname{rank}Q_o = n
$$

- 对角型直接法：$C$ 中对应列全零 ⇔ 该模态**不能观**

### 4.1.3 PBH 判据（备用）

- 能控：$\operatorname{rank}[\lambda I-A\ \ B] = n$（对所有特征值 $\lambda$）
- 能观：$\operatorname{rank}\begin{bmatrix}\lambda I-A\\ C\end{bmatrix}=n$（对所有特征值 $\lambda$）

### 4.1.4 格拉姆矩阵判据

$W_c=\int_0^{t_1}e^{At}BB^Te^{A^Tt}dt$ 非奇异 ⇔ 完全能控（可观对偶）。时变系统唯一判据，定常系统中主要用于理论推导。

### 4.1.5 完整例题：能控能观判别

> [!example] ✏️ **例：$A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix}$，$B=\begin{bmatrix}0\\1\end{bmatrix}$，$C=[1\ 0]$，判能控性与能观性**
>
> **① 能控性**：
> $$
> \begin{aligned}
> Q_c &= [B\ \ AB]\\
> &= \left[\begin{bmatrix}0\\1\end{bmatrix}\ \ \begin{bmatrix}0&1\\-2&-3\end{bmatrix}\begin{bmatrix}0\\1\end{bmatrix}\right]\\
> &= \begin{bmatrix}0&1\\1&-3\end{bmatrix}
> \end{aligned}
> $$
> $\det(Q_c) = 0\times(-3)-1\times1 = -1 \neq 0$，$\operatorname{rank}Q_c=2=n$ → **完全能控** ✓
>
> **② 能观性**：
> $$Q_o = \begin{bmatrix}C\\ CA\end{bmatrix} = \begin{bmatrix}1&0\\ [1\ 0]\begin{bmatrix}0&1\\-2&-3\end{bmatrix}\end{bmatrix} = \begin{bmatrix}1&0\\0&1\end{bmatrix}$$
> $\det(Q_o) = 1 \neq 0$，$\operatorname{rank}Q_o=2=n$ → **完全能观** ✓
>
> **③ 对角型验证**（互异特征值 $\lambda_1=-1,\lambda_2=-2$）：
> 对角化后 $A_d=\begin{bmatrix}-1&0\\0&-2\end{bmatrix}$，
> $B_d=P^{-1}B=\begin{bmatrix}2&1\\-1&-1\end{bmatrix}\begin{bmatrix}0\\1\end{bmatrix}=\begin{bmatrix}1\\-1\end{bmatrix}$，
> $C_d=CP=[1\ 0]\begin{bmatrix}1&1\\-1&-2\end{bmatrix}=[1\ -1]$
> $B_d$ 无零元素 → 两模态均能控；$C_d$ 无零元素 → 两模态均能观 ✓

> [!example] ✏️ **例：含不能控模态的系统**
> $A=\begin{bmatrix}-1&0\\0&-2\end{bmatrix}$，$B=\begin{bmatrix}1\\0\end{bmatrix}$，$C=[0\ 1]$
>
> $Q_c=[B\ AB]=\begin{bmatrix}1&-1\\0&0\end{bmatrix}$，$\operatorname{rank}Q_c=1<2$ → **不完全能控**
> $Q_o=\begin{bmatrix}C\\CA\end{bmatrix}=\begin{bmatrix}0&1\\0&-2\end{bmatrix}$，$\operatorname{rank}Q_o=1<2$ → **不完全能观**
>
> 对角型直接看：$B$ 第 2 行 = 0 → $\lambda_2=-2$ **不能控**；$C$ 第 1 列 = 0 → $\lambda_1=-1$ **不能观**。

## 🔷 4.2 对偶原理

$$
\boxed{(A,B,C)\ \text{能控} \ \Leftrightarrow\ (A^T,C^T,B^T)\ \text{能观}}
$$

双向对偶，因此求反馈增益 $K$ 和求观测器增益 $L$ 可对偶处理。

---

## 📝 4.3 能控性与能观性标准型

| 标准型 | $A$ 结构 | $B$ / $C$ 位置 |
|:--|:--|:--|
| **能控标准型** | 友矩阵 $A_c$（末行 $[-a_0\ -a_1\cdots]$） | $B_c=[0\cdots0\ 1]^T$ |
| **能观标准型** | $A_o = A_c^T$ | $C_o=[0\cdots0\ 1]$ |

由传函数直读实现：
$$
G(s)=\frac{\beta_{n-1}s^{n-1}+\cdots+\beta_0}{s^n+a_{n-1}s^{n-1}+\cdots+a_0}
\quad\Rightarrow\quad
C_c = [\beta_0\ \beta_1\ \cdots\ \beta_{n-1}],\ D=0
$$

> [!info] ℹ️
> 当 $m=n$ 时先长除分离出 $D$。

## 📖 4.4 对消与能控能观的对应

**SISO 传递函数发生零极对消 ⇔ 该实现非最小**（不完全能控或不能观）。

具体丢失哪个取决于实现方式：
- **能控标准型实现必能控** → 对消体现为**不能观**
- **能观标准型实现必能观** → 对消体现为**不能控**
- **对角型** → $B$ 或 $C$ 对应零元素显式标示

---

## 🔍 4.5 结构分解

### 4.5.1 按能控性分解（$\operatorname{rank}Q_c=r<n$）

从 $Q_c$ 选 $r$ 个无关列 + 补 $n-r$ 个单位向量，$P^{-1}=[s_1\cdots s_r\mid s_{r+1}\cdots s_n]$：

$$
\bar A = PAP^{-1} = \begin{bmatrix}\bar A_{11} & \bar A_{12}\\ 0 & \bar A_{22}\end{bmatrix},\qquad
\bar B = PB = \begin{bmatrix}\bar B_1\\ 0\end{bmatrix}
$$

- 传递函数 = **能控子系统** $(\bar A_{11},\bar B_1,\bar C_1)$ 的传递函数
- 不能控部分特征值（$\bar A_{22}$）必须在左半平面（否则系统不能镇定）
- $\det(sI-A)=\det(sI-\bar A_{11})\det(sI-\bar A_{22})$

### 4.5.2 按能观性分解（对偶）

从 $Q_o$ 选无关行写 $P$：
$$
\bar A=\begin{bmatrix}\bar A_{11}&0\\ \bar A_{21}&\bar A_{22}\end{bmatrix},\quad
\bar C=[\bar C_1\ 0]
$$

### 4.5.3 卡尔曼四分解

依次按能控→能观（或反序）分解，状态分成四类：

$$
\bar x = \begin{bmatrix}x_{co}\\ x_{c\bar o}\\ x_{\bar co}\\ x_{\bar c\bar o}\end{bmatrix}
\quad(\text{能控能观}\ /\ \text{能控不能观}\ /\ \text{不能控能观}\ /\ \text{不能控不能观})
$$

**传递函数只反映 $x_{co}$ 子系统**——$G(s)=C_{co}(sI-A_{co})^{-1}B_{co}$。这就是"传递函数描述不完全"的根源。

### 4.5.4 结构分解完整例题

> [!example] ✏️ **例：按能控性分解**
> $A=\begin{bmatrix}0&1&0\\0&0&0\\0&0&2\end{bmatrix}$，$B=\begin{bmatrix}0\\1\\0\end{bmatrix}$，$C=[1\ 0\ 0]$
>
> **① 算能控性**：
> $$AB = \begin{bmatrix}1\\0\\0\end{bmatrix},\qquad A^2B = \begin{bmatrix}0\\0\\0\end{bmatrix}\ \Rightarrow\ Q_c = [B\ AB\ A^2B] = \begin{bmatrix}0&1&0\\1&0&0\\0&0&0\end{bmatrix},\quad \operatorname{rank}Q_c=2<3$$
> （$A^2B=0$，第三列为零向量，秩 = 2）
>
> **② 选无关列构造变换阵**：
> 取 $Q_c$ 前两列 $s_1=B=\begin{bmatrix}0\\1\\0\end{bmatrix}$，$s_2=AB=\begin{bmatrix}1\\0\\0\end{bmatrix}$，补 $s_3=e_3=\begin{bmatrix}0\\0\\1\end{bmatrix}$（保证非奇异）
> $$P^{-1} = [s_1\ s_2\ s_3] = \begin{bmatrix}0&1&0\\1&0&0\\0&0&1\end{bmatrix},\quad P = P^{-1}\ (\text{置换阵})$$
>
> **③ 求分解后矩阵**：
> $$\bar A = PAP^{-1} = \begin{bmatrix}0&0&0\\1&0&0\\0&0&2\end{bmatrix} = \begin{bmatrix}\bar A_{11}&\bar A_{12}\\0&\bar A_{22}\end{bmatrix}$$
> $$\bar B = PB = \begin{bmatrix}1\\0\\0\end{bmatrix} = \begin{bmatrix}\bar B_1\\0\end{bmatrix},\quad \bar C = CP^{-1} = [0\ 1\ 0] = [\bar C_1\ \bar C_2]$$
>
> **④ 结论**：
> - 能控子系统：$\bar A_{11}=\begin{bmatrix}0&0\\1&0\end{bmatrix}$，$\bar B_1=\begin{bmatrix}1\\0\end{bmatrix}$，$\bar C_1=[0\ 1]$（2 维，对应状态 $x_1,x_2$）
> - 不能控子系统：$\bar A_{22}=[2]$（1 维，对应状态 $x_3$，特征值 $2$ 在右半平面 → 不稳定且不能控 → **系统不能镇定**）
> - 传递函数 = $\bar C_1(sI-\bar A_{11})^{-1}\bar B_1 = \dfrac{1}{s^2}$；直接算 $C(sI-A)^{-1}B$ 亦等于 $\dfrac{1}{s^2}$ ✓（传递函数只反映能控子系统，不含不能控模态 $x_3$）

### 4.5.5 结构分解考试步骤

① 算 $\operatorname{rank}Q_c$（或 $Q_o$）得 $r$；
② 挑 $r$ 个无关列 + 补单位向量 → 写 $P^{-1}$；
③ 求 $P$，算 $PAP^{-1}$、$PB$、$CP^{-1}$；
④ 从块三角中读出可控（可观）子系统。

## 📖 4.6 最小实现

### 4.6.1 定义与判据

在所有能实现 $G(s)$ 的 $(A,B,C,D)$ 中，**阶数最低者** = 最小实现。

> [!tip] 💡 **核心**
> 能控 + 能观 ⇔ 最小实现。既能控又能观的实现一定阶数最低。

- $G(s)$ **无对消阶次** = 最小实现的阶数
- 经典例：$G(s)=\frac{s+1}{(s+1)(s+2)} = \frac{1}{s+2}$ → 一阶最小实现

### 4.6.2 求法一：从 $G(s)$ 出发

1. 约去分子分母公因子
2. 对无对消传递函数写能控标准型 → 既已约简明，实现**必既能控又能观**
3. 阶次 = 不可约分母次数

### 4.6.3 求法二：从 $(A,B,C)$ 出发

1. 按能控性分解取能控子系统 $(\bar A_{11},\bar B_1,\bar C_1)$
2. 对该子系统再按能观性分解取"能控且能观"部分
3. 所得子系统的维数 $=\operatorname{rank}(Q_oQ_c)$（即 McMillan 度，与无对消后的分母次数一致；$\min(\operatorname{rank}Q_c,\operatorname{rank}Q_o)$ 只是上界），传递函数与原系统等价

### 4.6.4 考试要点

给一个二阶/三阶 $(A,B,C)$，算 $Q_c$、$Q_o$ 秩 → 若不都满秩 → 做结构分解取能控能观子系统 → 该子系统即最小实现。
