# 第 1 章（一）状态变量与模拟结构图

> [!abstract] 本讲定位
> 状态变量及状态空间表达式的基本概念与模拟结构图（教材 §1.1–1.2）：状态/状态变量/状态空间定义、标准形式，以及模拟结构图的画法（能控/能观标准型图形）。建立方法见 [[01-2 状态空间表达式的建立]]。

## 1.1 状态变量及状态空间表达式

$$
\boxed{\dot x = A x + B u,\qquad y = C x + D u}
$$

![[自控-状态空间结构图.png|620]]
*状态空间结构图：积分器输出为状态 $x$，$A$ 反馈、$B$ 输入、$C$ 输出、$D$ 直通*

- $x$：$n$ 维状态向量；$u$：$p$ 维输入向量；$y$：$q$ 维输出向量
- $A$（$n\times n$）：系统矩阵；$B$（$n\times p$）：输入矩阵（控制矩阵）
- $C$（$q\times n$）：输出矩阵；$D$（$q\times p$）：直接传递矩阵
- 对角型 $A$ 时各模态彼此解耦，可直接判断能控能观

## 1.2 状态变量及状态空间表达式的模拟结构图

### 1.2.1 三种标准型的图形

| 标准型 | 图形特征 |
|:--|:--|
| **能控标准型** | $n$ 个积分器**串联成链**；各 $-a_i$ 反馈到链首；分子系数 $\beta_i$ 前馈到输出加法器 |
| **对角型** | $n$ 条一阶支路**并联**，每条自反馈 $\lambda_i$ |
| **约当型** | 同块内积分器**串联**且共用 $\lambda_1$，块间并联 |

### 1.2.2 能控标准型（SISO）

设特征多项式 $\det(sI-A)=s^n+a_{n-1}s^{n-1}+\cdots+a_0$：

$$
A_c = \begin{bmatrix}0&1&&\\
&\ddots&\ddots&\\
&&0&1\\
-a_0&-a_1&\cdots&-a_{n-1}\end{bmatrix},\quad
B_c = \begin{bmatrix}0\\\vdots\\0\\1\end{bmatrix}
$$

传递函数 $G(s)=\frac{\beta_{n-1}s^{n-1}+\cdots+\beta_0}{s^n+a_{n-1}s^{n-1}+\cdots+a_0}$ 时：
$$
C_c = [\beta_0\ \beta_1\ \cdots\ \beta_{n-1}],\quad D=0
$$

### 1.2.3 能观标准型（对偶）

$A_o = A_c^T$，$C_o = B_c^T = [0\cdots0\ 1]$。

### 1.2.4 状态变量图绘制

三种图形元件：**积分器 $\int$**（输出 = $x_i$，输入 = $\dot x_i$）、**加法器**、**比例器**。

画法：① 一状态一积分器；② 按 $\dot x_i = \sum a_{ij}x_j + b_i u$ 在积分器输入端设加法器；③ 按 $y=\sum c_i x_i$ 合成输出。
