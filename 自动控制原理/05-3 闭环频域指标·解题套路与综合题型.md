# 第5章（三）闭环频域指标、解题套路与综合题型

> [!abstract] 本讲定位
> 闭环频域指标及时域关系（含三频段、带宽）、第5章解题套路、由频率特性曲线反求系统与校正的综合题型。对应原 5.5—5.7。

## 5.5 闭环频域指标及与时域关系

- **带宽** $\omega_b$：闭环幅频下降到 $0.707\lvert\Phi(\mathrm{j}0)\rvert$ 时的频率；带宽大 → 响应快、但易引入高频噪声。一阶系统 $\omega_b=\dfrac{1}{T}$。
- 典型二阶系统：

$$
\omega_b = \omega_n\sqrt{1-2\zeta^2+\sqrt{(1-2\zeta^2)^2+1}}
$$

$$
\omega_c = \omega_n\sqrt{\sqrt{1+4\zeta^4}-2\zeta^2},\qquad
\gamma = \arctan\frac{2\zeta}{\sqrt{\sqrt{1+4\zeta^4}-2\zeta^2}}
$$

- 工程近似：$\gamma \le 70°$ 时 $\zeta \approx 0.01\gamma$（$\gamma$ 取度数）；$M_r$ 越大超调越大
- **$M_r$ 工程经验**（教材 §5-5）：$M_r\in[1.0,1.4]$（即 $0\text{ dB}<M_r(\text{dB})<3\text{ dB}$）相当于有效阻尼比 $\zeta\in[0.4,0.7]$，此时**动态性能满意**；$M_r>1.5$ 时阶跃响应可能出现**多次过调**。
  验证：由 $M_r=\dfrac{1}{2\zeta\sqrt{1-\zeta^2}}$ 算得 $\zeta=0.4\to M_r\approx1.36$、$\zeta=0.7\to M_r\approx1.00$ ✓
- 闭环谐振峰与相角裕度的近似关系（$35°\le\gamma\le90°$，教材式 5-104）：$M_r \approx \dfrac{1}{\sin\gamma}$。
- **高阶系统时域指标的频域估算**（$1\le M_r\le1.8$，教材式 5-107/5-108）：

$$
\boxed{\sigma\% = \big[0.16+0.4(M_r-1)\big]\times100\%,\qquad
t_s = \frac{\pi}{\omega_c}\Big[2+1.5(M_r-1)+2.5(M_r-1)^2\Big]}
$$

- **三频段**：低频段定稳态精度（型别与增益）；中频段定动态性能（$\omega_c$、$\gamma$，过 0 dB 斜率宜为 $-20$ dB/dec 且有一定宽度）；高频段定抗高频噪声能力。

**信号频谱与系统带宽的关系**（常考概念题）：

- **周期信号**：可展成傅里叶级数——由基频 $\omega_0$ 的直流、基波（一次谐波）及各次谐波叠加。矩形波的频谱为奇数次谐波（$\omega_0, 3\omega_0, 5\omega_0, \dots$），阶梯逐次降低。
- **非周期信号**：傅里叶变换得连续频谱 $F(\mathrm{j}\omega)$——单一方波的频谱为 $\operatorname{Sa}$ 函数，能量集中在 $0\sim 2\pi/\tau$ 频带内。
- **带宽选择的工程原则**：系统带宽应当能覆盖输入信号的**主要能量频带**——$\omega_b \ge \omega_M$（信号有效最高频率）；同时带宽不应过宽以免引入过多高频噪声。
- **二阶系统带宽选择参考**（式 5-101）：输入信号有效频带宽度 $\omega_M$ 与系统带宽 $\omega_b$ 之比决定复现精度。

**由实验频率响应确定传递函数**（教材 §5-2.6，常考方法题）：
① 对待测系统施加不同频率的正弦信号，记录稳态输出幅值比 $A(\omega)$ 和相位差 $\varphi(\omega)$；
② 画出 $\omega:0.1\sim10$ 倍转折频率的对数幅频/相频曲线；
③ 由渐近线的低频斜率定系统型别 $\nu$；
④ 在每个转折频率处按斜率变化量 $(-20/-40/+20)$ 定环节类型及时间常数（$T=1/\omega_{\text{转}}$）；
⑤ 振荡环节的 $\zeta$ 由谐振峰 $M_r$ 反解（$M_r = 1/(2\zeta\sqrt{1-\zeta^2})$）；
⑥ 最小相位系统由幅频即可唯一确定传递函数。

## 5.6 解题套路

**① 画 Bode 渐近线**：按 5.2 四步；振荡环节在 $\omega_n$ 附近按 $\zeta$ 补谐振峰修正。

**② 渐近线法求 $\omega_c$**：写出穿越段的近似幅频令 $A(\omega)=1$。
如 Ⅰ 型系统在 $-20$ dB/dec 段穿越时 $A\approx K/\omega$，得 $\omega_c\approx K$；
在 $-40$ 段穿越时由 $A\approx\dfrac{K}{\omega^2T}=1$ 解出。

**③ 求稳定裕度**：$\omega_c$（$A=1$）→ $\gamma=180°+\varphi(\omega_c)$；
$\omega_g$（$\varphi=-180°$，常由 $\operatorname{Im}G(\mathrm{j}\omega)=0$ 解）→ $h=1/A(\omega_g)$。

**④ 奈氏判稳流程**：定 $P$ → 画 $\omega:0^+\!\to\infty$ 幅相曲线（$\nu$ 型补 $\nu\times90°$ 大圆弧）→ 数 $(-1,\mathrm{j}0)$ 左侧负实轴的正、负穿越 → $Z=P-2N$，$Z=0$ 稳定。

**⑤ 由渐近线反求 $G(s)$**（最小相位）：低频斜率 $-20\nu$ 定型别 → $\omega=1$ 处高度（或延长线与 0 dB 交点）定 $K$ → 每个转折频率按斜率变化定环节及时间常数；
振荡环节的 $\zeta$ 可由实测谐振峰高 $20\lg M_r$ 反解（$M_r=\dfrac{1}{2\zeta\sqrt{1-\zeta^2}}$，教材例 5-7）。

> [!example] **例：由对数幅频渐近线反求 $G(s)$**
> 已知最小相位系统的渐近线：低频段斜率 $-20$ dB/dec、过 $(1,\ 20\text{ dB})$ 点；在 $\omega=2$ 处斜率变为 $-40$，在 $\omega=10$ 处变为 $-60$。
>
> **① 定型别**：低频段斜率 $-20$ dB/dec → 含 1 个积分环节 → **Ⅰ 型系统**。
>
> **② 定增益**：低频延长线在 $\omega=1$ 处高度 $20\lg K=20$ dB → $K=10$。
>
> **③ 定转折频率对应环节**：$\omega=2$ 处 $-20\to-40$ → 惯性环节 $\dfrac{1}{1+s/2}$（$T_1=0.5$）；$\omega=10$ 处 $-40\to-60$ → 惯性环节 $\dfrac{1}{1+s/10}$（$T_2=0.1$）。
>
> **④ 写出传函**：
> $$
> \begin{aligned}
> G(s)&=\frac{10}{s(0.5s+1)(0.1s+1)}\\[4pt]
> &=\frac{10}{s\left(\frac{s}{2}+1\right)\left(\frac{s}{10}+1\right)}
> \end{aligned}
> $$
> **MATLAB 表示**：`num=[10]; den=conv([1 0],conv([0.5 1],[0.1 1])); sys = tf(num, den)`
>
> **⑤ 验证各段 dB 值**（几何法 $L(\omega_2)=L(\omega_1)+k\lg\dfrac{\omega_2}{\omega_1}$）：
> - $\omega<2$（$-20$ 段）：$L(1)=20\lg10=20$ dB ✓；$L(2)=20\lg\dfrac{10}{2}\approx14$ dB
> - $2<\omega<10$（$-40$ 段）：$L(10)=L(2)-40\lg5\approx14-28=-14$ dB ✓（直接算 $A(10)=\dfrac{10}{10\cdot5}=0.2$，$20\lg0.2=-14$ dB）
> - $\omega>10$（$-60$ 段）：$L(20)=L(10)-60\lg2\approx-14-18=-32$ dB ✓（直接算 $A(20)=\dfrac{200}{20^3}=0.025$，$20\lg0.025\approx-32$ dB）

## 5.7 综合题型：由频率特性曲线反求系统 + 校正（Word 补充 d15）

**题型 A：由闭环幅相特性（奈氏图）反求欠阻尼二阶系统 + 求裕度**（Word 补充 doc15 题4）
1. 已知闭环幅相曲线形似半圆（典型欠阻尼二阶），设 $\Phi(\mathrm{j}\omega)$ 为欠阻尼二阶闭环传函（参数 $\zeta,\omega_n$）；
2. 由曲线上的特征点定参数：实轴交点（$\omega\to\infty$ 时 $\Phi\to0$、$\omega\to0$ 时 $\Phi\to1$）与谐振峰值 $M_r$：
   - $M_r=\dfrac{1}{2\zeta\sqrt{1-\zeta^2}}$ 反解 $\zeta$；
   - 谐振频率 $\omega_r=\omega_n\sqrt{1-2\zeta^2}$ 反解 $\omega_n$；
3. 由 $\Phi(s)$ 反求开环 $G(s)=\dfrac{\Phi(s)}{1-\Phi(s)}$（单位反馈）→ 求 $\omega_c$、$\gamma$、$\sigma\%$、$t_s$；
4. 串入校正装置 $G_c$ 后重复求 $\gamma''$、$\sigma\%''$、$t_s''$（把 $G_c$ 并入开环重新算）。

**题型 B：由单位阶跃响应曲线反求系统 + 设计校正**（Word 补充 doc15 题5）
1. 从阶跃响应曲线读 $\sigma\%$、$t_s$（或 $t_p$）→ 反解 $\zeta,\omega_n$（公式见 [[03 第3章 线性系统的时域分析法]] 3.8②）→ 写出闭环 $\Phi(s)$ → 反求开环 $G(s)$ 并画结构图；
2. 按校正后期望指标（$\sigma\%'$、$t_s'$）再反解期望 $\zeta',\omega_n'$ → 确定期望闭环 $\Phi'(s)$；
3. **解法一（串联校正）**：$G_c(s)=\dfrac{\Phi'(s)}{G(s)\bigl[1-\Phi'(s)\bigr]}$（单位反馈）——由期望闭环反解校正装置；
4. **解法二（测速反馈）**：利用 $\zeta'=\zeta+K_t\omega_n/2$（等效阻尼增大）反解 $K_t$，画出测速反馈结构图；
5. 调整开环增益使稳态指标满足要求后验算。

> [!tip] 题型本质
> 两类题都是"**图形 → 参数 → 传函 → 指标/校正**"的逆向链路：读图取数（$\sigma\%$、$M_r$、$t_s$）→ 反解 $\zeta,\omega_n$ → 正推指标或反推校正装置。
> 第3章"已知响应反求"（[[03 第3章 线性系统的时域分析法]] 题型二）与这里完全同构，只是数据来源从时域曲线换成频域曲线。
