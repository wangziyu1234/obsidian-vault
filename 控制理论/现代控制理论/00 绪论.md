# 绪论

> [!abstract] 本讲定位
> 现代控制理论的研究对象、与经典控制的区别、状态空间方法引论。

## 0.1 现代控制理论的研究对象

- **经典控制理论**：传递函数模型，单输入单输出，频域法，适用于线性定常系统
- **现代控制理论**：状态空间模型，多输入多输出，时域法，适用于线性/非线性、定常/时变、连续/离散系统
- 现代控制理论的核心：状态、状态空间、能控性、能观性、极点配置、最优控制

---

## 0.2 状态空间法的基本概念

| 术语 | 定义 |
|:--|:--|
| **状态** | 一组独立变量在初始时刻的值，连同此后的给定输入，足以唯一确定模型的未来运动；常规最小状态描述使用最少必要变量 |
| **状态变量** | 构成状态向量的各个分量 $x_1,x_2,\dots,x_n$ |
| **状态空间** | 以各状态变量为坐标轴构成的 $n$ 维空间 |
| **状态方程** | 描述状态变量与输入之间关系的一阶微分方程组：$\dot x = f(x,u,t)$ |
| **输出方程** | 描述输出与状态、输入关系的代数方程：$y = g(x,u,t)$ |

## 0.3 两类数学模型的比较

| 方面 | 传递函数（经典） | 状态空间（现代） |
|:--|:--|:--|
| 适用范围 | 标量传函用于SISO；传递函数阵也可描述MIMO线性定常系统 | 适于MIMO及非线性、时变模型，但仍须有正确模型与适用方法 |
| 关注对象 | 输入-输出关系（外部描述） | 系统内部状态演化（内部描述） |
| 信息完整度 | 输入输出描述不一定显示原系统全部内部模态 | 状态描述保留所建模型的内部动态，不意味着建模忽略因素也被自动恢复 |
| 初始条件 | 默认零初始条件 | 可处理**任意初始条件** |
| 能控能观 | 单一传函不能判定某个给定非最小实现的隐藏模态 | 线性定常模型可用秩/PBH等判据；时变和非线性须使用相应条件 |
| 与传递函数互转 | — | $G(s)=C(sE-A)^{-1}B+D$ |

## 0.4 现代控制理论的主要内容

```
第1章 状态空间表达式            ← 建模（物理/微分方程/传函 → 状态空间）
第2章 状态空间表达式的解        ← 分析（状态转移矩阵、运动规律）
第3章 能控性和能观性            ← 结构特性（能控能观判据、标准型、结构分解、最小实现）
第4章 稳定性与李雅普诺夫方法    ← 稳定性（第一/第二法、李雅普诺夫方程、非线性）
第5章 线性定常系统的综合        ← 设计（极点配置、观测器、分离原理、解耦、内模）
```

贯穿始终的两大工具：线性变换（坐标变换）和对偶原理。

## 0.5 解题套路

① 明确输入、输出、单位和有效工况 → ② 选独立状态并列模型 → ③ 给定初值、检验模型 → ④ 分析能控能观与稳定性 → ⑤ 设计控制器/观测器 → ⑥ 回验跟踪、抗扰和实现约束。
