# 附录 能控能观判别速查

> [!abstract] 附录定位
> 能控性/能观性的三种判据、对偶关系、标准型、结构分解、最小实现的**纯速查**。所有推导与例题见 [[03 能控性和能观性]]（03-1~03-2）。

## 三种判据对比

| 判据 | 能控 | 能观 | 适用 |
| :-- | :-- | :-- | :-- |
| **秩判据** | $\operatorname{rank}[B\ AB\ \cdots\ A^{n-1}B]=n$ | $\operatorname{rank}\begin{bmatrix}C\\CA\\\vdots\\CA^{n-1}\end{bmatrix}=n$ | 通用（首选） |
| **PBH 判据** | $\operatorname{rank}[\lambda_i I-A\ \ B]=n$（$\forall\lambda_i$） | $\operatorname{rank}\begin{bmatrix}\lambda_i I-A\\C\end{bmatrix}=n$（$\forall\lambda_i$） | 含参数/对角型快速 |
| **格拉姆判据** | $W_c=\int_0^\infty e^{At}BB^Te^{A^Tt}dt$ 满秩 | $W_o=\int_0^\infty e^{A^Tt}C^TCe^{At}dt$ 满秩 | 理论推导/时变系统 |

> [!tip] 对角型直接看法
> 互异特征值对角化后 $A_d=\operatorname{diag}(\lambda_1,\dots,\lambda_n)$：
> - 能控：$B_d=P^{-1}B$ **每行不全零** ⟺ 对应模态能控
> - 能观：$C_d=CP$ **每列不全零** ⟺ 对应模态能观

## 约旦标准型快速判据

| 情况 | 能控条件 | 能观条件 |
| :-- | :-- | :-- |
| 单个约当块（孤立块） | $\tilde{B}$ 对应行**不全零** | $\tilde{C}$ 对应列**不全零** |
| 多个约当块（同特征值） | 各块**最后一行**对应的 $\tilde{B}$ 行向量**线性无关** | 各块**第一列**对应的 $\tilde{C}$ 列向量**线性无关** |

口诀：能控「**单块看全零行，多块看末行线性无关**」；能观对偶。

## 对偶关系

$$\text{系统 }(A,B,C) \text{ 的对偶系统为 }(A^T,C^T,B^T)$$

| 性质 | 说明 |
| :-- | :-- |
| $A$ 能控 ⟺ $A^T$ 能观 | 对偶系统能控/能观互换 |
| $Q_c(A,B)=Q_o(A^T,C^T)^T$ | 判别矩阵互为转置 |
| $W_c=W_o^T$（定常） | 格拉姆矩阵互为转置 |

## 标准型

| 标准型 | 构造 | 特点 |
| :-- | :-- | :-- |
| **能控标准型** | $A_c=\begin{bmatrix}0&1&\cdots&0\\\vdots&&\ddots&\vdots\\0&\cdots&0&1\\-a_n&\cdots&-a_2&-a_1\end{bmatrix},\ B_c=\begin{bmatrix}0\\\vdots\\0\\1\end{bmatrix}$ | $B_c$ 为末单位向量；传函分母直接读出 |
| **能观标准型** | $A_o=A_c^T,\ C_o=B_c^T$ | 能控标准型的对偶；$C_o$ 为末单位行向量 |
| **对角标准型** | $A_d=\operatorname{diag}(\lambda_1,\dots,\lambda_n)$ | 互异特征值时可用；模态解耦 |
| **约旦标准型** | 同特征值对应约当块 | 含重特征值时用 |

## 结构分解（卡尔曼分解）

$$\text{能控子空间 }x_c + \text{ 不能控子空间 }x_{\bar{c}}$$

$$\text{能观子空间 }x_o + \text{ 不能观子空间 }x_{\bar{o}}$$

| 分解 | 维数 | 判定 |
| :-- | :-- | :-- |
| 能控子空间 | $\operatorname{rank}Q_c$ | $x_c$ 的维度 = 能控状态个数 |
| 能观子空间 | $\operatorname{rank}Q_o$ | $x_o$ 的维度 = 能观状态个数 |
| **能控能观子空间** | $\operatorname{rank}\begin{pmatrix}Q_c\\Q_o\end{pmatrix}$ ？不，实际为 $r(Q_oQ_c)$（更精细） | 传递函数仅反映能控且能观部分 |

> [!warning] 传递函数零极点对消
> 传递函数 = 能控**且**能观部分的最小实现；零极点对消 ⟺ 不能控或不能观模态。

## 最小实现

| 条件 | 说明 |
| :-- | :-- |
| **充要条件** | 实现既是**能控**又是**能观** |
| 维数 | 最小实现的维度 = 传递函数分母阶数 $n$ |
| 求法 | 由传函 → 能控标准型（或能观标准型）→ 验能观（或能控）；不满足则降阶 |

## 离散系统

用 $(G,H,C)$ 代 $(A,B,C)$，判别方法完全平行：

- 能控：$\operatorname{rank}[H\ GH\ \cdots\ G^{n-1}H]=n$
- 能观：$\operatorname{rank}[C^T\ (CG)^T\ \cdots\ (CG^{n-1})^T]^T=n$
