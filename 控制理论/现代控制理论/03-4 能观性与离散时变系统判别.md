# 第 3 章（四） 能观性与离散时变系统判别

> [!abstract] 本讲定位
> 能观性的定义与判别（秩判据、PBH、格拉姆）、判别例题，及离散、时变系统的能控能观判据。

## 3.3 能观性的定义与判别

$$
\boxed{Q_o = \begin{bmatrix}C\\ CA\\ \vdots\\ CA^{n-1}\end{bmatrix}},\qquad
\text{完全能观} \ \Leftrightarrow\ \operatorname{rank}Q_o = n
$$

- 对角型直接法：$C$ 中对应列全零 ⇔ 该模态**不能观**

### 3.3.1 PBH 判据

- 能观：$\operatorname{rank}\begin{bmatrix}\lambda I-A\\ C\end{bmatrix}=n$（对所有特征值 $\lambda$）

与能控侧（§3.2.1）**对偶**：仅需对特征值 $\lambda_i$ 判秩；$\begin{bmatrix}\lambda_i I-A\\ C\end{bmatrix}$ 缺秩 ⇔ $\lambda_i$ 为**不能观**模态；可由 $C$ 的零列直接读出；$\operatorname{rank}Q_o=n$（$[C; CA; \cdots]$）与 PBH **充要等价**。

### 3.3.2 格拉姆矩阵判据

**能观格拉姆**（对偶对称）：$W_o=\int_0^\infty e^{A^Tt}C^TCe^{At}\,dt$ 满秩 ⇔ 完全能观；满足李雅普诺夫方程 $A^TW_o+W_oA=-C^TC$。

**与秩判据等价**：$W_o$ 非奇异 ⟺ $\operatorname{rank}Q_o=n$；格拉姆**数值上更稳**（对偶性质与能控侧对称，见 §3.2.2）。

### 3.3.3 能观判别例题

> [!example] ✏️ **例：$A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix}$，$C=[1\ 0]$，判能观性**
>
> **秩判据**：
> $$Q_o = \begin{bmatrix}C\\ CA\end{bmatrix}
> = \begin{bmatrix}1&0\\ [1\ 0]\begin{bmatrix}0&1\\-2&-3\end{bmatrix}\end{bmatrix}
> = \begin{bmatrix}1&0\\0&1\end{bmatrix}$$
> $\det(Q_o) = 1 \neq 0$，$\operatorname{rank}Q_o=2=n$ → **完全能观** ✓
>
> **对角型验证**（互异特征值 $\lambda_1=-1,\lambda_2=-2$）：对角化后 $A_d=\begin{bmatrix}-1&0\\0&-2\end{bmatrix}$，
> $B_d=P^{-1}B=\begin{bmatrix}2&1\\-1&-1\end{bmatrix}\begin{bmatrix}0\\1\end{bmatrix}=\begin{bmatrix}1\\-1\end{bmatrix}$，
> $C_d=CP=[1\ 0]\begin{bmatrix}1&1\\-1&-2\end{bmatrix}=[1\ 1]$
> $B_d$ 无零行 → 两模态均能控；$C_d$ 无零列 → 两模态均能观 ✓

> [!example] ✏️ **例：含不能控模态的系统**
> $A=\begin{bmatrix}-1&0\\0&-2\end{bmatrix}$，$B=\begin{bmatrix}1\\0\end{bmatrix}$，$C=[0\ 1]$
>
> $Q_c=[B\ AB]=\begin{bmatrix}1&-1\\0&0\end{bmatrix}$，$\operatorname{rank}Q_c=1<2$ → **不完全能控**
> $Q_o=\begin{bmatrix}C\\CA\end{bmatrix}=\begin{bmatrix}0&1\\0&-2\end{bmatrix}$，$\operatorname{rank}Q_o=1<2$ → **不完全能观**
>
> 对角型直接看：$B$ 第 2 行 = 0 → $\lambda_2=-2$ **不能控**；$C$ 第 1 列 = 0 → $\lambda_1=-1$ **不能观**。

## 3.4 离散时间系统的能控性与能观性

离散系统 $x(k+1)=Gx(k)+Hu(k),\ y(k)=Cx(k)$，能控性/能观性判别与连续系统完全平行（用 $(G,H,C)$ 代 $(A,B,C)$）：

- **能控性**：判别矩阵 $\operatorname{rank}M_c=n$，其中 $M_c=[H\ \ GH\ \ G^2H\ \cdots\ G^{n-1}H]$；
- **能观性**：判别矩阵 $\operatorname{rank}M_o=n$，其中 $M_o=\begin{bmatrix}C\\CG\\\vdots\\CG^{n-1}\end{bmatrix}$。

> [!example] ✏️ 例：$G=\begin{bmatrix}0&1\\-0.06&0.5\end{bmatrix}, H=\begin{bmatrix}0\\1\end{bmatrix}$
> $M_c=[H\ \ GH]=\begin{bmatrix}0&1\\1&0.5\end{bmatrix}$，$\operatorname{rank}=2$ ⟹ 能控（与 2.4 节的 $G(z)$ 对偶）；$C=[1\ \ 0]$ 时 $M_o=\begin{bmatrix}1&0\\0&1\end{bmatrix}$ 满秩 ⟹ 能观。

## 3.5 时变系统的能控性与能观性

时变系统 $\dot x(t)=A(t)x(t)+B(t)u(t),\ y(t)=C(t)x(t)$，能控/能观性用**格拉姆矩阵**判据（唯一一般方法）：

**能控格拉姆**：
$$
W_c(t_0,t_1)=\int_{t_0}^{t_1}\Phi(t_0,\tau)B(\tau)B^T(\tau)\Phi^T(t_0,\tau)\,d\tau
$$

**能观格拉姆**（对偶对称）：
$$
W_o(t_0,t_1)=\int_{t_0}^{t_1}\Phi^T(\tau,t_0)C^T(\tau)C(\tau)\Phi(\tau,t_0)\,d\tau
$$

系统在 $[t_0,t_1]$ 上**完全能控** ⟺ $W_c(t_0,t_1)$ 满秩；**完全能观** ⟺ $W_o(t_0,t_1)$ 满秩（$\operatorname{rank}=n$）。

> [!example] ✏️ 例3.9 时变系统能控性判别（格拉姆矩阵法）
>
> **题目**：系统 $\dot x = A(t)x + B(t)u$，其中 $A(t)=\begin{bmatrix}0&1\\0&t\end{bmatrix}$，$B(t)=\begin{bmatrix}0\\1\end{bmatrix}$，判别在 $[0,t_f]$（$t_f>0$）上的能控性。
>
> **解**：
>
> **(1) 求状态转移矩阵**
>
> 由于 $A(t)$ 满足 $A(t_1)A(t_2)=A(t_2)A(t_1)$（可验证），状态转移矩阵可写成封闭形式：
>
> $$\Phi(0,t) = I + \int_t^0 A(\tau)\,d\tau = \begin{bmatrix}1&-t\\0&1-\frac{t^2}{2}\end{bmatrix}$$
>
> **(2) 计算能控格拉姆矩阵**
>
> $$W_c(0,t_f) = \int_0^{t_f} \Phi(0,\tau)B(\tau)B^T(\tau)\Phi^T(0,\tau)\,d\tau$$
>
> 计算 $\Phi(0,\tau)B(\tau)$：
>
> $$\Phi(0,\tau)B(\tau) = \begin{bmatrix}1&-\tau\\0&1-\frac{\tau^2}{2}\end{bmatrix}\begin{bmatrix}0\\1\end{bmatrix} = \begin{bmatrix}-\tau\\1-\frac{\tau^2}{2}\end{bmatrix}$$
>
> $$W_c(0,t_f) = \int_0^{t_f} \begin{bmatrix}\tau^2&-\tau(1-\frac{\tau^2}{2})\\-\tau(1-\frac{\tau^2}{2})&(1-\frac{\tau^2}{2})^2\end{bmatrix}\,d\tau$$
>
> **(3) 判别非奇异性**
>
> $$\det W_c(0,t_f) = \int_0^{t_f} \tau^2\,d\tau \cdot \int_0^{t_f}(1-\frac{\tau^2}{2})^2\,d\tau - \left(\int_0^{t_f}\tau(1-\frac{\tau^2}{2})\,d\tau\right)^2$$
>
> 当 $t_f>0$ 时，可验证 $\det W_c(0,t_f)>0$。
>
> **结论**：系统在 $[0,t_f]$（$t_f>0$）上**完全能控**。
>
---

> [!example] ✏️ 例3.10 时变系统能控性判别（充分条件法）
>
> **题目**：系统同例3-9，用充分条件法判别能控性。
>
> **解**：定义辅助矩阵序列：
>
> $$B_1(t) = B(t) = \begin{bmatrix}0\\1\end{bmatrix}$$
>
> $$B_2(t) = -A(t)B_1(t) + \dot B_1(t) = -\begin{bmatrix}0&1\\0&t\end{bmatrix}\begin{bmatrix}0\\1\end{bmatrix} + \begin{bmatrix}0\\0\end{bmatrix} = \begin{bmatrix}-1\\-t\end{bmatrix}$$
>
> 构造矩阵：
>
> $$Q_c(t) = [B_1(t)\ \ B_2(t)] = \begin{bmatrix}0&-1\\1&-t\end{bmatrix}$$
>
> $$\det Q_c(t) = 0 \times (-t) - (-1) \times 1 = 1 \neq 0$$
>
> 故 $\operatorname{rank}Q_c(t) = 2 = n$，对任意 $t>0$ 成立。
>
> **结论**：由充分条件法，系统在 $[0,t_f]$（$t_f>0$）上**完全能控**。
>
---

> [!example] ✏️ 例3.11 时变系统能观性判别
>
> **题目**：系统 $\dot x = A(t)x$，$y = C(t)x$，其中 $A(t)=\begin{bmatrix}t&1\\0&t\end{bmatrix}$，$C(t)=[1\ \ 0\ \ 1]$（三阶系统），判别能观性。
>
> **解**：定义辅助矩阵序列：
>
> $$C_1(t) = C(t) = [1\ \ 0\ \ 1]$$
>
> $$C_2(t) = C_1(t)A(t) + \dot C_1(t) = [1\ \ 0\ \ 1]\begin{bmatrix}t&1&0\\0&t&1\\0&0&t\end{bmatrix} = [t\ \ 1\ \ t]$$
>
> $$C_3(t) = C_2(t)A(t) + \dot C_2(t) = [t\ \ 1\ \ t]\begin{bmatrix}t&1&0\\0&t&1\\0&0&t\end{bmatrix} + [1\ \ 0\ \ 1] = [t^2+1\ \ 2t\ \ t^2+2t]$$
>
> 构造能观性矩阵：
>
> $$R(t) = \begin{bmatrix}C_1(t)\\C_2(t)\\C_3(t)\end{bmatrix} = \begin{bmatrix}1&0&1\\t&1&t\\t^2+1&2t&t^2+2t\end{bmatrix}$$
>
> 计算行列式：
>
> $$\det R(t) = 1 \cdot (1 \cdot (t^2+2t) - t \cdot 2t) - 0 + 1 \cdot (t \cdot 2t - 1 \cdot (t^2+1))$$
> $$= (t^2+2t-2t^2) + (2t^2-t^2-1) = -t^2+2t + t^2-1 = 2t-1$$
>
> 当 $t>\frac{1}{2}$ 时，$\det R(t) \neq 0$，$\operatorname{rank}R(t)=3=n$。
>
> **结论**：系统在 $t>\frac{1}{2}$ 的时间区间上**完全能观**。
>
> **注意**：上述充分条件法（例3-10、例3-11）仅给出能控/能观的**充分条件**。若不满足该条件，不能直接得出系统不能控/不能观的结论。
