# 第 3 章（一） 能控能观的判别

> [!abstract] 本讲定位
> 能控性与能观性的定义与判别：秩判据、PBH、格拉姆判据，含能控/能观判别例题，及离散、时变系统的判据。

## 3.1 能控性的定义与判别

$$
\boxed{Q_c = [B\ \ AB\ \ A^2B\ \ \cdots\ \ A^{n-1}B]},\qquad
\text{完全能控} \ \Leftrightarrow\ \operatorname{rank}Q_c = n
$$

**能控性说明**：
1. 终端状态取**零状态**（$x(t_f)=0$）——不要求从零出发；
2. **能达性**：从零初始状态到任意终端状态，定常系统能控 ⟺ 能达（二者等价）；
3. 控制 $u(t)$ 无约束（任意大小）。

- 对角型直接法：$B$ 中对应行全零 ⇔ 该模态**不能控**
- **输出能控性**：$\operatorname{rank}[CB\ CAB\ \cdots\ CA^{n-1}B\ D]=q$ ⇔ 输出完全能控；与状态能控性无必然联系

---

## 3.2 线性定常系统的能控性判别

### 3.2.1 PBH 判据

- 能控：$\operatorname{rank}[\lambda I-A\ \ B] = n$（对所有特征值 $\lambda$）

**等价化简**：只需对所有**特征值** $\lambda=\lambda_i$ 判秩即可——其余 $s$ 使 $sI-A$ 可逆，$[sI-A\ \ B]$ 已自动满秩 $n$。故 PBH 判据等价于"**每个模态都可控**"。

**几何意义**：$[\lambda_i I-A\ \ B]$ 在 $\lambda_i$ 处**缺秩**（$<n$）⇔ $\lambda_i$ 为**不能控**模态。对分块对角/约当型可由 $B$ 的零行直接读出（能观侧见 §3.3.1）。

**与秩判据等价**：$\operatorname{rank}Q_c=n$（$[B\ AB\ \cdots]$）与 PBH 判据**充要等价**；当特征值一目了然（对角/约当型）或含参数符号时，PBH 逐特征值检验更省力。

### 3.2.2 格拉姆矩阵判据

**能控格拉姆**：$W_c=\int_0^\infty e^{At}BB^Te^{A^Tt}\,dt$ 满秩（非奇异）⇔ 完全能控。

**性质**：$W_c$ 满足李雅普诺夫方程 $AW_c+W_cA^T=-BB^T$。

**与秩判据等价**：定常时 $W_c$ 非奇异 ⟺ $\operatorname{rank}Q_c=n$（满秩 $[B\ AB\ \cdots]$），二者充要等价；但格拉姆**数值上更稳**（矩阵积分/解方程，避免列向量近似线性相关的病态）。时变系统**唯一**判据（见 §3.5）；定常系统中主要用于理论推导。

> [!note] **约旦标准型能控判据（快速判断法）**
> 将 $A$ 化为约旦标准型 $J=P^{-1}AP$，$\tilde B=P^{-1}B$。对每个约当块 $J_i$（对应特征值 $\lambda_i$）：
> - 若 $\lambda_i$ 的约当块**只有一个**（孤立块）：$\tilde B$ 中**对应行全零** ⟹ 该模态**不能控**；
> - 若 $\lambda_i$ 有**多个约当块**：各块**最后一行**对应的 $\tilde B$ 行向量须**线性无关** ⟹ 才能控。
>
> 口诀：**单块看全零行，多块看末行线性无关**。

### 3.2.3 能控判别例题

#### ✏️ 例3-1 约旦标准型系统的能控性判别

**题目**：判断下列系统的能控性：
- (1) $A=\begin{bmatrix}\lambda_1&0\\0&\lambda_2\end{bmatrix}$，$B=\begin{bmatrix}b_1\\b_2\end{bmatrix}$（对角型）
- (2) $A=\begin{bmatrix}\lambda_1&1\\0&\lambda_1\end{bmatrix}$，$B=\begin{bmatrix}b_1\\b_2\end{bmatrix}$（约当型）

**解**：

**(1) 对角型系统**

状态方程为：
$$\dot x_1 = \lambda_1 x_1 + b_1 u$$
$$\dot x_2 = \lambda_2 x_2 + b_2 u$$

- 若 $b_1 \neq 0$ 且 $b_2 \neq 0$：$x_1$、$x_2$ 均受 $u$ 控制 → **能控**
- 若 $b_1 = 0$：$x_1$ 不受 $u$ 控制 → **不能控**
- 若 $b_2 = 0$：$x_2$ 不受 $u$ 控制 → **不能控**

**结论**：对角型系统能控 ⟺ $B$ 中无全零行。

**(2) 约当型系统**

状态方程为：
$$\dot x_1 = \lambda_1 x_1 + x_2 + b_1 u$$
$$\dot x_2 = \lambda_1 x_2 + b_2 u$$

虽然 $\dot x_1$ 与 $u$ 无直接关系，但 $x_1$ 与 $x_2$ 有耦合，而 $x_2$ 受 $u$ 控制，故 $x_1$ 也可通过 $x_2$ 间接控制。

- 若 $b_2 \neq 0$：系统**能控**
- 若 $b_2 = 0$：$x_2$ 不能控 → $x_1$ 也不能控 → **不能控**

**结论**：约当型系统能控 ⟺ 每个约当块最后一行对应的 $B$ 行非零。

---

#### ✏️ 例3-4 用秩判据判别能控性（能控标准型）

**题目**：系统 $A=\begin{bmatrix}0&1&0\\0&0&1\\-a_0&-a_1&-a_2\end{bmatrix}$，$b=\begin{bmatrix}0\\0\\1\end{bmatrix}$，判能控性。

**解**：计算能控性矩阵：

$$M = [b\ \ Ab\ \ A^2b]$$

$$Ab = \begin{bmatrix}0&1&0\\0&0&1\\-a_0&-a_1&-a_2\end{bmatrix}\begin{bmatrix}0\\0\\1\end{bmatrix} = \begin{bmatrix}0\\1\\-a_2\end{bmatrix}$$

$$A^2b = A(Ab) = \begin{bmatrix}0&1&0\\0&0&1\\-a_0&-a_1&-a_2\end{bmatrix}\begin{bmatrix}0\\1\\-a_2\end{bmatrix} = \begin{bmatrix}1\\-a_2\\-a_1+a_2^2\end{bmatrix}$$

$$M = \begin{bmatrix}0&0&1\\0&1&-a_2\\1&-a_2&-a_1+a_2^2\end{bmatrix}$$

这是一个下三角矩阵，对角线元素为 $1,1,1$，故 $\det(M)=1 \neq 0$，$\operatorname{rank}M=3=n$。

**结论**：能控标准型**必然能控**。

---

#### ✏️ 例3-5 用传递函数法判别能控性

**题目**：系统 $A=\begin{bmatrix}-5&0\\0&1\end{bmatrix}$，$b=\begin{bmatrix}1\\-5\end{bmatrix}$，判能控性。

**解**：

**方法一：秩判据**

$$M = [b\ \ Ab] = \begin{bmatrix}1&-5\\-5&-5\end{bmatrix}$$

$$\det(M) = 1 \times (-5) - (-5) \times (-5) = -5 - 25 = -30 \neq 0$$

$\operatorname{rank}M=2=n$ → 系统能控。

**方法二：传递函数法**

$u \to x$ 间的传递函数阵为：

$$W_{ux}(s) = (sI-A)^{-1}b = \begin{bmatrix}\frac{1}{s+5}&0\\0&\frac{1}{s-1}\end{bmatrix}\begin{bmatrix}1\\-5\end{bmatrix} = \begin{bmatrix}\frac{1}{s+5}\\\frac{-5}{s-1}\end{bmatrix}$$

传递函数阵中无零极点对消 → **能控** ✓

---

#### ✏️ 例3-8 三阶两输入系统能控性判别

**题目**：系统 $A=\begin{bmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{bmatrix}$，$B=\begin{bmatrix}1&1\\0&1\\1&0\end{bmatrix}$，判能控性。

**解**：计算能控性矩阵：

$$M = [B\ \ AB\ \ A^2B]$$

$$AB = \begin{bmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{bmatrix}\begin{bmatrix}1&1\\0&1\\1&0\end{bmatrix} = \begin{bmatrix}0&1\\1&0\\-6&-5\end{bmatrix}$$

$$A^2B = A(AB) = \begin{bmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{bmatrix}\begin{bmatrix}0&1\\1&0\\-6&-5\end{bmatrix} = \begin{bmatrix}1&0\\-6&-5\\26&17\end{bmatrix}$$

$$M = \begin{bmatrix}1&1&0&1&1&0\\0&1&1&0&-6&-5\\1&0&-6&-5&26&17\end{bmatrix}$$

计算 $MM^T$：

$$MM^T = \begin{bmatrix}6&-5&17\\-5&6&-21\\17&-21&78\end{bmatrix}$$

$\det(MM^T) = 13 \neq 0$，故 $MM^T$ 非奇异 → $M$ 满秩 → **系统能控**。

**注**：多输入系统中，$M$ 是 $n \times nr$ 矩阵（行少列多），用 $\operatorname{rank}M = \operatorname{rank}(MM^T)$ 判秩更方便。

> [!example] **例：$A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix}$，$B=\begin{bmatrix}0\\1\end{bmatrix}$，判能控性**
>
> **秩判据**：
> $$
> \begin{aligned}
> Q_c &= [B\ \ AB]\\[4pt]
> &= \Big[\begin{bmatrix}0\\1\end{bmatrix}\ \ \begin{bmatrix}0&1\\-2&-3\end{bmatrix}\\[4pt]
> &\quad\cdot\begin{bmatrix}0\\1\end{bmatrix}\Big]\\[4pt]
> &= \begin{bmatrix}0&1\\1&-3\end{bmatrix}
> \end{aligned}
> $$
> $\det(Q_c) = 0\times(-3)-1\times1 = -1 \neq 0$，$\operatorname{rank}Q_c=2=n$ → **完全能控** ✓
>
> （对角型 $B_d=[1\ -1]^T$ 无零行 → 两模态均能控，验证见 §3.3.3）

## 3.3 能观性的定义与判别

$$
\boxed{Q_o = \begin{bmatrix}C\\ CA\\ \vdots\\ CA^{n-1}\end{bmatrix}},\qquad
\text{完全能观} \ \Leftrightarrow\ \operatorname{rank}Q_o = n
$$

- 对角型直接法：$C$ 中对应列全零 ⇔ 该模态**不能观**

### 3.3.1 PBH 判据

- 能观：$\operatorname{rank}\begin{bmatrix}\lambda I-A\\ C\end{bmatrix}=n$（对所有特征值 $\lambda$）

与能控侧（§3.2.1）**对偶**：仅需对特征值 $\lambda_i$ 判秩；$\begin{bmatrix}\lambda_i I-A\\ C\end{bmatrix}$ 缺秩 ⇔ $\lambda_i$ 为**不能观**模态；可由 $C$ 的零列直接读出；$\operatorname{rank}Q_o=n$（$[C; CA; \cdots]$）与 PBH **充要等价**。

### 3.3.2 格拉姆矩阵判据

**能观格拉姆**（对偶对称）：$W_o=\int_0^\infty e^{A^Tt}C^TCe^{At}\,dt$ 满秩 ⇔ 完全能观；满足李雅普诺夫方程 $A^TW_o+W_oA=-C^TC$。

**与秩判据等价**：$W_o$ 非奇异 ⟺ $\operatorname{rank}Q_o=n$；格拉姆**数值上更稳**（对偶性质与能控侧对称，见 §3.2.2）。

### 3.3.3 能观判别例题

> [!example] **例：$A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix}$，$C=[1\ 0]$，判能观性**
>
> **秩判据**：
> $$Q_o = \begin{bmatrix}C\\ CA\end{bmatrix}
> = \begin{bmatrix}1&0\\ [1\ 0]\begin{bmatrix}0&1\\-2&-3\end{bmatrix}\end{bmatrix}
> = \begin{bmatrix}1&0\\0&1\end{bmatrix}$$
> $\det(Q_o) = 1 \neq 0$，$\operatorname{rank}Q_o=2=n$ → **完全能观** ✓
>
> **对角型验证**（互异特征值 $\lambda_1=-1,\lambda_2=-2$）：对角化后 $A_d=\begin{bmatrix}-1&0\\0&-2\end{bmatrix}$，
> $B_d=P^{-1}B=\begin{bmatrix}2&1\\-1&-1\end{bmatrix}\begin{bmatrix}0\\1\end{bmatrix}=\begin{bmatrix}1\\-1\end{bmatrix}$，
> $C_d=CP=[1\ 0]\begin{bmatrix}1&1\\-1&-2\end{bmatrix}=[1\ 1]$
> $B_d$ 无零行 → 两模态均能控；$C_d$ 无零列 → 两模态均能观 ✓

> [!example] **例：含不能控模态的系统**
> $A=\begin{bmatrix}-1&0\\0&-2\end{bmatrix}$，$B=\begin{bmatrix}1\\0\end{bmatrix}$，$C=[0\ 1]$
>
> $Q_c=[B\ AB]=\begin{bmatrix}1&-1\\0&0\end{bmatrix}$，$\operatorname{rank}Q_c=1<2$ → **不完全能控**
> $Q_o=\begin{bmatrix}C\\CA\end{bmatrix}=\begin{bmatrix}0&1\\0&-2\end{bmatrix}$，$\operatorname{rank}Q_o=1<2$ → **不完全能观**
>
> 对角型直接看：$B$ 第 2 行 = 0 → $\lambda_2=-2$ **不能控**；$C$ 第 1 列 = 0 → $\lambda_1=-1$ **不能观**。

## 3.4 离散时间系统的能控性与能观性

离散系统 $x(k+1)=Gx(k)+Hu(k),\ y(k)=Cx(k)$，能控性/能观性判别与连续系统完全平行（用 $(G,H,C)$ 代 $(A,B,C)$）：

- **能控性**：判别矩阵 $\operatorname{rank}M_c=n$，其中 $M_c=[H\ \ GH\ \ G^2H\ \cdots\ G^{n-1}H]$；
- **能观性**：判别矩阵 $\operatorname{rank}M_o=n$，其中 $M_o=\begin{bmatrix}C\\CG\\\vdots\\CG^{n-1}\end{bmatrix}$。

> [!example] 例：$G=\begin{bmatrix}0&1\\-0.06&0.5\end{bmatrix}, H=\begin{bmatrix}0\\1\end{bmatrix}$
> $M_c=[H\ \ GH]=\begin{bmatrix}0&1\\1&0.5\end{bmatrix}$，$\operatorname{rank}=2$ ⟹ 能控（与 2.4 节的 $G(z)$ 对偶）；$C=[1\ \ 0]$ 时 $M_o=\begin{bmatrix}1&0\\0&1\end{bmatrix}$ 满秩 ⟹ 能观。

## 3.5 时变系统的能控性与能观性

时变系统 $\dot x(t)=A(t)x(t)+B(t)u(t),\ y(t)=C(t)x(t)$，能控/能观性用**格拉姆矩阵**判据（唯一一般方法）：

**能控格拉姆**：
$$
W_c(t_0,t_1)=\int_{t_0}^{t_1}\Phi(t_0,\tau)B(\tau)B^T(\tau)\Phi^T(t_0,\tau)\,d\tau
$$

**能观格拉姆**（对偶对称）：
$$
W_o(t_0,t_1)=\int_{t_0}^{t_1}\Phi^T(\tau,t_0)C^T(\tau)C(\tau)\Phi(\tau,t_0)\,d\tau
$$

系统在 $[t_0,t_1]$ 上**完全能控** ⟺ $W_c(t_0,t_1)$ 满秩；**完全能观** ⟺ $W_o(t_0,t_1)$ 满秩（$\operatorname{rank}=n$）。

#### ✏️ 例3-9 时变系统能控性判别（格拉姆矩阵法）

**题目**：系统 $\dot x = A(t)x + B(t)u$，其中 $A(t)=\begin{bmatrix}0&1\\0&t\end{bmatrix}$，$B(t)=\begin{bmatrix}0\\1\end{bmatrix}$，判别在 $[0,t_f]$（$t_f>0$）上的能控性。

**解**：

**(1) 求状态转移矩阵**

由于 $A(t)$ 满足 $A(t_1)A(t_2)=A(t_2)A(t_1)$（可验证），状态转移矩阵可写成封闭形式：

$$\Phi(0,t) = I + \int_t^0 A(\tau)\,d\tau = \begin{bmatrix}1&-t\\0&1-\frac{t^2}{2}\end{bmatrix}$$

**(2) 计算能控格拉姆矩阵**

$$W_c(0,t_f) = \int_0^{t_f} \Phi(0,\tau)B(\tau)B^T(\tau)\Phi^T(0,\tau)\,d\tau$$

计算 $\Phi(0,\tau)B(\tau)$：

$$\Phi(0,\tau)B(\tau) = \begin{bmatrix}1&-\tau\\0&1-\frac{\tau^2}{2}\end{bmatrix}\begin{bmatrix}0\\1\end{bmatrix} = \begin{bmatrix}-\tau\\1-\frac{\tau^2}{2}\end{bmatrix}$$

$$W_c(0,t_f) = \int_0^{t_f} \begin{bmatrix}\tau^2&-\tau(1-\frac{\tau^2}{2})\\-\tau(1-\frac{\tau^2}{2})&(1-\frac{\tau^2}{2})^2\end{bmatrix}\,d\tau$$

**(3) 判别非奇异性**

$$\det W_c(0,t_f) = \int_0^{t_f} \tau^2\,d\tau \cdot \int_0^{t_f}(1-\frac{\tau^2}{2})^2\,d\tau - \left(\int_0^{t_f}\tau(1-\frac{\tau^2}{2})\,d\tau\right)^2$$

当 $t_f>0$ 时，可验证 $\det W_c(0,t_f)>0$。

**结论**：系统在 $[0,t_f]$（$t_f>0$）上**完全能控**。

#### ✏️ 例3-10 时变系统能控性判别（充分条件法）

**题目**：系统同例3-9，用充分条件法判别能控性。

**解**：定义辅助矩阵序列：

$$B_1(t) = B(t) = \begin{bmatrix}0\\1\end{bmatrix}$$

$$B_2(t) = -A(t)B_1(t) + \dot B_1(t) = -\begin{bmatrix}0&1\\0&t\end{bmatrix}\begin{bmatrix}0\\1\end{bmatrix} + \begin{bmatrix}0\\0\end{bmatrix} = \begin{bmatrix}-1\\-t\end{bmatrix}$$

构造矩阵：

$$Q_c(t) = [B_1(t)\ \ B_2(t)] = \begin{bmatrix}0&-1\\1&-t\end{bmatrix}$$

$$\det Q_c(t) = 0 \times (-t) - (-1) \times 1 = 1 \neq 0$$

故 $\operatorname{rank}Q_c(t) = 2 = n$，对任意 $t>0$ 成立。

**结论**：由充分条件法，系统在 $[0,t_f]$（$t_f>0$）上**完全能控**。

---

#### ✏️ 例3-11 时变系统能观性判别

**题目**：系统 $\dot x = A(t)x$，$y = C(t)x$，其中 $A(t)=\begin{bmatrix}t&1\\0&t\end{bmatrix}$，$C(t)=[1\ \ 0\ \ 1]$（三阶系统），判别能观性。

**解**：定义辅助矩阵序列：

$$C_1(t) = C(t) = [1\ \ 0\ \ 1]$$

$$C_2(t) = C_1(t)A(t) + \dot C_1(t) = [1\ \ 0\ \ 1]\begin{bmatrix}t&1&0\\0&t&1\\0&0&t\end{bmatrix} = [t\ \ 1\ \ t]$$

$$C_3(t) = C_2(t)A(t) + \dot C_2(t) = [t\ \ 1\ \ t]\begin{bmatrix}t&1&0\\0&t&1\\0&0&t\end{bmatrix} + [1\ \ 0\ \ 1] = [t^2+1\ \ 2t\ \ t^2+2t]$$

构造能观性矩阵：

$$R(t) = \begin{bmatrix}C_1(t)\\C_2(t)\\C_3(t)\end{bmatrix} = \begin{bmatrix}1&0&1\\t&1&t\\t^2+1&2t&t^2+2t\end{bmatrix}$$

计算行列式：

$$\det R(t) = 1 \cdot (1 \cdot (t^2+2t) - t \cdot 2t) - 0 + 1 \cdot (t \cdot 2t - 1 \cdot (t^2+1))$$
$$= (t^2+2t-2t^2) + (2t^2-t^2-1) = -t^2+2t + t^2-1 = 2t-1$$

当 $t>\frac{1}{2}$ 时，$\det R(t) \neq 0$，$\operatorname{rank}R(t)=3=n$。

**结论**：系统在 $t>\frac{1}{2}$ 的时间区间上**完全能观**。

> [!warning] **注意**
> 上述充分条件法（例3-10、例3-11）仅给出能控/能观的**充分条件**。若不满足该条件，不能直接得出系统不能控/不能观的结论。
