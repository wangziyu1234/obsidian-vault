# 第 3 章（二） 能控能观的结构特性

> [!abstract] 本讲定位
> 能控能观的结构性质：对偶原理、能控/能观标准型、线性系统的结构分解（含卡尔曼分解完整例）、最小实现、零极对消与能控能观的关系。

## 3.6 能控性与能观性的对偶关系

**对偶系统**：$\Sigma=(A,B,C)$ 与 $\tilde\Sigma=(\tilde A,\tilde B,\tilde C)=(A^T,\,C^T,\,B^T)$ 互为对偶（输入输出互换、矩阵全部转置）。

$$
\boxed{(A,B,C)\ \text{能控} \ \Leftrightarrow\ (A^T,C^T,B^T)\ \text{能观}}
$$

**互证**（秩一眼看穿）：

$$
\tilde Q_c=\bigl[\tilde B\ \ \tilde A\tilde B\ \cdots\ \tilde A^{n-1}\tilde B\bigr]
=\bigl[C^T\ \ A^{T}C^{T}\ \cdots\ (A^{n-1})^{T}C^{T}\bigr]=Q_o^{T}
$$

转置不改变秩 ⟹ $\operatorname{rank}\tilde Q_c=\operatorname{rank}Q_o$，对偶成立。同理 $\tilde Q_o=Q_c^T$。

**推论与应用**：

- $(A,B,C)$ 能观 ⟺ 其对偶系统能控；求反馈增益 $K$ 与求观测器增益 $L$ 可对偶处理（阿克曼公式及其对偶式，见 [[05-1 状态反馈与观测器]] §5.2.1）；
- 对角/约当型的判别技巧也在对偶下互换（模态"看得见 vs 够得着"）。

## 3.7 状态空间表达式的能控标准型与能观标准型

| 标准型 | $A$ 结构 | $B$ / $C$ 位置 |
|:--|:--|:--|
| **能控标准型** | 友矩阵 $A_c$（末行 $[-a_0\ -a_1\cdots]$） | $B_c=[0\cdots0\ 1]^T$ |
| **能观标准型** | $A_o = A_c^T$ | $C_o=[0\cdots0\ 1]$ |

由传函数直读实现：
$$
G(s)=\frac{\beta_{n-1}s^{n-1}+\cdots+\beta_0}{s^n+a_{n-1}s^{n-1}+\cdots+a_0}
\quad\Rightarrow\quad
C_c = [\beta_0\ \beta_1\ \cdots\ \beta_{n-1}],\ D=0
$$

> [!info]
> 当 $m=n$ 时先长除分离出 $D$。
>
> 本节为速查对照表：变换矩阵如何具体构造见 [[控制理论/现代控制理论/01-3 线性变换与传递函数阵|01-3]] §1.5.2；三种标准型的模拟结构图与直读例题见 [[控制理论/现代控制理论/01-1 状态变量与模拟结构图|01-1]] §1.2.1–1.2.5（按库约定内容只留一处）。

#### ✏️ 例3-12 能控标准I型变换

**题目**：将状态空间表达式 $\dot x = \begin{bmatrix}2&1&0\\0&2&1\\0&0&1\end{bmatrix}x + \begin{bmatrix}0\\0\\1\end{bmatrix}u$，$y=[1\ \ 0\ \ 0]x$ 变换成能控标准I型。

**解**：

**(1) 判别能控性**

$$M = [b\ \ Ab\ \ A^2b] = \begin{bmatrix}0&0&1\\0&1&4\\1&1&9\end{bmatrix}$$

$\operatorname{rank}M=3=n$ → 系统能控，可变换为能控标准型。

**(2) 计算特征多项式**

$$\det(sI-A) = \begin{vmatrix}s-2&-1&0\\0&s-2&-1\\0&0&s-1\end{vmatrix} = (s-2)^2(s-1) = s^3-5s^2+8s-4$$

故 $a_2=-5$，$a_1=8$，$a_0=-4$。

**(3) 构造变换矩阵**

能控标准I型的变换矩阵为：

$$T_c^{-1} = [A^2b\ \ Ab\ \ b] = \begin{bmatrix}1&0&0\\4&0&1\\9&1&1\end{bmatrix}$$

$$T_c = (T_c^{-1})^{-1} = \begin{bmatrix}1&0&0\\-5&-1&1\\4&1&0\end{bmatrix}$$

**(4) 计算变换后的矩阵**

$$\bar A = T_c A T_c^{-1} = \begin{bmatrix}0&1&0\\0&0&1\\4&-8&5\end{bmatrix}$$

$$\bar b = T_c b = \begin{bmatrix}0\\0\\1\end{bmatrix}$$

$$\bar c = c T_c^{-1} = [1\ \ 0\ \ 0]\begin{bmatrix}1&0&0\\4&0&1\\9&1&1\end{bmatrix} = [1\ \ 0\ \ 0]$$

**能控标准I型**：
$$\dot{\bar x} = \begin{bmatrix}0&1&0\\0&0&1\\4&-8&5\end{bmatrix}\bar x + \begin{bmatrix}0\\0\\1\end{bmatrix}u$$
$$y = [1\ \ 0\ \ 0]\bar x$$

**传递函数**（直读）：
$$W(s) = \frac{1}{s^3-5s^2+8s-4} = \frac{\beta_0}{s^3+a_2s^2+a_1s+a_0}$$

#### ✏️ 例3-13 能控标准II型变换

**题目**：将例3-12中的状态空间表达式变换为能控标准II型。

**解**：

**(1) 构造变换矩阵**

能控标准II型的变换矩阵为：

$$T_c = [b\ \ Ab\ \ A^2b] = \begin{bmatrix}0&0&1\\0&1&4\\1&1&9\end{bmatrix}$$

**(2) 计算变换后的矩阵**

$$T_c^{-1} = \begin{bmatrix}5&-1&1\\-4&1&0\\1&0&0\end{bmatrix}$$

$$\bar A = T_c^{-1} A T_c = \begin{bmatrix}0&0&4\\1&0&-8\\0&1&5\end{bmatrix}$$

$$\bar b = T_c^{-1} b = \begin{bmatrix}1\\0\\0\end{bmatrix}$$

$$\bar c = c T_c = [1\ \ 0\ \ 0]\begin{bmatrix}0&0&1\\0&1&4\\1&1&9\end{bmatrix} = [0\ \ 0\ \ 1]$$

**能控标准II型**：
$$\dot{\bar x} = \begin{bmatrix}0&0&4\\1&0&-8\\0&1&5\end{bmatrix}\bar x + \begin{bmatrix}1\\0\\0\end{bmatrix}u$$
$$y = [0\ \ 0\ \ 1]\bar x$$

**传递函数**（直读）：
$$W(s) = \frac{4s^2-8s+1}{s^3-5s^2+8s-4}$$

#### ✏️ 例3-14 能观标准I型变换

**题目**：将例3-12中的状态空间表达式变换为能观标准I型。

**解**：

**(1) 判别能观性**

$$N = \begin{bmatrix}c\\cA\\cA^2\end{bmatrix} = \begin{bmatrix}1&0&0\\2&1&0\\4&4&1\end{bmatrix}$$

$\operatorname{rank}N=3=n$ → 系统能观，可变换为能观标准型。

**(2) 构造变换矩阵**

能观标准I型的变换矩阵为：

$$T_o = \begin{bmatrix}c\\cA\\cA^2\end{bmatrix} = \begin{bmatrix}1&0&0\\2&1&0\\4&4&1\end{bmatrix}$$

**(3) 计算变换后的矩阵**

$$T_o^{-1} = \begin{bmatrix}1&0&0\\-2&1&0\\4&-4&1\end{bmatrix}$$

$$\bar A = T_o A T_o^{-1} = \begin{bmatrix}0&0&4\\1&0&-8\\0&1&5\end{bmatrix}$$

$$\bar b = T_o b = \begin{bmatrix}1&0&0\\2&1&0\\4&4&1\end{bmatrix}\begin{bmatrix}0\\0\\1\end{bmatrix} = \begin{bmatrix}0\\0\\1\end{bmatrix}$$

$$\bar c = c T_o^{-1} = [1\ \ 0\ \ 0]\begin{bmatrix}1&0&0\\-2&1&0\\4&-4&1\end{bmatrix} = [1\ \ 0\ \ 0]$$

**能观标准I型**：
$$\dot{\bar x} = \begin{bmatrix}0&0&4\\1&0&-8\\0&1&5\end{bmatrix}\bar x + \begin{bmatrix}0\\0\\1\end{bmatrix}u$$
$$y = [1\ \ 0\ \ 0]\bar x$$

**传递函数**（直读）：
$$W(s) = \frac{4s^2-8s+1}{s^3-5s^2+8s-4}$$

> [!tip] **对偶关系**
> 能观标准I型的 $(\bar A,\bar b,\bar c)$ 与能控标准II型互为对偶（转置关系）。

## 3.8 线性系统的结构分解

### 3.8.1 按能控性分解（$\operatorname{rank}Q_c=r<n$）

从 $Q_c$ 选 $r$ 个无关列 + 补 $n-r$ 个单位向量，$P^{-1}=[s_1\cdots s_r\mid s_{r+1}\cdots s_n]$：

$$
\begin{aligned}
\bar A &= PAP^{-1} = \begin{bmatrix}\bar A_{11} & \bar A_{12}\\ 0 & \bar A_{22}\end{bmatrix},\\[4pt]
\bar B &= PB = \begin{bmatrix}\bar B_1\\ 0\end{bmatrix}
\end{aligned}
$$

- 传递函数 = **能控子系统** $(\bar A_{11},\bar B_1,\bar C_1)$ 的传递函数
- 不能控部分特征值（$\bar A_{22}$）必须在左半平面（否则系统不能镇定）
- $\det(sI-A)=\det(sI-\bar A_{11})\det(sI-\bar A_{22})$

### 3.8.2 按能观性分解（对偶）

从 $Q_o$ 选无关行写 $P$：
$$
\bar A=\begin{bmatrix}\bar A_{11}&0\\ \bar A_{21}&\bar A_{22}\end{bmatrix},\quad
\bar C=[\bar C_1\ 0]
$$

### 3.8.3 卡尔曼四分解

依次按能控→能观（或反序）分解，状态分成四类：

$$
\bar x = \begin{bmatrix}x_{co}\\
x_{c\bar o}\\
x_{\bar co}\\
x_{\bar c\bar o}\end{bmatrix}
\quad(\text{能控能观}\ /\ \text{能控不能观}\ /\ \text{不能控能观}\ /\ \text{不能控不能观})
$$

**传递函数只反映 $x_{co}$ 子系统**——$G(s)=C_{co}(sI-A_{co})^{-1}B_{co}$。这就是"传递函数描述不完全"的根源。

#### ✏️ 例3-15 按能控性分解

**题目**：系统 $A=\begin{bmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{bmatrix}$，$b=\begin{bmatrix}1\\2\\3\end{bmatrix}$，$c=[1\ \ 0\ \ 0]$，判别能控性，若不完全能控，按能控性分解。

**解**：

**(1) 计算能控性矩阵**

$$M = [b\ \ Ab\ \ A^2b]$$

$$Ab = \begin{bmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{bmatrix}\begin{bmatrix}1\\2\\3\end{bmatrix} = \begin{bmatrix}2\\3\\-40\end{bmatrix}$$

$$A^2b = A(Ab) = \begin{bmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{bmatrix}\begin{bmatrix}2\\3\\-40\end{bmatrix} = \begin{bmatrix}3\\-40\\216\end{bmatrix}$$

$$M = \begin{bmatrix}1&2&3\\2&3&-40\\3&-40&216\end{bmatrix}$$

计算秩：$\det(M) = 1(3 \times 216 - (-40)^2) - 2(2 \times 216 - (-40) \times 3) + 3(2 \times (-40) - 3 \times 3)$
$= 1(648-1600) - 2(432+120) + 3(-80-9)$
$= -952 - 1104 - 267 = -2323 \neq 0$

故 $\operatorname{rank}M=3=n$ → **系统完全能控**。

（注：此例为完全能控系统，无需分解。）

---

#### ✏️ 例3-16 按能观性分解

**题目**：系统 $A=\begin{bmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{bmatrix}$，$b=\begin{bmatrix}1\\2\\3\end{bmatrix}$，$c=[1\ \ 2\ \ 3]$，判别能观性，若不完全能观，按能观性分解。

**解**：

**(1) 计算能观性矩阵**

$$N = \begin{bmatrix}c\\cA\\cA^2\end{bmatrix}$$

$$cA = [1\ \ 2\ \ 3]\begin{bmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{bmatrix} = [-18\ \ -32\ \ -16]$$

$$cA^2 = cA \cdot A = [-18\ \ -32\ \ -16]\begin{bmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{bmatrix} = [96\ \ 174\ \ 80]$$

$$N = \begin{bmatrix}1&2&3\\-18&-32&-16\\96&174&80\end{bmatrix}$$

$\det(N) = 1(-32 \times 80 - (-16) \times 174) - 2(-18 \times 80 - (-16) \times 96) + 3(-18 \times 174 - (-32) \times 96)$
$= 1(-2560+2784) - 2(-1440+1536) + 3(-3132+3072)$
$= 224 - 192 - 180 = -148 \neq 0$

故 $\operatorname{rank}N=3=n$ → **系统完全能观**。

（注：此例为完全能观系统，无需分解。）

#### ✏️ 例3-17 按能控性和能观性进行结构分解（双侧分解）

**题目**：系统 $A=\begin{bmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{bmatrix}$，$b=\begin{bmatrix}0\\0\\1\end{bmatrix}$，$c=[1\ \ 1\ \ 0]$，进行能控性和能观性结构分解。

**解**：

**(1) 能控性分解**

$$M = [b\ \ Ab\ \ A^2b] = \begin{bmatrix}0&0&1\\0&1&-6\\1&-6&30\end{bmatrix}$$

$\det(M) = 1 \neq 0$，$\operatorname{rank}M=3$ → **完全能控**。

**(2) 能观性分解**

$$N = \begin{bmatrix}c\\cA\\cA^2\end{bmatrix} = \begin{bmatrix}1&1&0\\0&1&1\\-6&-5&-5\end{bmatrix}$$

$\det(N) = 1(-5+5) - 1(0+6) + 0 = -6 \neq 0$，$\operatorname{rank}N=3$ → **完全能观**。

**结论**：系统既完全能控又完全能观，无需结构分解，$x_{co}=x$（全状态为能控能观子空间）。

### 3.8.4 结构分解完整例题（能控→能观→$x_{co}$）

> [!example] **例：** 给定系统 $A,B,C$，做卡尔曼分解并求最小实现。
> $$
> A=\begin{bmatrix}0&1&0\\0&0&0\\0&0&2\end{bmatrix},\quad
> B=\begin{bmatrix}0\\1\\0\end{bmatrix},\quad
> C=[1\ 0\ 0]
> $$
>
> **① 算能控性（$Q_c$ 取列）**：
> $$
> \begin{aligned}
> AB &= \begin{bmatrix}1\\0\\0\end{bmatrix},\quad A^2B = \begin{bmatrix}0\\0\\0\end{bmatrix}\\[4pt]
> &\Rightarrow Q_c = [B\ AB\ A^2B] = \begin{bmatrix}0&1&0\\1&0&0\\0&0&0\end{bmatrix},\\[4pt]
> &\operatorname{rank}Q_c = 2 < 3
> \end{aligned}
> $$
> 第三列为零向量（$A^2B=0$），故秩 $=2$。
>
> MATLAB `S=ctrb(A,B); rank(S)` → `2`，一致 ✓。
>
> **② 选无关列构造能控变换阵**：
> 取 $Q_c$ 前两列 $s_1=B$、$s_2=AB$，补单位向量 $s_3=e_3$。
> $$
> s_1=\begin{bmatrix}0\\1\\0\end{bmatrix},\quad s_2=\begin{bmatrix}1\\0\\0\end{bmatrix},\quad s_3=\begin{bmatrix}0\\0\\1\end{bmatrix}
> $$
>
> $$
> P^{-1} = [s_1\ s_2\ s_3] = \begin{bmatrix}0&1&0\\1&0&0\\0&0&1\end{bmatrix},\qquad P = P^{-1}\ (\text{置换阵})
> $$
>
> $$
> \begin{aligned}
> \bar A &= PAP^{-1} = \begin{bmatrix}0&0&0\\1&0&0\\0&0&2\end{bmatrix} = \begin{bmatrix}\bar A_{11}&\bar A_{12}\\0&\bar A_{22}\end{bmatrix},\\[4pt]
> \bar B &= PB = \begin{bmatrix}1\\0\\0\end{bmatrix} = \begin{bmatrix}\bar B_1\\0\end{bmatrix},\\[4pt]
> \bar C &= CP^{-1} = [0\ 1\ 0] = [\bar C_1\ \bar C_2]
> \end{aligned}
> $$
> 能控子系统 $(\bar A_{11},\bar B_1,\bar C_1)$（状态 $x_1,x_2$）：
> $$
> \bar A_{11}=\begin{bmatrix}0&0\\1&0\end{bmatrix},\quad
> \bar B_1=\begin{bmatrix}1\\0\end{bmatrix},\quad
> \bar C_1=[0\ 1]
> $$
> 不能控部分为 $\bar A_{22}=[2]$（$x_3$）。
>
> **③ 按能观性分解（$Q_o$ 取行）**：对能控子系统判能观。
> $$
> Q_o = \begin{bmatrix}\bar C_1\\ \bar C_1\bar A_{11}\end{bmatrix} = \begin{bmatrix}0&1\\1&0\end{bmatrix},\quad \operatorname{rank}Q_o = 2 = \text{满}
> $$
> 能控子系统**已完全能观**，无需再降阶。
>
> **④ 卡尔曼分解结论**：
> $$
> x_{co}=\{x_1,x_2\},\quad x_{\bar c\bar o}=\{x_3\},\quad x_{c\bar o}=x_{\bar co}=\varnothing
> $$
> 即 $\bar x=x_{co}\oplus x_{\bar c\bar o}$。
>
> **⑤ 最小实现（对应 §3.9）**：取 $x_{co}$ 子系统即最小实现。
> $$
> \bar C_1(sI-\bar A_{11})^{-1}\bar B_1=\dfrac{1}{s^2}
> $$
> 传递函数 $C(sI-A)^{-1}B$ 亦 $\dfrac{1}{s^2}$ ✓。
>
> 其**维数**为最小实现的阶数（不可约分母次数，与 §3.9.3 求法二一致）：
> $$
> \operatorname{rank}(Q_oQ_c)=2
> $$
>
> $x_3$ 特征值 $2$ 在右半平面且不能控 → 系统**不能镇定**。

### 3.8.5 结构分解考试步骤

① 算 $\operatorname{rank}Q_c$（或 $Q_o$）得 $r$；
② 挑 $r$ 个无关列 + 补单位向量 → 写 $P^{-1}$；
③ 求 $P$，算 $PAP^{-1}$、$PB$、$CP^{-1}$；
④ 从块三角中读出能控（能观）子系统。
⑤ 对能控子系统再按能观性分解，取 $x_{co}$ 即最小实现。
