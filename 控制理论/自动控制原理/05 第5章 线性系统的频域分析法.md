# 第 5 章 线性系统的频域分析法

> [!abstract] 本讲定位
> **本章讲什么**：不用解微分方程，只用**开环频率特性曲线**来判断闭环稳不稳、算稳定程度、估时域指标、反求系统。
>
> **对应教材**：胡寿松第八版 §5-1—§5-6（书内197—254页 / PDF205—262页，含习题5-1—5-29）。
>
> **三句话主线**：① 画曲线（典型环节叠加）；② 判稳定（$Z=P-2N$）与量裕度（$\gamma$、$h$）；③ 换算指标、反求系统、选校正。
>

## 🧭 全章主线

1. **频率特性**：$G(\mathrm j\omega)=G(s)\big|_{s=\mathrm j\omega}$，是传递函数的频域版本（见 [[05-1-1 频率特性的基本概念]]）。
2. **图示**：极坐标图（奈氏图）与伯德图（$L(\omega)$ + $\varphi(\omega)$），都是典型环节叠加（见 [[05-1-2 典型环节频率特性]]、[[05-1-3 开环频率特性]]）。
3. **判稳**：奈氏判据 $Z=P-2N$（半支穿越 + 必要补弧），稳定还须无虚轴闭环根、无不稳定隐对消（见 [[05-2 奈氏判据与稳定裕度]]）。
4. **指标与综合**：闭环频域指标 $\leftrightarrow$ 时域指标；由曲线反求系统、选校正（见 [[05-3-1 三频段与闭环频域指标]]，衔接 [[06-1 串联校正（超前·滞后·滞后-超前）]]）。

## 🧭 5.11 解题套路

先分解环路、统计右半平面极点 $P$ → 画幅相曲线并处理虚轴补弧 → 用完整奈氏计数判稳 → 求所有相关交越与两个裕度 → 在模型前提下估算闭环指标 → 最后用实际响应验收。每步的细节见 [[05-3-2 频率特性辨识与解题套路]] §5.9。
