## 🧵 ③ 全章主线：先分清对象，再代公式

下表按单位负反馈写，$G$ 表示环路传函；非单位反馈要先重写通道。

| 对象 | 回答什么问题 |
| :-- | :-- |
| 开环 $G(\mathrm j\omega)$ | 画伯德图、奈氏图，判稳并求 $\gamma$、$h$ |
| 闭环 $\Phi=\frac{G}{1+G}$ | 求稳态输出、闭环谐振峰 $M_r$、带宽与阶跃指标 |
| 偏差通道 $\Phi_e=\frac{1}{1+G}$ | 求输入端偏差与稳态误差；非单位反馈须重新列写 |

## 🧭 ⑥ 5.10 解题套路

1. **先选图**：给的是对数曲线就走第一部分（渐近线读数），给的是极坐标曲线就走第二部分（数穿越）；两图都要用裕度与指标时，先用伯德图取 $\omega_c$，再回奈氏图核交点。
2. **辨对象**：分清环路 $G(\mathrm j\omega)$、闭环 $\Phi$ 与偏差通道 $\Phi_e$，写明反馈方式。
3. **画曲线**：分解环节、定转折频率；幅频与相频分别处理，相频必须**连续展开**（允许越过 $-180°$、$-360°$）。
4. **先判稳**：统计 $P$ → 补齐虚轴极点对应的弧 → 按实际行进方向数 $(-\infty,-1)$ 穿越 → 算 $Z=P-2N$，最后另查虚轴闭环根。
5. **再量裕度**：找齐相关交越，区分幅值倍率 $h$ 与 $h(\mathrm{dB})$；多交越系统不能只挑一个。
6. **读性能或反求参数**：注明模型（是否标准二阶、有无零点）、归一化与近似条件。
7. **回代验收**：用精确频响、闭环极点或实际阶跃响应检查结果。

逐步展开的计算方法与渐近线练习见 [[05-5-3 频域解题套路]] §5.9；确认闭环稳定后再读 [[05-5-1 三频段与闭环频域指标]]；实验辨识与 MATLAB 见 [[05-5-2 频率特性的实验确定与MATLAB]]；校正设计接 [[06-1 串联校正（超前·滞后·滞后-超前）]]。

> [!warning] 三处最容易混用
> **图的叠加**：串联环节的**对数**幅值与相角可相加；奈氏图上的复数不能直接相加。
>
> **判稳与裕度**：先按完整计数判稳，再解释裕度；$\gamma<0$ 或 $h(\mathrm{dB})<0$ 不能单独用来否定闭环稳定（$P>0$ 时允许为负）。
>
> **精确与近似**：渐近线读数、二阶近似与高阶经验式都要注明前提，最后用实际闭环响应验收。
