## 🧭 全章主线

**先分清对象，再代公式。** 下表的闭环关系按单位负反馈，$G$ 表示环路传函。

| 对象 | 回答的问题 |
| :-- | :-- |
| 开环 $G(\mathrm j\omega)$ | 画伯德图、奈氏图，判稳并求 $\gamma$、$h$ |
| 闭环 $\Phi=\frac{G}{1+G}$ | 求稳态输出、闭环谐振峰、带宽和阶跃指标 |
| 偏差通道 $\Phi_e=\frac1{1+G}$ | 求输入端偏差；非单位反馈须重新写通道 |

> [!warning] 三处不要混用
> **图的叠加**：串联环节的伯德对数幅值、相角可相加；奈氏图上的复数不能直接相加。
>
> **判稳与裕度**：先按完整计数判稳，再解释裕度；有多个交越时不能只挑一个。
>
> **精确与近似**：渐近线读数、二阶近似和高阶经验式都要注明前提，最后用实际闭环响应验收。

## 🧭 5.11 解题套路

1. **辨对象**：分清环路、闭环与偏差通道，写明反馈方式。
2. **画曲线**：分解环节，定转折频率；幅频与相频分别处理。
3. **先判稳**：统计 $P$，补齐虚轴极点的弧，统一方向后计算 $Z=P-2N$。
4. **再量裕度**：找齐相关交越，区分幅值倍率 $h$ 与 $h_{\mathrm{dB}}$。
5. **读性能或反求参数**：注明模型、归一化与近似条件。
6. **回代验收**：用精确频响、闭环极点或实际响应检查结果。

展开的计算方法与两道渐近线练习见 [[05-3-2 频率特性辨识与解题套路]] §5.9；校正设计接 [[06-1 串联校正（超前·滞后·滞后-超前）]]。
