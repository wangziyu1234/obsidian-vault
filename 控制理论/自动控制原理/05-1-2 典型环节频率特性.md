# 第5章（一-2）典型环节频率特性

> [!abstract] 本讲定位
> **讲什么**：八个典型环节（比例、积分、微分、惯性、一阶微分、振荡、二阶微分、延迟）各自的伯德图与奈氏图特征，以及串进系统后会带来什么。
>
> **对应教材**：§5-2 典型环节与开环系统的频率特性（书内202—209、218页 / PDF210—217、226页）。
>
> **主线**：每个环节只需记三件事——**幅频斜率变化多少、转折频率在哪、相角范围多少**；其余（对系统的影响）都是这三件事的推论。每个环节都配**伯德图 + 幅相曲线**两张图；§5.2 开头把伯德特征与奈氏形状分成两张窄表，不稳定（非最小相位）对应项见 §5.2.6。
>
> **本篇范围**：§5.2 总览表、§5.2.1 比例/积分/微分、§5.2.2 惯性/一阶微分、§5.2.6 非最小相位（不稳定）环节；振荡、二阶微分、延迟见 [[05-1-2-b 振荡·二阶微分与延迟环节]]。
>
> **默认参数**：$K>0$、$T>0$、$\omega_n>0$、$0<\zeta<1$、$\tau\ge0$；非最小相位环节见 [[05-1-3-b 开环幅相图与最小相位]]。

## 📈 5.2 典型环节频率特性

先按“伯德特征”和“奈氏形状”分别查表，不把传函、斜率、相角和图形挤在同一行。下文给出一阶环节；二阶与延迟的传函、推导见 [[05-1-2-b 振荡·二阶微分与延迟环节]]。

**伯德图速查**（斜率单位：dB/dec）

| 环节 | 转折频率与幅频斜率 | 相角范围 |
| :-- | :-- | :-- |
| 比例 | 无转折；恒为 $0$ | $0°$ |
| 积分 | 无转折；恒为 $-20$ | $-90°$ |
| 微分 | 无转折；恒为 $+20$ | $+90°$ |
| 惯性 | $1/T$ 处由 $0$ 变为 $-20$ | $0°\to-90°$ |
| 一阶微分 | $1/T$ 处由 $0$ 变为 $+20$ | $0°\to+90°$ |
| 振荡 | $\omega_n$ 处由 $0$ 变为 $-40$ | $0°\to-180°$ |
| 二阶微分 | $\omega_n$ 处由 $0$ 变为 $+40$ | $0°\to+180°$ |
| 延迟 | 无转折；恒为 $0$ | $-\omega\tau$（rad） |

**奈氏图速查**（正频率支）

| 环节 | 起点、终点与形状 |
| :-- | :-- |
| 比例 | 实轴上的定点 $(K,0)$ |
| 积分 | 沿负虚轴从无穷远趋向原点 |
| 微分 | 沿正虚轴从原点趋向无穷远 |
| 惯性 | 第四象限半圆，从 $(1,0)$ 趋向原点；圆心 $(0.5,0)$，半径 $0.5$ |
| 一阶微分 | 从 $(1,0)$ 出发，沿 $\operatorname{Re}=1$ 竖直向上 |
| 振荡 | 下半平面，穿过 $-\mathrm j/(2\zeta)$，沿 $-180°$ 方向趋向原点 |
| 二阶微分 | 上半平面，穿过 $\mathrm j2\zeta$，位置角趋于 $+180°$、幅值趋于无穷 |
| 延迟 | $\tau>0$ 时沿单位圆顺时针无限绕转；$\tau=0$ 时退化为定点 $1$ |

> [!note] 分类与边界
> 以上是八个**常用**环节，不是“八个最小相位环节”。非零纯延迟不属于最小相位环节；教材的分类口径与负比例例外见 5.2.6。

### 5.2.1 比例、微分、积分

**比例环节** $G(s)=K$，频响仍是实常数 $K$。

$
A(\omega)=K
$

$
\varphi(\omega)=0°
$

- 幅频：一条 $20\lg K$ dB 水平线；相频：恒为 $0°$；转折频率无（—）。
- 作用：只整体缩放幅值——$K>1$ 上移、$0<K<1$ 下移；变化量为 $20\lg K$ dB，不引入相移、不改变型别。
- 影响：仅改变开环增益，从而影响稳态精度与幅值裕度。

![[频域-典型环节-比例Bode.png|430]]

![[频域-典型环节-比例Nyquist.png|430]]

**积分环节** $G(s)=\frac1s$。

$
G(\mathrm j\omega)=-\frac{\mathrm j}{\omega}
$

$
A(\omega)=\frac1\omega
$

$
\varphi(\omega)=-90°
$

- 幅频：过 $(1,\ 0)$ 点、斜率 $-20$ dB/dec 的直线；相频：恒为 $-90°$；转折频率无（—）。
- 作用：提供积分因子以**提升型别、消除稳态误差**（见 [[03-5 稳态误差]]）。
- 影响：在同一频率处引入 $-90°$ 相角滞后。

![[频域-典型环节-积分Bode.png|430]]

![[频域-典型环节-积分Nyquist.png|430]]

**微分环节** $G(s)=s$。

$
G(\mathrm j\omega)=\mathrm j\omega
$

$
A(\omega)=\omega
$

$
\varphi(\omega)=+90°
$

- 幅频：过 $(1,\ 0)$ 点、斜率 $+20$ dB/dec 的直线；相频：恒为 $+90°$；转折频率无（—）。
- 作用：在同一频率处引入超前相角，可用于改善动态性能；需兼顾可实现性与高频噪声。
- 与积分**互为倒数**：$A_2=\frac1{A_1}$、$\varphi_2=-\varphi_1$，对数幅频关于 0 dB 线对称、相频关于 $0°$ 线对称（见 [[05-1-3-b 开环幅相图与最小相位]]）。

![[频域-典型环节-微分Bode.png|430]]

![[频域-典型环节-微分Nyquist.png|430]]

### 5.2.2 惯性、一阶微分

**惯性环节** $G(s)=\frac1{Ts+1}$（$T>0$）：$G(\mathrm j\omega)=\frac1{1+\mathrm jT\omega}$，

$$
A(\omega)=\frac{1}{\sqrt{1+T^2\omega^2}}
$$

$$
\varphi(\omega)=-\arctan T\omega
$$

转折频率 $\omega=\frac1T$ 处相角 $\varphi=-45°$、$A=\frac1{\sqrt2}$（$L=-3$ dB）。

- 幅频由 $0$ dB 转为以 $-20$ dB/dec 下降，相角由 $0°$ 单调降至 $-90°$。
- **影响**：高频渐近线增加 $-20$ dB/dec 斜率，同一频率处增加相角滞后。
- $T$ 越大，转折越低、滞后越早。

![[频域-典型环节-惯性Bode.png|430]]

![[频域-典型环节-惯性Nyquist.png|430]]

**惯性环节的幅相曲线怎么画**（逐点描点；以 $T=0.5$ 为例，$G(s)=\frac{1}{0.5s+1}=\frac{2}{s+2}$）：

| $\omega$ | 极坐标 | 直角坐标 |
|:--|:--|:--|
| $0$ | $1\angle0°$ | $1+\mathrm j0$ |
| $0.6$ | $0.958\angle-16.7°$ | $0.92-\mathrm j0.27$ |
| $1$ | $0.894\angle-26.6°$ | $0.8-\mathrm j0.4$ |
| $2=1/T$ | $0.707\angle-45°$ | $0.5-\mathrm j0.5$（最低点） |
| $4$ | $0.447\angle-63.4°$ | $0.2-\mathrm j0.4$ |
| $8$ | $0.243\angle-76.0°$ | $0.06-\mathrm j0.24$ |
| $\infty$ | $0\angle-90°$ | $0+\mathrm j0$ |

![[频域-惯性环节-描点.png|430]]
*逐点描出的第四象限半圆：$\omega=1/T$ 处最低 $(0.5,-0.5)$，把 $\omega\to\infty$ 的点补在原点即闭合成半圆。*

- 实用画法：先定**三个特殊点**（$\omega=0$、$\omega=1/T$、$\omega\to\infty$），中间再补 2—3 点连线，草图就够了；矢量法见 [[05-1-1-a 矢量法与频率特性图示]]；在 $\omega=1/T$ 处，环节相角为 $-45°$，曲线恰到最低点。
> [!derivation] 为什么轨迹是半圆？
> 把实部 $\frac1{1+\omega^2T^2}$ 与虚部 $\frac{-\omega T}{1+\omega^2T^2}$ 代入，可得
>
> $$
> \left(\operatorname{Re}G-\frac12\right)^2+(\operatorname{Im}G)^2=\frac14
> $$
>
> 再结合正频率时虚部非正，取圆的下半部分。

**一阶微分环节** $G(s)=Ts+1$：$G(\mathrm j\omega)=1+\mathrm jT\omega$，

$$
A(\omega)=\sqrt{1+T^2\omega^2}
$$

$$
\varphi(\omega)=+\arctan T\omega
$$

转折频率 $\omega=\frac1T$ 处相角 $\varphi=+45°$。

- 幅频由 $0$ dB 转为以 $+20$ dB/dec 上升，相角由 $0°$ 升至 $+90°$。
- **影响**：引入超前相角、抵消惯性滞后，常作串联校正用（见 [[06-1 串联校正（超前·滞后·滞后-超前）]]）。
- 与惯性互为倒数，对数幅频关于 0 dB 对称、相频关于 $0°$ 线对称（见 [[05-1-3-b 开环幅相图与最小相位]]）。

### 5.2.6 最小相位与非最小相位（不稳定）典型环节

**按教材的典型环节口径**，前七种正参数环节归为最小相位一组；积分、微分的原点因子单独按型别处理，并不因此成为渐近稳定系统。

- **四类一阶、二阶镜像环节**：把一次项系数变号，得到右半平面零点或极点；对应两项的幅频相同、相频反号，奈氏图关于实轴对称。
- **负比例是单独的符号项**：$-K$（$K>0$）只额外增加 $180°$ 相移，本身没有零极点，不能说“必有右半平面零极点”。
- **非零纯延迟**：幅值为 $1$、相位持续滞后，不在教材这十二种有理典型环节的列表中。

五种非最小相位对应项的传函表、两组镜像配图，以及“镜像”和“取倒数”的区别，统一见 [[05-1-3-b 开环幅相图与最小相位]] 5.3.3，不在两篇中重复展开。

## ⚠️ 边界与易错

**环节相角 ≠ 系统裕度**

- 惯性在同一频率处滞后、微分在同一频率处超前，但串入环节还会**移动交越频率** $|G(\mathrm j\omega_c)|=1$。
- 所以必须重新求 $\omega_c$ 与 $\gamma$，不能由“某频率处加了超前/滞后”直接断言裕度必升/必降；积分环节同理。

**延迟与采样、保持器不是一回事**

- 恒定传输延迟才是 $e^{-\tau s}$；采样开关会造成频谱复制，不是连续时间纯延迟。
- 零阶保持器也不等于纯延迟。设采样周期 $T_s$，归一化零阶保持器的频率特性为

$$
G_{h,n}(\mathrm j\omega)=e^{-\mathrm j\omega T_s/2}\frac{\sin(\omega T_s/2)}{\omega T_s/2}
$$

它还带 sinc 幅值衰减，只在 $\omega T_s\ll1$ 时才能近似成 $T_s/2$ 的延迟。采样、保持与离散系统模型见 [[07-1 采样与z变换]]。

**几个容易记错的边界**

- 振荡环节在**有限正频率**下相角不会达到或越过 $-180°$。
- 正频率谐振峰只在 $0<\zeta<1/\sqrt2$ 时存在；$\zeta\ge1/\sqrt2$ 时幅频单调不增，最大值是 $A(0)=1$。
- 二阶微分环节与振荡环节幅频关于 0 dB 线镜像，别把两者的谷值与峰值位置记混。
- 二阶微分环节若改善快速性与裕度，同样要按新的交越频率与闭环响应核算，不能只看"提供了超前相角"。
