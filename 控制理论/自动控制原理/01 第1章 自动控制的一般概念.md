# 第 1 章 自动控制的一般概念

> [!abstract] 本讲定位
> 自动控制的一般概念：反馈控制原理、系统组成与基本工作方式、开/闭环控制、系统分类、基本要求（稳/准/快）与发展回顾。

## 1.1 自动控制系统的组成和基本工作方式

### 系统组成

自动控制系统按功能由以下基本环节组成：

| 环节 | 作用 |
|:--|:--|
| **被控对象** | 要求实现自动控制的机器、设备或生产过程，其输出即为被控量 |
| **给定元件** | 给出与所希望的被控量值对应的给定信号 $r(t)$ |
| **测量元件** | 测量被控量并转换成可比较的反馈信号 |
| **比较元件** | 将给定信号与反馈信号比较，产生偏差信号 $e(t)$ |
| **控制器（校正元件）** | 对偏差信号进行运算与放大，给出控制规律 |
| **执行元件** | 根据控制信号驱动被控对象，使被控量趋向给定值 |

### 反馈控制原理

**反馈控制原理**：取被控量与给定量比较产生偏差，按偏差进行控制（按偏差调节）。凡能按此原理构成的系统即为闭环（反馈）控制系统。

**闭环信号流（按偏差调节的回路）**：给定信号 $r$ 与由测量元件送回的反馈信号 $b$ 在比较元件处相减，得偏差 $e=r-b$；偏差经控制器运算、放大成控制信号，驱动执行元件带动被控对象，产生被控量 $c$；测量元件再把 $c$ 转换为反馈量 $b=H(s)c$ 送回比较元件，构成**闭合**回路。信号沿回路流动一圈，即完成一次"测量—比较—校正"。

**为什么负反馈能抗扰、提高精度**：

- **误差驱动（按偏差调节）**：只要 $e\neq0$ 就有控制作用，偏差越大校正越强，输出自动向给定值逼进；稳态时 $e\to0$，故能自动消除偏差、抑制扰动。
- **对扰动有抑制作用**：扰动在被控对象处进入，直接反映为输出偏差，负反馈随即产生校正以抵消其影响；而开环系统对扰动无任何补偿。

**闭环增益对参数不敏感（抗参数漂移）**：单位反馈时闭环传递函数

$$
\Phi(s)=\frac{G(s)}{1+G(s)}
$$

当 $|G(j\omega)|\gg1$ 时 $\Phi(s)\approx1$，几乎只由反馈通道（测量元件）决定——前向通道的参数漂移、元件老化对输出的影响被反馈大幅削弱，故精度主要由反馈通道保证。

**开环 vs 闭环一句话总结**：开环只靠顺向作用、无反馈，结构简单、成本低，但无抗扰能力、精度受参数漂移制约；闭环按偏差调节，抗扰、精度高，但引入反馈带来稳定性问题，需在增益与稳定之间折中。

### 基本工作方式

- **开环控制**：控制装置与被控对象之间只有顺向作用、无反馈回路。结构简单、成本低，但无抗扰能力，适用于精度要求不高、扰动小的场合。
- **闭环控制（反馈控制）**：按偏差调节，构成负反馈回路。抗扰、精度高，但存在稳定性问题。
- **复合控制**：反馈 + 前馈（按扰动或按输入补偿），兼取开环补偿与闭环反馈之长。

## 1.2 自动控制系统示例

- **恒值控制系统（工业）**：如恒温箱温度控制、锅炉水位控制、机床主轴恒速控制。给定值恒定，扰动（电网电压、负载、环境温度变化）是主要矛盾，系统任务是抑制扰动使被控量保持恒定。
- **随动系统（跟踪系统）**：如雷达天线自动跟踪目标、火炮瞄准随动系统、机床刀具进给跟踪。输入信号随时间任意变化，系统任务是使输出快速、准确地跟踪输入。
- **程序控制系统（其他领域）**：如数控机床沿预定切削轨迹运动、工业机器人按示教程序作业。输入按预定规律变化，系统按给定时间程序或空间轨迹执行。

三类示例的共同点：它们都构成负反馈闭环，本质是"使被控量以一定精度复现给定（参考）信号"——恒值控制以**抗扰**为主（给定恒定，扰动是主要矛盾，靠反馈抑制扰动使被控量恒定），随动系统以**跟踪**为主（输入任意变化，靠反馈使输出迅速准确地跟上），程序控制系统以**按预定规律执行**为主（输入随给定程序变化，靠反馈保证实际轨迹与预定规律吻合）。

## 1.3 自动控制系统的分类

| 分类依据 | 类型 |
|:--|:--|
| 按给定量变化规律 | **恒值控制系统**（给定值恒定）、**随动系统**（跟踪任意变化输入）、**程序控制系统**（按预定规律变化） |
| 按系统特性（线性/非线性） | **线性系统**（满足叠加原理，可用 $n$ 阶常系数微分方程 $a_nc^{(n)}+\cdots+a_0c=b_mr^{(m)}+\cdots+b_0r$ 描述）、**非线性系统**（含非线性元件，不满足叠加原理，不能用统一传递函数） |
| 按信号形式（连续/离散） | **连续控制系统**（信号为时间连续函数，用微分方程描述）、**离散控制系统**（含采样开关/数字计算机，用差分方程描述） |
| 按变量数（SISO/MIMO） | **单输入单输出系统（SISO）**（一个被控量、一个控制量，可用传递函数分析）、**多输入多输出系统（MIMO）**（多个被控量相互耦合，需用状态空间法） |

**两类反馈控制（开环/闭环）**：

- **开环控制**：无反馈回路，结构简单、无抗扰能力。
- **闭环（反馈）控制**：按偏差调节，抗扰、精度高，但存在稳定性问题。

**其他分类**：定常/时变、线性/非线性、连续/离散采样、单变量/多变量（SISO/MIMO）。

## 1.4 自动控制系统设计的基本要求

### 1.4.1 基本要求（稳/准/快）

对自动控制系统的基本要求可概括为**稳、准、快**：

- **稳（稳定性）**：系统受扰动偏离平衡状态后能自行恢复；对线性定常系统要求闭环极点位于左半 $s$ 平面。
- **准（准确性/稳态精度）**：稳态时输出跟踪给定的精度，取决于系统型别与开环增益。
- **快（快速性/动态性能）**：过渡过程的持续时间与超调大小，取决于闭环阻尼比与自然频率。

三性之间往往相互制约：追求稳定性与准确性常需牺牲快速性，工程上须折中设计。

### 1.4.2 设计概述

自动控制系统的设计一般包括：机理建模（建立微分方程并求解）、推导传递函数与结构图、稳定性与动态性能分析、校正（引入校正装置以满足性能指标）。

**设计的典型步骤**：

1. **建模**：由物理机理（牛顿定律、基尔霍夫定律、转矩平衡等）列写被控对象的微分方程，必要时在工作点线性化；取拉氏变换得传递函数，或用实验方法辨识模型参数。
2. **确定性能指标**：把"稳、准、快"定量化，如超调量 $\sigma\%$、调节时间 $t_s$、稳态误差 $e_{ss}$、相角裕度 $\gamma$、截止频率 $\omega_c$、谐振峰值 $M_r$ 等，并按任务划分主次与优先级。
3. **选型与综合（校正）**：选定控制器结构与参数（P、PI、PID、超前/滞后/超前-滞后校正等），用**根轨迹法**配置主导极点，或用**频域法**整形开环频率特性，使系统满足给定指标。
4. **校验**：检验校正后闭环极点是否落入期望区域、各项指标是否达标、稳定裕度是否足够，不满足则回到第 3 步迭代。
5. **仿真与实验**：用 MATLAB/Simulink 仿真验证，再经半实物或实物实验校核；实测与仿真有出入时，返回修改模型或参数。

**指标间的折中（稳、准、快的矛盾）**：提高开环增益可减小稳态误差（**准**），但往往使振荡加剧、超调增大甚至失稳（**稳**、**快**下降）；增大阻尼比可抑制超调（**快**），却使过渡过程变慢。三性常互相制约，须按任务主次权衡——工程上先保稳定，再求精度与快速性。

**现代设计工具**：借助 MATLAB（含 Simulink 与 Control System Toolbox）完成建模、仿真与参数寻优，并通过**根轨迹**与**频域**两条综合通道（绘制根轨迹、Bode 图、Nichols 图）直观地配置校正装置，这是经典控制设计的标准流程。

## *1.5 自动控制理论的发展回顾和本书内容简介

**发展回顾**：经典控制理论以传递函数为基础，研究单输入单输出定常线性系统的分析与设计，以频率法、根轨迹法为主要工具，解决稳定性与动态性能问题；现代控制理论以状态空间法为基础，研究多输入多输出、时变及非线性系统，能更完整地描述系统的内部状态与内部结构。

**本书内容简介**：第 1 章为绪论，建立自动控制的一般概念；第 2～8 章为经典控制理论——第 2 章控制系统的数学模型、第 3 章线性系统的时域分析法、第 4 章线性系统的根轨迹法、第 5 章线性系统的频域分析法、第 6 章线性系统的校正方法、第 7 章线性离散系统的分析与校正、第 8 章非线性控制系统分析；第 9 章引入现代控制理论——线性系统的状态空间分析与综合（状态空间表达式、状态方程求解、能控性与能观性、稳定性与李雅普诺夫方法、线性定常系统的综合）。

## 1.6 典型外作用（考研补充）

在零初始条件下，系统响应均由以下四种典型输入定义：

| 名称 | 时域 $r(t)$ | 拉氏变换 $R(s)$ | 说明 |
|:--|:--|:--|:--|
| **单位阶跃** | $\begin{cases}0, & t<0 \\[2pt] 1, & t\ge0\end{cases}$ | $\dfrac{1}{s}$ | 最常用，反映恒定给定或突变扰动 |
| **单位斜坡** | $t\cdot 1(t)$ | $\dfrac{1}{s^2}$ | 反映匀速跟踪性能 |
| **单位加速度** | $\dfrac{t^2}{2}\cdot 1(t)$ | $\dfrac{1}{s^3}$ | 反映匀加速跟踪性能 |
| **单位脉冲** | $\delta(t)$ | $1$ | 瞬间冲击，面积 $=1$，理想模型 |

- 实际脉冲函数用宽度 $b$ 的矩形脉冲近似，当 $b$ 远小于系统时间常数时可近似为理想脉冲。
- 正弦函数 $\sin\omega t$ 的拉氏变换 $\dfrac{\omega}{s^2+\omega^2}$ 也是常用输入（用于频域分析）。
- 各输入之间的微分/积分关系，对应输出的同样关系（线性定常系统通性）。

## 1.7 常考概念辨析

| 概念 | 要点 |
|:--|:--|
| 稳/准/快 | 稳定性（稳）→ 极点在左半平面；稳态精度（准）→ 型别与增益；动态性能（快）→ 阻尼比与自然频率 |
| 反馈 vs 前馈 | 反馈按**偏差**调节（闭环），前馈按**扰动/输入**补偿（开环）；前馈不改变稳定性 |
| 线性 vs 非线性 | 线性系统满足叠加原理、可定义传递函数；非线性系统不满足叠加、不能用统一传递函数 |
| 恒值 vs 随动 | 恒值：给定恒定，扰动是主要矛盾；随动：输入变化，跟踪性能是主要矛盾 |
| 采样 vs 数字控制 | 采样系统 = 连续对象 + 采样开关；数字系统 = A/D + 数字计算机 + D/A |
