# 第5章（四-3）稳定裕度

> [!abstract] 本讲定位
> **讲什么**：判稳只回答「稳不稳」，裕度回答「**有多稳**」——把环路的相位或增益单独改动时，到临界条件还差多少。
>
> **对应教材**：§5-4 稳定裕度（书内229—234页 / PDF237—242页）。
>
> **两图通用**：$\gamma$、$h$ 的定义对奈氏图与伯德图完全一致，读法不同——奈氏图看曲线与单位圆、负实轴的交点，伯德图看 $0$ dB 线与 $-180°$ 线。

## 🧭 5.4.5 相角裕度与幅值裕度

裕度衡量把环路单独改变相位或增益时，到相关临界条件还差多少。下表按常见的 $-180°$ 相位分支定义；多个交越与其他奇数倍 $180°$ 边界须分别检查。

| 量 | 定义与读取方式 |
| :-- | :-- |
| 截止频率 $\omega_c$ | $A(\omega_c)=1$，即对数幅值为 $0$ dB |
| 相角裕度 $\gamma$ | $\gamma=180°+\varphi(\omega_c)$；在幅值交越处读取 |
| 相角穿越频率 $\omega_g$（教材记 $\omega_x$） | $\varphi(\omega_g)=-180°$；检查该频率处的幅值 |
| 幅值裕度倍率 $h$ | $h=\dfrac1{A(\omega_g)}$；倍率始终为正 |
| 分贝幅值裕度 $h_{\mathrm{dB}}$ | $h_{\mathrm{dB}}=20\lg h$；等于该处对数幅值的相反数 |

![[频域-稳定裕度.png|430]]

*$\gamma$ 在幅值交越处量，$h$ 在相位交越处量：$\gamma$ 是相频曲线到 $-180°$ 线的余量，$h$ 是该处幅值到 $0$ dB 线的余量。*

## 📏 常见设计参考

$$
\gamma=30°\sim60°,\qquad h\ge2
$$

倍率 $2$ 约对应 $6$ dB。中频段通常希望以 $-20$ dB/dec 过零并保持一定宽度，但实际 $\gamma$ 必须由完整相频计算，不能仅凭局部斜率保证；见 [[05-5-1 三频段与闭环频域指标]] §5.5.2。

## ⏱️ 含延迟环节时

$e^{-\tau s}$ 不改幅频，只额外滞后 $\tau\omega$（rad），相角裕度约损失 $57.3°\cdot\tau\omega_c$，对稳定性明显不利。

## 🔁 条件稳定系统

**常考概念**：开环增益只在某一区间内闭环稳定，$K$ 过高或过低都不稳定——奈氏曲线多次穿过 $(-1,\mathrm j0)$ 左侧段。教材例5-8 见 [[05-4-a 奈氏特殊情形与条件稳定]]。

同一系统在 $K=5$ 与 $K=20$ 下的 $\omega_c$、$\gamma$、$h$ 对照，见 [[05-4-d 对数判稳例题]] 例5-14。

## ⚠️ 不能只凭一个裕度下结论

> [!warning] 裕度的三个边界
> **倍率 $h$ 不会为负**：$h>1$ 才等于 $h_{\mathrm{dB}}>0$；$h>0$ 本身不代表有正裕度，负 dB 只表示该倍率小于 $1$。
>
> **简化判稳有前提**：只有「开环无右半平面极点 + 单一相关交越 + 无虚轴闭环根」时，才能用 $\gamma>0$ 且 $h>1$ 直接判稳。
>
> **$P>0$ 时裕度可以为负**：开环不稳定或多次交越时，某些相关交越处出现负 $\gamma$、负 $h_{\mathrm{dB}}$，不能据此否定闭环稳定。必须先按完整奈氏计数，再解释各增益/相位边界。

> [!note] 两个容易推广过头的结论
> **多个截止频率**：应逐一检查相位与相关稳定边界，不能机械地只取最高截止频率。
>
> **$h=\infty$ 的适用范围**：正参数惯性环节、标准正阻尼振荡环节在有限正频率处不与负实轴相交，通常记 $h=\infty$；不能推广到所有带零点、延迟或右半平面极点的一阶、二阶模型。
