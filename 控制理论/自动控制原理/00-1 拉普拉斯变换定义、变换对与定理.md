# 拉普拉斯变换：定义、变换对与定理

> [!abstract] 本讲定位
> 单边拉氏定义、常用变换对、微分/积分与平移等性质，以及初终值定理和复积分的适用条件。

## 定义

$$
\boxed{F(s)=\mathcal L[f(t)]=\int_0^\infty f(t)e^{-st}\,dt}
$$

其中 $s=\sigma+\mathrm j\omega$。本文采用单边变换，外加输入通常取因果信号；普通函数的积分下限写作 0，涉及原点冲激时采用包含 $t=0$ 冲激的 $0^-$ 约定。

反变换（梅林公式，实际计算通常用下文部分分式法查表）：

$$
\begin{aligned}
f(t)&=\mathcal L^{-1}[F(s)]\\[4pt]
&=\frac1{2\pi\mathrm j}\int_{c-\mathrm j\infty}^{c+\mathrm j\infty}
F(s)e^{st}\,ds
\end{aligned}
$$

普通函数变换存在的常用充分条件：$f(t)$ 分段连续且为指数阶，充分大 $t$ 时满足 $\lvert f(t)\rvert\le Me^{\alpha t}$，积分在 $\Re s>\alpha$ 收敛。反演直线 $\Re s=c$ 须位于收敛域内；冲激按广义函数另行理解。

|:--|:--|
| 单位脉冲$\delta(t)$                      | $1$                                    |
| 单位阶跃$1(t)$                           | $\frac{1}{s}$                         |
| 斜坡$t$                                  | $\frac{1}{s^{2}}$                     |
| $t^{n}\ (n=1,2,\dots)$                   | $\frac{n!}{s^{n+1}}$                  |

## 基本定理与重要性质

| 性质 | 公式 |
|:--|:--|
| 线性                   | $\mathcal{L}[af_1+bf_2] = aF_1(s)+bF_2(s)$                                        |
| 微分定理 | $\mathcal L[\dot f]=sF(s)-f(0^-)$ |
| $n$ 阶微分 | $\mathcal L[f^{(n)}]=s^nF(s)-s^{n-1}f(0^-)-s^{n-2}\dot f(0^-)-\cdots-f^{(n-1)}(0^-)$ |
| 积分定理 | $\mathcal L[\int_0^t f(\tau)\,d\tau]=\frac{F(s)}s$ |
| 延迟定理（时域平移） | $\mathcal L[f(t-\tau)1(t-\tau)]=e^{-\tau s}F(s)\quad(\tau\ge0)$ |
| 复位移定理（s 域平移） | $\mathcal{L}[e^{-at}f(t)] = F(s+a)$                                               |
| 相似定理（尺度变换）   | $\mathcal{L}[f(at)] = \frac{1}{a}F\!\left(\frac{s}{a}\right)\ (a>0)$            |
| 复微分                 | $\mathcal{L}[tf(t)] = -\frac{dF(s)}{ds}$                                         |
| 除以 $t$（复积分） | $\mathcal L[\frac{f(t)}t](s)=\int_0^\infty F(s+u)\,du$（须满足下述可积条件） |
| 卷积定理               | $\mathcal{L}[f_1*f_2] = F_1(s)F_2(s)$                                             |
| 初值定理               | $f(0^{+}) = \lim\limits_{s\to\infty}sF(s)$                                        |
| 终值定理               | $\lim\limits_{t\to\infty}f(t) = \lim\limits_{s\to 0}sF(s)$                        |

> [!note] 定理的使用边界
> **微分**：保留 $0^-$ 初值；函数及其相应导数在原点连续时可简写为 $f(0)$。零初始条件下才有 $\mathcal L[f^{(n)}]=s^nF(s)$。
>
> **初值**：$f(0^+)$ 须存在且有限，响应不含原点冲激等奇异项；不能对 $F(s)=1$ 的冲激响应套普通初值定理。
>
> **复积分**：还要求 $f(t)/t$ 在原点附近可积、右端积分收敛；常用充分情形是 $f(0^+)=0$ 且原点附近可微。仅有 $F(s)$ 收敛不够，例如 $e^{-t}/t$ 在原点不可积。

#### ✏️ 复积分例：$\sin t/t$（实数 $s>0$）

$$
\begin{aligned}
\mathcal{L}\left[\frac{\sin t}{t}\right]
&=\int_s^{+\infty}\frac1{1+\sigma^2}\,d\sigma\\
&=\arctan\sigma\Big|_s^{+\infty}\\
&=\frac\pi2-\arctan s=\arctan\frac1s\qquad(s>0)
\end{aligned}
$$

$s>0$ 时，两边同处 $(0,\pi/2)$ 且正切均为 $1/s$，所以 $\frac\pi2-\arctan s=\arctan\frac1s$。数值检查：$s=1$ 时积分为 $\pi/4$；$\sin t/t$ 在原点的极限为 1，满足局部可积条件。

> [!warning] 终值定理先查极点
> 对本章常见的有理象函数及普通响应，先约分，再检查 $sF(s)$ 的所有极点均在严格左半平面，才可按表中公式求有限终值。
>
> 反例：$F(s)=\frac{\omega}{s^2+\omega^2}$（$\omega>0$）对应正弦，无终值；机械代入 $s\to0$ 会误得 0。
