# 附录 频域分析速查

> [!abstract] 附录定位
> 伯德图绘制规则、奈氏判据、稳定裕度、典型环节相角表的**纯速查**。所有推导与例题见 [[05 第5章 线性系统的频域分析法]]（05-1~05-3）。

## 典型环节频率特性

| 环节 | $G(\mathrm{j}\omega)$ | $L(\omega)$（dB） | $\varphi(\omega)$ |
| :-- | :-- | :--: | :--: |
| 比例 $K$ | $K$ | $20\lg K$ | $0°$ |
| 积分 $\dfrac{1}{s}$ | $\dfrac{1}{\mathrm{j}\omega}$ | $-20\lg\omega$ | $-90°$ |
| 微分 $s$ | $\mathrm{j}\omega$ | $20\lg\omega$ | $+90°$ |
| 惯性 $\dfrac{1}{Ts+1}$ | $\dfrac{1}{1+\mathrm{j}\omega T}$ | $\approx\begin{cases}0,&\omega\ll1/T\\-20\lg\omega T,&\omega\gg1/T\end{cases}$ | $-\arctan\omega T$ |
| 一阶微分 $Ts+1$ | $1+\mathrm{j}\omega T$ | $\approx\begin{cases}0,&\omega\ll1/T\\20\lg\omega T,&\omega\gg1/T\end{cases}$ | $+\arctan\omega T$ |
| 振荡 $\dfrac{1}{s^2/\omega_n^2+2\zeta s/\omega_n+1}$ | $\dfrac{1}{1-(\omega/\omega_n)^2+\mathrm{j}2\zeta\omega/\omega_n}$ | $\omega=\omega_n$ 时 $-20\lg2\zeta$（谐振峰） | 超 $-180°$ 时穿越 |

> **分贝换算**：$20\lg2\approx6$ dB，$20\lg3\approx9.5$ dB，$20\lg10=20$ dB。

## 伯德图绘制规则

1. **化尾一标准式**：$G(s)=K\dfrac{(\tau_1s+1)\cdots}{s^\nu(T_1s+1)\cdots}$
2. **画渐近线**：低频段斜率 $-20\nu$ dB/dec，过 $(1,20\lg K)$ 点；每遇一个转折频率 $\omega_i=1/T_i$（或 $1/\tau_i$），斜率变化 $-20$（惯性）或 $+20$（微分）dB/dec
3. **修正**：惯性环节在 $\omega_i$ 处实际值比渐近线低 $3$ dB；振荡环节在 $\omega_n$ 处低 $20\lg2\zeta$ dB
4. **相频**：各因子相角代数和

### 相角速查

| 因子 | 相角 |
| :-- | :-- |
| $\mathrm{j}\omega$ | $+90°$ |
| $\dfrac{1}{\mathrm{j}\omega}$ | $-90°$ |
| $1+\mathrm{j}\omega T$ | $+\arctan\omega T$ |
| $\dfrac{1}{1+\mathrm{j}\omega T}$ | $-\arctan\omega T$ |

> 总相角 = 各因子相角**代数和**（串联叠加）。

## 奈氏判据

$$\boxed{Z=P-2N}$$

- $P$：开环右半平面极点数
- $N$：幅相曲线对 $(-1,\mathrm{j}0)$ 的**净穿越次数**（正穿越 $N_+$ − 负穿越 $N_-$）
- **闭环稳定 ⟺ $Z=0$** ⟺ $N=P/2$

> [!tip] 伯德图判稳（等价）
> 在 $L(\omega)>0$（即 $A(\omega)>1$）的频段内，相频曲线对 $-180°$ 线的正、负穿越差 $N_+-N_-=P/2$。

### 穿越计数规则

| 情况 | 计数 |
| :-- | :-- |
| 幅相曲线**自上而下**穿过负实轴（$-1$ 左侧） | 正穿越 $+1$ |
| 幅相曲线**自下而上**穿过负实轴（$-1$ 左侧） | 负穿越 $-1$ |
| 起/止于负实轴上 | 半次穿越 |
| 含积分环节（$\nu>0$） | 需**补弧**：从 $\omega=0^+$ 逆时针补 $\nu\times90°$ 无穷大圆弧 |

## 稳定裕度

| 裕度 | 定义 | 公式 | 物理意义 |
| :-- | :-- | :-- | :-- |
| **相角裕度** $\gamma$ | $\omega_c$（截止频率）处的相角余量 | $\gamma=180°+\varphi(\omega_c)$ | $\gamma>0$ 才稳定；$\gamma$ 越大越稳定 |
| **幅值裕度** $h$ | $\omega_g$（穿越频率）处的幅值余量 | $h=\dfrac{1}{A(\omega_g)}$ | $h>1$ 才稳定；$h_{dB}=20\lg h$ |

> [!tip] 关键频率
> - **截止频率 $\omega_c$**：$A(\omega_c)=1$（即 $L(\omega_c)=0$ dB）
> - **穿越频率 $\omega_g$**：$\varphi(\omega_g)=-180°$
> - $\gamma$ 和 $h$ 均为正 ⟹ 闭环稳定

## 频域-时域对应

| 频域指标 | 时域指标 |
| :-- | :-- |
| $\omega_c$ 越大 | $t_r$、$t_p$ 越短（响应越快） |
| $\gamma$ 越大 | $\sigma\%$ 越小（超调越小） |
| $h$ 越大 | 稳定裕度越大 |
| $M_r$（谐振峰值）越大 | $\sigma\%$ 越大 |
| $\omega_b$（带宽频率）越大 | 响应越快 |
