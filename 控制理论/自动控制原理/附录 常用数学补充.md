# 附录 常用数学补充

> [!abstract] 本讲定位
> 自控计算中反复用到的数学工具速查；通用三角恒等式见 [[附录 三角与代数补充]]（数学笔记）。

## 复数运算（频域分析基础）

- 表示：$z=a+\mathrm{j}b$（代数）、$z=\lvert z\rvert e^{\mathrm{j}\theta}$（指数）、$z=\lvert z\rvert(\cos\theta+\mathrm{j}\sin\theta)$（三角）；
- 模与辐角：$\lvert z\rvert=\sqrt{a^2+b^2}$；$z\ne0$ 时用 $\theta=\operatorname{atan2}(b,a)$ 定象限。$\arctan(b/a)$ 须补象限，$a=0$ 时单独判断正/负虚轴；$z=0$ 的辐角未定义。
- 共轭：$\bar z=a-\mathrm{j}b$，$z\bar z=\lvert z\rvert^2$；
- 模与辐角运算：$\lvert z_1z_2\rvert=\lvert z_1\rvert\lvert z_2\rvert$；乘法的辐角相加、除法的辐角相减，等式按模 $2\pi$ 理解（除数须非零）。
- **乘除**：模相乘除、辐角相加减（伯德 图"叠加各因子"的理论依据）。
- 欧拉公式：$e^{\mathrm{j}\theta}=\cos\theta+\mathrm{j}\sin\theta$；
- $\cos\theta=\frac{e^{\mathrm{j}\theta}+e^{-\mathrm{j}\theta}}{2}$，$\sin\theta=\frac{e^{\mathrm{j}\theta}-e^{-\mathrm{j}\theta}}{2\mathrm{j}}$。

## 相角计算速查（伯德/奈氏图常用）

下表默认 $\omega>0$、$T>0$、$\omega_n>0$、$\zeta>0$；负频率或右半平面因子须另按象限计算。

| 因子 $G(\mathrm{j}\omega)$ | 相角 $\angle G$ |
|:--|:--|
| $\mathrm{j}\omega$ | $+90°$ |
| $\frac{1}{\mathrm{j}\omega}$ | $-90°$ |
| $1+\mathrm{j}\omega T$ | $\arctan(\omega T)$ |
| $\frac{1}{1+\mathrm{j}\omega T}$ | $-\arctan(\omega T)$ |
| $1+\mathrm j2\zeta\omega/\omega_n-(\omega/\omega_n)^2$ | $\operatorname{atan2}(2\zeta\omega/\omega_n,\,1-(\omega/\omega_n)^2)$；$\omega<\omega_n$ 在第一象限，等于时为 $90°$，大于时在第二象限 |

- 总相角是各因子相角的代数和；绘制伯德图时按需要连续展开，不要每次相加后都强行截回主值区间。

## 分贝换算

- $L(\omega)=20\lg\lvert G(\mathrm{j}\omega)\rvert$；斜率 $-20$ dB/dec 即每十倍频程下降 20 dB；
  常用分贝值：$20\lg 2\approx6$ dB，$20\lg 3\approx9.5$ dB，$20\lg 10=20$ dB，$20\lg 0.1=-20$ dB。
- 幅值裕度以 dB 计为 $h_{dB}=20\lg h$，其中 $h=1/A(\omega_g)$，$\omega_g$ 为相角穿越频率。把开环增益**乘以** $h$，曲线在该频率到达 $(-1,\mathrm j0)$；$h<1$ 时不是“继续增大”增益。若有多个穿越点须分别检查，详见 [[05 第5章 线性系统的频域分析法]]。

## 指数/振荡函数速查（时域响应形态）

- $e^{-at}\sin\omega t$、$e^{-at}\cos\omega t$ 在 $a>0$ 时为衰减振荡；标准二阶欠阻尼模型中 $a=\zeta\omega_n$ 决定包络衰减，振荡角频率为 $\omega=\omega_n\sqrt{1-\zeta^2}$。
- 拉氏变换对：$\mathcal{L}\{e^{-at}\}=\frac{1}{s+a}$；
- $\mathcal{L}\{e^{-at}\sin\omega t\}=\frac{\omega}{(s+a)^2+\omega^2}$；
- $\mathcal{L}\{e^{-at}\cos\omega t\}=\frac{s+a}{(s+a)^2+\omega^2}$（完整表见 [[00 拉普拉斯变换（数学基础）]]）。
