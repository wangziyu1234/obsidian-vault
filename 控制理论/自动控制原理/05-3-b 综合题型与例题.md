# 第5章（三）综合题型与例题

> [!abstract] 本讲定位
> **这一部分讲什么**：两类"由图形反求系统"的题型（闭环幅相、阶跃响应）+ 教材 §5-6 的两个设计案例 + 二阶指标互算例题。
>
> **对应教材**：例5-13、5-15 在 §5-4、§5-5；例5-17、5-18 在 §5-6；题型 5.10.1、5.10.2 来自补充讲义。
>
> **共同链路**：读图取数 → 反解 $\zeta,\omega_n$ → 写闭环 $\Phi(s)$ → 反求开环 $G(s)$ → 正推指标或反推校正装置。
