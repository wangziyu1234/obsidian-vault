# 第5章（一-3）开环频率特性

> [!abstract] 本讲定位
> 开环频率特性：对数渐近线绘制、开环幅相图（奈氏图）要点、最小相位/非最小相位。对应教材第 5 章 5.3。

## 5.3 开环频率特性

### 5.3.1 开环对数频率特性

低频段斜率 $-20\nu$ dB/dec 对应 $\nu$ 型系统；低频段（延长线）在 $\omega=1$ 处高度为 $20\lg K$。

**开环伯德渐近线绘制步骤**：
① 化为时间常数形式，求各转折频率并由小到大排序；
② 低频段斜率 $-20\nu$ dB/dec，过 $(1,\ 20\lg K)$ 点（或其延长线）；
③ 每经过一个转折频率，斜率按环节类型改变（惯性 $-20$、振荡 $-40$、一阶微分 $+20$……）；
④ 相频按各环节相角叠加。

**几何法求解伯德图（斜率-高度换算）**：渐近线每段都是直线，同段上任两点满足

$$
\begin{aligned}
L(\omega_2)&=L(\omega_1)+k\,\lg\frac{\omega_2}{\omega_1}\\[4pt]
&\qquad(k\ 为该段斜率，\mathrm{dB/dec})
\end{aligned}
$$

由此得以下三种用法：

1. **逐段递推求高度**：从 $(1,20\lg K)$（或低频延长线）出发，按上式依次算出每个转折频率处的高度，全图数值即定。
2. **求截止频率**：设穿越段斜率为 $-k$（$k>0$），段上已知点 $(\omega_1, L_1)$（$L_1>0$），则

$$
\omega_c = \omega_1\cdot 10^{L_1/k}
$$

   近似速算：$-20$ 段上高 20 dB 对应 10 倍频、高 6 dB 对应 2 倍频；$-40$ 段上高 40 dB 对应 10 倍频、高 12 dB 对应 2 倍频（20 dB 对应 $\sqrt{10}\approx3.16$ 倍频）。
3. **穿越段直接解析**（等价写法，任取其一）——穿越段的渐近幅频＝$\dfrac{K}{\omega^\nu}$，再对每个**低于该段的转折频率** $\omega_j$ 补一个因子，令其 $=1$ 解出 $\omega_c$：
    - 惯性补 $\dfrac{\omega_j}{\omega}$；
    - 振荡补 $\dfrac{\omega_j^2}{\omega^2}$；
    - 一阶微分补 $\dfrac{\omega}{\omega_j}$。
常用结论：

| 穿越段情形 | $\omega_c$ |
| :-- | :-- |
| Ⅰ 型在 $-20$ 段穿越（$\omega_c<\omega_1$） | $\omega_c = K$ |
| Ⅰ 型在 $-40$ 段穿越（转折 $\omega_1$ 后） | $\omega_c = \sqrt{K\omega_1}$ |
| Ⅱ 型 $\dfrac{K}{s^2(\cdots)}$ 在 $-40$ 段穿越 | $\omega_c = \sqrt{K}$ |
| Ⅰ 型在 $-60$ 段穿越（转折 $\omega_1,\omega_2$ 后） | $\omega_c = \sqrt[3]{K\omega_1\omega_2}$ |

反向应用（由图定参数）：Ⅰ 型低频（延长）线与 0 dB 线交点横坐标 $=K$；Ⅱ 型低频线与 0 dB 交点 $=\sqrt{K}$；任意型别 $\omega=1$ 处（延长线）高度 $=20\lg K$。

![[频域-Bode绘制示例.png|430]]

图中示例 $G(s)=\dfrac{40(0.5s+1)}{s(2s+1)(0.05s+1)}$：
$20\lg K=32$ dB → $L(0.5)=32+20\lg2=38$ dB → $L(2)=38-40\lg4=14$ dB
在 $-20$ 段：$\omega_c=2\times10^{14/20}\approx10$，$\gamma=180°+\varphi(10)\approx55°$。

### 5.3.2 开环幅相图

**开环幅相曲线（奈氏图）要点**：

- 起点（$\omega\to0^+$）：0 型系统起于实轴上 $(K,\mathrm{j}0)$ 点；$\nu$ 型系统起于相角 $-\nu\times90°$ 方向的无穷远处。
- 终点（$\omega\to\infty$）：$n>m$ 时幅值 $\to0$，沿相角 $-(n-m)\times90°$ 方向趋于原点。
- 与负实轴交点：令 $\operatorname{Im}G(\mathrm{j}\omega)=0$ 解出 $\omega$，代入实部求交点坐标（判稳关键点）。

绘制概略幅相曲线抓**三要素**：起点、终点、与实轴交点（再辅以象限/单调性）。常用交点结果——$G(s)=\dfrac{K}{s(T_1s+1)(T_2s+1)}$：

$$
\omega_x = \frac{1}{\sqrt{T_1T_2}},\qquad
G(\mathrm{j}\omega_x) = -\frac{KT_1T_2}{T_1+T_2}
$$

（推导：$\varphi=-180°$ ⇔ $\arctan T_1\omega+\arctan T_2\omega=90°$ ⇔ $T_1T_2\omega^2=1$。）
Ⅰ 型系统起始段还有**渐近线** $\operatorname{Re}=-K\sum T_i$（各惯性时间常数之和），概略图中起始段沿它下探。

### 5.3.3 最小相位与非最小相位

- **最小相位系统**：开环零极点均在左半平面，幅频与相频一一对应，可由 $L(\omega)$ 曲线确定传递函数。

![[自控-频域-最小相位.png|430]]
*惯性 $1/(Ts+1)$ 与不稳定惯性 $1/(1-Ts)$：幅频完全相同，相频关于 $0°$ 线对称*

**非最小相位环节**（教材 §5-2）：与对应最小相位环节相比仅参数符号相反——**幅频相同、相频互为相反数（幅相曲线关于实轴对称），对数幅频相同、对数相频关于 $0°$ 线对称**。共五类（$T>0,\ 0<\zeta<1$）：

| 非最小相位环节 | 传递函数 | 相频特点 |
|:--|:--|:--|
| 比例 $K<0$ | $-K$ | $\varphi\equiv-180°$ |
| 不稳定惯性 | $\dfrac{1}{1-Ts}$ | $0°\to+90°$（对应惯性 $0°\to-90°$） |
| 非最小相位一阶微分 | $1-Ts$ | $0°\to-90°$（对应一阶微分 $0°\to+90°$） |
| 不稳定振荡 | $\dfrac{\omega_n^2}{s^2-2\zeta\omega_ns+\omega_n^2}$ | $0°\to+180°$（对应振荡 $0°\to-180°$） |
| 非最小相位二阶微分 | $\dfrac{s^2}{\omega_n^2}-\dfrac{2\zeta}{\omega_n}s+1$ | $0°\to-180°$（对应二阶微分 $0°\to+180°$） |

**互为倒数的环节**（教材式 5-30/5-31）：$G_2(s)=\dfrac{1}{G_1(s)}$ 时 $A_2=\dfrac{1}{A_1}$、$\varphi_2=-\varphi_1$，故**对数幅频关于 0 dB 线对称、对数相频关于 $0°$ 线对称**。
典型对：积分 ↔ 微分、惯性 $\dfrac{1}{Ts+1}$ ↔ 一阶微分 $Ts+1$、振荡 ↔ 二阶微分（非最小相位环节中同样成立）。
