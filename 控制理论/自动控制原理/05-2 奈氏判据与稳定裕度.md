## 🧭 5.4 频域稳定性判据

本节判稳对象是环路 $G(s)H(s)$；单位反馈时简写为 $G(s)$。下文 $A$、$\varphi$ 都指**环路的**幅值与相角，不能换成闭环量。

### 两个核心式子

$$
\boxed{Z=P-2N}
$$

$$
\boxed{N=N_+-N_-}
$$

$Z$ 是闭环右半平面极点数；**$Z=0$ 且无虚轴闭环根**才算闭环稳定。

### 5.4.1 符号的含义与判据分工

**三个符号。**

| 符号 | 含义 | 易错 |
| :--: | :-- | :-- |
| $P$ | 开环**右半平面**极点数 | **不含**虚轴极点；$P=0$ 不等于开环渐近稳定 |
| $Z$ | 闭环右半平面极点数 | $Z=0$ 还要另查虚轴闭环根 |
| $N_+$、$N_-$ | 正频率半支（含必要补弧）在 $(-1,\mathrm j0)$ **左侧**负实轴上，自上而下／自下而上的穿越次数 | 两者都按**非负**次数记 |

**为什么要拿 $P$ 和曲线一起算。** 闭环特征方程是

$$
F(s)=1+G(s)H(s)=0
$$

$F$ 的零点就是闭环特征根，$F$ 的极点来自开环。所以不能只看开环稳不稳。

> [!note] $P=0$ 不等于「开环渐近稳定」
> $1/s$ 有虚轴极点，$P=0$ 却不是开环渐近稳定。再看单位负反馈 $G(s)=\frac{K}{s(s+1)}$，特征方程 $s^2+s+K=0$ 对**所有 $K>0$** 都稳定，不能拿它说明「增大增益一定失稳」。

**与另两个判据的分工**（三者研究的是同一个闭环特征方程）：

| 判据 | 看什么 | 代价 |
| :-- | :-- | :-- |
| [[04 第4章 线性系统的根轨迹法\|根轨迹]] | 随参数变化，特征根往哪跑 | 要逐条画轨迹 |
| [[03-4 高阶系统、稳定性与校正\|劳斯判据]] | 由多项式系数直接算右半平面根数 | 只给根数，不给位置 |
| 奈氏判据 | 不解方程，只用开环曲线算 $Z=P-2N$ | 要画对曲线、数对穿越 |

### 5.4.2 幅角原理与奈氏判据

**先定围线方向，再定正负号。**

对**逆时针**围线，幅角原理为

$$
\Delta_\Gamma\arg F=2\pi(Z-P)
$$

奈氏判据用的 D 形围线走的是**顺时针**：沿虚轴由 $-\mathrm j\infty$ 到 $+\mathrm j\infty$，再沿右侧无穷大半圆返回。所以改成

$$
\Delta_\Gamma\arg F=2\pi(P-Z)
$$

虚轴上的开环极点用小右半圆绕过，留在围线外面。又因为 $F=1+GH$ 相对 $GH$ 只是平移一个单位，$F$ 绕原点的净圈数就等于 $GH$ 绕 $(-1,\mathrm j0)$ 的净圈数。

> [!tip] 两种记法，选一种用到底
> - **整条奈氏曲线**（正、负频率支 + 补弧）：逆时针净圈数记 $W$，则 $Z=P-W$。
> - **半支穿越法**（教材用法：正频率支 + 补弧）：记 $N=N_+-N_-$；由共轭对称 $W=2N$，故 $Z=P-2N$。
>
> 用了半支计数，就不要再把负频率半支加进 $N$。

### 5.4.3 虚轴极点的补弧与穿越计数

开环有虚轴**极点**时，半闭合曲线要补上无穷大半径的弧（教材书内224—228页）。

| 极点情况 | 画法 | 数法 |
| :-- | :-- | :-- |
| 原点有 $\nu$ 重极点（低频系数为正） | 从 $\omega=0^+$ 的端点**逆时针**画 $\nu\times90°$ 到正实轴方向 | 按围线行进方向，从正实轴端沿弧**顺时针**走到 $\omega=0^+$，再沿 $\omega$ 增大方向走正常段 |
| 非零虚轴极点 $\mathrm j\omega_0$ 为 $q$ 重 | 小右半圆映射成行进方向**顺时针** $q\times180°$ 的弧 | 穿越左侧负实轴的部分同样计入 |

> [!note] 虚轴上的**零点**不用补弧
> 开环零点落在 $\mathrm j\omega_0$ 时，$G(\mathrm j\omega_0)=0$，两侧的图像在**原点**自动接上，不产生无穷远补弧，也没有真正的相角跳变——只有用主值 $\arctan$ 分两段写相角时，才会看到 $-101.3°$ 跳到 $-281.3°$ 这种账面跳变。完整例题见 [[05-2-c-1 例题·虚轴零点与奈氏判据|习题5-16]]。

> [!warning] 画的方向 ≠ 数的方向
> 原点补弧画起来是逆时针，计数却要沿它顺时针走一圈。三个具体算例见 [[05-2-c 奈氏特殊情形与条件稳定]]，虚轴零点的不补弧情形见 [[05-2-c-1 例题·虚轴零点与奈氏判据|习题5-16]]。

**穿越怎么记。**

| 曲线动作 | 计数 |
| :-- | :-- |
| 自上而下穿过 $(-\infty,-1)$ | $N_+$ 加 $1$ |
| 自下而上穿过 $(-\infty,-1)$ | $N_-$ 加 $1$ |
| 由上方止于、或向下方起于该轴 | **正半次**；反方向为负半次 |
| 只相切、没有穿过 | 贡献 $0$ |

### 5.4.4 对数频率稳定判据（伯德图判稳）

在 $L(\omega)>0$ 的频段内数相频曲线对 $(2k+1)180°$ 线的穿越，判稳式子不变。由 $Z=P-2N=0$ 得

$$
\boxed{N_+-N_-=\frac{P}{2}}
$$

$P=0$ 且无虚轴闭环根时，就是**正、负穿越次数相等**。

**两图对应关系。**

| 极坐标图 | 伯德图（只在 $L(\omega)>0$ 段数） |
| :-- | :-- |
| 自上而下穿 $(-\infty,-1)$，正穿越 | 相角**增大**（相频自下而上）穿 $(2k+1)180°$ |
| 自下而上穿 $(-\infty,-1)$，负穿越 | 相角**减小**（相频自上而下）穿 $(2k+1)180°$ |
| 起点或终点落在该轴上 | 起止于 $(2k+1)180°$ 线，按半次计 |

> [!derivation] 为什么两张图的“上下方向”相反？
> 在负实轴附近，令 $\varphi=-180°+\delta$，虚部随小角度变化近似为 $-A\delta$（$\delta$ 按弧度）。
>
> 相角从 $-181°$ 增至 $-179°$，虚部从正变负，是奈氏图的自上而下，即正穿越；相角减小则反过来。

两种判据完全等价：伯德图上相频穿越 $-180°$，正对应奈氏图穿过 $(-1,\mathrm j0)$ 左侧负实轴，$N$ 相同、结论一致。伯德图的优点是幅值、相位分画两张图，数值分级直观、便于手绘。

**逐点核对一例**（下图，$G=\frac{5}{s(s+1)(0.5s+1)}$）：相角由 $\omega=1$ 处的 $-161.6°$ 降到 $\omega=2$ 处的 $-198.4°$，相角**减小**，对应负穿越。

![[自控-频域-伯德判稳.png|520]]

*伯德图判稳示例 $G=\frac{5}{s(s+1)(0.5s+1)}$：只在 $L(\omega)>0$ 段（浅蓝区）数穿越——相频在 $\omega=\sqrt2$ 处由 $-161.6°$ 继续降到 $-198.4°$，相角减小（相频自上而下穿 $-180°$），是负穿越 $1$ 次。$P=0$、$N=0-1$，故 $Z=P-2N=2$：闭环有两个右半平面极点，不稳定。*

> [!warning] “相角减小”与“奈氏图上自下而上”是同一件事
> 同一段穿越，两张图记录的东西不同，别用其中一个去反推另一个：
>
> - **伯德图**记的是**连续相角**：$-161.6°\to-198.4°$，数值在减小；
> - **奈氏图**记的是**曲线走向**：$\operatorname{Im}G$ 由 $-1$（$\omega=1$）经 $0$（$\omega=\sqrt2$）变为 $+0.25$（$\omega=2$），曲线**自下而上**穿过 $(-1,\mathrm j0)$ 左侧负实轴——[[05-2-b 频域判稳例题]] 例1 的“自下而上”是对的。
>
> 两者一致：$-198.4°$ 与 $+161.6°$ 只差 $360°$，是同一位置的两种写法（$198.43°=180°+\arctan\frac13$，落在第三象限）。上表“相角减小 ↔ 负穿越”一行正是这条对应关系；判 $N$ 的符号请以奈氏图的实际走向为准。

**两条常被漏掉的规则。**

- $L(\omega)<0$ 段（幅值已小于 $1$，曲线在单位圆内）不可能包围 $(-1,\mathrm j0)$，那一段的相频起伏**不计入** $N$。
- 开环含积分环节或等幅振荡环节时，先补 $\nu\times90°$（或 $l\times180°$）虚直线；**补出来的虚直线带来的穿越一律算负穿越**（教材 §5-3.3）。

相频画法不唯一、补线带来的半次穿越，见 [[05-2-d 对数判据与稳定裕度例题]]。

### 5.4.5 相对稳定性：相角裕度与幅值裕度

裕度衡量把环路单独改变相位或增益时，到相关临界条件还差多少。下表按常见的 $-180°$ 相位分支定义；多个交越与其他奇数倍 $180°$ 边界须分别检查。

| 量 | 定义与读取方式 |
| :-- | :-- |
| 截止频率 $\omega_c$ | $A(\omega_c)=1$，即对数幅值为 $0$ dB |
| 相角裕度 $\gamma$ | $\gamma=180°+\varphi(\omega_c)$；在幅值交越处读取 |
| 相角穿越频率 $\omega_g$（教材记 $\omega_x$） | $\varphi(\omega_g)=-180°$；检查该频率处的幅值 |
| 幅值裕度倍率 $h$ | $h=\frac1{A(\omega_g)}$；倍率始终为正 |
| 分贝幅值裕度 $h_{\mathrm{dB}}$ | $h_{\mathrm{dB}}=20\lg h$；等于该处对数幅值的相反数 |

![[频域-稳定裕度.png|430]]

*$\gamma$ 在幅值交越处量，$h$ 在相位交越处量：$\gamma$ 是相频曲线到 $-180°$ 线的余量，$h$ 是该处幅值到 $0$ dB 线的余量。*

**常见设计参考**（不是对任意系统都适用的判稳定理）：

$$
\gamma=30°\sim60°,\qquad h\ge2
$$

倍率 $2$ 约对应 $6$ dB。中频段通常希望以 $-20$ dB/dec 过零并保持一定宽度，但实际 $\gamma$ 必须由完整相频计算，不能仅凭局部斜率保证；见 [[05-3-1 三频段与闭环频域指标]] 5.5.2。

**含延迟环节时**：$e^{-\tau s}$ 不改幅频，只额外滞后 $\tau\omega$（rad），相角裕度约损失 $57.3°\cdot\tau\omega_c$，对稳定性明显不利。

**条件稳定系统**（常考概念）：开环增益只在某一区间内闭环稳定，$K$ 过高或过低都不稳定——奈氏曲线多次穿过 $(-1,\mathrm j0)$ 左侧段。教材例5-8 见 [[05-2-c 奈氏特殊情形与条件稳定]]。

![[频域-奈氏判稳补弧.png|520]]

*原点补弧与穿越计数：画弧是逆时针，计数要沿弧顺时针走回 $\omega=0^+$，再沿频率增大方向数正常段。*

同一系统在 $K=5$ 与 $K=20$ 下的 $\omega_c$、$\gamma$、$h$ 对照，见 [[05-2-d 对数判据与稳定裕度例题]] 例5-14。

## ⚠️ 边界与易错

### 适用前提

| 条件 | 说明 |
| :-- | :-- |
| 实系数负反馈 | 判据只对这类系统成立 |
| 无隐对消 | 不稳定零极点的隐对消要单独排除 |
| $P$ 的定义 | **不含**虚轴极点；$P=0$ 不等于开环渐近稳定 |
| 稳定的完整含义 | $Z=0$ **且无虚轴闭环根**；曲线正好穿过 $(-1,\mathrm j0)$ 时不能直接判稳，要单独查根 |
| 连续相位 | $\gamma$ 里的 $\varphi(\omega_c)$ 取连续相位；一般还应检查其他奇数倍 $180°$ 的交越 |
| 只在 $L>0$ 段数 | $L(\omega)<0$ 段的相频起伏不计入 $N$ |

### 常见错法

| 错法 | 正确做法 |
| :-- | :-- |
| 把 $N_-$ 先记成负数再减一次 | $N_+$、$N_-$ 都是非负数，只在最后作差 |
| 用了半支计数，又把负频率支加进 $N$ | 二选一，用到底 |
| 把画补弧的方向当成计数方向 | 画是逆时针，计数要顺时针走 |
| 虚轴上的**零点**也照极点补一段大弧 | 零点处 $G=0$，图像收于原点、连续，**不补弧** |
| 有积分或等幅振荡环节却不补虚直线 | 先补 $\nu\times90°$ 或 $l\times180°$ |
| 补出来的穿越当成正穿越 | **补弧带来的穿越一律算负穿越** |

### 不能只凭一个裕度下结论

> [!warning] 裕度的三个边界
> **倍率 $h$ 不会为负**：$h>1$ 才等于 $h_{\mathrm{dB}}>0$；$h>0$ 本身不代表有正裕度，负 dB 只表示该倍率小于 $1$。
>
> **简化判稳有前提**：只有「开环无右半平面极点 + 单一相关交越 + 无虚轴闭环根」时，才能用 $\gamma>0$ 且 $h>1$ 直接判稳。
>
> **$P>0$ 时裕度可以为负**：开环不稳定或多次交越时，某些相关交越处出现负 $\gamma$、负 $h_{\mathrm{dB}}$，不能据此否定闭环稳定。必须先按完整奈氏计数，再解释各增益/相位边界。

> [!note] 两个容易推广过头的结论
> **多个截止频率**：应逐一检查相位与相关稳定边界，不能机械地只取最高截止频率。
>
> **$h=\infty$ 的适用范围**：正参数惯性环节、标准正阻尼振荡环节在有限正频率处不与负实轴相交，通常记 $h=\infty$；不能推广到所有带零点、延迟或右半平面极点的一阶、二阶模型。
