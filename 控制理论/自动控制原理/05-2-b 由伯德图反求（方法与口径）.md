>
> **配套**：正向绘图（尾1标准化、修正、三条自检）见 [[05-2-1 开环伯德图（画法·相频·修正）]]；反求出的频率在奈氏图上的落点见 [[05-3-a 伯德图与奈氏图的点对应]]；用伯德图判稳见 [[05-4-d 对数判稳例题]]。

> [!tip] 🎯 考点速记
> - **反求三要素**：低频段斜率 $-20\nu$ dB/dec 定型别；低频**延长线**高度定 $K$（$\omega=1$ 处 $20\lg K$）；**折点频率定 $T_j=1/\omega_j$**；斜率增量定环节类型。
> - **钉住低频线的三种取法**：① 任取一点 $\lg K=\frac{L_a(\omega_a)}{20}+\nu\lg\omega_a$；② $\omega=1$ 处 $K=10^{L_a(1)/20}$；③ 延长线与 0 dB 交点 $\omega_0=K^{1/\nu}$——**$\nu=0$ 没有入口③**。
> - **Ⅱ 型速算**：$\omega_c$ 落在 $-20$ dB/dec 段时 $K=\omega_1\omega_c$，即 $\omega_0^2=\omega_1\omega_c$（$\omega_0$ 是两者的几何平均，在对数轴上居中）。
> - **三类定式**：一阶（水平线＋一折点，$K=10^{L/20}$、$T=1/\omega_1$）；二阶振荡（**峰高扣基线**得 $M_r$ → 解 $\zeta$ → $\omega_n=\omega_r/\sqrt{1-2\zeta^2}$）；Ⅱ 型（先定 $K$，$\zeta$ 由峰按 $\Delta L=-20\lg2\zeta$ 反解）。
> - **只凭幅频反求三前提**：**最小相位**、**有频率标定**、$\zeta<\frac1{\sqrt2}$ 才有峰；两处翻车——解 $\zeta$ 的两根要**靠「图上有没有峰」舍大根**、**峰高必须先扣基线**。

## 📈 5.11 由伯德图反求传函

### 5.11.1 反求三要素

**低频定 $K$ 与 $\nu$，转折定时间常数，斜率定环节类型。** 三句话之外都是细节。

| 图上读什么 | 反求什么 | 判据 |
| :-- | :-- | :-- |
| 低频段斜率 | 型别 $\nu$ | $-20\nu$ dB/dec |
| 低频段（延长线）高度 | 总增益 $K$ | $\omega=1$ 处高 $20\lg K$；**延长线与 $0$ dB 线的交点** $\omega_0=K^{1/\nu}$（Ⅰ 型即 $K$，Ⅱ 型即 $\sqrt K$） |
| 每个折点的频率 | 时间常数 | $T_j=1/\omega_j$，振荡环节记 $\omega_n$ |
| 每个折点的斜率增量 | 环节类型 | $-20$ 惯性 · $+20$ 一阶复合微分 · $-40$ 振荡（或两惯性）· $+40$ 二阶复合微分 |
| 谐振峰高（扣掉基线后） | 阻尼比 $\zeta$ | $M_r=\dfrac{1}{2\zeta\sqrt{1-\zeta^2}}$ |
| 相频两端 | 交叉验证 | 起点 $-90°\nu$，终值 $-90°(n-m)$ |

四步走完要回代三遍：**数值**（分段折线的高度）、**相频**（惯性折点 $±45°$、振荡环节 $\omega_n$ 处 $-90°$）、**奈氏图的落点**（见 [[05-3-a 伯德图与奈氏图的点对应]]），三处都对上才算定案。

### 5.11.2 型别与增益：钉住低频渐近线的三种取法

**低频段（第一个交接频率之前）只有一条直线**，两个未知数 $K$ 与 $\nu$，所以**再钉一个点就定死**：

$$
L_a(\omega)=20\lg K-20\nu\lg\omega
$$

教材 §5-2.4（式5-55—式5-57，书内215—216页）给了三种取点法，**三者完全等价，只是图上好不好读不同**：

| 取法 | 取哪个点 | 公式 | 什么时候最好用 |
| :-- | :-- | :-- | :-- |
| **方法一** 任取一点算高度 | 低频直线上任意 $(\omega_a,L_a)$ | $\lg K=\dfrac{L_a(\omega_a)}{20}+\nu\lg\omega_a$ | 图上已经标出某个 $\omega$ 的高度／给了坐标点时 |
| **方法二** 取 $\omega=1$ | 延长线与 $\omega=1$ 竖线的交点 | $L_a(1)=20\lg K$，即 $K=10^{L_a(1)/20}$ | $\omega=1$ 落在低频段内（0 型、Ⅰ 型通常如此） |
| **方法三** 取 $L_a(\omega_0)=0$ | 延长线与 $0$ dB 线的交点 | 见下式 | Ⅱ 型题：交点落在横轴附近，比量高度直观 |

三种取法都要**先把低频直线延长**到要用到的位置（图上画虚线），延长出来的那一段不是曲线的一部分，只是读数辅助。方法一、二的口径与正向画法一致（见 [[05-2-1 开环伯德图（画法·相频·修正）]] §5.3），本篇只讲反求侧。

方法三的式子：

$$
20\lg\frac{K}{\omega_0^{\nu}}=0
\ \Longrightarrow\
K=\omega_0^{\nu},\qquad \omega_0=K^{1/\nu}
$$

$\nu=1$ 时退化为 $K=\omega_0$，$\nu=2$ 时 $K=\omega_0^2$。**$\nu=0$ 没有这个入口**——低频是水平线，一般不与 $0$ dB 相交，只能走方法一或二。

![[频域-反求-低频延长线与ω0.png|430]]

三种型别的低频延长线都过同一个点 $(1,\,20\lg K)$：把它当作"钉子"，从它出发斜着画 $\nu$ 段，落到 $0$ dB 线上就是 $\omega_0$。方法二读的是这个点的高度，方法三读的是斜线落到横轴的位置——同一条线，两种读法。

Ⅱ 型还有一条等价速算：**$\omega_c$ 落在 $-20$ dB/dec 段时 $K=\omega_1\omega_c$**，于是

$$
\omega_0^2=\omega_1\omega_c
$$

即 $\omega_0$ 是 $\omega_1$ 与 $\omega_c$ 在对数轴上的中点（几何平均）。三种取法在同一道题上各演一遍、得到同一个答案，见 [[05-2-e 伯德图反求例题]] 例5.26。

课件的同型例（Ⅰ 型，低频段 $-20$ dB/dec）：红虚线就是低频段的延长线，它与 $0$ dB 线的交点直接标成 $K$；粉色水平线把 $\omega_1$ 处的高度搬到 $-20$ 段上，于是 $K=\omega_1\omega_c$ 一眼可见。

![[自控-频域-反求延长线与K.png|430]]

### 5.11.3 三类系统的定式

| 系统 | 图上特征 | 反求动作 |
| :-- | :-- | :-- |
| **一阶**（$\nu=0$） | 低频水平线高 $20\lg K$，一个折点 $\omega_1$ | $K=10^{L/20}$，$T=1/\omega_1$；相频在折点恰 $-45°$ |
| **二阶振荡**（$\nu=0$） | 水平线 + 谐振峰 $\omega_r$，峰后 $-40$ dB/dec | 峰高**扣基线**得 $M_r$ → 解 $\zeta$（两根取小）→ $\omega_n=\omega_r/\sqrt{1-2\zeta^2}$，并与相频 $-90°$ 处互验 |
| **Ⅱ 型**（$\nu=2$） | 低频 $-40$ dB/dec，$\omega_1$ 处折 $-20$，$\omega_2$ 处折 $-60$ | 先由 $\omega_0$ 或 $\omega_c$ 定 $K$（见 §5.11.2），$\zeta$ 由 $\omega_2$ 处谐振峰按 $\Delta L=-20\lg2\zeta$ 反解 |

## ⚠️ 边界与易错

**只凭幅频反求的前提**

- 必须**最小相位**（无右半平面零点／极点、无延迟），否则同一条幅频可以对应多个相频模型；
- 曲线必须有**频率标定**，否则只能得到归一化形状，定不出 $\omega_n$；
- 只有 $\zeta<1/\sqrt2$ 才有正频率谐振峰，"峰高 $=M_r$"才成立；$\zeta\ge1/\sqrt2$ 时改用 $\omega_n$ 处幅值 $\zeta=1/(2A_{\mathrm{osc}}(\omega_n))$ 等入口，见 [[05-5-b-1 频域反求与教材设计案例]]。

**两处最常翻车**

- **解 $\zeta$ 的两根**：$u^2-u+c=0$ 的两支都满足 $2\zeta\sqrt{1-\zeta^2}=1/M_r$，要靠"图上到底有没有峰"（即 $1-2\zeta^2>0$）舍去大根；盲目取小根只是碰对了。
- **峰高必须先归一化**：峰附近若还有别的转折环节，基线不再是低频线，要先把该环节的贡献从总幅值里扣掉。

**读数口径**

- 渐近读数不是精确频响：$\nu=0$ 一阶系统只差 $0.05\%$，但 $\zeta=0.2$ 的振荡系统给出 $\omega_c=94.9$、精确值 $99.1$（差 $4.5\%$），该点真实幅值 $1.10$；$\zeta$ 越小、偏差越大。
- 相频要按**连续相角**读，$-\!180°$ 只是中间站；终值由 $-90°(n-m)$ 决定。
