## 有穷区间常用值（秒查）

| 积分 | 值 | 说明/方法 |
| :-- | :-- | :-- |
| $\int_0^{\pi}\sin x\,dx$ | $2$ | 直接积（$\int\sin=-\cos$） |
| $\int_0^{\pi/2}\sin x\,dx=\int_0^{\pi/2}\cos x\,dx$ | $1$ | — |
| $\int_0^{\pi/2}\sin^{2}x\,dx$ | $\dfrac{\pi}{4}$ | 降幂 $\sin^2=\tfrac{1-\cos2x}2$ |
| $\int_0^{\pi}\sin^{2}x\,dx=\int_0^{\pi}\cos^{2}x\,dx$ | $\dfrac{\pi}{2}$ | 半周期 |
| $\int_0^{2\pi}\sin^{2}x\,dx=\int_0^{2\pi}\cos^{2}x\,dx$ | $\pi$ | 整周期 |
| $\int_0^{\pi/2}\sin^{4}x\,dx$ | $\dfrac{3\pi}{16}$ | 华里士 $\frac{3!!}{4!!}\cdot\frac\pi2$ |
| $\int_0^{\pi/2}\sin^{6}x\,dx$ | $\dfrac{5\pi}{32}$ | 华里士 $\frac{5!!}{6!!}\cdot\frac\pi2$ |
| $\int_0^a\sqrt{a^{2}-x^{2}}\,dx$ | $\dfrac{\pi a^{2}}4$ | 四分之一圆面积 |
| $\int_0^1\ln x\,dx$ | $-1$ | 分部（$x\ln x-x$） |
| $\int_0^1 x\ln x\,dx$ | $-\dfrac14$ | 分部 |
| $\int_0^1\dfrac{dx}{1+x^{2}}$ | $\dfrac{\pi}{4}$ | $\arctan1$ |
| $\int_0^1\dfrac{\ln(1-x)}{x}\,dx$ | $-\dfrac{\pi^{2}}{6}$ | 展开 $\ln(1-x)=-\sum\dfrac{x^n}{n}$ 逐项积 |
| $\int_0^{\pi}\dfrac{x\sin x}{1+\cos^{2}x}\,dx$ | $\dfrac{\pi^{2}}4$ | 区间再现 $x\to\pi-x$ |

> [!derivation] 区间再现消去 $x$ 的条件
> 设 $h(x)=g(\sin x,\cos x)$ 在 $[0,\pi]$ 上可积。按此对称套路消去 $x$，须先验证 $h(\pi-x)=h(x)$，即 $g(\sin x,-\cos x)=g(\sin x,\cos x)$。
> 记 $I=\int_0^\pi xh(x)\,dx$，令 $x=\pi-t$，并使用上述对称性：
>
> $$
> I=\int_0^\pi(\pi-x)h(x)\,dx
> $$
>
> 两式相加，得
>
> $$
> I=\frac{\pi}{2}\int_0^\pi h(x)\,dx
> $$
>
> 原例 $h(x)=\frac{\sin x}{1+\cos^2x}$ 满足该条件；令 $u=\cos x$，有
>
> $$
> \int_0^\pi\frac{\sin x}{1+\cos^2x}\,dx=\int_{-1}^1\frac{du}{1+u^2}=\frac{\pi}{2}
> $$
>
> 因此原例的值仍为 $I=\frac{\pi^2}{4}$。教材例 9.18 的 $f(\sin x)$ 型自动满足上述对称性。

## 反常积分常用值（秒查，前提：已判敛）

| 积分 | 值 | 方法 |
| :-- | :-- | :-- |
| $\int_0^{+\infty}e^{-ax}\,dx$ | $\dfrac1a\ (a>0)$ | 直接积 |
| $\int_0^{+\infty}x^n e^{-ax}\,dx$ | $\dfrac{n!}{a^{n+1}}$ | Gamma：$\Gamma(n+1)/a^{n+1}$ |
| $\int_0^{+\infty}e^{-x^2}\,dx$ | $\dfrac{\sqrt\pi}{2}$ | 概率积分（二重积分法） |
| $\int_0^{+\infty}\dfrac{dx}{1+x^2}$ | $\dfrac{\pi}{2}$ | $\arctan$ 取极限 |
| $\int_0^{+\infty}\dfrac{\sin x}{x}\,dx$ | $\dfrac{\pi}{2}$ | Dirichlet 积分 |
| $\int_0^{+\infty}\dfrac{\sin^{2}x}{x^{2}}\,dx$ | $\dfrac{\pi}{2}$ | 分部 + Dirichlet 或参变积分 |
| $\int_0^{+\infty}e^{-x}\sin x\,dx$ | $\dfrac12$ | $\mathcal L[\sin]=\dfrac1{s^2+1}$ 取 $s=1$ |
| $\int_0^{+\infty}e^{-x}\cos x\,dx$ | $\dfrac12$ | $\mathcal L[\cos]=\dfrac s{s^2+1}$ 取 $s=1$ |
| $\int_0^{+\infty}\dfrac{\ln(1+x^2)}{1+x^2}\,dx$ | $\pi\ln2$ | $x=\tan t$ 化 $-\int_0^{\pi/2}\ln\cos^2t\,dt$ |
| $\Gamma\Bigl(\dfrac12\Bigr)=\int_0^{+\infty}x^{-1/2}e^{-x}dx$ | $\sqrt{\pi}$ | 概率积分换元 $x=t^2$ |

> [!tip] 弦类反常积分的通用武器
> $\int_0^{+\infty}e^{-ax}\sin bx\,dx=\dfrac{b}{a^2+b^2}$、$\int_0^{+\infty}e^{-ax}\cos bx\,dx=\dfrac{a}{a^2+b^2}$（$a>0$——拉氏变换表即此）；$\dfrac{\sin x}x$ 类用 **Dirichlet 积分** $\int_0^{+\infty}\dfrac{\sin ax}{x}dx=\dfrac\pi2\operatorname{sgn}a$ 及其参变推广。

## 华里士（Wallis）速查（详见 [[09-2 定积分的计算技巧]]）

| 积分 | 值 |
| :-- | :-- |
| $\int_0^{\pi/2}\sin^{n}x\,dx=\int_0^{\pi/2}\cos^{n}x\,dx$（$n$ 偶） | $\dfrac{(n-1)!!}{n!!}\cdot\dfrac{\pi}{2}$ |
| 同上（$n$ 奇） | $\dfrac{(n-1)!!}{n!!}$ |
| $\int_0^{\pi}\sin^{n}x\,dx$ | $n$ 偶：$\dfrac{(n-1)!!}{n!!}\pi$；$n$ 奇：$\dfrac{2(n-1)!!}{n!!}$ |
| $\int_0^{2\pi}\sin^{2k}x\,dx=\int_0^{2\pi}\cos^{2k}x\,dx$ | $\dfrac{(2k-1)!!}{(2k)!!}\cdot 2\pi$ |

> [!warning] 华里士三大易错
> - ① 区间不同系数不同：$\dfrac\pi2$ / $\pi$ / $2\pi$ 三个版本别混（见上表）；
> - ② $n$ 奇时**没有** $\pi$ 因子（$\int_0^{\pi/2}\sin^3x\,dx=\dfrac23$ 而非带 $\pi$）；
> - ③ 幂次看**被积函数**：$\int_0^{\pi/2}\sin^3x$ 是奇次用 $\dfrac{2!!}{3!!}=\dfrac23$，而 $\sin^2x$ 偶次才有 $\dfrac\pi4$。

## 对称性速查（配合定积分）

| 积分 | 结论 |
| :-- | :-- |
| $\int_{-a}^{a}f(x)\,dx$ | $f$ 偶 $=2\int_0^a f$；$f$ 奇 $=0$ |
| $\int_{-a}^{a}f(x)\,dx$（$f$ 任意） | $=\int_0^a[f(x)+f(-x)]\,dx$（奇偶拆分万能式） |
| $\int_0^a f(x)\,dx=\int_0^a f(a-x)\,dx$ | 区间再现（同值互换） |
| $\int_0^{2\pi}R(\sin x,\cos x)\,dx$（$R$ 为有理式） | $=\int_0^{2\pi}$，可令 $t=\tan\frac x2$ 化有理积分 |
| $\int_0^\pi x f(\sin x)\,dx$ | $=\dfrac\pi2\int_0^\pi f(\sin x)\,dx$（区间再现经典结论） |
