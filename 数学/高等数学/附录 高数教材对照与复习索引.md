## 按知识链复习

1. **函数 → 极限 → 连续 → 导数**：先弄清定义，再识别能否使用运算法则；不能反向使用必要条件。
2. **导数计算 → 几何性质 → 中值定理**：判符号与比较值；证明题先写定理条件，再找辅助函数。
3. **原函数 → 定积分 → 反常积分**：求出形式上的原函数不等于积分存在；奇点、端点与无穷远分别判敛。
4. **积分计算 → 微元应用**：先画区间或区域，再列被积式；体积、面积、压力、功的量纲不能混。
5. **二元微分 → 条件极值 → 二重积分**：可微与偏导存在区别清楚；约束点、边界和换元多重性单独检查。
6. **微分方程 → 初值 → 验证**：辨类型、解方程、补丢解、限区间，再代原式与全部条件验算。

## 每道题的自检清单

- 条件允许我取倒数、开方、取对数或做等价替换吗？
- 洛必达、中值定理、泰勒、积分换序及求导的前提满足吗？
- 除数为零、参数特殊值、边界点或不可导点是否漏掉？
- 由必要条件找到的候选点，是否进一步验证为真正解或极值？
- 求出的表达式能否代回原方程、原积分区域、原始初值？
- 结果符号、大小、极限情况与单位合理吗？
