## 按知识链复习

1. **函数 → 极限 → 连续 → 导数**：先弄清定义，再识别能否使用运算法则；不能反向使用必要条件。
2. **导数计算 → 几何性质 → 中值定理**：判符号与比较值；证明题先写定理条件，再找辅助函数。
3. **原函数 → 定积分 → 反常积分**：求出形式上的原函数不等于积分存在；奇点、端点与无穷远分别判敛。
4. **积分计算 → 微元应用**：先画区间或区域，再列被积式；体积、面积、压力、功的量纲不能混。
5. **二元微分 → 条件极值 → 二重积分**：可微与偏导存在区别清楚；约束点、边界和换元多重性单独检查。
6. **微分方程 → 初值 → 验证**：辨类型、解方程、补丢解、限区间，再代原式与全部条件验算。

## 模块穿插与二刷节奏

> [!note] 为什么按模块回刷，不按讲次
> 讲次是教材的**推进顺序**，不是**复习顺序**。同一件工具会横跨好几讲反复出场——极限既是 [[01 第1讲 函数极限与连续]] 与 [[02 第2讲 数列极限]] 的正面内容，又要在求导、定积分定义、二重极限处被再调用一遍。所以回头刷的单位应该是**模块**，不是讲。
>
> 下面的「三组四块」与「一刷新模块、穿插二刷上一模块」取自大观题库的编排说明；讲次映射按本库现有目录落，不新建文件。

**挑题原则**

- **不挨个做**：每个题型先做真题里的母题，会了就过，不会才接着练同类。
- **学一类、刷一类、会一类**：一类题算通的标志是**看到题型就能出思路**，不是"做过一遍"。
- **及时止损**：一类题做完仍有超过一半要翻答案，说明缺的是方法而不是熟练度 → 回对应讲次补，不要在同一捆题里硬耗。

> [!warning] 这是调度规则，不替代错题本的复习日期
> 题目级的复习（当天 / 次日 / +3 / +7 / +30）仍由 [[数学/错题本/01 错题本使用规范|错题本使用规范]] 的 `review` 字段管，两者不要混：本节只管**模块什么时候回头**，不负责单题的到期提醒。

## 每道题的自检清单

- 条件允许我取倒数、开方、取对数或做等价替换吗？
- 洛必达、中值定理、泰勒、积分换序及求导的前提满足吗？
- 除数为零、参数特殊值、边界点或不可导点是否漏掉？
- 由必要条件找到的候选点，是否进一步验证为真正解或极值？
- 求出的表达式能否代回原方程、原积分区域、原始初值？
- 结果符号、大小、极限情况与单位合理吗？
