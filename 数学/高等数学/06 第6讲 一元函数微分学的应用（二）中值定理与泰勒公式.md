# 第6讲 一元函数微分学的应用（二）——中值定理与泰勒公式

> [!abstract] 📋 本讲定位
> 对应张宇《基础30讲》第6讲（一元函数微分学的应用（二）——中值定理、微分等式与微分不等式）。核心：四大中值定理、构造辅助函数、泰勒公式、五种不等式证明方法。

## 📖 费马引理（张宇第6讲，一切中值定理的起点）

$$
\boxed{\text{$f$ 在 }x_0\text{ 处取极值且可导}\ \Longrightarrow\ f'(x_0)=0}
$$

- **极值点**（局部最大/最小）是证明题构造的出发点：罗尔定理正是对取到端点等值内部的极值点用费马引理证得 $f'(\xi)=0$。
- 条件缺一不可：**可导**（不可导点如 $\lvert x\rvert$ 在 0 处取极小但 $f'(0)$ 不存在）；**极值**（驻点不一定是极值点，如 $x^3$ 在 0 处 $f'(0)=0$ 但无极值）。
- **用途**：① 找极值候选点（驻点 + 不可导点 + 端点）；② 证明"可导函数在开区间内部取最值 ⟹ 该点为驻点"。

**达布定理（导数的介值性，了解）**：$f$ 在 $[a,b]$ 可导，$f'_-(a)<\mu<f'_+(b)$（或 $f'(a)<\mu<f'(b)$）⟹ $\exists\,\xi\in(a,b):\ f'(\xi)=\mu$。推论：**导函数没有第一类间断点**（跳跃间断不可能出现在导函数上）——这是第8讲"有第一类间断的函数无原函数"的根源（[[08 第8讲 一元函数积分学的概念与性质]]）。

## 📖 四大中值定理

| 定理 | 条件 | 结论 |
| ---- | ---- | ---- |
| 罗尔 | $[a,b]$ 连续、$(a,b)$ 可导、$f(a)=f(b)$ | $\exists\,\xi\in(a,b):\ f'(\xi)=0$ |
| 拉格朗日 | $[a,b]$ 连续、$(a,b)$ 可导 | $f(b)-f(a)=f'(\xi)(b-a)$ |
| 柯西 | 再加 $g'(x)\ne 0$ | $\dfrac{f(b)-f(a)}{g(b)-g(a)}=\dfrac{f'(\xi)}{g'(\xi)}$ |
| 积分中值 | $f$ 在 $[a,b]$ 连续 | $\displaystyle\int_a^b f\,dx=f(\xi)(b-a),\ \xi\in[a,b]$ |

> [!note] 📌 **两条推广形式（无穷区间专用）**
> - **推广零点定理**：$f$ 在 $(a,b)$ 内连续，$\lim\limits_{x\to a^+}f=\alpha$、$\lim\limits_{x\to b^-}f=\beta$，$\alpha\beta<0$ ⟹ $f(x)=0$ 在 $(a,b)$ 内至少有一个根（$a,b,\alpha,\beta$ 都可为 $\pm\infty$）。
> - **推广罗尔定理**：$f$ 在 $(a,b)$ 内可导，$\lim\limits_{x\to a^+}f=\lim\limits_{x\to b^-}f=A$ ⟹ $\exists\,\xi\in(a,b):\ f'(\xi)=0$。
> 用法：端点无定义或区间为无穷时，把端点极限当成"函数值"即可套罗尔/零点定理。

> [!note] 📌 **判断 $f'$ 有界 ⟹ $f$ 有界（拉格朗日过渡）**
> 设 $f$ 在 $(a,b)$ 可导且 $f'$ **有界**（$\lvert f'\rvert\le k$），取 $x_0\in(a,b)$，则 $\lvert f(x)\rvert\le\lvert f(x_0)\rvert+\lvert f'(\xi)\rvert\lvert x-x_0\rvert\le\lvert f(x_0)\rvert+k(b-a)$ ⟹ $f$ 在 $(a,b)$ 有界。
> 拉格朗日中值定理的精髓：**用导函数的值控制函数值的增减**。

## 💡 证明题套路：构造辅助函数

把待证式整理成「某函数的导数在 $\xi$ 处为零」，常用对照表：

| 待证式中出现 | 构造 $F(x)$ | 依据 |
| ------------ | ----------- | ---- |
| $f'+\lambda f$ | $f(x)\,e^{\lambda x}$ | $(fe^{\lambda x})'=e^{\lambda x}(f'+\lambda f)$ |
| $f'g-fg'$ | $\dfrac{f(x)}{g(x)}$ | 商导数的分子 |
| $ff'$ | $f^{2}(x)$ | $(f^{2})'=2ff'$ |
| $xf'+f$ | $x\,f(x)$ | 乘积导数 |
| $xf'-f$ | $\dfrac{f(x)}{x}$ | $\Bigl(\dfrac{f}{x}\Bigr)'=\dfrac{xf'-f}{x^{2}}$ |
| $f'(\xi)=k$（常数） | $f(x)-kx$ | 罗尔 |
| $\dfrac{f'}{f}$ | $\ln\lvert f(x)\rvert$ | 对数导数 |
| $f''f+[f']^{2}$ | $f'\cdot f$ | $(ff')'=[f']^{2}+ff''$ |
| $f''f-[f']^{2}$（$f>0$） | $\dfrac{f'}{f}$ 或 $\ln f$ | $\bigl(\dfrac{f'}{f}\bigr)'=\dfrac{f''f-[f']^{2}}{f^{2}}$ |

> [!tip] 💡 **多次罗尔定理（证 $f^{(n)}(\xi)=0$）**
> 找**三个等值点** $f(a)=f(b)=f(c)$（不妨 $a<b<c$）→ 在 $[a,b]$、$[b,c]$ 各用一次罗尔得 $f'(\xi_1)=f'(\xi_2)=0$ → 在 $[\xi_1,\xi_2]$ 再用一次罗尔得 $f''(\xi)=0$。**口诀**："$n+1$ 个等值点 → $n$ 次罗尔 → $f^{(n)}$ 有零点"。常配合"直线 $AB$ 与曲线相交于第三点 $C$"的几何背景，造 $F(x)=f(x)-$ 直线。
> 注：证 $f^{(n)}(\xi)=0$ 多用罗尔；证 $f^{(n)}(\xi)\ne0$（不等式）多用泰勒公式。

- **双中值 $\xi,\eta$**：拆成两段各用一次拉格朗日；或一次拉格朗日 + 一次柯西（$g$ 取 $x^{2},e^{x}$ 等）。
- **端点组合**（式含 $f(a),f(b),f\bigl(\tfrac{a+b}{2}\bigr)$ 或二阶导）：往泰勒展开靠（在中点/端点展开再相加减）。
- 用罗尔前先凑出"两端函数值相等"，必要时用零点/介值定理先造出等值点。

> [!note] 📌 **罗尔原话（精确推论，必背）**
> 若 $f^{(n)}(x)=0$ 至多有 $k$ 个实根，则 $f(x)=0$ 至多有 $k+n$ 个实根（**阶数降几阶、根数加几根**）。
> - 推论：$f^{(n)}$ 无零点 ⟹ $f$ 至多 $n$ 个零点；$f^{(n)}$ 至多 $n$ 个根 ⟹ $f$ 至多 $2n$ 个根。
> - "以阶数换根数"：先逐阶求导把根的控制上限交给高阶导，再用"观察法 + 零点定理"凑足下界。

> [!note] 📌 **实系数奇次方程至少有一个实根**
> 设 $f(x)=x^{2n+1}+a_1 x^{2n}+\cdots+a_{2n+1}$，则 $\lim\limits_{x\to+\infty}f=+\infty$、$\lim\limits_{x\to-\infty}f=-\infty$；由连续性 + 推广零点定理 ⟹ $f(x)=0$ 在 $\mathbb{R}$ 上至少有一个实根。
> 若再有其偶次导组成的双二次方程判别式 $<0$（如 $f''=0$ 无实根 ⟹ $f'$ 单调 ⟹ $f$ 至多一个极值 ⟹ $f=0$ 至多两个根），就可得到**唯一实根**。

## 📖 泰勒公式

### 一般形式与两种余项

$$
\boxed{f(x)=f(x_0)+f'(x_0)(x-x_0)+\frac{f''(x_0)}{2!}(x-x_0)^{2}+\cdots+\frac{f^{(n)}(x_0)}{n!}(x-x_0)^{n}+R_n(x)}
$$

- **佩亚诺余项** $R_n=o\bigl((x-x_0)^{n}\bigr)$ —— 局部性质，用于**求极限、判阶**。
- **拉格朗日余项** $R_n=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$（$\xi$ 介于 $x_0,x$ 之间）—— 用于**证明与误差估计**。

$x_0=0$ 时称麦克劳林公式。

### 📝 常用麦克劳林展开

| 函数                 | 展开式                                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------------------------- |
| $e^{x}$              | $1+x+\dfrac{x^{2}}{2!}+\dfrac{x^{3}}{3!}+\cdots+\dfrac{x^{n}}{n!}+o(x^{n})$                                   |
| $\sin x$             | $x-\dfrac{x^{3}}{3!}+\dfrac{x^{5}}{5!}-\cdots+(-1)^{n}\dfrac{x^{2n+1}}{(2n+1)!}+o(x^{2n+1})$                  |
| $\cos x$             | $1-\dfrac{x^{2}}{2!}+\dfrac{x^{4}}{4!}-\cdots+(-1)^{n}\dfrac{x^{2n}}{(2n)!}+o(x^{2n})$                        |
| $\ln(1+x)$           | $x-\dfrac{x^{2}}{2}+\dfrac{x^{3}}{3}-\cdots+(-1)^{n-1}\dfrac{x^{n}}{n}+o(x^{n})$                              |
| $(1+x)^{\alpha}$     | $1+\alpha x+\dfrac{\alpha(\alpha-1)}{2!}x^{2}+\cdots+\dfrac{\alpha(\alpha-1)\cdots(\alpha-n+1)}{n!}x^{n}+o(x^{n})$ |
| $\dfrac{1}{1-x}$     | $1+x+x^{2}+\cdots+x^{n}+o(x^{n})$                                                                             |
| $\dfrac{1}{1+x}$     | $1-x+x^{2}-\cdots+(-1)^{n}x^{n}+o(x^{n})$                                                                     |
| $\tan x$             | $x+\dfrac{x^{3}}{3}+\dfrac{2x^{5}}{15}+o(x^{5})$                                                              |
| $\arcsin x$          | $x+\dfrac{x^{3}}{6}+\dfrac{3x^{5}}{40}+o(x^{5})$                                                              |
| $\arctan x$          | $x-\dfrac{x^{3}}{3}+\dfrac{x^{5}}{5}+o(x^{5})$                                                                |

> [!tip] 💡 展开到第几阶？
> - **比值型** $\dfrac{A(x)}{x^{k}}$：分子各项都展到 $x^{k}$ 阶为止。
> - **相消型** $A-B$：展到**第一个不相消的阶**为止（如 $\tan x-\sin x$ 展到 $x^3$）。
> - 高阶等价无穷小表（[[01 第1讲 函数极限与连续]]）就是这些展开的直接推论，两处对照记忆。

### 泰勒展开在证明题中的应用

- **端点/中点展开**：在区间内选点展开 $f(x)$ 至一阶，代入端点 $f(a),f(b)$ 或 $f\bigl(\tfrac{a+b}{2}\bigr)$，相加减消去一阶项，用 $f''$ 的范围估出需要的不等式。
- **含 $f''$ 的界估计**（给 $f''$ 的上下界，证 $f\ge g$ 型）：在每点处带拉格朗日余项展至一阶，用 $f''\ge m$（或 $\le M$）作放缩。
- **含 $f+c$（常数）型**：考虑移项构造函数 $F(x)=f(x)-g(x)$，在合适的点展开估值。
- 更高阶题目少见，核心是一阶/二阶泰勒。

## 💡 五种不等式证明方法

### 方法一：单调性法（最常用）

令 $F(x)=f(x)-g(x)$ → 求 $F'$ 判符号 → $F$ 单调 → 端点/驻点值 → $F\ge0$ 或 $\le0$

**变体**：要证 $f\le g$ 在 $[a,b]$ 上但 $F'$ 符号不直观 → 再求 $F''$（凹凸性辅助）或泰勒展开。

### 方法二：凹凸性法
![[高数-凹凸切线.png|560]]
*下凸 $f''>0$：曲线在切线上方；上凸 $f''<0$：曲线在切线下方*


利用 **$f''$ 的符号** 判定 $f$ 在每点的切线位置关系：
- $f''>0$（下凸）⟹ 曲线位于切线的**上方**：$f(x)\ge f(x_0)+f'(x_0)(x-x_0)$
- $f''<0$（上凸）⟹ 曲线位于切线的**下方**：$f(x)\le f(x_0)+f'(x_0)(x-x_0)$

### 方法三：拉格朗日中值定理法

目标形式中含 **$f(b)-f(a)$** → 直接用拉格朗日：
$$
f(b)-f(a)=f'(\xi)(b-a)
$$
放缩 $f'(\xi)$ 的范围（利用 $f'$ 的有界性或单调性得到上/下界估计）。

**二阶扩展**：含 $f(b)+f(a)-2f(\frac{a+b}{2})$ 型 → 对称分别在 $a,b$ 和 $\frac{a+b}{2}$ 处用泰勒中值定理。

### 方法四：泰勒展开法

目标中出现了 $f'$、$f''$ 等与 $f$ 混合的形式：在选定的点带拉格朗日余项展开，用 $f''$ 的取值范围放缩余项。

**常用展开点**：端点（$a$ 或 $b$）、中点（$\frac{a+b}{2}$）、极值点/拐点。

**端点倒置公式**（张宇"截长补短"）：$f(a)$ 和 $f(b)$ 分别在 $x$ 处展开再相加/相减 → 消去一阶项 → 仅剩 $f(x)+f'(\xi)(a-x)$ 型和 $f''$ 项。

### 方法五：积分法

含 $\int_a^b$ 的不等式：利用积分保序性/绝对值不等式/柯西-施瓦茨（详见 [[11 第11讲 一元函数积分学的应用（二）积分等式与积分不等式]]）。

### ⚖️ 微分不等式四个常用结论（必背，源自凹凸性辅助）

设 $f$ 在 $(a,b)$ 二阶可导（结论 4 要求 $f''>0,\ f(a)=f(b)=0$）：

| 编号 | 条件 | 结论 |
|:--|:--|:--|
| ① | $f'(x)\ge0$ 在 $(a,b)$ | $f(a)\le f(x)\le f(b)$（一阶保单调） |
| ② | $f''(x)\ge0$ 在 $(a,b)$ | $f'(a)\le f'(x)\le f'(b)$；进一步若 $f'(a)>0$ 则 $f$ 单调增，若 $f'(b)<0$ 则 $f$ 单调减 |
| ③ | $f$ 在 $I$ 连续、有唯一极值点 $x_0$ | 若 $x_0$ 为极大值点则 $f(x_0)$ 即 $I$ 上最大值；若为极小则 $f(x_0)$ 为最小值 |
| ④ | $f''>0$ 在 $(a,b)$ 且 $f(a)=f(b)=0$ | $f(x)<0$ 在 $(a,b)$ 内恒成立（**两端为 0、内部下凸 ⟹ 函数全在弦下方**） |

> [!tip] 💡 **结论 ④ 的几何速记**
> "$f''>0$ 下凸 + 两端点同高 ⟹ 弧在弦下方、函数取负"。常用于证 $f(x)<0$ 型不等式，配合 ② 单独或对比使用。

## 📝 常考题型速查（中值定理与不等式证明）

| 题型 | 核心操作 |
|:--|:--|
| 证 $f\ge g$ 型不等式 | 单调性法，令差函数 |
| 证 $f\le$ 某常数 | 找 $f$ 的最值 |
| 证 $\lvert f'\rvert\le M$ 型 | 拉格朗日中值定理（$f'(\xi)$ 放缩） |
| 证 $f$ 有 $n$ 个零点 | 罗尔+介值+单调组合 |
| 罗尔推论定界 | 最高阶导数的零点情况 → 原函数至多几个零点 |
| 证"存在 $\xi$ 使 $f^{(k)}(\xi)=$ 某式" | 构造辅助函数 + 罗尔/拉格朗日 |
| 含 $\lvert f''\rvert$ 的界估计 | 泰勒展开带拉格朗日余项放缩 |
| 证 $f(b)+f(a)-2f\bigl(\tfrac{a+b}{2}\bigr)$ 型 | 中点/端点泰勒展开相加减 |

## ✏️ 典型例题

> [!example] ✏️ **例1：罗尔定理（验证条件）**
> 验证 $f(x)=x^3-3x$ 在 $[0,\sqrt3]$ 上满足罗尔定理并求 $\xi$：$f(0)=0=f(\sqrt3)$，连续可导 ✓，故 $\exists\,\xi\in(0,\sqrt3):\ f'(\xi)=3\xi^2-3=0$ ⟹ $\xi=1$。

> [!example] ✏️ **例2：拉格朗日中值定理（估差值）**
> 证明 $\lvert\arctan b-\arctan a\rvert\le\lvert b-a\rvert$：由拉格朗日，$\arctan b-\arctan a=\dfrac{1}{1+\xi^2}(b-a)$，而 $\Bigl\lvert\dfrac{1}{1+\xi^2}\Bigr\rvert\le1$ ⟹ 不等式成立。取 $a=0,b=x$ 得 $\arctan x<x$（$x>0$）。

> [!example] ✏️ **例3：柯西中值定理**
> 证明 $\dfrac{\sin b-\sin a}{\cos b-\cos a}$ 相关型：$f(x)=\sin x,\ g(x)=\cos x$ 在 $[a,b]$ 用柯西中值定理：$\dfrac{\sin b-\sin a}{\cos b-\cos a}=\dfrac{\cos\xi}{-\sin\xi}=-\cot\xi$。典型题：证 $\dfrac{f(b)-f(a)}{e^b-e^a}=\dfrac{f'(\xi)}{e^\xi}$（取 $g(x)=e^x$）。

> [!example] ✏️ **例4：构造辅助函数**
> 设 $f$ 在 $[0,1]$ 连续、$(0,1)$ 可导，$f(1)=0$，证明 $\exists\,\xi:\ f'(\xi)=-\dfrac{f(\xi)}{\xi}$。
> **解**：目标式改写为 $\xi f'(\xi)+f(\xi)=0$，即 $\bigl[xf(x)\bigr]'\bigr|_{x=\xi}=0$。令 $F(x)=xf(x)$，则 $F(0)=0,\ F(1)=f(1)=0$，罗尔定理 ⟹ $\exists\,\xi\in(0,1):\ F'(\xi)=\xi f'(\xi)+f(\xi)=0$ ✓。
> **套路**：目标含 $f'$ 与 $f$ 线性组合 → 反推出 $F$ 的乘积/除法形式（$\times x$、$\div x$、$\times e^x$、$\times e^{-x}$ 等）。

> [!example] ✏️ **例5：泰勒中值定理证不等式**
> 设 $f''>0$，证明 $f(x)\ge f(x_0)+f'(x_0)(x-x_0)$（曲线在切线上方）。
> **解**：在 $x_0$ 处带拉格朗日余项展至一阶：$f(x)=f(x_0)+f'(x_0)(x-x_0)+\dfrac{f''(\xi)}{2}(x-x_0)^2$，由 $f''(\xi)>0$ 余项 $\ge0$ ⟹ 命题成立（**凹凸性法/切线不等式**的本质）。

> [!example] ✏️ **例6：双中值（两次拉格朗日/柯西）**
> 设 $f$ 在 $[a,b]$ 二阶可导，$f(a)=f(b)=0$，证明 $\exists\,\xi:\ \lvert f''(\xi)\rvert\ge\dfrac{4\lvert f(c)\rvert}{(b-a)^2}$（$c$ 为区间中点）。思路：分别在 $[a,c]$、$[c,b]$ 用拉格朗日得 $f'(\xi_1)=\dfrac{f(c)-f(a)}{c-a}$、$f'(\xi_2)=\dfrac{f(b)-f(c)}{b-c}$，再用 $f'(\xi_1)-f'(\xi_2)$ 上二次拉格朗日放缩 $\lvert f''\rvert$。
