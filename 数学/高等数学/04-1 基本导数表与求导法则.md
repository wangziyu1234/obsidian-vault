# 第4讲（一）基本导数表与求导法则

## 基本导数表

| $f(x)$ | $f'(x)$ | $f(x)$ | $f'(x)$ |
| :-- | :-- | :-- | :-- |
| $C$ | $0$ | $x^{\alpha}$ | $\alpha x^{\alpha-1}$ |
| $e^{x}$ | $e^{x}$ | $a^{x}$ | $a^{x}\ln a$ |
| $\ln\lvert x\rvert$ | $\dfrac{1}{x}$ | $\log_a x$ | $\dfrac{1}{x\ln a}$ |
| $\sin x$ | $\cos x$ | $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^{2}x$ | $\cot x$ | $-\csc^{2}x$ |
| $\sec x$ | $\sec x\tan x$ | $\csc x$ | $-\csc x\cot x$ |
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^{2}}}$ | $\arccos x$ | $-\dfrac{1}{\sqrt{1-x^{2}}}$ |
| $\arctan x$ | $\dfrac{1}{1+x^{2}}$ | $\operatorname{arccot}x$ | $-\dfrac{1}{1+x^{2}}$ |
| $\ln\bigl(x+\sqrt{x^{2}+1}\bigr)$ | $\dfrac{1}{\sqrt{x^{2}+1}}$ | $\ln\bigl\lvert x+\sqrt{x^{2}-1}\bigr\rvert$ | $\dfrac{1}{\sqrt{x^{2}-1}}$ |

## 求导法则

| 法则 | 公式 |
| :-- | :-- |
| 四则 | $(u\pm v)'=u'\pm v'$；$(uv)'=u'v+uv'$；$\left(\dfrac{u}{v}\right)'=\dfrac{u'v-uv'}{v^{2}}$ |
| 复合（链式） | $\{f[g(x)]\}'=f'[g(x)]\cdot g'(x)$ |
| **微分形式不变性** | $d\bigl[f(u)\bigr]=f'(u)\,du$，无论 $u$ 是自变量还是中间变量都成立 |
| 反函数 | $\dfrac{dy}{dx}=\dfrac{1}{dx/dy}$；二阶 $\dfrac{d^{2}x}{dy^{2}}=-\dfrac{y''}{(y')^{3}}$ |
| 参数方程 | $\dfrac{dy}{dx}=\dfrac{\dot y}{\dot x}$；$\dfrac{d^{2}y}{dx^{2}}=\dfrac{\ddot y\,\dot x-\dot y\,\ddot x}{\dot x^{3}}$ |
| 隐函数 | $F(x,y)=0$ 两边对 $x$ 求导（$y$ 视为 $y(x)$），或 $\dfrac{dy}{dx}=-\dfrac{F'_x}{F'_y}$（前提 $F'_y\ne0$，此时方程局部唯一确定 $y=y(x)$） |
| 幂指函数 | $u^{v}=e^{v\ln u}$ 再求导，或对数求导法（两边取 $\ln$） |

**对数求导法完整套路**（幂指函数、连乘/连除/幂积混合型的首选）：
1. 两边取 $\ln$（$y>0$；若 $y$ 可负，先加绝对值或分区间讨论）；
2. 用对数性质化简：$\ln u^v=v\ln u$、$\ln(uv)=\ln u+\ln v$、$\ln\frac uv=\ln u-\ln v$；
3. 两边对 $x$ 求导（左边 $\dfrac{y'}{y}$，右边按链式/四则）；
4. 解出 $y'=y\cdot(\text{右边导数})$，代回 $y$ 的表达式。

> [!example] 例：对数求导法
>
> $y=x^{\sin x}\ (x>0)$，求 $y'$。
>
> 取对数：$\ln y=\sin x\ln x$
>
> 两边求导：$\dfrac{y'}{y}=\cos x\ln x+\dfrac{\sin x}{x}$
>
> 故：$y'=x^{\sin x}\Bigl(\cos x\ln x+\dfrac{\sin x}{x}\Bigr)$
>

> [!tip] **多因式相乘化"经典形式"**
> 因式超过 3 个的乘积直接求导计算量爆炸。**化两项乘积** $f(x)=g_1(x)\cdot g_2(x)$（把"特立独行"的项单独拎出，其余 $n-1$ 项凑成一项）；
> 再用乘法公式 $(g_1g_2)'=g_1'g_2+g_1g_2'$，往往 $g_1$ 在该点的导数为 0 或直接代入后只剩 $g_2$ 项。
> 张宇称此为"经典形式"。
