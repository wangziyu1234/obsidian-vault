# 附录 幂指对函数图像与计算

> [!abstract] 附录定位
> 以 $x$（幂）、$\ln x$（对数）、$e^x$（指数）三个基本函数为核心，汇总它们的图像、增长阶（比阶）、常见**组合函数**的图像与关键结论，以及高频极限/导数/积分。解极限比阶、单调极值、渐近线题时的速查。

## 三个基本函数

![[高数-幂指对基本函数.png|520]]

| 函数 | 定义域 | 关键点 | 导数 | 单调/凹凸 |
| :-- | :-- | :-- | :-- | :-- |
| $y=x$ | $\mathbb{R}$ | 过原点 | $y'=1$ | 恒增，直线 |
| $y=\ln x$ | $x>0$ | 过 $(1,0)$ | $y'=\dfrac{1}{x}>0$ | 恒增，**上凸**（$y''=-\dfrac{1}{x^2}<0$） |
| $y=e^{x}$ | $\mathbb{R}$ | 过 $(0,1)$ | $y'=e^{x}>0$ | 恒增，**下凸**（$y''=e^{x}>0$） |

**核心关系**：$y=e^x$ 与 $y=\ln x$ 互为反函数（关于 $y=x$ 对称）；$e^x\ge 1+x$、$\ln x\le x-1$（切线不等式，$x=0/1$ 处取等）。

## 增长阶（比阶，$x\to+\infty$）

$$
\boxed{\ \ln x \ll x^{\alpha}\ (\alpha>0) \ll a^{x}\ (a>1) \ll x^{x}\ }
$$

即**对数 << 幂 << 指数**：$x\to+\infty$ 时 $\dfrac{\ln x}{x^{\alpha}}\to0$、$\dfrac{x^{\alpha}}{a^{x}}\to0$。比阶、夹逼、渐近线题的第一判断依据。

## 常见组合函数的图像与结论

![[高数-幂指对组合函数.png|520]]

| 函数 | 定义域 | 极值（含位置） | $x\to0^{+}$ | $x\to+\infty$ | 图像特征 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| $x\ln x$ | $x>0$ | 极小 $-\dfrac{1}{e}$ @ $x=\dfrac{1}{e}$ | $\to0$ | $\to+\infty$ | 先降后升（**0·∞ 型**典型） |
| $\dfrac{\ln x}{x}$ | $x>0$ | 极大 $\dfrac{1}{e}$ @ $x=e$ | $\to-\infty$ | $\to0$ | 先升后降（**∞/∞ 型**典型） |
| $\dfrac{x}{\ln x}$ | $x>0,\ x\ne1$ | 极小 $e$ @ $x=e$ | $\to0^{-}$ | $\to+\infty$ | $x=1$ 无穷间断 |
| $x\,e^{x}$ | $\mathbb{R}$ | 极小 $-\dfrac{1}{e}$ @ $x=-1$ | $\to0$ | $\to+\infty$ | 左端趋 0、右端爆增 |
| $x\,e^{-x}$ | $\mathbb{R}$ | 极大 $\dfrac{1}{e}$ @ $x=1$ | $\to0$ | $\to0$ | 两端趋 0、中间单峰 |
| $\dfrac{e^{x}}{x}$ | $x\ne0$ | 极小 $e$ @ $x=1$ | $\to+\infty$ | $\to+\infty$ | 两端爆增、中间有谷 |
| $x^{x}$ | $x>0$ | 极小 $e^{-1/e}$ @ $x=\dfrac{1}{e}$ | $\to1$ | $\to+\infty$ | **$1^\infty$ 型**（$x^x=e^{x\ln x}$） |
| $x^{1/x}$ | $x>0$ | 极大 $e^{1/e}$ @ $x=e$ | $\to0$ | $\to1$ | 先升后降、右端趋 1 |

> [!tip] 记忆锚点
> - $\ln x/x$ 与 $x^{1/x}$ 都在 $x=e$ 取极值（前者极大 $1/e$、后者极大 $e^{1/e}$）；
> - $x\ln x$ 与 $x^x$ 都在 $x=1/e$ 取极值（前者极小 $-1/e$、后者极小 $e^{-1/e}$）；
> - 含 $\ln x$ 的组合，极值点不是 $e$ 就是 $1/e$——都是解 $\ln x=\pm1$ 得到。

## 常用极限（背）

$$
\lim_{x\to0^{+}}x^{\alpha}\ln x=0\ (\alpha>0),\qquad
\lim_{x\to+\infty}\frac{\ln x}{x^{\alpha}}=0\ (\alpha>0),\qquad
\lim_{x\to+\infty}\frac{x^{\alpha}}{e^{x}}=0
$$

$$
\lim_{x\to0^{+}}x^{x}=1,\qquad
\lim_{x\to+\infty}x^{1/x}=1
$$

前三个是"对数/幂/指数比阶"的直接推论（$0\cdot\infty$、$\infty/\infty$ 型）；后两个用 $x^x=e^{x\ln x}$、$x^{1/x}=e^{\ln x/x}$ 化为 $\exp(0)$。

## 常用导数与积分

| 导数 | 结果 |
| :-- | :-- |
| $(x^{x})'$ | $x^{x}(\ln x+1)$ |
| $\bigl(x^{1/x}\bigr)'$ | $x^{1/x}\cdot\dfrac{1-\ln x}{x^{2}}$ |

| 积分 | 结果 |
| :-- | :-- |
| $\displaystyle\int x\ln x\,dx$ | $\dfrac{x^{2}}{2}\ln x-\dfrac{x^{2}}{4}+C$ |
| $\displaystyle\int x\,e^{x}\,dx$ | $e^{x}(x-1)+C$ |
| $\displaystyle\int x\,e^{-x}\,dx$ | $-e^{-x}(x+1)+C$ |
| $\displaystyle\int(\ln x)^{2}dx$ | $x(\ln x)^{2}-2x\ln x+2x+C$ |

> [!note] 计算套路
> - **幂×对数**（$\int x^{n}\ln x$）与**幂×指数**（$\int x^{n}e^{ax}$）：分部积分，$u$ 取 $\ln x$（或幂 $x^{n}$），见 [[09-1 积分方法（凑微分·换元·分部·部分分式）]]；
> - **$x^x$ 求导/求极值**：先化 $x^x=e^{x\ln x}$ 再算；**$x^x\to0$ 的极限**：$e^{x\ln x}\to e^{0}=1$（因 $x\ln x\to0$）。
