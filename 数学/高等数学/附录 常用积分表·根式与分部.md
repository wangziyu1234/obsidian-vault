# 附录 常用积分表·根式与分部

> [!abstract] 本讲定位
> 根式的三角/双曲换元、负半轴符号，以及对数反三角和幂函数的分部积分。

## 三、根式（三角 / 双曲换元）

本节圆/平方和参数取 $a>0$；反根式分别要求 $|x|<a$ 或 $|x|>a$，其他对数和分母避开零点，在每个连通定义区间单独取常数。一般二次式中的 $a,b,c$ 另按其符号和判别式分类，不适用这一正半径约定。

| 积分 | 原函数 |
| :-- | :-- |
| **1** $\int\frac{dx}{\sqrt{a^{2}-x^{2}}}$ | $\arcsin\frac xa+C$ |
| **2** $\int\frac{dx}{\sqrt{x^{2}+a^{2}}}$ | $\ln\left\lvert x+\sqrt{x^{2}+a^{2}}\right\rvert+C$ |
| **3** $\int\frac{dx}{\sqrt{x^{2}-a^{2}}}$ | $\ln\left\lvert x+\sqrt{x^{2}-a^{2}}\right\rvert+C$ |
| **4** $\int\frac{dx}{x^{2}-a^{2}}$ | $\frac1{2a}\ln\left\lvert\frac{x-a}{x+a}\right\rvert+C$ |
| **5** $\int\sqrt{a^{2}-x^{2}}\,dx$ | $\frac x2\sqrt{a^{2}-x^{2}}+\frac{a^{2}}2\arcsin\frac xa+C$ |
| **6** $\int\sqrt{x^{2}+a^{2}}\,dx$ | $\frac x2\sqrt{x^{2}+a^{2}}+\frac{a^{2}}2\ln\left\lvert x+\sqrt{x^{2}+a^{2}}\right\rvert+C$ |
| **7** $\int\sqrt{x^{2}-a^{2}}\,dx$ | $\frac x2\sqrt{x^{2}-a^{2}}-\frac{a^{2}}2\ln\left\lvert x+\sqrt{x^{2}-a^{2}}\right\rvert+C$ |
| **8** $\int\frac{dx}{x\sqrt{x^{2}-a^{2}}}$ | $\frac1a\arccos\frac a{\vert x\vert }+C$ |
| **9** $\int\frac{dx}{x\sqrt{x^{2}+a^{2}}}$ | $\frac1a\ln\frac{\lvert x\rvert}{\sqrt{x^{2}+a^{2}}+a}+C$（等价：$-\frac1a\ln\left\lvert\frac{a+\sqrt{x^{2}+a^{2}}}{x}\right\rvert$） |
| **10** $\int\frac{dx}{\sqrt{ax^{2}+bx+c}}$ | 配方后化 $\int\frac{du}{\sqrt{u^{2}\pm k^{2}}}$ 或 $\int\frac{du}{\sqrt{k^{2}-u^{2}}}$ |
| **11** $\int\sqrt{ax^{2}+bx+c}\,dx$ | 配方后化 $\int\sqrt{u^{2}\pm k^{2}}\,du$ 或 $\int\sqrt{k^{2}-u^{2}}\,du$ |

**对应方法**：

1. $x=a\sin t$
2. $x=a\tan t$ 或 $x=a\,\mathrm{sh}t$
3. $x=a\sec t$ 或 $x=a\,\mathrm{ch}t$
4. 部分分式（见上）
5. $x=a\sin t$，$dx=a\cos t\,dt$，原积分 $=a^{2}\displaystyle\int\cos^{2}t\,dt$
6. $x=a\,\mathrm{sh}t$（或分部）
7. $x=a\,\mathrm{ch}t$
8. $x=\frac a{\cos t}$，或 $u=\frac ax$
9. 倒代换 $x=\frac at$ 或 $x=a\,\mathrm{sh}t$
10. 先配方 $(ax^{2}+bx+c)=a\bigl[\bigl(x+\tfrac b{2a}\bigr)^{2}\pm k^{2}\bigr]$
11. 同上（先完全配方即得）

> 令 $u=\frac ax$（$x=\frac au$），$dx=-\frac a{u^{2}}du$，$\sqrt{x^{2}+a^{2}}=\frac a{\lvert u\rvert}\sqrt{1+u^{2}}$：
> $$
> \begin{aligned}
> \int\frac{dx}{x\sqrt{x^{2}+a^{2}}}&=-\frac{\operatorname{sgn}u}{a}\int\frac{du}{\sqrt{1+u^{2}}}\\[4pt]
> &=-\frac{\operatorname{sgn}u}{a}\operatorname{arsh}u\\[4pt]
> &=-\frac1a\ln\Bigl\lvert\frac{a+\sqrt{x^{2}+a^{2}}}{x}\Bigr\rvert+C\\[4pt]
> &=\frac1a\ln\frac{\lvert x\rvert}{\sqrt{x^{2}+a^{2}}+a}+C
> \end{aligned}
> $$
> （中间用 $\operatorname{arsh}u=\ln\lvert u+\sqrt{u^{2}+1}\rvert$，见 [[附录 双曲函数]]。）

> 令 $x=a\sin t\ (t\in[-\frac\pi2,\frac\pi2])$，$\sqrt{a^{2}-x^{2}}=a\cos t$，$dx=a\cos t\,dt$：
> $$
> \begin{aligned}
> \int\sqrt{a^{2}-x^{2}}\,dx&=a^{2}\int\cos^{2}t\,dt\\[4pt]
> &=\frac{a^{2}}2\Bigl(t+\frac{\sin2t}2\Bigr)\\[4pt]
> &=\frac{a^{2}}2\arcsin\frac xa+\frac x2\sqrt{a^{2}-x^{2}}+C
> \end{aligned}
> $$
> （末步用 $\sin t=\frac xa$、$\cos t=\frac{\sqrt{a^{2}-x^{2}}}a$ 回代。）

---

当 $m=\pm n\ne0$ 时，直接用 $\sin(mx)\cos(mx)=\frac12\sin(2mx)$，不要代入有零分母的通式。

## 四、对数与反三角（分部积分的"去超越"）

> $\int\ln x$、$\int\arctan x$、$\int\arcsin x$、$\int x\ln x$、$\int x e^{x}$ 等**基础去超越**见 09-1 基本积分表（结论）与方法三（分部推导）；下表起于**幂 × 对/反三角的高阶**（$x\cdot\arctan$、$x^{2}e^{x}$、$x^{2}\sin$ 等）与递推。

| 积分 | 原函数 |
| :-- | :-- |
| **1** $\int\ln x\,dx$ | $x\ln x-x+C$ |
| **2** $\int(\ln x)^{2}dx$ | $x(\ln x)^{2}-2x\ln x+2x+C$ |
| **3** $\int\ln^{n}x\,dx$ | $x\ln^{n}x-n\displaystyle\int\ln^{n-1}x\,dx$ |
| **4** $\int x^{n}\ln x\,dx$ | $\frac{x^{n+1}}{n+1}\ln x-\frac{x^{n+1}}{(n+1)^{2}}+C$ |
| **5** $\int\arctan x\,dx$ | $x\arctan x-\frac12\ln(1+x^{2})+C$ |
| **6** $\int\arcsin x\,dx$ | $x\arcsin x+\sqrt{1-x^{2}}+C$ |
| **7** $\int x e^{x}\,dx$ | $e^{x}(x-1)+C$ |
| **8** $\int x e^{-x}\,dx$ | $-e^{-x}(x+1)+C$ |
| **9** $\int x\sin x\,dx$ | $-x\cos x+\sin x+C$ |
| **10** $\int x\cos x\,dx$ | $x\sin x+\cos x+C$ |
| **11** $\int x\arctan x\,dx$ | $\frac12(x^{2}+1)\arctan x-\frac x2+C$ |
| **12** $\int x\arcsin x\,dx$ | $\frac14\bigl[(2x^{2}-1)\arcsin x+x\sqrt{1-x^{2}}\bigr]+C$ |
| **13** $\int x^{2}e^{x}\,dx$ | $e^{x}(x^{2}-2x+2)+C$ |
| **14** $\int x^{2}\sin x\,dx$ | $-x^{2}\cos x+2x\sin x+2\cos x+C$ |

**对应方法**：

1. $u=\ln x,\ dv=dx$
2. 对 $\int\ln x$ 递推
3. $u=\ln^{n}x,\ dv=dx$（递推）
4. $u=\ln x,\ dv=x^{n}dx$
5. $u=\arctan x$
6. $u=\arcsin x$，$\int\frac{x}{\sqrt{1-x^{2}}}dx=-\sqrt{1-x^{2}}$
7. $u=x,\ dv=e^{x}dx$
8. $u=x,\ dv=e^{-x}dx$
9. $u=x,\ dv=\sin x\,dx$
10. $u=x,\ dv=\cos x\,dx$
11. $u=\arctan x,\ dv=x\,dx$，$\int\frac{x^{2}}{1+x^{2}}=x-\arctan x$
12. $u=\arcsin x,\ dv=x\,dx$，$\int\frac{x^{2}}{\sqrt{1-x^{2}}}dx=\frac12\arcsin x-\frac x2\sqrt{1-x^{2}}$
13. 表格法（$x^{2}\to2x\to2\to0$）
14. 分部两次（$u=x^{2}$ 降幂）

> 取 $u=x^{2},\ dv=\sin x\,dx$：$\int x^{2}\sin x=-x^{2}\cos x+2\int x\cos x\,dx$，再对 $\int x\cos x=x\sin x+\cos x$：
> $$
> \begin{aligned}
> \int x^{2}\sin x\,dx&=-x^{2}\cos x+2\bigl(x\sin x+\cos x\bigr)+C\\[4pt]
> &=-x^{2}\cos x+2x\sin x+2\cos x+C
> \end{aligned}
> $$
> （幂×三角/指数：$u$ 取幂，分部一次降幂一次，反复至幂消失；幂次高时用表格法更快。）
