## 💡 方法一：凑微分（第一类换元）

| 凑法 | 凑法 |
| ---- | ---- |
| $x\,dx=\dfrac{1}{2}d(x^{2})$ | $\dfrac{dx}{x}=d(\ln\lvert x\rvert)$ |
| $e^{x}dx=d(e^{x})$ | $\dfrac{dx}{\sqrt{x}}=2\,d(\sqrt{x})$ |
| $\dfrac{dx}{x^{2}}=-d\!\left(\dfrac{1}{x}\right)$ | $\sin x\,dx=-d(\cos x)$，$\cos x\,dx=d(\sin x)$ |
| $\sec^{2}x\,dx=d(\tan x)$ | $\dfrac{dx}{1+x^{2}}=d(\arctan x)$ |
| $\dfrac{f'(x)}{f(x)}dx=d\bigl(\ln\lvert f(x)\rvert\bigr)$ | $(1+\ln x)\,dx=d(x\ln x)$ |

> [!tip] 💡 凑微分的"导数检验"（张宇第9讲）
> 遇到不知怎么凑的积分，**对被积函数的复杂部分 $g(x)$ 求导**：若 $g'(x)=f(x)$（或只差常数倍），则 $d[g(x)]=f(x)dx$ 即可凑。例：$\displaystyle\int\frac{\cos\theta+\sin\theta}{(\cos\theta-\sin\theta)^{2}}d\theta$——对复杂部分 $g=\cos\theta-\sin\theta$ 求导得 $g'=-(\sin\theta+\cos\theta)$，恰为分子的相反数，故 $\dfrac{\cos\theta+\sin\theta}{(\cos\theta-\sin\theta)^{2}}d\theta=-d\!\Bigl(\dfrac{1}{g}\Bigr)$，直接积分。

## 💡 方法二：换元（第二类）

| 根式形状 | 代换 | 微分 |
| -------- | ---- | ---- |
| $\sqrt{a^{2}-x^{2}}$ | $x=a\sin t$ | $dx=a\cos t\,dt$ |
| $\sqrt{a^{2}+x^{2}}$ | $x=a\tan t$ | $dx=a\sec^{2}t\,dt$ |
| $\sqrt{x^{2}-a^{2}}$ | $x=a\sec t$ | $dx=a\sec t\tan t\,dt$ |

- 回代画**直角三角形**还原。
- 其它常用：$\sqrt[n]{ax+b}=t$ 整体代换；分母幂次高时**倒代换** $x=\dfrac{1}{t}$。
- **万能代换** $t=\tan\dfrac{x}{2}$：$\sin x=\dfrac{2t}{1+t^{2}},\ \cos x=\dfrac{1-t^{2}}{1+t^{2}},\ dx=\dfrac{2\,dt}{1+t^{2}}$（三角有理式的最后手段）。

> [!note] 📌 **倒代换触发条件**
> 当被积函数**分母的 $x$ 幂次比分子高 $\ge2$ 次**时，作倒代换 $x=\dfrac1t$（$dx=-\dfrac{dt}{t^2}$），可把高次项翻到分子、化简为低幂结构。

> [!note] 📌 **复杂整体直接代换**
> 被积函数含 $\sqrt{ax+b}$、$\sqrt{ax^2+bx+c}$、$e^x$、$\ln x$、$\arcsin x$、$\arctan x$ 等复杂结构时，可"举重若轻"直接令复杂部分 $=t$。
> **但例外**：当 $\ln x$、$\arcsin x$、$\arctan x$ 与 $P_n(x)$ 或 $e^x$ 相乘时，**优先用分部积分**（取它们为 $u$，求导后简化），直接代换反而会复杂化。

## 💡 方法三：分部积分

$$
\int u\,dv=uv-\int v\,du
$$

取 $u$ 的优先顺序口诀「**反、对、幂、三、指**」——排在前面的留下当 $u$，排在后面的凑进 $dv$（三角与指数相遇则循环两次解方程）。

**分部积分的三大场景**：

1. **降幂**：被积函数为 $x^n\cdot$ 三角函数/指数（$u=x^n$，对幂次反复分部直至 $x^n$ 消失——$\int P_n(x)e^{ax}dx$、$\int P_n(x)\sin ax\,dx$ 皆属此类）；
2. **去超越**：被积函数为 $x^n\cdot$ 对数/反三角（$u=$ 对数/反三角，$dv=x^n dx$，分部一次消去 $\ln x/\arcsin x/\arctan x$）；
3. **循环方程**：$\int e^{ax}\sin bx\,dx$、$\int e^{ax}\cos bx\,dx$、$\int\sec^n x\,dx$（$n\ge3$ 奇数两次分部回自身 → 解方程）。循环积分直接背结论：

$$
\boxed{\int e^{ax}\sin bx\,dx=\frac{e^{ax}(a\sin bx-b\cos bx)}{a^{2}+b^{2}}+C},\qquad
\boxed{\int e^{ax}\cos bx\,dx=\frac{e^{ax}(a\cos bx+b\sin bx)}{a^{2}+b^{2}}+C}
$$

$\int\sec x\,dx$ 的推导（凑出部分分式）：$\int\sec x\,dx=\int\frac{\sec x(\sec x+\tan x)}{\sec x+\tan x}dx=\ln|\sec x+\tan x|+C$。$\int\csc x\,dx$ 同理。

### 📊 分部积分推广公式（表格法，张宇第9讲）

对 $\int P_n(x)\,e^{ax}dx$、$\int P_n(x)\sin ax\,dx$、$\int P_n(x)\cos ax\,dx$（$P_n$ 为 $n$ 次多项式），用**表格法**一行行算，免去反复分部：

1. 左列放 $P_n(x)$（求导）与 $u$，右列放 $\int dv$ 对应的原函数；
2. 左列反复求导到 $0$，右列反复积分；**斜线相乘、符号 + - + - 交替**，最后求和加 $C$。

**例**：$\displaystyle\int (x^{2}+1)e^{x}dx$ 表格法：

| 符号 | 求导列 | 积分列 |
|:--:|:--|:--|
| $+$ | $x^{2}+1$ | $e^{x}$ |
| $-$ | $2x$ | $e^{x}$ |
| $+$ | $2$ | $e^{x}$ |
| $-$ | $0$ | $e^{x}$ |

结果：$(x^{2}+1)e^{x}-2x e^{x}+2 e^{x}+C=(x^{2}-2x+3)e^{x}+C$。（"反、对、幂、三、指"中靠后的当 $u$ 时也可用表格法，只需注意左右列交换。）

> [!tip] 💡 表格法适用范围
> $u$ 是多**项式**（求导有限次归零）时表格法最优；$u$ 是对数/反三角（求导不归零）时仍用普通分部。三角×指数的循环型用表格法也能算（周期循环后解方程），但直接背结论更快。

## 💡 有理函数：部分分式

$\dfrac{P(x)}{Q(x)}$（假分式先长除）按分母因式拆：

- 每个 $(x-a)^{k}$ 贡献 $\dfrac{A_1}{x-a}+\cdots+\dfrac{A_k}{(x-a)^{k}}$；
- 每个不可约 $(x^{2}+px+q)^{k}$ 贡献 $\dfrac{B_1x+C_1}{x^{2}+px+q}+\cdots+\dfrac{B_kx+C_k}{(x^{2}+px+q)^{k}}$。

与拉氏反变换的部分分式法是同一套路（系数留数法见 [[00 拉普拉斯变换（数学基础）]]）。

## 📝 牛顿-莱布尼茨公式与变限积分求导
![[高数-变上限积分.png|560]]
*变上限积分函数 $\Phi(x)=\int_a^x f(t)\,dt$ 满足 $\Phi'(x)=f(x)$*


$$
\int_a^b f(x)\,dx=F(b)-F(a),\qquad
\frac{d}{dx}\int_{\varphi_1(x)}^{\varphi_2(x)}f(t)\,dt=f\bigl(\varphi_2(x)\bigr)\varphi_2'(x)-f\bigl(\varphi_1(x)\bigr)\varphi_1'(x)
$$

> [!note] 📌 **NL 公式推广（分段有原函数）**
> 若 $f$ 在 $[a,b]$ 上分段可积，在 $[a,c)$ 上原函数为 $F_1(x)$、$(c,b]$ 上原函数为 $F_2(x)$，则
> $$
> \int_a^b f\,dx = F_1(c^-)-F_1(a) + F_2(b)-F_2(c^+)
> $$
> 单侧极限 $F_1(c^-)$ 与 $F_2(c^+)$ **都存在**才收敛；任一不存在 ⟹ 积分发散。反常积分计算的关键 —— 把分段原函数在分界点处求单侧极限。

> [!note] 📌 **定积分换元"三换"原则**
> 换元 $x=\varphi(t)$ 时**三处必须同步换**：① 被积函数 $f(x)\to f(\varphi(t))$；② 积分变量 $dx\to \varphi'(t)dt$；③ **积分上下限**（$\varphi(\alpha)=a,\varphi(\beta)=b$）。漏掉上下限是最常见错误。
> 常用快速换元：$x=\pi\pm t$ ✓ $\sin(\pi\pm t)=\mp$ 等符号翻号；$x=\tfrac\pi2\pm t$ ✓ $\sin\leftrightarrow\cos$ 互换。

> [!warning] 被积函数中含 $x$ 的情形
> 例如 $\displaystyle\int_0^{x}(x-t)f(t)\,dt$，应先将 $x$ 提出积分号（$=x\!\int_0^x\! f\,dt-\int_0^x\! tf\,dt$）或作换元 $u=x-t$ 处理，再求导。

## 变限积分函数的性质

设 $F(x)=\displaystyle\int_0^{x}f(t)\,dt$：

| $f$ 的性质 | $F$ 的性质 |
| ---------- | ---------- |
| 奇函数 | $F$ 为偶函数（此时 $f$ 的一切原函数都是偶函数） |
| 偶函数 | $F$ 为奇函数（仅 $F$ 这一个原函数是奇函数） |
| 以 $T$ 为周期 | $F$ 以 $T$ 为周期 $\iff \displaystyle\int_0^{T}f\,dt=0$ |
| 连续 | $F$ 可导；$f$ 有跳跃间断点时 $F$ 在该点连续但不可导 |

## 🔷 对称性、周期性、区间再现
![[高数-奇偶积分对称性.png|560]]
*对称区间：奇函数积分为 0，偶函数积分为 $2\int_0^a$*


| 性质 | 公式 |
| ---- | ---- |
| 奇偶性 | $\displaystyle\int_{-a}^{a}$：奇函数 $=0$；偶函数 $=2\int_0^{a}$ |
| 区间再现 | $\displaystyle\int_a^b f(x)\,dx=\int_a^b f(a+b-x)\,dx$（凑对称、去绝对值） |
| $\sin/\cos$ 互换 | $\displaystyle\int_0^{\pi/2}f(\sin x)\,dx=\int_0^{\pi/2}f(\cos x)\,dx$ |
| 含 $x$ 公式 | $\displaystyle\int_0^{\pi}x f(\sin x)\,dx=\frac{\pi}{2}\int_0^{\pi}f(\sin x)\,dx$ |
| 周期性 | $\displaystyle\int_a^{a+T}f=\int_0^{T}f$（$f$ 以 $T$ 为周期） |

## 📝 华里士（Wallis）公式

$$
\int_0^{\pi/2}\sin^{n}x\,dx=\int_0^{\pi/2}\cos^{n}x\,dx=
\begin{cases}
\dfrac{n-1}{n}\cdot\dfrac{n-3}{n-2}\cdots\dfrac{1}{2}\cdot\dfrac{\pi}{2}, & n\ \text{为偶数}\\[3mm]
\dfrac{n-1}{n}\cdot\dfrac{n-3}{n-2}\cdots\dfrac{2}{3}, & n\ \text{为奇数}
\end{cases}
$$

**递推公式（推导本质）**：$I_n=\int_0^{\pi/2}\sin^n x\,dx$，分部积分得
$$
\boxed{I_n=\dfrac{n-1}{n}I_{n-2}},\quad I_0=\dfrac{\pi}{2},\ I_1=1,\quad I_2=\dfrac12\cdot\dfrac{\pi}{2},\ I_3=\dfrac23
$$
"n 偶 → 含 $I_0\cdot\pi/2$"；"n 奇 → 含 $I_1=1$"（折半连乘即得华里士公式）。

双阶乘写法：$n$ 为偶数时 $=\dfrac{(n-1)!!}{n!!}\cdot\dfrac{\pi}{2}$，$n$ 为奇数时 $=\dfrac{(n-1)!!}{n!!}$（双阶乘见 [[附录 三角与代数补充]]）。

区间扩展：$\displaystyle\int_0^{\pi}\sin^{n}=2\int_0^{\pi/2}\sin^{n}$（对任意 $n$ 成立）；$\displaystyle\int_0^{\pi}\cos^{n}$ 与 $\displaystyle\int_0^{2\pi}\sin^{n}$（或 $\cos^{n}$）：$n$ 为奇数时 $=0$，$n$ 为偶数时分别为 $2$ 倍、$4$ 倍的 $\displaystyle\int_0^{\pi/2}$。

## 📝 反常积分（无穷限与瑕积分）

### 1. 无穷限反常积分

$$
\int_a^{+\infty}f(x)\,dx=\lim_{b\to+\infty}\int_a^b f(x)\,dx,\qquad
\int_{-\infty}^{b}f(x)\,dx=\lim_{a\to-\infty}\int_a^b f(x)\,dx
$$

- **两侧无穷**：$\displaystyle\int_{-\infty}^{+\infty}f(x)\,dx$ 必须**拆成两段** $\int_{-\infty}^{c}+\int_c^{+\infty}$，**两段都收敛**才收敛（不能用"对称区间奇函数为0"直接判定——$\int_{-\infty}^{+\infty}x\,dx$ 不收敛）。
- 若 $\lim\limits_{b\to+\infty}\int_a^b f$ 存在（有限），称**收敛**；极限为 $\infty$ 或不存在，称**发散**。

### 2. 瑕积分（无界函数的反常积分）

若 $f$ 在 $x=a$（或 $x=b$）附近无界（$a$ 为**瑕点**）：

$$
\int_a^b f(x)\,dx=\lim_{\varepsilon\to0^+}\int_{a+\varepsilon}^b f(x)\,dx\qquad(\text{瑕点在左端点})
$$

- 常见瑕点：分母为 0（$\dfrac{1}{x^a}$ 在 $x=0$）、$\ln$ 真数为 0（$\ln x$ 在 $x=0$）、根号内为 0（$\dfrac{1}{\sqrt{x-a}}$）、$\tan x$ 在 $\dfrac{\pi}{2}$ 等。
- 区间**内部有瑕点**（如 $\int_{-1}^{1}\dfrac{dx}{x^2}$ 在 $x=0$）：必须**按瑕点拆开** $\int_{-1}^{0}+\int_0^{1}$，两段都收敛才收敛（$\int_{-1}^1\dfrac{dx}{x^2}$ 发散！不能当普通定积分算）。

### 3. 计算步骤（三步法）

1. **找坏点**：无穷点 + 所有瑕点（分母/对数/根号为 0 的点），**按坏点把积分拆段**；
2. **逐段求**：每段用 NL 公式求原函数，代上下限时对坏点取**极限**（$b\to+\infty$ 或 $\varepsilon\to0^+$）；
3. **判断**：全部段都收敛 ⟹ 原积分收敛；任一段发散 ⟹ 原积分发散（收敛值 = 各段之和）。

### 4. 经典例题

> [!example] ✏️ **例1：无穷限**
> $\displaystyle\int_1^{+\infty}\frac{dx}{x^2}=\lim_{b\to+\infty}\Bigl[-\frac1x\Bigr]_1^b=\lim_{b\to+\infty}\Bigl(1-\frac1b\Bigr)=1$ ⟹ 收敛。
>
> $\displaystyle\int_1^{+\infty}\frac{dx}{x}=\lim_{b\to+\infty}\ln b=+\infty$ ⟹ 发散（$p=1$ 时发散）。

> [!example] ✏️ **例2：瑕积分**
> $\displaystyle\int_0^1\frac{dx}{\sqrt{x}}=\lim_{\varepsilon\to0^+}\Bigl[2\sqrt{x}\Bigr]_\varepsilon^1=2$ ⟹ 收敛。
>
> $\displaystyle\int_0^1\frac{dx}{x}=\lim_{\varepsilon\to0^+}\bigl[-\ln\varepsilon\bigr]=+\infty$ ⟹ 发散。

> [!example] ✏️ **例3：内部瑕点必须拆**
> $\displaystyle\int_{-1}^{1}\frac{dx}{x^2}$：$x=0$ 为瑕点，拆 $\int_{-1}^0+\int_0^1$；$\int_0^1\dfrac{dx}{x^2}=\lim\limits_{\varepsilon\to0^+}\Bigl[\dfrac{1}{\varepsilon}-1\Bigr]=+\infty$ ⟹ 发散。（若直接当普通积分得 $-2$，是**错误**的。）

> [!example] ✏️ **例4：换元/分部求反常积分**
> $\displaystyle\int_0^{+\infty}x e^{-x}\,dx=\lim_{b\to+\infty}\Bigl[-(x+1)e^{-x}\Bigr]_0^b=\lim_{b\to+\infty}\Bigl[1-\frac{b+1}{e^b}\Bigr]=1$（用 $\lim\frac{x}{e^x}=0$）。

### 5. 常用结果（背）

$$
\boxed{\int_0^{+\infty}e^{-ax}\,dx=\frac1a\ (a>0)},\qquad
\boxed{\int_0^{+\infty}x^n e^{-ax}\,dx=\frac{n!}{a^{n+1}}\ (a>0)}
$$

> [!note] 📌 **Gamma 函数（联系 $\int_0^{+\infty}x^n e^{-x} dx = n!$）**
> $\Gamma(\alpha)=\displaystyle\int_0^{+\infty}x^{\alpha-1}e^{-x}dx$（$\alpha>0$），递推 $\Gamma(\alpha+1)=\alpha\,\Gamma(\alpha)$，$\Gamma(1)=1$，$\Gamma(n+1)=n!$（$n$ 非负整数）。$\Gamma(\tfrac12)=\sqrt\pi$（用 $\int_0^{+\infty}e^{-x^2}dx=\frac{\sqrt\pi}{2}$ 代入 $x=t^2$）。
> 应用：$\int_0^{+\infty}x^n e^{-x}dx = \Gamma(n+1)=n!$；非整数幂有 $\int_0^{+\infty}\sqrt{x}\,e^{-x}dx = \Gamma(\tfrac32)=\tfrac12\Gamma(\tfrac12)=\tfrac{\sqrt\pi}{2}$。
> 张宇提示：考研虽不考严谨推导，但记住 $\Gamma(n+1)=n!$ 可秒算 $\int_0^{+\infty}P_n(x)e^{-x}dx$ 类题。

$$
\int_0^{+\infty}e^{-x^2}\,dx=\frac{\sqrt{\pi}}{2}\ \,(\text{概率积分}),\qquad
\int_0^{+\infty}\frac{dx}{1+x^2}=\frac{\pi}{2}
$$

> 概率积分 $\displaystyle\int_0^{+\infty}e^{-x^2}dx=\frac{\sqrt\pi}{2}$ 的推导见 [[14 第14讲 二重积分]]（极坐标换元）。

### 6. $p$ 判别（速查）

| 反常积分类型 | 收敛条件 |
|:--|:--|
| $\displaystyle\int_1^{+\infty}\frac{dx}{x^p}$ | $p>1$ |
| $\displaystyle\int_0^1\frac{dx}{x^p}$ | $p<1$ |
| $\displaystyle\int_2^{+\infty}\frac{dx}{x\ln^p x}$ | $p>1$ |

> [!warning] ⚠️ 易错
> ① 无穷限 $p>1$ 收敛、瑕积分 $p<1$ 收敛——**两者相反**，别记混；② $p=1$ 是分界（$\int_1^\infty\frac{dx}{x}$、$\int_0^1\frac{dx}{x}$ 都发散）；③ 内部瑕点必须拆段，否则会算出错误的有穷值；④ 两侧无穷要拆成两段，不能直接对 $[-\infty,+\infty]$ 算。

## ✏️ 定积分计算核心例题（华里士 / 对称性 / 区间再现 / 含 x 公式）

> [!example] ✏️ **例1：华里士公式**
> 求 $I=\displaystyle\int_0^{\pi}\sin^4 x\,dx$：$I=2\int_0^{\pi/2}\sin^4 x\,dx=2\cdot\dfrac{3}{4}\cdot\dfrac{1}{2}\cdot\dfrac{\pi}{2}=\dfrac{3\pi}{8}$（偶数次用双阶乘 $\frac{(n-1)!!}{n!!}\cdot\frac\pi2$）。

> [!example] ✏️ **例2：对称区间奇偶性**
> $I=\displaystyle\int_{-1}^{1}\Bigl(x^3\cos x+\sqrt{1-x^2}\Bigr)\,dx$：$x^3\cos x$ 为奇函数（$=0$），$\sqrt{1-x^2}$ 为偶函数，故 $I=2\int_0^1\sqrt{1-x^2}\,dx=2\cdot\dfrac{\pi}{4}=\dfrac{\pi}{2}$（四分之一圆面积）。

> [!example] ✏️ **例3：区间再现**
> 求 $I=\displaystyle\int_0^{\pi}\frac{x\sin x}{1+\cos^2 x}\,dx$：令 $x\to\pi-x$，$I=\displaystyle\int_0^{\pi}\frac{(\pi-x)\sin x}{1+\cos^2 x}\,dx$，两式相加：
> $$
> 2I=\pi\int_0^{\pi}\frac{\sin x}{1+\cos^2 x}\,dx=\pi\Bigl[-\arctan(\cos x)\Bigr]_0^{\pi}=\pi\Bigl(\frac{\pi}{4}+\frac{\pi}{4}\Bigr)=\frac{\pi^2}{2}
> $$
> ⟹ $I=\dfrac{\pi^2}{4}$。（区间再现消去"分子上的 $x$"——高频技巧）

> [!example] ✏️ **例4：含 $x$ 公式**
> $I=\displaystyle\int_0^{\pi}x\sin^3 x\,dx=\frac{\pi}{2}\int_0^{\pi}\sin^3 x\,dx=\frac{\pi}{2}\cdot2\int_0^{\pi/2}\sin^3 x\,dx=\frac{\pi}{2}\cdot2\cdot\frac23=\frac{2\pi}{3}$（华里士奇数次 $\frac{(n-1)!!}{n!!}=\frac23$）。

> [!example] ✏️ **例5：变限积分求导 + 洛必达**
> 求 $\displaystyle\lim_{x\to0}\frac{\int_0^x e^{t^2}\,dt-\int_0^x\cos t\,dt}{x^3}$：分子求导 $e^{x^2}-\cos x\sim x^2-\bigl(1-\frac{x^2}{2}\bigr)\cdots$，用洛必达：原式 $=\lim\limits_{x\to0}\dfrac{e^{x^2}-\cos x}{3x^2}=\lim\limits_{x\to0}\dfrac{(1+x^2)-(1-\frac{x^2}{2})}{3x^2}=\dfrac{\frac32}{3}=\dfrac12$。

## ✏️📝 定积分计算的常用手法总结

| 手法 | 场景 |
| ---- | ---- |
| 对称性（奇偶） | 对称区间优先看奇偶，奇函数直接 $=0$ |
| 区间再现 $x\to a+b-x$ | 被积函数含 $f(a+b-x)$ 与 $f(x)$ 时相加消元 |
| 周期函数平移 | $\int_a^{a+T}f=\int_0^T f$ |
| 华里士公式 | 幂三角 $\sin^n,\cos^n$ 在 $[0,\pi/2]$ |
| 含 $x$ 公式 | $\int_0^\pi x f(\sin x)dx=\frac{\pi}{2}\int_0^\pi f(\sin x)dx$ |
| 换元法 | 根式三角代换、倒代换、$x=\frac1t$ |
| 分部积分 | 幂×超越、循环型 |
| 变限积分求导 | 上限下限同时是函数时用 NL 求导公式 |
