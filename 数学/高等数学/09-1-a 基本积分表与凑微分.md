# 第9讲（一-1）基本积分表与凑微分

> [!abstract] 本讲定位
> 基本积分表（含根式三兄弟）、凑微分的常用凑法表与「导数检验」技巧。

## 🧮 9.1 基本积分表

| 公式 | 公式 |
| :-- | :-- |
| $\displaystyle\int x^{\alpha}dx=\frac{x^{\alpha+1}}{\alpha+1}+C\ (\alpha\ne-1)$ | $\displaystyle\int\frac{dx}{x}=\ln\lvert x\rvert+C$ |
| $\displaystyle\int e^{x}dx=e^{x}+C$ | $\displaystyle\int a^{x}dx=\frac{a^{x}}{\ln a}+C$ |
| $\displaystyle\int \sin x\,dx=-\cos x+C$ | $\displaystyle\int \cos x\,dx=\sin x+C$ |
| $\displaystyle\int \sec^{2}x\,dx=\tan x+C$ | $\displaystyle\int \csc^{2}x\,dx=-\cot x+C$ |
| $\displaystyle\int \sec x\tan x\,dx=\sec x+C$ | $\displaystyle\int\frac{dx}{\sqrt{a^{2}-x^{2}}}=\arcsin\frac{x}{a}+C$ |
| $\displaystyle\int \tan x\,dx=-\ln\lvert\cos x\rvert+C$ | $\displaystyle\int \cot x\,dx=\ln\lvert\sin x\rvert+C$ |
| $\displaystyle\int \sec x\,dx=\ln\lvert\sec x+\tan x\rvert+C$ | $\displaystyle\int \csc x\,dx=\ln\lvert\csc x-\cot x\rvert+C$ |
| $\displaystyle\int\frac{dx}{a^{2}+x^{2}}=\frac{1}{a}\arctan\frac{x}{a}+C$ | $\displaystyle\int\frac{dx}{\sqrt{a^{2}-x^{2}}}=\arcsin\frac{x}{a}+C$ |
| $\displaystyle\int\frac{dx}{x^{2}-a^{2}}=\frac{1}{2a}\ln\left\lvert\frac{x-a}{x+a}\right\rvert+C$ | $\displaystyle\int\frac{dx}{a^{2}-x^{2}}=\frac{1}{2a}\ln\left\lvert\frac{a+x}{a-x}\right\rvert+C$ |
| $\displaystyle\int\ln x\,dx=x\ln x-x+C$ | $\displaystyle\int\frac{dx}{1+x^{2}}=\arctan x+C$ |
| $\displaystyle\int\frac{dx}{\sqrt{1-x^{2}}}=\arcsin x+C$ | $\displaystyle\int\arctan x\,dx=x\arctan x-\frac{1}{2}\ln(1+x^{2})+C$ |
| $\displaystyle\int\arcsin x\,dx=x\arcsin x+\sqrt{1-x^{2}}+C$ | $\displaystyle\int\log_{a}x\,dx=\frac{x\ln x-x}{\ln a}+C$ |

根式三兄弟（$\pm$ 号对应取）：

$$
\int\frac{dx}{\sqrt{x^{2}\pm a^{2}}}=\ln\left\lvert x+\sqrt{x^{2}\pm a^{2}}\right\rvert+C
$$

$$
\begin{aligned}
\int\sqrt{a^{2}-x^{2}}\,dx&=\frac{x}{2}\sqrt{a^{2}-x^{2}}\\[4pt]
&\quad+\frac{a^{2}}{2}\arcsin\frac{x}{a}+C
\end{aligned}
$$

$$
\begin{aligned}
\int\sqrt{x^{2}\pm a^{2}}\,dx&=\frac{x}{2}\sqrt{x^{2}\pm a^{2}}\\[4pt]
&\quad\pm\frac{a^{2}}{2}\ln\left\lvert x+\sqrt{x^{2}\pm a^{2}}\right\rvert+C
\end{aligned}
$$

## 🧮 9.2 方法一：凑微分（第一类换元）

| 凑法 | 凑法 |
| :-- | :-- |
| $x\,dx=\frac{1}{2}d(x^{2})$ | $\frac{dx}{x}=d(\ln\lvert x\rvert)$ |
| $e^{x}dx=d(e^{x})$ | $\frac{dx}{\sqrt{x}}=2\,d(\sqrt{x})$ |
| $\frac{dx}{x^{2}}=-d\!\left(\frac{1}{x}\right)$ | $\sin x\,dx=-d(\cos x)$，$\cos x\,dx=d(\sin x)$ |
| $\sec^{2}x\,dx=d(\tan x)$ | $\frac{dx}{1+x^{2}}=d(\arctan x)$ |
| $\frac{f'(x)}{f(x)}dx=d\bigl(\ln\lvert f(x)\rvert\bigr)$ | $(1+\ln x)\,dx=d(x\ln x)$ |

> [!tip] 凑微分的"导数检验"（张宇第9讲）
> 遇到不知怎么凑的积分，**对被积函数的复杂部分 $g(x)$ 求导**：若 $g'(x)=f(x)$（或只差常数倍），则 $d[g(x)]=f(x)dx$ 即可凑。
>
> 例：$\displaystyle\int\frac{\cos\theta+\sin\theta}{(\cos\theta-\sin\theta)^{2}}d\theta$——
> 对复杂部分 $g=\cos\theta-\sin\theta$ 求导得 $g'=-(\sin\theta+\cos\theta)$，恰为分子的相反数，故：
>
> $$
> \begin{aligned}
> \dfrac{\cos\theta+\sin\theta}{(\cos\theta-\sin\theta)^{2}}\,d\theta&=d\!\Bigl(\dfrac{1}{g}\Bigr)
> \end{aligned}
> $$
>
> 直接积分。
