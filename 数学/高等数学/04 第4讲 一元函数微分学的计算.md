## 📝 求导法则

| 法则 | 公式 |
| ---- | ---- |
| 四则 | $(u\pm v)'=u'\pm v'$；$(uv)'=u'v+uv'$；$\left(\dfrac{u}{v}\right)'=\dfrac{u'v-uv'}{v^{2}}$ |
| 复合（链式） | $\{f[g(x)]\}'=f'[g(x)]\cdot g'(x)$ |
| **微分形式不变性** | $d\bigl[f(u)\bigr]=f'(u)\,du$，无论 $u$ 是自变量还是中间变量都成立 |
| 反函数 | $\dfrac{dy}{dx}=\dfrac{1}{dx/dy}$；二阶 $\dfrac{d^{2}x}{dy^{2}}=-\dfrac{y''}{(y')^{3}}$ |
| 参数方程 | $\dfrac{dy}{dx}=\dfrac{\dot y}{\dot x}$；$\dfrac{d^{2}y}{dx^{2}}=\dfrac{\ddot y\,\dot x-\dot y\,\ddot x}{\dot x^{3}}$ |
| 隐函数 | $F(x,y)=0$ 两边对 $x$ 求导（$y$ 视为 $y(x)$），或 $\dfrac{dy}{dx}=-\dfrac{F_x}{F_y}$（前提 **$F_y\ne0$**：$F_y\ne0$ 时方程局部唯一确定 $y=y(x)$） |
| 幂指函数 | $u^{v}=e^{v\ln u}$ 再求导，或对数求导法（两边取 $\ln$） |

**对数求导法完整套路**（幂指函数、连乘/连除/幂积混合型的首选）：
1. 两边取 $\ln$（$y>0$；若 $y$ 可负，先加绝对值或分区间讨论）；
2. 用对数性质化简：$\ln u^v=v\ln u$、$\ln(uv)=\ln u+\ln v$、$\ln\frac uv=\ln u-\ln v$；
3. 两边对 $x$ 求导（左边 $\dfrac{y'}{y}$，右边按链式/四则）；
4. 解出 $y'=y\cdot(\text{右边导数})$，代回 $y$ 的表达式。

> [!example] ✏️ **例**
> $y=x^{\sin x}\ (x>0)$：$\ln y=\sin x\ln x$，两边求导 $\dfrac{y'}{y}=\cos x\ln x+\dfrac{\sin x}{x}$，故 $y'=x^{\sin x}\Bigl(\cos x\ln x+\dfrac{\sin x}{x}\Bigr)$。

> [!tip] 💡 **多因式相乘化"经典形式"**
> 因式超过 3 个的乘积直接求导计算量爆炸。**化两项乘积** $f(x)=g_1(x)\cdot g_2(x)$（把"特立独行"的项单独拎出，其余 $n-1$ 项凑成一项），再用乘法公式 $(g_1g_2)'=g_1'g_2+g_1g_2'$，往往 $g_1$ 在该点的导数为 0 或直接代入后只剩 $g_2$ 项。张宇称此为"经典形式"。

## 📝 分段函数与含绝对值函数求导

**分段函数求导原则**（书 p130）：

1. **分段点** $x_0$：用导数定义求 $f'_-(x_0)$ 与 $f'_+(x_0)$，二者相等才可导；
2. **非分段点**：直接用导数公式（在该侧用该侧的表达式）。

**含绝对值函数求导套路**（书 p130）：

1. 先去绝对值写成分段函数 $y=\lvert x\rvert\Rightarrow\begin{cases}x,&x\ge0\\-x,&x<0\end{cases}$；
2. 无定义点自然不连续也不可导，不必管；
3. 分段点用定义，非分段点用公式。

> [!note] 📌 **关键反例**
> $y=\lvert x\rvert e^x$ 在 $x=0$ 处：$\ln$-型去绝对值得 $\begin{cases}-xe^x,x<0\\xe^x,x\ge0\end{cases}$，左右导 $y'_-(0)=\lim\dfrac{-xe^x}{x}=-1$、$y'_+(0)=\lim\dfrac{xe^x}{x}=1$ 不等 ⟹ $x=0$ 处**不可导**。

> [!warning] ⚠️ **常见错误**
> $(\ln\lvert x\rvert)'=\dfrac{1}{x}$（$x\ne0$）：可"视绝对值不见"直接求导。但 $(\lvert x\rvert)'$ 不能视而不见 ⟹ 分段点不可导。

> [!tip] 💡 **二阶隐函数公式管背**
> 涉及 $y^n$、$xy$ 类隐函数：$(y^n)'=ny^{n-1}y'$，$(xy)'=y+xy'$，$(xy')'=y'+xy''$。

## 📝 常用高阶导数

| 公式 |
| ---- |
| $(e^{ax})^{(n)}=a^{n}e^{ax}$ |
| $(\sin ax)^{(n)}=a^{n}\sin\left(ax+\dfrac{n\pi}{2}\right)$，$\cos$ 同理 |
| $\left(\dfrac{1}{ax+b}\right)^{(n)}=\dfrac{(-1)^{n}\,n!\,a^{n}}{(ax+b)^{n+1}}$ |
| $[\ln(ax+b)]^{(n)}=\dfrac{(-1)^{n-1}(n-1)!\,a^{n}}{(ax+b)^{n}}$ |
| $(x^{m})^{(n)}=m(m-1)\cdots(m-n+1)\,x^{m-n}$ |
| 莱布尼茨：$(uv)^{(n)}=\sum\limits_{k=0}^{n}C_n^{k}\,u^{(n-k)}v^{(k)}$ |

**莱布尼茨公式用法**：取 $v$ 为**低次多项式**（$x,x^{2}$ 等），$k$ 超过次数后 $v^{(k)}\equiv0$，和式只剩前几项。

> [!example] ✏️ **经典例**
> $$
> \boxed{\bigl(x^{2}e^{x}\bigr)^{(n)}=e^{x}\bigl[x^{2}+2nx+n(n-1)\bigr]}
> \quad\text{（只有 }k=0,1,2\text{ 三项：}C_n^{0}x^{2}+C_n^{1}\cdot2x+C_n^{2}\cdot2\text{）}
> $$

系数就是组合数 $C_n^{k}$，排列组合公式见 [[附录 三角与代数补充]]；公式形状与二项式定理 $(a+b)^{n}$ 完全同构，一起记。

**求 $f^{(n)}(0)$ 套路**：写出麦克劳林展开 $f=\sum a_k x^k$，则 $f^{(n)}(0)=n!\,a_n$（比硬求 $n$ 阶导快得多），展开式见 [[06 第6讲 一元函数微分学的应用（二）中值定理与泰勒公式]]。

## 📝 切线与法线（常考小题）

| 曲线形式 | 切线方程 | 法线方程 |
|:--|:--|:--|
| $y=f(x)$ 在 $x_0$ 处 | $y-y_0=f'(x_0)(x-x_0)$ | $y-y_0=-\dfrac{1}{f'(x_0)}(x-x_0)$ |
| 参数式 $\begin{cases}x=x(t)\\y=y(t)\end{cases}$ 在 $t_0$ 处 | $\dfrac{y-y_0}{\dot y(t_0)}=\dfrac{x-x_0}{\dot x(t_0)}$ | $\dfrac{y-y_0}{\dot x(t_0)}=-\dfrac{x-x_0}{\dot y(t_0)}$ |
| $F(x,y)=0$ 在 $(x_0,y_0)$ 处 | $F_x(x_0,y_0)(x-x_0)+F_y(x_0,y_0)(y-y_0)=0$ | 交换 $F_x,F_y$ 并添负号 |

> [!abstract] 📋 补充说明
> 切线斜率 $k=f'(x_0)$；法线斜率 $=-1/k$（切线水平时法线铅直反之亦然）。参数式用 $\dot y/\dot x$ 求导，隐函数用公式 $dy/dx=-F_x/F_y$。

## ✏️ 典型例题

> [!example] ✏️ **例1：复合求导**
> $y=\ln(1+e^{2x})$：$y'=\dfrac{1}{1+e^{2x}}\cdot e^{2x}\cdot2=\dfrac{2e^{2x}}{1+e^{2x}}$。

> [!example] ✏️ **例2：隐函数求导**
> $y=1+xe^y$，求 $y'$ 与 $y''$：两边对 $x$ 求导 $y'=e^y+xe^y y'$ ⟹ $y'=\dfrac{e^y}{1-xe^y}=\dfrac{e^y}{2-y}$（利用原式 $1-xe^y=2-y$）。再对 $x$ 求导得 $y''=\dfrac{e^y y'(2-y)+e^y y'}{(2-y)^2}=\dfrac{e^y y'(3-y)}{(2-y)^2}$。

> [!example] ✏️ **例3：参数方程求导**
> $\begin{cases}x=t^2\\y=t^3\end{cases}$，求 $\dfrac{dy}{dx}$ 与 $\dfrac{d^2y}{dx^2}$：$\dot x=2t,\ \dot y=3t^2$ ⟹ $\dfrac{dy}{dx}=\dfrac{3t^2}{2t}=\dfrac{3t}{2}$；$\dfrac{d^2y}{dx^2}=\dfrac{\ddot y\dot x-\dot y\ddot x}{\dot x^3}=\dfrac{6t\cdot2t-3t^2\cdot2}{(2t)^3}=\dfrac{12t^2-6t^2}{8t^3}=\dfrac{3}{4t}$。

> [!example] ✏️ **例4：莱布尼茨求高阶导**
> 求 $(x^2\sin x)^{(10)}$：取 $u=\sin x$（$u^{(k)}=\sin\bigl(x+\tfrac{k\pi}{2}\bigr)$）、$v=x^2$（$k>2$ 后为 0）：$(x^2\sin x)^{(10)}=C_{10}^0 x^2\sin\bigl(x+\tfrac{10\pi}{2}\bigr)+C_{10}^1\cdot2x\sin\bigl(x+\tfrac{9\pi}{2}\bigr)+C_{10}^2\cdot2\sin\bigl(x+\tfrac{8\pi}{2}\bigr)$，化简即得。

> [!example] ✏️ **例5：麦克劳林求 $f^{(n)}(0)$**
> 求 $f(x)=e^{x^2}$ 的 $f^{(100)}(0)$：$e^{x^2}=\sum\dfrac{x^{2k}}{k!}$，$x^{100}$ 项对应 $k=50$，系数 $a_{100}=\dfrac{1}{50!}$ ⟹ $f^{(100)}(0)=100!\cdot\dfrac{1}{50!}$。

> [!example] ✏️ **例6：反函数求导**
> $y=f(x)=x+e^x$，求 $\dfrac{dx}{dy}$ 与 $\dfrac{d^2x}{dy^2}$ 在 $y=1$ 处的值。
> $f(0)=1$，$f'(x)=1+e^x$，$f''(x)=e^x$。$\dfrac{dx}{dy}=\dfrac{1}{f'(x)}=\dfrac{1}{1+e^x}$；在 $y=1$（$x=0$）处 $=\dfrac12$。
> $\dfrac{d^2x}{dy^2}=-\dfrac{f''(x)}{[f'(x)]^3}=-\dfrac{e^x}{(1+e^x)^3}$；在 $x=0$ 处 $=-\dfrac18$。
