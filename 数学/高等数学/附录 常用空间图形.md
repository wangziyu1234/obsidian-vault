## 二次曲面标准方程速查

下表半轴与半径参数 $a,b,c$ 均取正数，抛物柱面取 $p\ne0$。

| 曲面 | 标准方程 | 图形要点 |
| :-- | :-- | :-- |
| 椭球面 | $\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1$ | 关于三坐标面对称的"蛋形"，三半轴 $a,b,c$ |
| 单叶双曲面 | $\frac{x^2}{a^2}+\frac{y^2}{b^2}-\frac{z^2}{c^2}=1$ | “腰细两头粗”、整体连通的曲面（不是上下分离的两叶；连通不等于单连通） |
| 双叶双曲面 | $\frac{x^2}{a^2}+\frac{y^2}{b^2}-\frac{z^2}{c^2}=-1$ | 上下两叶，$z$ 轴分开 |
| 椭圆抛物面 | $z=\frac{x^2}{a^2}+\frac{y^2}{b^2}$ | 开口向上的"碗"，顶点在原点 |
| 双曲抛物面 | $z=\frac{x^2}{a^2}-\frac{y^2}{b^2}$ | "马鞍面"，$z=xy$ 经旋转即此形（见下） |
| 二次锥面 | $\frac{x^2}{a^2}+\frac{y^2}{b^2}-\frac{z^2}{c^2}=0$ | 顶点在原点的（椭）圆锥面 |
| 椭圆柱面 | $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$ | 沿 $z$ 轴无限延伸的"椭圆柱"（缺哪个变量即平行哪个轴） |
| 抛物柱面 | $y^2=2px$ | 沿 $z$ 轴延伸的抛物柱面 |

> [!tip] 缺哪个字母 = 平行哪个轴
> 方程缺某变量（如 $x^2+y^2=a^2$ 缺 $z$）⟹ 曲面是**平行于该轴**的柱面。这是柱面识别的口诀。

## 球面与半球

| 方程 | 图形 |
| :-- | :-- |
| $x^2+y^2+z^2=a^2$ | 球心原点、半径 $a$ 的球面 |
| $z=\sqrt{a^2-x^2-y^2}\ (a>0)$ | 上半球面（$z\ge0$） |
| $x^2+y^2=a^2,\ z\ge0$ | 半圆柱面（柱轴 $z$ 轴，只取 $z\ge0$） |

## 旋转曲面（绕坐标轴旋转）

若 $yz$ 平面母线已选在 $y\ge0$，绕 $z$ 轴时可用 $r=\sqrt{x^2+y^2}$ 替换 $y$；一般母线含负半平面分支时必须同时保留 $y=r$ 和 $y=-r$：

$$
f(r,z)=0\quad\text{或}\quad f(-r,z)=0,\qquad r=\sqrt{x^2+y^2}
$$

绕 $y$ 轴同理保留原 $z$ 的正负分支。若原方程只含该变量偶次幂，可直接替换平方；例如整条 $y=z$ 旋转生成双锥，而 $r=z$ 仅为上半锥。

| 原曲线（$yz$ 平面） | 绕 $z$ 轴旋转所得 | 方程 |
| :-- | :-- | :-- |
| $z=y^2$（抛物线） | 旋转抛物面 | $z=x^2+y^2$ |
| $\frac{y^2}{a^2}-\frac{z^2}{c^2}=1$（双曲线，开口⊥转轴） | 单叶双曲面 | $\frac{x^2+y^2}{a^2}-\frac{z^2}{c^2}=1$；若开口沿转轴（$\frac{z^2}{c^2}-\frac{y^2}{a^2}=1$ 绕 $z$ 轴）才得双叶 |
| $y=z$（直线） | 圆锥面 | $x^2+y^2=z^2$ |
| 教材图(16)：$x^2+(y-z)^2=(1-z)^2,0\le z\le1$ | 斜圆锥侧面（并非上述坐标轴旋转面的例子） | 顶点固定为 $(0,1,1)$；水平截面圆心 $(0,z,z)$、半径 $1-z$ |

## 双曲抛物面 $z=xy$ 与旋转

$z=xy$ 是**双曲抛物面**（马鞍面）：将坐标轴旋转 $45^\circ$（令 $x=\frac{u-v}{\sqrt2},\ y=\frac{u+v}{\sqrt2}$）得

$$
z=\frac{u^2-v^2}{2}\ \Longrightarrow\ z=\frac12(u^2-v^2)
$$

化为标准双曲抛物面。$z=xy$ 关于 $z$ 轴旋转 $180°$ 对称（$(x,y)\to(-x,-y)$，$z$ 不变）、关于平面 $y=x$ 与 $y=-x$ 对称；**不是**关于原点的中心对称（$(-x)(-y)=xy\ne-z$）。

## 典型相交曲线（书末实例）

| 曲面组合 | 交线或围域含义 |
| :-- | :-- |
| $z=xy,\ y=x$ | 平面与马鞍面交于抛物线 |
| $z=xy,\ x+y=1$ | 截出抛物线弧 |
| $x=1,\ z=0$ | 两平面之交：平行 $y$ 轴的直线 $(1,\ t,\ 0)$ |
| $z=x^2+y^2,\ x^2+y^2=x$ | 旋转抛物面与柱面 $x^2+y^2=x$ 的交线 |
| $z=2(x^2+y^2),\ x^2+y^2=x,\ x^2+y^2=2x,\ z=0$ | 教材图(18)：两圆柱之间、下底0与一个抛物面之间的区域边界，不是把四式同时联立的交线 |

> [!warning] 画图优先：投影法
> 对复杂空间区域，**先把曲面投影到某个坐标面**（消去一个变量，得到投影区域 $D$ 的边界曲线），再在 $D$ 上分上下界。书末几例（图 15–18）皆强调"**投影法更方便**"，统一用"先投影、后定限"。
