# 附录 常用空间图形

> [!abstract] 📋 附录定位
> 对应张宇《基础30讲》高数分册附录3（常用空间图形）。该附录以**图集**形式给出常用二次曲面与典型相交曲线的图像，是**仅数一** [[14 第14讲 二重积分|二重积分]]（及数一第17、18讲）确定积分区域、画投影、求体积的重要参考。本笔记整理各曲面的**标准方程与图形要点**，原图集见书 p552–554。

> [!note] 使用方法
> 画三重积分 / 曲面积分区域时，先把曲面方程对到下列**标准形**，再据标准形特征作图；多数空间曲面都是标准形的**平移、伸缩、旋转**所得。

## 📝 二次曲面标准方程速查

| 曲面 | 标准方程 | 图形要点 |
| :-- | :-- | :-- |
| 椭球面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}+\dfrac{z^2}{c^2}=1$ | 关于三坐标面对称的"蛋形"，三半轴 $a,b,c$ |
| 单叶双曲面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}-\dfrac{z^2}{c^2}=1$ | "腰细两头粗"单连通曲面 |
| 双叶双曲面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}-\dfrac{z^2}{c^2}=-1$ | 上下两叶，$z$ 轴分开 |
| 椭圆抛物面 | $z=\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}$ | 开口向上的"碗"，顶点在原点 |
| 双曲抛物面 | $z=\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}$ | "马鞍面"，$z=xy$ 经旋转即此形（见下） |
| 二次锥面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}-\dfrac{z^2}{c^2}=0$ | 顶点在原点的（椭）圆锥面 |
| 椭圆柱面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1$ | 沿 $z$ 轴无限延伸的"椭圆柱"（缺哪个变量即平行哪个轴） |
| 抛物柱面 | $y^2=2px$ | 沿 $z$ 轴延伸的抛物柱面 |

> [!tip] 缺哪个字母 = 平行哪个轴
> 方程缺某变量（如 $x^2+y^2=a^2$ 缺 $z$）⟹ 曲面是**平行于该轴**的柱面。这是柱面识别的口诀。

## 📝 球面与半球

| 方程 | 图形 |
| :-- | :-- |
| $x^2+y^2+z^2=a^2$ | 球心原点、半径 $a$ 的球面 |
| $z=\sqrt{a^2-x^2-y^2}\ (a>0)$ | 上半球面（$z\ge0$） |
| $x^2+y^2=a^2,\ z\ge0$ | 半圆柱面（柱轴 $z$ 轴，只取 $z\ge0$） |

---

## 📝 旋转曲面（绕坐标轴旋转）

把 $yz$ 平面曲线 $f(y,z)=0$ 绕 $z$ 轴旋转 ⟹ 用 $\sqrt{x^2+y^2}$ 替换 $y$：
$$
f\!\left(\sqrt{x^2+y^2},\ z\right)=0
$$
绕 $y$ 轴则用 $\sqrt{x^2+z^2}$ 替换 $z$，依此类推。

| 原曲线（$yz$ 平面） | 绕 $z$ 轴旋转所得 | 方程 |
| :-- | :-- | :-- |
| $z=y^2$（抛物线） | 旋转抛物面 | $z=x^2+y^2$ |
| $\dfrac{y^2}{a^2}-\dfrac{z^2}{c^2}=1$（双曲线） | 单/双叶双曲面 | 依开口而定 |
| $y=z$（直线） | 圆锥面 | $x^2+y^2=z^2$ |
| 书中例：$x^2+(y-z)^2=(1-z)^2$ | "倒锥形"漏斗 | 顶点随参数移动的旋转面 |

---

## 📝 双曲抛物面 $z=xy$ 与旋转

$z=xy$ 是**双曲抛物面**（马鞍面）：将坐标轴旋转 $45^\circ$（令 $x=\dfrac{u-v}{\sqrt2},\ y=\dfrac{u+v}{\sqrt2}$）得
$$
z=\frac{u^2-v^2}{2}\ \Longrightarrow\ z=\frac12(u^2-v^2)
$$
化为标准双曲抛物面。$z=xy$ 关于原点对称、关于平面 $y=x$ 与 $y=-x$ 对称。

---

## 📝 典型相交曲线（书末实例）

| 交线方程组 | 这是… |
| :-- | :-- |
| $z=xy,\ y=x$ | 平面与马鞍面交于抛物线 |
| $z=xy,\ x+y=1$ | 截出抛物线弧 |
| $x=1,\ z=0$ | 坐标面与柱面的截口 |
| $z=x^2+y^2,\ x^2+y^2=x$ | 旋转抛物面与柱面 $x^2+y^2=x$ 的交线 |
| $z=2(x^2+y^2),\ z=x^2+y^2,\ x^2+y^2=2x,\ z=0$ | 两个旋转抛物面与竖直柱面围成区域的边界 |

> [!warning] ⚠️ 画图优先：投影法
> 对复杂空间区域，**先把曲面投影到某个坐标面**（消去一个变量，得到投影区域 $D$ 的边界曲线），再在 $D$ 上分上下界。书末几例（图 15–18）皆强调"**投影法更方便**"，统一用"先投影、后定限"。
