# 附录 常用积分表·指数三角与双曲

> [!abstract] 本讲定位
> 指数三角循环积分与矩阵法，双曲积分及实反函数定义域。

## 五、指数×三角（循环方程 / 矩阵算法）

下式要求 $a^2+b^2>0$；若 $a=b=0$，直接分别积分0或1，不套矩阵逆式。

| 积分 | 原函数 |
| :-- | :-- |
| **1** $\int e^{ax}\sin bx\,dx$ | $\frac{e^{ax}(a\sin bx-b\cos bx)}{a^{2}+b^{2}}+C$ |
| **2** $\int e^{ax}\cos bx\,dx$ | $\frac{e^{ax}(a\cos bx+b\sin bx)}{a^{2}+b^{2}}+C$ |
| **3** $\int e^{x}\sin x\,dx$ | $\frac{e^{x}}2(\sin x-\cos x)+C$ |

**对应方法**：

1. 分部两次回自身；或矩阵 $M^{-1}$
2. 同上
3. 上表 $a=b=1$

> 配向量 $\vec v=\dbinom{e^{ax}\sin bx}{e^{ax}\cos bx}$，求导矩阵 $M=\begin{pmatrix}a&b\\-b&a\end{pmatrix}$（复乘 $a+bi$ 的矩阵表示）：
> $$
> \begin{aligned}
> \frac{d}{dx}\vec v&=M\vec v\ \Longrightarrow\ \int\vec v\,dx=M^{-1}\vec v,\\[4pt]
> M^{-1}&=\frac{1}{a^{2}+b^{2}}\begin{pmatrix}a&-b\\b&a\end{pmatrix}
> \end{aligned}
> $$
> 展开两行即得上表 sin、cos 两式（详见 [[09-1 积分方法（凑微分·换元·分部·部分分式）]]）。

## 六、双曲函数

| 积分 | 原函数 |
| :-- | :-- |
| **1** $\int\mathrm{sh}\,x\,dx$ | $\mathrm{ch}\,x+C$ |
| **2** $\int\mathrm{ch}\,x\,dx$ | $\mathrm{sh}\,x+C$ |
| **3** $\int\mathrm{th}\,x\,dx$ | $\ln(\mathrm{ch}\,x)+C$ |
| **4** $\int\frac{dx}{1-x^2}$ | $\frac12\ln\left\vert \frac{1+x}{1-x}\right\vert +C$ |
| **5** $\int\frac{dx}{\sqrt{x^2-1}}$ | $\ln\lvert x+\sqrt{x^2-1}\rvert+C$ |

**对应方法**：

1. $(\mathrm{ch})'=\mathrm{sh}$
2. $(\mathrm{sh})'=\mathrm{ch}$
3. $\frac{\mathrm{sh}}{\mathrm{ch}}$，凑 $d(\mathrm{ch})$
4. 在 $\vert x\vert <1$ 才可称为实反双曲正切 $\operatorname{arth}x$；对数式也适用于外侧各区间
5. 对数式在 $x>1$、$x<-1$ 各自有效；只有 $x>1$ 时写为实 $\operatorname{arch}x$

> **记忆**：双曲与三角"同公式、异符号"——$\mathrm{ch}^{2}-\mathrm{sh}^{2}=1$，导数 $(\mathrm{sh})'=\mathrm{ch}$、$(\mathrm{ch})'=\mathrm{sh}$（无负号），反双曲恒等见 [[附录 双曲函数]]。
