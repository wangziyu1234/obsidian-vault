# 附录 常用积分表·指数三角与双曲

> [!abstract] 本讲定位
> 指数三角循环积分与矩阵法（五），双曲积分及实反函数定义域（六），以及分母含 $\mathrm e^{x}$ 的指数型分式（七）。

## 五、指数×三角（循环方程 / 矩阵算法）

下式要求 $a^2+b^2>0$；若 $a=b=0$，直接分别积分0或1，不套矩阵逆式。

| 积分 | 原函数 |
| :-- | :-- |
| **1** $\int e^{ax}\sin bx\,dx$ | $\frac{e^{ax}(a\sin bx-b\cos bx)}{a^{2}+b^{2}}+C$ |
| **2** $\int e^{ax}\cos bx\,dx$ | $\frac{e^{ax}(a\cos bx+b\sin bx)}{a^{2}+b^{2}}+C$ |
| **3** $\int e^{x}\sin x\,dx$ | $\frac{e^{x}}2(\sin x-\cos x)+C$ |

**对应方法**：

1. 分部两次回自身；或矩阵 $M^{-1}$
2. 同上
3. 上表 $a=b=1$

> 配向量 $\vec v=\dbinom{e^{ax}\sin bx}{e^{ax}\cos bx}$，求导矩阵 $M=\begin{pmatrix}a&b\\-b&a\end{pmatrix}$（复乘 $a+bi$ 的矩阵表示）：
> $$
> \begin{aligned}
> \frac{d}{dx}\vec v&=M\vec v\ \Longrightarrow\ \int\vec v\,dx=M^{-1}\vec v,\\[4pt]
> M^{-1}&=\frac{1}{a^{2}+b^{2}}\begin{pmatrix}a&-b\\b&a\end{pmatrix}
> \end{aligned}
> $$
> 展开两行即得上表 sin、cos 两式（详见 [[09-1 积分方法（凑微分·换元·分部·部分分式）]]）。

## 六、双曲函数

| 积分 | 原函数 |
| :-- | :-- |
| **1** $\int\mathrm{sh}\,x\,dx$ | $\mathrm{ch}\,x+C$ |
| **2** $\int\mathrm{ch}\,x\,dx$ | $\mathrm{sh}\,x+C$ |
| **3** $\int\mathrm{th}\,x\,dx$ | $\ln(\mathrm{ch}\,x)+C$ |
| **4** $\int\frac{dx}{1-x^2}$ | $\frac12\ln\left\vert \frac{1+x}{1-x}\right\vert +C$ |
| **5** $\int\frac{dx}{\sqrt{x^2-1}}$ | $\ln\lvert x+\sqrt{x^2-1}\rvert+C$ |

**对应方法**：

1. $(\mathrm{ch})'=\mathrm{sh}$
2. $(\mathrm{sh})'=\mathrm{ch}$
3. $\frac{\mathrm{sh}}{\mathrm{ch}}$，凑 $d(\mathrm{ch})$
4. 在 $\vert x\vert <1$ 才可称为实反双曲正切 $\operatorname{arth}x$；对数式也适用于外侧各区间
5. 对数式在 $x>1$、$x<-1$ 各自有效；只有 $x>1$ 时写为实 $\operatorname{arch}x$

> **记忆**：双曲与三角"同公式、异符号"——$\mathrm{ch}^{2}-\mathrm{sh}^{2}=1$，导数 $(\mathrm{sh})'=\mathrm{ch}$、$(\mathrm{ch})'=\mathrm{sh}$（无负号），反双曲恒等见 [[附录 双曲函数]]。

## 七、指数型分式（分母含 $\mathrm e^{x}$）

> 形状是「分母为 $1\pm\mathrm e^{x}$、分子只有 $dx$」时的专用表。**两条固定出路**：① 拆项 $\frac{1}{1+\mathrm e^{x}}=1-\frac{\mathrm e^{x}}{1+\mathrm e^{x}}$，第二项凑 $d(1+\mathrm e^{x})$；② 分子分母同乘 $\mathrm e^{-x}$，把分母拉回 $u'$ 在分子上的 $\frac{u'}{u}$ 形。两条路给出的是**同一个**原函数。

| 积分 | 原函数 |
| :-- | :-- |
| **1** $\int\dfrac{dx}{1+\mathrm e^{x}}$ | $x-\ln(1+\mathrm e^{x})+C=-\ln(1+\mathrm e^{-x})+C$ |
| **2** $\int\dfrac{dx}{1-\mathrm e^{x}}$ | $x-\ln\lvert\mathrm e^{x}-1\rvert+C$ |
| **3** $\int\dfrac{\mathrm e^{x}\,dx}{1+\mathrm e^{x}}$ | $\ln(1+\mathrm e^{x})+C$ |
| **4** $\int\dfrac{\mathrm e^{-x}\,dx}{1+\mathrm e^{-x}}$ | $-\ln(1+\mathrm e^{-x})+C$ |

**对应方法**：

1. 同乘 $\mathrm e^{-x}$ 得 $\frac{\mathrm e^{-x}}{1+\mathrm e^{-x}}$，凑 $d(1+\mathrm e^{-x})$；或拆项 $1-\frac{\mathrm e^{x}}{1+\mathrm e^{x}}$
2. 同乘 $\mathrm e^{-x}$ 得 $\frac{\mathrm e^{-x}}{\mathrm e^{-x}-1}$，凑 $d(\mathrm e^{-x}-1)$
3. 直接凑 $d(1+\mathrm e^{x})$
4. 直接凑 $d(1+\mathrm e^{-x})$

> $$
> \begin{aligned}
> \int\frac{dx}{1+\mathrm e^{x}}
> &=\int\frac{\mathrm e^{-x}}{\mathrm e^{-x}+1}\,dx\\[4pt]
> &=-\int\frac{d(\mathrm e^{-x}+1)}{\mathrm e^{-x}+1}\\[4pt]
> &=-\ln(1+\mathrm e^{-x})+C
> \end{aligned}
> $$
> $$
> \begin{aligned}
> \int\frac{dx}{1+\mathrm e^{x}}
> &=\int\frac{1+\mathrm e^{x}-\mathrm e^{x}}{1+\mathrm e^{x}}\,dx\\[4pt]
> &=\int dx-\int\frac{d(1+\mathrm e^{x})}{1+\mathrm e^{x}}\\[4pt]
> &=x-\ln(1+\mathrm e^{x})+C
> \end{aligned}
> $$

> [!tip] 两条路为什么"完全相等"而不是"相差常数"
> 由 $\ln(1+\mathrm e^{-x})=\ln\dfrac{1+\mathrm e^{x}}{\mathrm e^{x}}=\ln(1+\mathrm e^{x})-x$，得
>
> $$
> -\ln(1+\mathrm e^{-x})=x-\ln(1+\mathrm e^{x})
> $$
>
> 两边是**同一个式子**，所以两种写法给出的是同一个原函数。这个恒等式在换元回代、化简结果时也常用。
>
> 记法：**看到分母是 $1\pm\mathrm e^{x}$、分子只有 $dx$，先同乘 $\mathrm e^{-x}$**。这类积分常作为分部积分的"余项"出现——2000 数二第 11 题 $\int\mathrm e^{-x}\ln(1+\mathrm e^{x})\,dx$ 分部之后剩下的正是 $\int\frac{dx}{1+\mathrm e^{x}}$（错题：[[2000-11 分母含指数的积分卡住]]）。
