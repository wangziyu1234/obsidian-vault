# 附录 常用曲线

> [!abstract] 📋 附录定位

## 📝 极坐标族

![[高数-常用曲线1-极坐标.png|520]]

| 曲线 | 方程 | 常用结论 |
| ---- | ---- | -------- |
| 心形线 | $r=a(1\pm\cos\theta)$ 朝右/左；$r=a(1\pm\sin\theta)$ 朝上/下 | 面积 $\dfrac{3\pi a^{2}}{2}$；周长 $8a$；$r_{\max}=2a$ |
| 伯努利双纽线 | $r^{2}=a^{2}\cos 2\theta$（横放）；$r^{2}=a^{2}\sin 2\theta$（转 $45^{\circ}$） | 总面积 $a^{2}$；$\cos$ 版只在 $\theta\in[-\frac{\pi}{4},\frac{\pi}{4}]\cup[\frac{3\pi}{4},\frac{5\pi}{4}]$ 存在 |
| 三叶玫瑰线 | $r=a\sin 3\theta$（两瓣朝上一瓣朝下）；$r=a\cos 3\theta$（一瓣朝右） | 一瓣 $\theta\in[0,\frac{\pi}{3}]$（$\sin$ 版）；总面积 $\dfrac{\pi a^{2}}{4}$ |
| 四叶玫瑰线 | $r=a\sin 2\theta$（瓣在对角线）；$r=a\cos 2\theta$（瓣在坐标轴） | 总面积 $\dfrac{\pi a^{2}}{2}$ |
| 圆 | $r=2a\cos\theta\iff(x-a)^{2}+y^{2}=a^{2}$；$r=2a\sin\theta\iff x^{2}+(y-a)^{2}=a^{2}$ | 二重积分极坐标定限高频（[[14 第14讲 二重积分]]） |
| 阿基米德螺线 | $r=a\theta\ (\theta\ge0)$ | 第一圈与极轴围面积 $\dfrac{4\pi^{3}a^{2}}{3}$ |
| 对数螺线 | $r=e^{a\theta}$ | 等角性：切线与向径夹角恒定 |
| 双曲螺线 | $r\theta=a$ | 渐近线 $y=a$（$\theta\to0^{+}$） |

## 📝 参数方程与直角坐标族

![[高数-常用曲线2-参数与直角.png|520]]

| 曲线 | 方程 | 常用结论 |
| ---- | ---- | -------- |
| 摆线（平摆线） | $x=a(t-\sin t),\ y=a(1-\cos t)$；一拱 $t\in[0,2\pi]$，顶点 $(\pi a,2a)$ | 一拱弧长 $8a$；一拱下面积 $3\pi a^{2}$；绕 $x$ 轴 $V=5\pi^{2}a^{3}$ |
| 星形线（内摆线） | $x=a\cos^{3}t,\ y=a\sin^{3}t\iff x^{2/3}+y^{2/3}=a^{2/3}$ | 全长 $6a$；面积 $\dfrac{3\pi a^{2}}{8}$；绕 $x$ 轴 $V=\dfrac{32\pi a^{3}}{105}$ |
| 笛卡尔叶形线 | $x^{3}+y^{3}=3axy$；$x=\dfrac{3at}{1+t^{3}},\ y=\dfrac{3at^{2}}{1+t^{3}}$ | 渐近线 $x+y+a=0$；叶面积 $=$ 渐近线与曲线间面积 $=\dfrac{3a^{2}}{2}$ |
| 半立方抛物线 | $y^{2}=x^{3}$；$x=t^{2},\ y=t^{3}$ | 原点为尖点；$[0,x]$ 弧长 $s=\dfrac{8}{27}\Bigl[\bigl(1+\dfrac{9x}{4}\bigr)^{3/2}-1\Bigr]$ |
| 悬链线 | $y=a\,\mathrm{ch}\dfrac{x}{a}$ | 最低点 $(0,a)$；$1+y'^{2}=\mathrm{ch}^{2}\dfrac{x}{a}$（开根无痛）；$[0,x]$ 弧长 $s=a\,\mathrm{sh}\dfrac{x}{a}$ |
| 箕舌线 | $y=\dfrac{8a^{3}}{x^{2}+4a^{2}}$ | 峰 $(0,2a)$；与 $x$ 轴之间面积 $4\pi a^{2}$ |
| 蔓叶线 | $y^{2}=\dfrac{x^{3}}{2a-x}$ | 渐近线 $x=2a$；与渐近线间面积 $3\pi a^{2}$ |
| 概率曲线 | $y=e^{-x^{2}}$ | 与 $x$ 轴间面积 $\sqrt{\pi}$（[[09 第9讲 一元函数积分学的计算]] 概率积分）；拐点 $x=\pm\dfrac{1}{\sqrt{2}}$ |
| 椭圆 | $x=a\cos t,\ y=b\sin t$ | 面积 $\pi ab$；绕 $x$ 轴 $V=\dfrac{4}{3}\pi ab^{2}$；周长无初等公式（只考弧长微元） |
---

## 💡 使用提示

- **极坐标定限**：令 $r=0$ 解出一瓣的边界 $\theta$，$r$ 最大处定对称轴；先算一瓣再乘份数。
- 心形线、玫瑰线、双纽线的面积都是 $S=\dfrac12\displaystyle\int r^{2}\,d\theta$ 配降幂公式；摆线一拱下面积 $\displaystyle\int_0^{2\pi}a^{2}(1-\cos t)^{2}dt$ 用降幂/华里士。
- 双曲函数记号：$\mathrm{ch}\,x=\dfrac{e^{x}+e^{-x}}{2}$，$\mathrm{sh}\,x=\dfrac{e^{x}-e^{-x}}{2}$；$\mathrm{ch}^{2}x-\mathrm{sh}^{2}x=1$，$(\mathrm{sh})'=\mathrm{ch}$，$(\mathrm{ch})'=\mathrm{sh}$。
- 图中虚线为同族的另一种朝向/形式，考题给哪种都要认得。
