| 蔓叶线 | $y^{2}=\dfrac{x^{3}}{2a-x}$ | 渐近线 $x=2a$；与渐近线间面积 $3\pi a^{2}$ |

| 椭圆 | $x=a\cos t,\ y=b\sin t$ | 面积 $\pi ab$；绕 $x$ 轴 $V=\dfrac{4}{3}\pi ab^{2}$；周长无初等公式（只考弧长微元） |

## 椭圆专题

### 标准方程与基本量

$$\frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}=1\qquad(a\ge b>0)$$

| 量 | 公式 | 说明 |
| :-- | :-- | :-- |
| 半长轴 | $a$ | $x$ 方向半轴 |
| 半短轴 | $b$ | $y$ 方向半轴 |
| 半焦距 | $c=\sqrt{a^{2}-b^{2}}$ | 焦点在 $x$ 轴上 $(\pm c,0)$ |
| 离心率 | $e=\dfrac{c}{a}=\sqrt{1-\dfrac{b^{2}}{a^{2}}}$ | $0<e<1$；$e$ 越接近 $0$ 越圆 |
| 准线 | $x=\pm\dfrac{a}{e}=\pm\dfrac{a^{2}}{c}$ | 焦点到准线距离 $=\dfrac{b^{2}}{c}$ |

> [!note] 数二不考解析几何，但椭圆的**参数方程、面积、旋转体、二重积分**是高频考点。

### 参数方程与导数

$$x=a\cos t,\qquad y=b\sin t\qquad(t\in[0,2\pi])$$

$$\frac{dy}{dx}=-\frac{b\cos t}{a\sin t},\qquad \frac{d^{2}y}{dx^{2}}=-\frac{b}{a^{2}\sin^{3}t}$$

> [!tip] 参数方程求导链式法则
> $\dfrac{dy}{dx}=\dfrac{dy/dt}{dx/dt}$；$\dfrac{d^{2}y}{dx^{2}}=\dfrac{d(dy/dx)/dt}{dx/dt}$（注意分母是 $dx/dt$ 不是 $d^{2}x/dt^{2}$）。

### 面积

$$S=\pi ab$$

**推导**（广义极坐标）：令 $x=ar\cos\theta,\ y=br\sin\theta$，雅可比 $J=abr$：

$$S=\iint_{D}dxdy=\int_{0}^{2\pi}d\theta\int_{0}^{1}abr\,dr=ab\cdot2\pi\cdot\frac{1}{2}=\pi ab$$

### 弧长

弧长**无初等闭式**，只考弧长微元的积分表达式：

$$L=\int_{0}^{2\pi}\sqrt{a^{2}\sin^{2}t+b^{2}\cos^{2}t}\,dt$$

或直角坐标：

$$L=4\int_{0}^{a}\sqrt{1+\frac{b^{2}x^{2}}{a^{4}(1-x^{2}/a^{2})}}\,dx$$

> [!warning] 考试中椭圆周长不要求算出数值，只需写出积分表达式或判断其存在性。

### 旋转体体积

| 旋转轴 | 体积公式 |
| :-- | :-- |
| 绕 $x$ 轴 | $V_{x}=\pi\displaystyle\int_{-a}^{a}y^{2}dx=\dfrac{4}{3}\pi ab^{2}$ |
| 绕 $y$ 轴 | $V_{y}=\pi\displaystyle\int_{-b}^{b}x^{2}dy=\dfrac{4}{3}\pi a^{2}b$ |

> 推导：$V_{x}=\pi\displaystyle\int_{-a}^{a}b^{2}(1-x^{2}/a^{2})dx=\pi b^{2}\bigl[x-\dfrac{x^{3}}{3a^{2}}\bigr]_{-a}^{a}=\dfrac{4}{3}\pi ab^{2}$。

### 二重积分：椭圆域上的常用积分

椭圆域 $D:\dfrac{x^{2}}{a^{2}}+\dfrac{y^{2}}{b^{2}}\le1$，用广义极坐标 $x=ar\cos\theta,\ y=br\sin\theta$（$J=abr$）：

| 被积函数 | 结果 | 做法 |
| :-- | :-- | :-- |
| $1$ | $\pi ab$ | 面积 |
| $x^{2}$ | $\dfrac{\pi a^{3}b}{4}$ | $\int_{0}^{2\pi}\cos^{2}\theta\,d\theta\cdot\int_{0}^{1}a^{2}r^{2}\cdot br\,dr=\pi\cdot\dfrac{a^{2}b}{4}$ |
| $y^{2}$ | $\dfrac{\pi ab^{3}}{4}$ | 对称，$a\leftrightarrow b$ |
| $\dfrac{x^{2}}{a^{2}}+\dfrac{y^{2}}{b^{2}}$ | $\dfrac{\pi ab}{2}$ | $\displaystyle\int_{0}^{2\pi}d\theta\int_{0}^{1}r^{2}\cdot abr\,dr=\dfrac{\pi ab}{2}$ |
| $x^{2}y^{2}$ | $\dfrac{\pi a^{3}b^{3}}{24}$ | 华里士 |

> [!tip] 椭圆域积分口诀
> **广义极坐标一把梭**：$x=ar\cos\theta,\ y=br\sin\theta$，雅可比 $abr$，$r\in[0,1],\ \theta\in[0,2\pi]$，然后用华里士。

### 常见变形

| 变形 | 标准化 |
| :-- | :-- |
| $\dfrac{x^{2}}{a^{2}}+\dfrac{y^{2}}{b^{2}}\le1$（中心在原点） | 直接用 |
| $\dfrac{(x-x_{0})^{2}}{a^{2}}+\dfrac{(y-y_{0})^{2}}{b^{2}}\le1$（中心在 $(x_0,y_0)$） | 平移 $u=x-x_0,\ v=y-y_0$ 后化标准 |
| $4x^{2}+y^{2}\le9$ | $\dfrac{x^{2}}{(3/2)^{2}}+\dfrac{y^{2}}{3^{2}}\le1$，半轴 $a=\frac{3}{2},\ b=3$ |
| $x^{2}+4y^{2}\le4$ | $\dfrac{x^{2}}{2^{2}}+\dfrac{y^{2}}{1^{2}}\le1$，半轴 $a=2,\ b=1$ |

> [!warning] 识别椭圆的关键
> $Ax^{2}+By^{2}=C$（$A,B,C$ 同号）⟺ $\dfrac{x^{2}}{C/A}+\dfrac{y^{2}}{C/B}=1$，半轴 $a=\sqrt{C/A},\ b=\sqrt{C/B}$。

### 斜椭圆（含 $xy$ 交叉项）

**一般二次曲线**：

$$Ax^{2}+Bxy+Cy^{2}+Dx+Ey+F=0$$

判别：$\Delta=B^{2}-4AC$。

| $\Delta$ | 曲线类型 |
| :--: | :-- |
| $<0$ | 椭圆（含圆，$B=0$ 时） |
| $=0$ | 抛物线 |
| $>0$ | 双曲线 |

> [!tip] 斜椭圆的本质
> $B\ne0$ 时椭圆的长短轴**不平行于坐标轴**——即"斜的"。消去 $xy$ 项的方法是**旋转变换**。

#### 旋转变换消 $xy$ 项

令 $\begin{pmatrix}x\\y\end{pmatrix}=\begin{pmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{pmatrix}\begin{pmatrix}u\\v\end{pmatrix}$（逆时针旋转 $\theta$），代入后令 $uv$ 项系数为零：

$$\boxed{\tan 2\theta=\frac{B}{A-C}}$$

取 $\theta\in\bigl(0,\dfrac{\pi}{2}\bigr)$，旋转后得到标准椭圆 $\dfrac{u^{2}}{a^{2}}+\dfrac{v^{2}}{b^{2}}=1$。

> [!note] 旋转角的线代本质
> 二次型 $f(x,y)=Ax^{2}+Bxy+Cy^{2}$ 的矩阵 $M=\begin{pmatrix}A&B/2\\B/2&C\end{pmatrix}$，旋转角 $\theta$ 即使 $M$ 对角化的正交矩阵 $Q$ 的列向量方向——$\tan\theta$ 为特征向量的斜率。特征值 $\lambda_{1,2}$ 就是旋转后的系数 $1/a^{2},\ 1/b^{2}$（差一个常数倍）。

#### 旋转后的系数

旋转后新方程 $A'u^{2}+C'v^{2}+\cdots=0$，其中：

$$A'+C'=A+C\qquad\text{（迹不变）}$$

$$A'-C'=\sqrt{(A-C)^{2}+B^{2}}$$

$$\Rightarrow\quad A'=\frac{A+C+\sqrt{(A-C)^{2}+B^{2}}}{2},\quad C'=\frac{A+C-\sqrt{(A-C)^{2}+B^{2}}}{2}$$

> 半轴 $a=\sqrt{\dfrac{-F}{A'}}$，$b=\sqrt{\dfrac{-F}{C'}}$（假设 $F<0$，椭圆封闭）。

#### 完整化简步骤（考试实操）

1. **写矩阵** $M=\begin{pmatrix}A&B/2\\B/2&C\end{pmatrix}$
2. **求特征值** $\lambda_{1,2}=\dfrac{A+C\pm\sqrt{(A-C)^{2}+B^{2}}}{2}$
3. **旋转**：$\begin{pmatrix}x\\y\end{pmatrix}=Q\begin{pmatrix}u\\v\end{pmatrix}$，$Q$ 为正交矩阵（列 = 单位特征向量）
4. **平移**（如有一次项）：配方消去 $u,v$ 的一次项
5. **得标准方程** $\dfrac{u^{2}}{a^{2}}+\dfrac{v^{2}}{b^{2}}=1$

#### 雅可比

旋转变换的雅可比 $\lvert J\rvert=1$（正交变换保面积）：

$$\iint_{D}f(x,y)\,dxdy=\iint_{D'}f(x(u,v),y(u,v))\cdot1\,dudv$$

> 消去 $xy$ 项后直接用标准椭圆域的积分公式（见上方「椭圆域二重积分」表）。

#### 典型例题

> [!example] 例：化简 $5x^{2}-6xy+5y^{2}=1$
> **① 矩阵** $M=\begin{pmatrix}5&-3\\-3&5\end{pmatrix}$。
>
> **② 特征值** $\lambda=\dfrac{10\pm\sqrt{0+36}}{2}=\dfrac{10\pm6}{2}$，$\lambda_1=8,\ \lambda_2=2$。
>
> **③ 旋转后方程** $8u^{2}+2v^{2}=1$，即 $\dfrac{u^{2}}{1/8}+\dfrac{v^{2}}{1/2}=1$。
>
> **④ 半轴** $a=\dfrac{1}{2\sqrt{2}},\ b=\dfrac{1}{\sqrt{2}}$；面积 $S=\pi ab=\dfrac{\pi}{4}$。
>
> **⑤ 旋转角** $\tan2\theta=\dfrac{-6}{5-5}\to\infty$，$\theta=45°$；$Q=\dfrac{1}{\sqrt{2}}\begin{pmatrix}1&-1\\1&1\end{pmatrix}$。

- **极坐标定限**：令 $r=0$ 解出一瓣的边界 $\theta$，$r$ 最大处定对称轴；先算一瓣再乘份数。
- 心形线、玫瑰线、双纽线的面积都是 $S=\dfrac12\displaystyle\int r^{2}\,d\theta$ 配降幂公式；摆线一拱下面积 $\displaystyle\int_0^{2\pi}a^{2}(1-\cos t)^{2}dt$ 用降幂/华里士。
- 双曲函数记号：$\mathrm{ch}\,x=\dfrac{e^{x}+e^{-x}}{2}$，$\mathrm{sh}\,x=\dfrac{e^{x}-e^{-x}}{2}$；
  $\mathrm{ch}^{2}x-\mathrm{sh}^{2}x=1$，$(\mathrm{sh})'=\mathrm{ch}$，$(\mathrm{ch})'=\mathrm{sh}$。
- 图中虚线为同族的另一种朝向/形式，考题给哪种都要认得。
