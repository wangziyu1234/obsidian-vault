# 附录 双曲函数

## 📖 从指数函数说起

指数函数 $y=a^x$ 的底数可取任意不等于 1 的正数；实际问题中最常见以 $e$ 为底：
$$
y=e^x,\qquad y=e^{-x}
$$

> [!note] 微分方程中的指数函数
> 凡因变量变化率与自身成正比的关系 $\dfrac{dy}{dt}=ky$ 都有指数解。$k>0$：$y=Ce^{kt}$（增长）；$k<0$：$y=Ce^{-|k|t}$（衰减）。第15讲一阶线性常系数齐次方程的解即源于此。

$y=e^x$ 的反函数是自然对数 $y=\ln x=\log_e x$。与常用对数 $\lg x=\log_{10}x$ 的换算：
$$
\ln x=\ln 10\cdot\lg x\ (\ln 10\approx 2.302585),\qquad \lg x=\lg e\cdot\ln x\ (\lg e\approx 0.434294)
$$

## 📝 双曲函数定义

由 $e^x$ 与 $e^{-x}$ 构成三类常用双曲函数：

| 名称 | 记号 | 定义 |
| :-- | :-- | :-- |
| 双曲正弦 | $\operatorname{sh}x$ | $\dfrac{e^x-e^{-x}}{2}$ |
| 双曲余弦 | $\operatorname{ch}x$ | $\dfrac{e^x+e^{-x}}{2}$ |
| 双曲正切 | $\operatorname{th}x$ | $\dfrac{\operatorname{sh}x}{\operatorname{ch}x}=\dfrac{e^x-e^{-x}}{e^x+e^{-x}}$ |

> 有时记作 $\sinh x,\ \cosh x,\ \tanh x$。

**奇偶性**：
$$
\operatorname{sh}(-x)=-\operatorname{sh}x,\quad \operatorname{th}(-x)=-\operatorname{th}x,\quad \operatorname{ch}(-x)=\operatorname{ch}x
$$
故 $\operatorname{sh}x$、$\operatorname{th}x$ 为奇函数，$\operatorname{ch}x$ 为偶函数。

**图像要点**：先画右半平面 $x\ge0$。
- $\operatorname{ch}x$ = 两曲线纵坐标之和，$x$ 很大时逼近 $\frac12 e^x$ 且总大于它；
- $\operatorname{sh}x$ = 两曲线纵坐标之差，$x$ 很大时逼近 $\frac12 e^x$ 且总小于它；
- $\operatorname{th}x$ $x>0$ 时介于 $0$ 与 $1$，$x\to+\infty$ 时 $\to1$；由奇性得左半图像。

## 📝 双曲恒等式（与三角恒等式对照）

**基础二恒等式**（指数 ↔ 双曲）：
$$
e^x=\operatorname{ch}x+\operatorname{sh}x,\qquad e^{-x}=\operatorname{ch}x-\operatorname{sh}x
$$

| 类别 | 三角公式 | 双曲公式（注意符号差异） |
| :-- | :-- | :-- |
| 和差角 | $\sin(A\pm B)=\sin A\cos B\pm\cos A\sin B$ | $\operatorname{sh}(u\pm v)=\operatorname{sh}u\,\operatorname{ch}v\pm\operatorname{ch}u\,\operatorname{sh}v$ |
| | $\cos(A\pm B)=\cos A\cos B\mp\sin A\sin B$ | $\operatorname{ch}(u\pm v)=\operatorname{ch}u\,\operatorname{ch}v\pm\operatorname{sh}u\,\operatorname{sh}v$ |
| 平方关系 | $\sin^2 A+\cos^2 A=1$ | $\boxed{\operatorname{ch}^2 u-\operatorname{sh}^2 u=1}$ |
| | $1+\tan^2 A=\sec^2 A$ | $1-\operatorname{th}^2 u=\dfrac{1}{\operatorname{ch}^2 u}$ |
| 倍角 | $\sin 2A=2\sin A\cos A$ | $\operatorname{sh}2u=2\operatorname{sh}u\,\operatorname{ch}u$ |
| | $\cos 2A=2\cos^2A-1=1-2\sin^2A$ | $\operatorname{ch}2u=\operatorname{ch}^2u+\operatorname{sh}^2u=2\operatorname{ch}^2u-1$ |

> [!tip] 三角 ↔ 双曲的「替换规则」
> 把 $\sin\to\operatorname{sh}$、$\cos\to\operatorname{ch}$，**两式平方项中含 $\sin^2$ 前的符号取反**（$\cos^2+\sin^2=1$ 变 $\operatorname{ch}^2-\operatorname{sh}^2=1$；和角公式 $\cos$ 中 $\mp\sin A\sin B$ 变 $\pm\operatorname{sh}u\operatorname{sh}v$）。原因：欧拉公式 $e^{ix}=\cos x+i\sin x$ 与 $e^x=\operatorname{ch}x+\operatorname{sh}x$ 平行，把 $x\to ix$ 即可互推。

## 📝 反双曲函数

由 $y=\operatorname{sh}x$ 解出 $e^y$：$e^{2y}-2xe^y-1=0$ ⟹ $e^y=x+\sqrt{x^2+1}$（取正根），两边取 $\ln$：

| 反函数 | 表达式 | 定义域 |
| :-- | :-- | :-- |
| 反双曲正弦 | $\operatorname{arsh}x=\ln(x+\sqrt{x^2+1})$ | $(-\infty,+\infty)$ |
| 反双曲余弦（主值） | $\operatorname{arch}x=\ln(x+\sqrt{x^2-1})$ | $x\ge1$ |
| 反双曲正切 | $\operatorname{arth}x=\frac12\ln\dfrac{1+x}{1-x}$ | $(-1,1)$ |

> [!note] 主值分支
> $\operatorname{arch}x$ 本是双值，取上平面那支作主值：$\operatorname{arch}x=\ln(x+\sqrt{x^2-1})$。利用
> $\ln(x-\sqrt{x^2-1})=-\ln(x+\sqrt{x^2-1})\ (x\ge1)$ 来化简。

> [!tip] 与第1讲反函数的联系
> $y=\ln(x+\sqrt{x^2+1})$ 是第1讲讲过的**反双曲正弦**，其图像关于原点对称，是常见**奇函数**例子。$\operatorname{ch}x$ 是偶函数、特殊悬链线（达·芬奇《抱银貂的女子》项链形状），$a=1$ 即 $y=\operatorname{ch}x=\frac{e^x+e^{-x}}{2}$。
