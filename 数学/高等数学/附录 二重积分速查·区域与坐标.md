> [!abstract] 附录定位
> 直角坐标与极坐标区域、几何描述和综合练习区域。

## 一、直角坐标系·基础区域

| 序号 | 区域 $D$ | 形状 | 备注 |
| :--: | :-- | :-- | :-- |
| 1 | $0\le x\le1,\ 0\le y\le x$ | 直角三角形 | 顶点 $(0,0),(1,0),(1,1)$；$y$ 型：$0\le y\le1,\ y\le x\le1$ |

| 5 | $0\le x\le2,\ 0\le y\le x$ | 直角三角形 | 顶点 $(0,0),(2,0),(2,2)$；$S=2$ |
| 6 | $x+y\ge2,\ x\ge0,\ y\ge0$ | 无界区域 | 第一象限中直线 $x+y=2$ 的右上方；常与其它曲线配合截取有界子区域 |
| 7 | $0\le x\le1,\ \arctan x\le y\le\frac\pi4$ | 曲边梯形 | 上界水平线 $y=\frac\pi4$，下界 $y=\arctan x$ |
| 8 | $0\le x\le1,\ 0\le y\le(x-1)^{2}$ | 抛物弓形 | 顶点 $(1,0)$，开口向上；面积 $S=\frac{1}{3}$ |
| 9 | $0\le x\le1,\ x^{2}\le y\le x^{3}+1$ | 综合曲线域 | 下界抛物线 $y=x^{2}$，上界三次曲线 $y=x^{3}+1$ |

| 11 | $0\le x\le2,\ x\le y\le x+1$ | 平行四边形 | 宽 2、高 1；$S=2$ |

| 14 | $0\le x\le2,\ y\le3x,\ x+y\le4$ | 向下无界 | 没有 $y\ge0$ 条件；若另加它，才是顶点 $(0,0),(1,3),(2,2),(2,0)$ 的有界四边形 |
| 15 | $\lvert x\rvert+\lvert y\rvert\le1$ | 菱形 | 四顶点 $(\pm1,0),(0,\pm1)$；$S=2$ |

| 17 | $0\le x\le1, 0\le y\le2-x$ | 梯形 | 顶点 $(0,0),(1,0),(1,1),(0,2)$ |
| 18 | $\frac13\le x\le1, 1-x\le y\le2x$ | 三角形 | 先由下界不超过上界，得到有效横坐标 $x\ge1/3$ |
| 19 | $0\le y\le2,\ 2-y\le x\le4-y$ | 平行四边形 | $x$ 型视角：$y$ 固定时 $x$ 跨度恒为 2 |
| 20 | $-1\le x\le1,\ x^{2}\le y\le2-x^{2}$ | 抛物弓形 | 上界 $y=2-x^{2}$（下开口抛物线），下界 $y=x^{2}$（上开口抛物线）；交点 $x=\pm1$ |
| 21 | $0\le x\le2,\ 0\le y\le2-x$ | 直角三角形 | 顶点 $(0,0),(2,0),(0,2)$；$S=2$ |

| 序号 | 区域 $D$ | 形状 | 备注 |
| :--: | :-- | :-- | :-- |
| 22 | $0\le x\le2,\ 0\le y\le x^{2}$ | 抛物线下区域 | $S=\frac{8}{3}$ |
| 23 | $\frac12x^{2}\le y\le x^{2},\ 0\le x\le1$ | 抛物线带 | 两抛物线间，$S=\frac{1}{6}$ |
| 24 | $0\le x\le1,\ 1-x\le y\le\sqrt{1-x^{2}}$ | 直线与圆弧间 | 下界 $y=1-x$（直线）、上界 $y=\sqrt{1-x^{2}}$（单位圆弧）；两曲线交于 $(0,1),(1,0)$；$S=\frac{\pi-2}{4}$ |
| 25 | $1\le x\le\sqrt2,\\frac x2\le y\le\frac1x$ | 双曲线与直线间 | 交点横坐标 $\sqrt2$；写到2会使一段内层上下限反向 |
| 26 | $1\le x\le2,\\frac1x\le y\le x$ | 双曲线与直线间 | 下界 $1/x$、上界 $x$；不是上一题的简单上下界互换 |
| 27 | $0\le x\le2,\ x\le y\le\sqrt{2x}$ | 抛物弓形 | 两交点 $(0,0),(2,2)$；面积 $2/3$。若把上下界反写，区域仅剩端点 |

| :--: | :-- | :-- | :-- |
| 28 | $\lvert x\rvert+\lvert y\rvert\le1$ | 菱形 | 同序号15 |
| 29 | $x^{2}+y^{2}\le2y$ | 圆 | 配方 $x^{2}+(y-1)^{2}\le1$，圆心 $(0,1)$，半径 $1$ |
| 30 | $x^{2}+y^{2}\le4,\ x^{2}+y^{2}\ge2y$ | 圆环截取 | 大圆 $R=2$ 减去小圆（圆心 $(0,1)$，$r=1$） |
| 31 | $(x-1)^{2}+(y-1)^{2}\le2,\ x+y\ge2$ | 圆截取 | 圆心 $(1,1)$，半径 $\sqrt{2}$；直线 $x+y=2$ 过圆心 |
| 32 | $x^{2}+y^{2}\le2y,\ y\le\frac{\sqrt{3}}{3}x,\ x\ge0$ | 圆扇形截取 | 圆 $r\le2\sin\theta$ 与直线 $y=\frac{x}{\sqrt{3}}$（$\theta=\frac\pi6$）围成 |
| 33 | $1\le x^2+y^2\le4, x,y\ge0$ | 四分之一圆环 | $1\le r\le2$；面积 $3\pi/4$。若用根式上下界，须按 $x=1$ 分段 |
| 34 | $0\le y\le\sqrt{2x-x^{2}}$ | 半圆 | 配方 $(x-1)^{2}+y^{2}\le1$，圆心 $(1,0)$，上半圆 |
| 35 | $0\le y\le1,\ 1-\sqrt{1-y^{2}}\le x\le\sqrt{y}$ | 曲边域 | 左界半圆弧，右界抛物线 |
| 36 | $4x^{2}+y^{2}\le9,\ y\ge0$ | 上半椭圆 | $\frac{x^{2}}{(3/2)^{2}}+\frac{y^{2}}{3^{2}}\le1$，半轴 $a=\frac{3}{2},\ b=3$ |
| 37 | $x^{2}+(y-2)^{2}\le4,\ (x+1)^{2}+y^{2}\ge1$ | 两圆之间 | 大圆圆心 $(0,2)$ 半径 $2$；挖去小圆圆心 $(-1,0)$ 半径 $1$ |
| 38 | $x^2+y^2\le1, x,y\ge0$ | 四分之一圆盘 | 面积 $\pi/4$；$\iint_Dx=\iint_Dy=1/3$ |
| 39 | $x^2+y^2\le\sqrt{2x}, x^2+y^2\le\sqrt{2y}$ | 非圆曲边域 | 第一象限；$0\le r\le\min(\sqrt[3]{2\cos\theta},\sqrt[3]{2\sin\theta})$ |

## 椭圆与圆锥曲线

| 序号 | 区域 $D$ | 形状 | 备注 |
| :--: | :-- | :-- | :-- |
| 40 | $x^{2}+(y-2)^{2}\le4$ | 圆 | 圆心 $(0,2)$，半径 $2$ |
| 41 | $(x^{2}+y^{2})^{2}\le x^{2}-y^{2},\ x\ge0$ | 双纽线（右叶） | 极坐标 $r^{2}\le\cos2\theta$，$\theta\in[-\frac\pi4,\frac\pi4]$ |
| 42 | $(x^{2}+y^{2})^{2}\le2xy,\ x\ge0,\ y\ge0$ | 双纽线（第一象限叶） | 极坐标 $r^{2}\le2\sin\theta\cos\theta=\sin2\theta$ |
| 43 | $(x^2+y^2)^2\le x^2$ | 两个相切圆盘的并 | $0\le r\le\vert \cos\theta\vert $，等价于 $(\vert x\vert -1/2)^2+y^2\le1/4$；不是双纽线 |
| 44 | $(x^2+y^2)^2\le4(x^2-y^2), x\ge0, x^2+y^2\ge\sqrt{2x}$ | 双纽线右叶截取 | $r^2\le4\cos2\theta$ 与 $r^3\ge2\cos\theta$ 同时成立；后者不是圆界 |
| 45 | $0\le x\le2,\ 2x^{2}\le y\le x^{2}+4$ | 抛物线带 | 下界 $y=2x^{2}$（开口大）、上界 $y=x^{2}+4$（开口小+上移）；交点 $x=2$ |

| :--: | :-- | :-- | :-- |

| 47 | $\frac1{1+x^2}\le y\le\sqrt{1-x^2}, x\ge0$ | 曲边域 | 有效范围 $0\le x\le\sqrt{(\sqrt5-1)/2}$；需先比较上下界 |
| 48 | $\sin x\le y\le1,\ \frac\pi2\le x\le\frac{3\pi}2$ | 正弦弓形 | $y=\sin x$ 与 $y=1$ 之间 |
| 49 | $\sin x\le y\le\frac\pi2,\ 0\le x\le\frac\pi4$ | 曲边梯形 | 上界水平线 $y=\frac\pi2$，下界 $y=\sin x$ |
| 50 | $y^2\le\sqrt{x-y^2}, y^2\ge1-\sqrt{x-y^2}$ | 无界曲边域 | 令 $u=x-y^2\ge0$，有 $\sqrt u\ge\max(y^2,1-y^2)$，并无上界 |

## 三、极坐标系区域

## 直线对应的极坐标区域

| 序号 | 区域 $(r,\theta)$ | 直角坐标等价 | 备注 |
| :--: | :-- | :-- | :-- |
| 1 | $0\le r\le\sec\theta,\ 0\le\theta\le\frac\pi4$ | $0\le x\le1,\ 0\le y\le x$ | 直线 $x=1$ 对应 $r=\sec\theta$；第一象限三角形 |
| 2 | $0\le r\le\csc\theta,\\pi/4\le\theta\le\pi/2$ | $0\le x\le y\le1$ | 上界直线 $y=1$；不是 $y\le x$ 部分 |
| 3 | $0\le r\le2\sec\theta,\\pi/6\le\theta\le\pi/3$ | $0\le x\le2, x/\sqrt3\le y\le\sqrt3x$ | 从原点开始，没有 $x\ge1$ 的下限 |
| 4 | $0\le r\le\frac{1}{\cos\theta+\sin\theta},\ 0\le\theta\le\frac\pi4$ | $x+y\le1$ 的扇形部分 | 直线 $x+y=1$ 对应 $r=\frac{1}{\cos\theta+\sin\theta}$ |
| 5 | $0\le r\le\frac{1}{\cos\theta+\sin\theta},\ \frac\pi4\le\theta\le\frac\pi2$ | 同上，$y\ge x$ 部分 | 与上一题互补 |
| 6 | $0\le r\le\frac{2}{\sin\theta+\cos\theta},\ \frac\pi4\le\theta\le\frac\pi2$ | $x+y\le2$ 的 $y\ge x$ 部分 | 直线 $x+y=2$ 对应 $r=\frac{2}{\sin\theta+\cos\theta}$ |

| :--: | :-- | :-- | :-- |
| 7 | $0\le r\le1,\ \frac\pi4\le\theta\le\frac\pi2$ | 单位圆扇形 | 圆心角 $\frac\pi4$，$S=\frac\pi8$ |
| 8 | $0\le r\le2\cos\theta,\ 0\le\theta\le\frac\pi4$ | $r=2\cos\theta$ 圆（圆心 $(1,0)$，半径 $1$）在 $y\le x$ 内部分 | |
| 9 | $0\le r\le2\cos\theta,\ \frac\pi4\le\theta\le\frac\pi2$ | 同上圆在 $y\ge x$ 内部分 | 与上一题互补 |
| 10 | $0\le r\le2\cos\theta, 0\le\theta\le\pi/2$ | $(x-1)^2+y^2\le1, y\ge0$ | 平移圆的上半圆盘；完整圆盘需 $-\pi/2\le\theta\le\pi/2$ |
| 11 | $0\le r\le2\sin\theta,\ 0\le\theta\le\frac\pi4$ | $r=2\sin\theta$ 圆（圆心 $(0,1)$，半径 $1$）在 $y\le x$ 内部分 | |
| 12 | $0\le r\le2\sin\theta,\ \frac\pi4\le\theta\le\frac\pi2$ | 同上圆在 $y\ge x$ 内部分 | 与上一题互补 |
| 13 | $0\le r\le2\sin\theta,\ \frac\pi2\le\theta\le\frac{3\pi}4$ | 同上圆在第二象限部分 | $\sin\theta$ 仍为正 |
| 14 | $0\le r\le\sqrt{3}\sin\theta,\ 0\le\theta\le\frac\pi3$ | $r=\sqrt{3}\sin\theta$ 圆扇形 | 圆心 $(0,\frac{\sqrt{3}}{2})$，半径 $\frac{\sqrt{3}}{2}$ |
| 15 | $1\le r\le\sqrt2,\\arccos(1/r)\le\theta\le\pi/4$ | 第一象限内 $r\ge1,x\le1,y\le x$ | 原若写 $r\le2$，超过 $\sqrt2$ 后角下限大于上限，必须缩到有效区间 |

> [!tip] 常见圆域极坐标形态（背）
> 以下 $a>0$：$x^{2}+y^{2}=2ax\Rightarrow r=2a\cos\theta,\ \theta\in[-\frac\pi2,\frac\pi2]$；$x^{2}+y^{2}=2ay\Rightarrow r=2a\sin\theta,\ \theta\in[0,\pi]$。

## 四、综合练习区域

常见综合练习中的区域形态汇总：

| 区域类型 | 典型描述 | 常见考法 |
| :-- | :-- | :-- |
| 曲边弓形 $y=x,\ y=x^{2}$ 之间 | $0\le x\le1,\ x^{2}\le y\le x$ | 面积 $\frac{1}{6}$；$\iint x\,y$ 型 |
| 双曲线 $xy=1$ 截取 | $1\le x\le a,\ \frac{1}{x}\le y\le x$ | 调和函数积分 |
| 单位圆 $x^{2}+y^{2}\le1$ | 极坐标 $0\le r\le1$ | 概率积分、高斯型 |
| 抛物线 $y^2=x$ 与直线 $y=x$ | $0\le x\le1, x\le y\le\sqrt x$ | 换序为 $0\le y\le1, y^2\le x\le y$ |
| $y=\ln x$ 与坐标轴 | $1\le x\le a,\ 0\le y\le\ln x$ | 分部积分 |
| $y=e^{x}$ 截取 | $0\le x\le1,\ 0\le y\le e^{x}$ | 指数型 |
| $y=\sin x$ 一个拱 | $0\le x\le\pi,\ 0\le y\le\sin x$ | 三角型；面积 $2$ |

> [!tip] 区域识别口诀
> **直线定角、抛物定形、圆定中心、双曲定界**——拿到区域先判类型，再选坐标系：
> - 含 $x^{2}+y^{2}$ → 极坐标优先
> - 含 $\frac{y}{x}$ 或 $\arctan\frac{y}{x}$ → 极坐标
> - 三角形/梯形/平行四边形 → 直角坐标
> - 抛物线 $y=x^{2}$ 与直线 $y=x$ → 直角坐标（换序可能更简）
> - 含 $\sqrt{a^{2}-x^{2}}$ → 极坐标或三角代换
