# 第1讲（四-1）无穷小基础与等价替换

> [!abstract] 本讲定位
> 无穷小/无穷大的阶与比较、两个重要极限与 $1^{\infty}$ 万能套路、等价无穷小表（基础组/高阶组）与替换规则，含例题A、B。

## 🧮 1.11 无穷小与无穷大的阶（张宇第1讲）

**无穷小**：$\lim f=0$ 的 $f$（$x\to x_0$ 时）。**无穷大**：$\lim f=\infty$（绝对值趋于 $+\infty$）。

**无穷小的阶的比较**（设 $\alpha,\beta\to0$，$\lim\frac{\beta}{\alpha}=l$）：

| 情形 | 名称 |
| :-- | :-- |
| $l=0$ | $\beta$ 是比 $\alpha$ **高阶**的无穷小：$\beta=o(\alpha)$ |
| $l=\infty$ | $\beta$ 是比 $\alpha$ **低阶**的无穷小 |
| $0<\vert l\vert <+\infty$ | $\beta$ 与 $\alpha$ **同阶**无穷小 |
| $l=1$ | $\beta$ 与 $\alpha$ **等价**无穷小：$\beta\sim\alpha$ |
| $\lim\frac{\beta}{\alpha^{k}}=c\ne0$ | $\beta$ 是 $\alpha$ 的 **$k$ 阶**无穷小（$k=1$ 即与上条同阶重合） |

- **无穷小的运算性质**：有限个无穷小之和仍为无穷小；有界函数×无穷小仍为无穷小；常数×无穷小仍为无穷小。
- **无穷大的比较**：$x\to+\infty$ 时 $\ln^\alpha x \ll x^\beta \ll a^x$（固定 $\alpha,\beta>0,a>1$）$\ll x^x$（增长速度表见下）；$\frac{1}{\text{无穷大}}=\text{无穷小}$，反之亦然（同极限过程）。

**等价替换优先用于乘除因子**。分别替换差式 $\alpha-\beta$ 时，主项之比极限不等于1是常用充分条件；和式 $\alpha+\beta$ 则要排除比值为 $-1$ 的抵消。若主项可能抵消，应整体变形、比较替换误差或展开更高阶，不能直接逐项换。

> [!example] ✏️ 例题A. 判断无穷小的阶
> **题目**：$x\to0$ 时 $\alpha=\sqrt{1+x^{2}}-1$ 是 $x$ 的几阶无穷小？
> **解**：分子有理化：
> $$
> \sqrt{1+x^{2}}-1=\frac{x^{2}}{\sqrt{1+x^{2}}+1}
> $$
> $$
> \frac{\alpha}{x^{2}}=\frac{1}{\sqrt{1+x^{2}}+1}\to\frac12\ (\ne0)
> $$
> 故 $\alpha$ 与 $x^{2}$ **同阶**，是 $x$ 的**二阶**无穷小（极限为 $\frac12$，非等价）。

---

$$
\boxed{\lim_{x\to 0}\frac{\sin x}{x}=1},\qquad
\boxed{\lim_{x\to\infty}\Bigl(1+\frac{1}{x}\Bigr)^{x}=\lim_{x\to 0}(1+x)^{\frac{1}{x}}=e}
$$

**$e$ 的定义（数列版）**：$\left\{\left(1+\frac1n\right)^n\right\}$ **单调递增且有上界** ⟹ 极限存在，定义该极限为 $e$（证明链见 [[02 第2讲 数列极限]]）。

![[高数-极限sinx除以x.png|430]]
*$y=\frac{\sin x}{x}$：$x=0$ 处无定义但极限为 1（两个重要极限之一）*

**$1^\infty$ 型万能套路**：当 $\alpha\to 0,\ \beta\to\infty$ 时

$$
\boxed{\lim(1+\alpha)^{\beta}=e^{\lim \alpha\beta}}
\qquad\text{（一般幂指：}\lim u^{v}=e^{\lim v\ln u}\text{）}
$$

> $\displaystyle\lim_{x\to\infty}\left(1+\frac{a}{x}\right)^{x}=e^{a}$。

---

带参数的等价式默认 $a>0,a\ne1$、$\alpha\ne0$ 为固定实数、$n$ 为正整数；$\alpha=0$ 时相关差恒零，应单独处理，不写成“零比零趋1”的等价关系。

## 🧮 1.12 等价无穷小表（$x\to 0$）

基础组（一阶）：

| 等价关系 | 等价关系 |
| :-- | :-- |
| $\sin x \sim x$ | $\tan x \sim x$ |
| $\arcsin x \sim x$ | $\arctan x \sim x$ |
| $\ln(1+x) \sim x$ | $e^{x}-1 \sim x$ |
| $a^{x}-1 \sim x\ln a$ | $\log_a(1+x) \sim \frac{x}{\ln a}$ |
| $(1+x)^{\alpha}-1 \sim \alpha x$ | $\sqrt[n]{1+x}-1 \sim \frac{x}{n}$ |
| $1-\cos x \sim \frac{x^{2}}{2}$ | $1-\cos^{\alpha}x \sim \frac{\alpha x^{2}}{2}$ |
| **$\ln(x+\sqrt{x^{2}+1})\sim x$**（反双曲正弦 $\operatorname{arsh}x$） | $\operatorname{arsh}x=\ln(x+\sqrt{x^2+1})$，详见 [[附录 双曲函数]] |

> [!note] 反双曲正弦为何等价于 $x$
> $x\to0$ 时：
> $$
> \begin{aligned}
> \sqrt{x^2+1}&=1+\frac{x^2}{2}+o(x^2)\ \Longrightarrow\ x+\sqrt{x^2+1}\\[4pt]
> &=1+x+\frac{x^2}{2}+o(x^2)
> \end{aligned}
> $$
> $$
> \ln(1+x+\cdots)\sim x+\frac{x^2}{2}-\frac{x^2}{2}=x
> $$
> 张宇标注：这条小结论「$\ln(x+\sqrt{x^2+1})$ 是奇函数，$x\to0$ 时 $\sim x$」是常见隐含考点。

高阶组（差型，全部可由泰勒展开导出，与 [[06 第6讲 一元函数微分学的应用（二）中值定理与泰勒公式]] 对照记）：

| 等价关系 | 等价关系 |
| :-- | :-- |
| $x-\sin x \sim \frac{x^{3}}{6}$ | $\tan x - x \sim \frac{x^{3}}{3}$ |
| $\arcsin x - x \sim \frac{x^{3}}{6}$ | $x-\arctan x \sim \frac{x^{3}}{3}$ |
| $\tan x-\sin x \sim \frac{x^{3}}{2}$ | $x-\ln(1+x) \sim \frac{x^{2}}{2}$ |
| $e^{x}-1-x \sim \frac{x^{2}}{2}$ | $(1+u)^{v}-1 \sim uv\ \ (u\to0,\ uv\to0)$ |

> [!warning] 等价替换规则
> - **乘除因子**：可放心整体替换。
> - **加减项**：$\alpha-\beta$ 中把 $\alpha\sim\alpha_1,\ \beta\sim\beta_1$ 替换，要求 $\lim\frac{\alpha_1}{\beta_1}\ne 1$（差不抵消）；
> $\alpha+\beta$ 则要求 $\lim\frac{\alpha_1}{\beta_1}\ne -1$。
> **抵消时必须用泰勒展开**（如 $\tan x-\sin x$ 不能各自换成 $x$）。
> - **指数位置、复合内部不能乱换**：如 $e^{\tan x}-e^{\sin x}$ 应提因子 $e^{\sin x}\bigl(e^{\tan x-\sin x}-1\bigr)\sim \tan x-\sin x$。

> [!example] ✏️ 例题B. 差型为何不能各自替换（等价替换陷阱）
> **题目**：求 $\lim\limits_{x\to0}\frac{\tan x-\sin x}{x^{3}}$。
> **解**：**错误**做法：$\tan x\sim x$、$\sin x\sim x$，代入得 $\frac{x-x}{x^{3}}=0$（**错**，差型抵消，必须更高阶展开）。
> **正确**：提公因式 $\tan x$，出现差的因子再用等价：
> $$
> \tan x-\sin x=\tan x\,\bigl(1-\cos x\bigr)\sim x\cdot\frac{x^{2}}{2}=\frac{x^{3}}{2}
> $$
> $$
> \lim_{x\to0}\frac{\tan x-\sin x}{x^{3}}=\frac{x^{3}/2}{x^{3}}=\frac12
> $$
> **要点**：$\tan x-\sin x$ 的一次项相消，需要三次主项；也可把 $\tan x-x\sim x^3/3$ 与 $x-\sin x\sim x^3/6$ **相加**，得到 $x^3/2$，不是相减。
