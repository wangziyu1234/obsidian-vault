# 附录 二重积分速查

> [!abstract] 附录定位
> **纯速查表**：二重积分**常用区域**的积分结果、极坐标/换元/对称性/形心的**结论速查**。所有推导与例题见 [[14 第14讲 二重积分]]（计算/换序/对称性/综合证明）；[[09 第9讲 一元函数积分学的计算]]（华里士）、[[10 第10讲 一元函数积分学的应用（一）几何应用]]（旋转体/半球）。

## 总览：常用区域积分结果秒查

| 区域 $D$ | 面积 $S_D$ | 常用积分结果 |
| :-- | :-- | :-- |
| 圆 $x^{2}+y^{2}\le R^{2}$ | $\pi R^{2}$ | $\iint x^{2}=\iint y^{2}=\dfrac{\pi R^{4}}4$；$\iint(x^{2}+y^{2})=\dfrac{\pi R^{4}}2$；$\iint(x^{2}+y^{2})^{n}=\dfrac{\pi R^{2n+2}}{n+1}$ |
| 圆盘（任意被积） | — | $\iint e^{-r^{2}}=\pi(1-e^{-R^{2}})$；$\iint\sin r^{2}=\pi(1-\cos R^{2})$；$\iint\cos r^{2}=\pi\sin R^{2}$；$\iint\sqrt{1-r^{2}}=\dfrac{2\pi}3\bigl(1-(1-R^{2})^{3/2}\bigr)$（$R=1$ 即半球 $\dfrac{2\pi}3$） |
| 椭圆 $\dfrac{x^{2}}{a^{2}}+\dfrac{y^{2}}{b^{2}}\le1$ | $\pi ab$ | $\iint x^{2}=\dfrac{\pi a^{3}b}4$；$\iint y^{2}=\dfrac{\pi ab^{3}}4$；$\iint\Bigl(\dfrac{x^{2}}{a^{2}}+\dfrac{y^{2}}{b^{2}}\Bigr)=\dfrac{\pi ab}2$ |
| 半圆 $x^{2}+y^{2}\le R^{2},\ y\ge0$ | $\dfrac{\pi R^{2}}2$ | $\iint y^{2}=\dfrac{\pi R^{4}}8$（圆域一半） |
| 环形 $r_1\le r\le r_2$ | $\pi(r_2^{2}-r_1^{2})$ | $\iint(x^{2}+y^{2})=\dfrac{\pi(r_2^{4}-r_1^{4})}2$ |
| 扇形 $\alpha\le\theta\le\beta,\ 0\le r\le R$ | $\dfrac{R^{2}}2(\beta-\alpha)$ | $\iint(x^{2}+y^{2})=\dfrac{R^{4}}4(\beta-\alpha)$ |
| 三角形 $\begin{cases}x\ge0\\[2pt]y\ge0\\[2pt]x+y\le a\end{cases}$ | $\dfrac{a^{2}}2$ | 形心 $\Bigl(\dfrac a3,\dfrac a3\Bigr)$：$\iint x=\iint y=\dfrac{a^{3}}6$；$\iint xy=\dfrac{a^{4}}{24}$ |
| 菱形 $\lvert x\rvert+\lvert y\rvert\le a$ | $2a^{2}$ | $\iint(\lvert x\rvert+\lvert y\rvert)=\dfrac{4a^{3}}3$；$\iint\lvert x\rvert=\iint\lvert y\rvert=\dfrac{2a^{3}}3$ |
| 抛物 $y=x^{2}$ 与 $y=x$ | $\dfrac16$ | $\iint x=\dfrac1{12}$；$\iint y=\dfrac1{15}$；$\iint(x-y)=\dfrac1{60}$ |
| 抛物线 $y^{2}\le2px,\ 0\le x\le a$ | $\dfrac{4a}{3}\sqrt{2pa}$ | $\iint1$ 即面积；$\iint x=\dfrac{2a^{2}}{3}\sqrt{2pa}$ |
| 圆 $x^{2}+y^{2}\le2ax$（含圆） | $\dfrac{\pi a^{2}}2$ | 极坐标 $r\in[0,2a\cos\theta],\ \theta\in[-\frac\pi2,\frac\pi2]$ |

## 圆域上的通用积分（$D:x^{2}+y^{2}\le R^{2}$，极坐标一次算完）

| 被积函数 | 结果 |
| :-- | :-- |
| $1$ | $\pi R^{2}$ |
| $x^{2}$ 或 $y^{2}$ | $\dfrac{\pi R^{4}}4$（$\iint x^{2}=\iint y^{2}$） |
| $x^{2}+y^{2}$ | $\dfrac{\pi R^{4}}2$ |
| $(x^{2}+y^{2})^{n}$ | $\dfrac{\pi R^{2n+2}}{n+1}$ |
| $x^{m}y^{n}$（$m,n$ 均偶） | $\dfrac{\pi R^{m+n+2}}{m+n+2}\cdot\dfrac{(m-1)!!(n-1)!!}{(m+n)!!}\cdot$（$\theta$ 部分华里士；$m$ 或 $n$ 奇时 $=0$） |
| $e^{-(x^{2}+y^{2})}$ | $\pi\bigl(1-e^{-R^{2}}\bigr)$ |
| $\sin(x^{2}+y^{2})$ | $\pi(1-\cos R^{2})$ |
| $\sqrt{1-x^{2}-y^{2}}$ | $\dfrac{2\pi}3\bigl(1-(1-R^{2})^{3/2}\bigr)$（$R=1$ 即半球 $\dfrac{2\pi}3$） |
| $\lvert x\rvert+\lvert y\rvert$ | $\dfrac{8R^{3}}3$（$\iint\lvert x\rvert=\iint\lvert y\rvert=\dfrac{4R^{3}}3$） |
| $x$ 或 $y$（奇次幂） | $0$（对称性） |

## 极坐标常用 $\theta$ 积分（配华里士）

| 积分 | 结果 |
| :-- | :-- |
| $\int_0^{2\pi}\sin^{2}\theta\,d\theta=\int_0^{2\pi}\cos^{2}\theta\,d\theta$ | $\pi$ |
| $\int_0^{\pi}\sin^{2}\theta\,d\theta=\int_0^{\pi}\cos^{2}\theta\,d\theta$ | $\dfrac{\pi}2$ |
| $\int_0^{2\pi}\sin^{3}\theta\,d\theta=\int_0^{2\pi}\cos^{3}\theta\,d\theta$ | $0$（奇函数整周期） |
| $\int_0^{2\pi}\sin^{4}\theta\,d\theta=\int_0^{2\pi}\cos^{4}\theta\,d\theta$ | $\dfrac{3\pi}4$ |
| $\int_0^{\pi/2}\sin^{n}\theta\,d\theta$ | 偶次 $\dfrac{(n-1)!!}{n!!}\cdot\dfrac{\pi}2$；奇次 $\dfrac{(n-1)!!}{n!!}$（华里士） |
| $\int_0^{2\pi}\sin^{2k}\theta\cos^{2l}\theta\,d\theta$ | 积化和差/倍角（$\sin^{2}\cos^{2}=\dfrac{\sin^{2}2\theta}4$） |

> [!tip] 常见圆域极坐标形态（背）
> $x^{2}+y^{2}=2ax\Rightarrow r=2a\cos\theta,\ \theta\in[-\frac\pi2,\frac\pi2]$；$x^{2}+y^{2}=2ay\Rightarrow r=2a\sin\theta,\ \theta\in[0,\pi]$。

## 常用换元与雅可比

| 换元 | 雅可比 | 适用 |
| :-- | :-- | :-- |
| 极坐标 $x=r\cos\theta,\ y=r\sin\theta$ | $r$ | 圆域/环/扇形；被积含 $x^{2}+y^{2}$、$\dfrac yx$ |
| 广义极坐标 $x=ar\cos\theta,\ y=br\sin\theta$ | $abr$ | 椭圆域 |
| $u=x+y,\ v=x-y$（或 $x=\frac{u+v}2,\ y=\frac{u-v}2$） | $\lvert J\rvert=2$ 或 $\dfrac12$ | 被积/区域含 $x+y$ 或 $x-y$ |
| 平移 $u=x-a,\ v=y-b$ | $1$ | 圆心/重心移到原点 |

（雅可比推导细节见 [[14 第14讲 二重积分]]「一般换元法」。）

## 对称性与形心（秒杀结论）

| 情形 | 结论 |
| :-- | :-- |
| $D$ 关于 $y$ 轴对称、$f$ 对 $x$ 奇 | $=0$ |
| $D$ 关于 $y$ 轴对称、$f$ 对 $x$ 偶 | $=2\displaystyle\iint_{D_{x\ge0}}$ |
| $D$ 关于 $y=x$ 对称、$f(x,y)+f(y,x)=a$（常数） | $=\dfrac a2\,S_D$（轮换对称） |
| 形心反用 | $\iint_D x\,d\sigma=\bar x\,S_D$（圆中心 $\iint x=\iint y=0$） |
| $\lvert x\rvert+\lvert y\rvert$ 型（$D$ 关于两轴与 $y=x$ 对称） | $\iint(\lvert x\rvert+\lvert y\rvert)=8\displaystyle\iint_{\text{象限1}}x\,d\sigma$；$\iint\lvert x\rvert=4\displaystyle\iint_{\text{象限1}}x$ |
| 圆盘 $\iint(\lvert x\rvert+\lvert y\rvert)$ | $\dfrac{8R^{3}}3$ |
| 菱形 $\lvert x\rvert+\lvert y\rvert\le a$ 上 $\iint(\lvert x\rvert+\lvert y\rvert)$ | $\dfrac{4a^{3}}3$ |
