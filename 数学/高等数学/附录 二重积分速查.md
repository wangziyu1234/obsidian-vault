# 附录 二重积分速查

> [!abstract] 附录定位
> 二重积分**常用区域与积分结论速查**。前半部分按**直角坐标/极坐标**系统整理常见区域 $D$ 的集合描述与几何类型；后半部分给出对应区域的**积分结果、华里士公式、换元、对称性/形心**结论。所有推导与例题见 [[14 第14讲 二重积分]]（计算/换序/对称性/综合证明）；[[09 第9讲 一元函数积分学的计算]]（华里士）、[[10 第10讲 一元函数积分学的应用（一）几何应用]]（旋转体/半球）。

## 四、圆域通用积分（$D:x^{2}+y^{2}\le R^{2}$，极坐标一次算完）

| 被积函数 | 结果 | 做法 |
| :-- | :-- | :-- |
| $1$ | $\pi R^{2}$ | 极坐标 $\int_0^{2\pi}d\theta\int_0^R r\,dr$ |
| $x^{2}$ 或 $y^{2}$ | $\dfrac{\pi R^{4}}4$（$\iint x^{2}=\iint y^{2}$） | 极坐标 + $\int\cos^{2}\theta=\pi$ |
| $x^{2}+y^{2}$ | $\dfrac{\pi R^{4}}2$ | 极坐标 $\int r^{3}dr$ |
| $(x^{2}+y^{2})^{n}$ | $\dfrac{\pi R^{2n+2}}{n+1}$ | 极坐标 $\int r^{2n+1}dr$ |
| $x^{m}y^{n}$（$m,n$ 均偶） | $\dfrac{2\pi R^{m+n+2}}{m+n+2}\cdot\dfrac{(m-1)!!(n-1)!!}{(m+n)!!}$（$\theta$ 部分华里士 $\int_0^{2\pi}\cos^m\theta\sin^n\theta\,d\theta=2\pi\dfrac{(m-1)!!(n-1)!!}{(m+n)!!}$；$m$ 或 $n$ 奇时 $=0$） | 极坐标分离 $r^{m+n+1}\times$ 华里士 |
| $x^{2}y^{2}$ | $\dfrac{\pi R^{6}}{24}$ | 上式 $m=n=2$ |
| $x^{4}$ 或 $y^{4}$ | $\dfrac{\pi R^{6}}8$ | 上式 $m=4,\ n=0$ |
| $\sqrt{x^{2}+y^{2}}$ | $\dfrac{2\pi R^{3}}3$（$\int_0^{2\pi}d\theta\int_0^R r^2dr$） | 极坐标 $\int r^{2}dr$ |
| $\dfrac1{\sqrt{x^{2}+y^{2}}}$ | $2\pi R$（仅 $R>0$，瑕积累积后收敛） | 极坐标 $r$ 约掉，$\int dr$ |
| $\sqrt{x^{2}+y^{2}+c^{2}}$ | $\dfrac{2\pi}3\bigl[(R^{2}+c^{2})^{3/2}-\lvert c\rvert^{3}\bigr]$（位移平移，$c\to0$ 退化为 $\dfrac{2\pi R^3}{3}$） | 极坐标 + 凑 $d(r^{2}+c^{2})$ |
| $\dfrac1{x^{2}+y^{2}+c^{2}}$ | $\pi\ln\dfrac{R^{2}+c^{2}}{c^{2}}$（$2\pi\int_0^R\dfrac r{r^2+c^2}\,dr$） | 极坐标 + 凑 $d(r^{2}+c^{2})$ 得 $\ln$ |
| $\ln(x^{2}+y^{2})$ | $\pi R^{2}(2\ln R-1)$（$R=1$ 时 $=-\pi$） | 极坐标 + 分部积分 |
| $\dfrac{x^{2}}{x^{2}+y^{2}}$（或 $y^{2}$ 型） | $\dfrac{\pi R^{2}}2$（$\int_0^{2\pi}\cos^2\theta\,d\theta\int_0^R r\,dr$） | 极坐标约掉 $r^{2}$，只剩 $\int\cos^{2}\theta$ |
| $e^{-(x^{2}+y^{2})}$ | $\pi\bigl(1-e^{-R^{2}}\bigr)$（$R\to\infty$ 即高斯积分 $\pi$） | 极坐标凑 $d(r^{2})$：$\int e^{-r^{2}}r\,dr$ |
| $\sin(x^{2}+y^{2})$ | $\pi(1-\cos R^{2})$ | 极坐标凑 $d(r^{2})$ |
| $\sqrt{1-x^{2}-y^{2}}$ | $\dfrac{2\pi}3\bigl(1-(1-R^{2})^{3/2}\bigr)$（$R=1$ 即半球 $\dfrac{2\pi}3$） | 极坐标换 $u=1-r^{2}$ |
| $\lvert x\rvert+\lvert y\rvert$ | $\dfrac{8R^{3}}3$（$\iint\lvert x\rvert=\iint\lvert y\rvert=\dfrac{4R^{3}}3$） | 对称拆象限 $\times4$ |
| $x$ 或 $y$（奇次幂） | $0$（对称性） | 关于 $y$ 轴/$x$ 轴奇函数 |

## 五、极坐标 $\theta$ 积分与华里士公式

| 积分 | 结果 | 做法 |
| :-- | :-- | :-- |
| $\int_0^{2\pi}\sin^{2}\theta\,d\theta=\int_0^{2\pi}\cos^{2}\theta\,d\theta$ | $\pi$ | 降幂 $\sin^2=\frac{1-\cos2\theta}2$ |
| $\int_0^{\pi}\sin^{2}\theta\,d\theta=\int_0^{\pi}\cos^{2}\theta\,d\theta$ | $\dfrac{\pi}2$ | 半周期或直接积 |
| $\int_0^{2\pi}\sin^{3}\theta\,d\theta=\int_0^{2\pi}\cos^{3}\theta\,d\theta$ | $0$（奇函数整周期） | 奇函数周期积分 |
| $\int_0^{2\pi}\sin^{4}\theta\,d\theta=\int_0^{2\pi}\cos^{4}\theta\,d\theta$ | $\dfrac{3\pi}4$ | 降幂两次或华里士 |
| $\int_0^{\pi/2}\sin^{n}\theta\,d\theta$ | 偶次 $\dfrac{(n-1)!!}{n!!}\cdot\dfrac{\pi}2$；奇次 $\dfrac{(n-1)!!}{n!!}$（华里士） | 华里士公式 |
| $\int_0^{2\pi}\sin^{2k}\theta\cos^{2l}\theta\,d\theta$ | 积化和差/倍角（$\sin^{2}\cos^{2}=\dfrac{\sin^{2}2\theta}4$） | 倍角降幂拆开 |

### 第一象限圆域通用公式

> 华里士一象限式：$\int_0^{\pi/2}\cos^{m}\theta\sin^{n}\theta\,d\theta=\begin{cases}\dfrac{(m-1)!!(n-1)!!}{(m+n)!!}\cdot\dfrac\pi2,&m,n\text{均偶}\\[4pt]\dfrac{(m-1)!!(n-1)!!}{(m+n)!!},&m,n\text{至少一奇}\end{cases}$（约定 $0!!=1$、$(-1)!!=1$，如 $\int_0^{\pi/2}\cos^3\theta\,d\theta=\dfrac{2!!\cdot(-1)!!}{3!!}=\dfrac23$）

| 被积函数 | 结果 | 做法 |
| :-- | :-- | :-- |
| $x^{m}y^{n}$（$m,n$ 均偶） | $\dfrac{R^{m+n+2}}{m+n+2}\cdot\dfrac{(m-1)!!(n-1)!!}{(m+n)!!}\cdot\dfrac\pi2$（如 $\iint x^{2}=\dfrac{\pi R^{4}}{16}$、$x^{2}y^{2}=\dfrac{\pi R^{6}}{96}$） | 华里士一象限式（见表头） |
| $x^{m}y^{n}$（$m,n$ 至少一奇） | $\dfrac{R^{m+n+2}}{m+n+2}\cdot\dfrac{(m-1)!!(n-1)!!}{(m+n)!!}$（如 $\iint xy=\dfrac{R^{4}}8$、$\iint x=\dfrac{R^{3}}3$） | 华里士一象限式，奇次无 $\pi$ |
| $\sqrt{R^{2}-x^{2}-y^{2}}$ | $\dfrac{\pi R^{3}}6$（球体第一象限八分之一 $\dfrac18\cdot\dfrac{2\pi R^3}3$） | 极坐标换 $u=1-r^{2}$ 或球体对称 |

## 六、极坐标特殊曲线区域

| 曲线（$a>0$） | 面积 $S$ | 常用积分结果 | 做法 |
| :-- | :-- | :-- | :-- |
| 心形线 $r=a(1+\cos\theta)$ | $\dfrac{3\pi a^{2}}2$ | $\iint x=\dfrac{5\pi a^{3}}4$（形心 $\bar x=\dfrac{5a}6$）；$\iint(x^{2}+y^{2})=\dfrac{35\pi a^{4}}{16}$ | $S=\frac12\int r^2$；$\iint x=\int\cos\theta\frac{r^3}3$ |
| 双纽线 $r^{2}=a^{2}\cos2\theta$ | $a^{2}$ | $\iint(x^{2}+y^{2})=\dfrac{\pi a^{4}}8$（两叶各 $\dfrac{\pi a^{4}}{16}$）；$\iint x^{2}=\dfrac{\pi a^{4}}{16}+\dfrac{a^{4}}6$；$\iint y^{2}=\dfrac{\pi a^{4}}{16}-\dfrac{a^{4}}6$（$\iint x^2+\iint y^2=\dfrac{\pi a^4}{8}$ 自洽） | 一叶 $\theta\in[-\frac\pi4,\frac\pi4]$，$\times2$ |
| 三叶玫瑰线 $r=a\sin3\theta$ | $\dfrac{\pi a^{2}}4$ | 单叶面积 $\dfrac{\pi a^{2}}{12}$ | 单叶 $\theta\in[0,\frac\pi3]$，$\times3$ |
| 四叶玫瑰线 $r=a\cos2\theta$ | $\dfrac{\pi a^{2}}2$ | 单叶面积 $\dfrac{\pi a^{2}}8$ | 单叶 $\theta\in[-\frac\pi4,\frac\pi4]$，$\times4$ |

> [!note] 极坐标面积万能式
> $S=\dfrac12\int_\alpha^\beta r^{2}(\theta)\,d\theta$；带角度的曲线（玫瑰线/双纽线）先画图定叶区间，逐叶积分求和，切勿直接积分整周期（如 $\sin3\theta$ 每叶区间为 $\dfrac{\pi}{3}$、共三叶覆盖 $[0,\pi]$，逐叶积分乘以叶数才对）。

## 八、对称性与形心

| 情形 | 结论 |
| :-- | :-- |
| $D$ 关于 $y$ 轴对称、$f$ 对 $x$ 奇 | $=0$ |
| $D$ 关于 $y$ 轴对称、$f$ 对 $x$ 偶 | $=2\displaystyle\iint_{D_{x\ge0}}$ |
| $D$ 关于 $y=x$ 对称、$f(x,y)+f(y,x)=a$（常数） | $=\dfrac a2\,S_D$（轮换对称） |
| $D$ 关于 $y=x$ 对称（轮换） | $\iint x\,d\sigma=\iint y\,d\sigma=\dfrac12\displaystyle\iint(x+y)$；$\iint x^2=\iint y^2=\dfrac12\displaystyle\iint(x^2+y^2)$ |
| 形心反用 | $\iint_D x\,d\sigma=\bar x\,S_D$（圆中心 $\iint x=\iint y=0$） |
| 半圆 $x^2+y^2\le R^2,\ y\ge0$ | 形心 $\Bigl(0,\dfrac{4R}{3\pi}\Bigr)$：$\iint y=\dfrac{2R^3}{3}$ |
| 扇形（圆心角 $2\alpha$，沿 $x$ 轴对称） | 形心 $\bar x=\dfrac{2R\sin\alpha}{3\alpha}$（如 $90°$ 扇形（$\alpha=\frac\pi4$）$\bar x=\dfrac{4\sqrt2\,R}{3\pi}$） |
| 半球 $x^2+y^2+z^2\le R^2,\ z\ge0$（投影圆盘） | $\iint\sqrt{R^2-x^2-y^2}=\dfrac{2\pi R^3}{3}$；第一象限 $\dfrac{\pi R^3}{6}$ |
| $\lvert x\rvert+\lvert y\rvert$ 型（$D$ 关于两轴与 $y=x$ 对称） | $\iint(\lvert x\rvert+\lvert y\rvert)=8\displaystyle\iint_{\text{象限1}}x\,d\sigma$；$\iint\lvert x\rvert=4\displaystyle\iint_{\text{象限1}}x$ |
| 圆盘 $\iint(\lvert x\rvert+\lvert y\rvert)$ | $\dfrac{8R^{3}}3$ |
| 菱形 $\lvert x\rvert+\lvert y\rvert\le a$ 上 $\iint(\lvert x\rvert+\lvert y\rvert)$ | $\dfrac{4a^{3}}3$ |

> [!tip] 轮换对称（$D$ 关于 $y=x$ 对称时）
> $f$ 轮换前后**对称和**已知即用 $\frac a2 S_D$；只有单一表达式时也可写成两项平均，如 $\iint x^2=\frac12\iint(x^2+y^2)$（圆/菱形/单位正方形均适用，常配合极坐标一次算完）。

## 九、综合练习区域

常见综合练习中的区域形态汇总：

| 区域类型 | 典型描述 | 常见考法 |
| :-- | :-- | :-- |
| 三角形 $y=x,\ y=x^{2}$ 之间 | $0\le x\le1,\ x^{2}\le y\le x$ | 面积 $\frac{1}{6}$；$\iint x\,y$ 型 |
| 双曲线 $xy=1$ 截取 | $1\le x\le a,\ \frac{1}{x}\le y\le x$ | 调和函数积分 |
| 单位圆 $x^{2}+y^{2}\le1$ | 极坐标 $0\le r\le1$ | 概率积分、高斯型 |
| 抛物线 $y^{2}=x$ 与直线 $y=x$ | $0\le x\le1,\ x^{2}\le y\le\sqrt{x}$（$y$ 型） | 换序练习 |
| $y=\ln x$ 与坐标轴 | $1\le x\le a,\ 0\le y\le\ln x$ | 分部积分 |
| $y=e^{x}$ 截取 | $0\le x\le1,\ 0\le y\le e^{x}$ | 指数型 |
| $y=\sin x$ 一个拱 | $0\le x\le\pi,\ 0\le y\le\sin x$ | 三角型；面积 $2$ |

> [!tip] 区域识别口诀
> **直线定角、抛物定形、圆定中心、双曲定界**——拿到区域先判类型，再选坐标系：
> - 含 $x^{2}+y^{2}$ → 极坐标优先
> - 含 $\frac{y}{x}$ 或 $\arctan\frac{y}{x}$ → 极坐标
> - 三角形/梯形/平行四边形 → 直角坐标
> - 抛物线 $y=x^{2}$ 与直线 $y=x$ → 直角坐标（换序可能更简）
> - 含 $\sqrt{a^{2}-x^{2}}$ → 极坐标或三角代换
