# 附录 变形技巧

> [!abstract] 附录定位
> 对应张宇《基础30讲》高数分册附录6（变形技巧）。考研数学解题本质是「建立连接条件与结论的桥梁」，每一步都是一个**转化（变形）**：
> 等量关系（等式变形）、等价关系（等价变形）、不等量放缩（不等式变形）、充分/必要关系。

## 一、等式变形与等价变形

## (1) 定义法

用 $A$ 定义 $B$ ⟹ $B\Leftrightarrow A$：给出 $B$ 回归定义 $A$。
- $\lim f(x)=0$ ⟹ 用 "$\varepsilon$-$\delta$" 定义任给 $\varepsilon>0$ 取 $\delta$；
- 导数定义 $f'(x_0)=\lim\dfrac{f(x)-f(x_0)}{x-x_0}$ 常考。

> [!example] 1. 导数定义的等价改写
> - 已知 $f$ 在 $x_0$ 连续、$\lim\limits_{x\to x_0}\dfrac{f(x)}{x-x_0}=a$ ⟹ $f(x_0)=0$、$f'(x_0)=a$。
> - 已知 $f$ 在 $x_0$ 邻域可导、$\lim\limits_{x\to x_0}\dfrac{f(x)}{(x-x_0)^2}=a$ ⟹ $f(x_0)=0$、$f'(x_0)=0$（分子须比分母高阶）。
> - 已知 $f$、$g$ 在 $x_0$ 相切 ⟹ $f(x_0)=g(x_0)$、$f'(x_0)=g'(x_0)$；
> 若 $f''>0,g''<0$，令 $F=f-g$ ⟹ $F'(x_0)=0$、$F''(x_0)>0$ ⟹ $x_0$ 为 $F$ 极小值点。

## (2) 公式法

留意公式**独特性**（指向何方）与**成立条件**（何时可用）。例：泰勒展开的独特性是用 $x=0$ 处各阶导近似表示邻域值，成立条件是 $n$ 阶可导——见标识"n 阶可导"即可考虑泰勒。

## (3) 换元法

引入新元代旧元，使形式简单化、规范化。

| 情形 | 换元 |
| :-- | :-- |
| 复杂部分代换 | 把最复杂整体令成 $t$（宏观 / 微观两层面） |
| 平移换元 | $x\to1$ ⟹ $t=x-1\to0$；$a<b$ ⟹ $c=a+\varepsilon,\ 0<\varepsilon<b-a$ |
| 消元换元 | $x_1>x_2$ ⟹ $x_1=x_2+t$；$x_1>x_2>0$ ⟹ $x_1=tx_2$ |
| 零和换元 | $x_1+x_2=a$ ⟹ 令 $x_1=\frac a2+t,\ x_2=\frac a2-t$；$x+y+z=1$ 类似 |

## (4) 相消法

| 形式 | 要点 |
| :-- | :-- |
| 加减相消 | 裂项 $a_{n+1}-a_n$；构造 $a_{n+1}-a_n=f(n)$ 后累加；本质是通分逆运算（同形分解） |
| 乘除相消 | 乘积递推 $a_{n+1}=c_n\,a_n$ ⟹ $a_n=a_1\prod c_k$；比值累乘相消 |
| 错位相消 | 等比数列求和 $S_n=a+aq+\cdots+aq^{n-1}$，乘 $q$ 后与原式相减：$(1-q)S_n=a-aq^n$ |

> [!note] 同形分解意识
> 关键是看见这类**裂项**：
> $$
> \begin{aligned}
> \dfrac{1}{n(n+1)}&=\dfrac1n-\dfrac1{n+1},\\[4pt]
> \dfrac{1}{(2n-1)(2n+1)}&=\dfrac12\!\left(\dfrac{1}{2n-1}-\dfrac{1}{2n+1}\right),\\[4pt]
> \dfrac{e^n}{(e^n-1)(e^{n+1}-1)}&=\dfrac{1}{e-1}\left(\dfrac{1}{e^n-1}-\dfrac{1}{e^{n+1}-1}\right)
> \end{aligned}
> $$
> 与共轭法 $\sqrt{n+1}-\sqrt n=\dfrac1{\sqrt{n+1}+\sqrt n}$、对数 $\ln\!\dfrac{n+1}{n}=\ln(n+1)-\ln n$ 结合。

## (5) 同除法或解方程法（递推数列标准型）

设递推 $a_{n+1}=k\,a_n+f(n)$，按 $k$ 分类：

| 递推形式 | 通解结构 |
| :-- | :-- |
| $a_{n+1}=k a_n+f(n),\ k\ne0,1$ | $\dfrac{a_{n+1}}{k^{n+1}}=\dfrac{a_n}{k^n}+\dfrac{f(n)}{k^{n+1}}$（化为可累加形式，逐项求和） |
| $a_{n+1}+A a_n=B^n P_m(n),\ B\ne-A$ | $a_n=C(-A)^n+B^n Q_m(n)$，$Q_m$ 为 $n$ 的 $m$ 次多项式 |
| $a_{n+1}+A a_n=B^n P_m(n),\ B=-A$ | $a_n=C(-A)^n+nB^n Q_m(n)$ |
| $a_n a_{n+1}=p\,a_n+q\,a_{n+1}$ | 两边除以 $a_n a_{n+1}$：$\dfrac{p}{a_{n+1}}+\dfrac{q}{a_n}=1$ ⟹ $\left\{\dfrac1{a_n}\right\}$ 化为线性递推（取倒数） |
| 线性二阶 $a_{n+1}+Aa_n+Ba_{n-1}=0$ | 设 $\lambda^n$ ⟹ 特征方程 $\lambda^2+A\lambda+B=0$；$\Delta=A^2-4B$：两互异实根 $\lambda_1,\lambda_2$ ⟹ $a_n=C_1\lambda_1^n+C_2\lambda_2^n$；重根 ⟹ $(C_1+C_2 n)\lambda^n$ |

## (6) 倒置法

取倒数改变分子分母结构，常用于**分母复杂、分子单一**：$a_{n+1}=\dfrac{a_n}{a_n+2}$ ⟹ $\dfrac1{a_{n+1}}=1+\dfrac2{a_n}$（化为线性递推）。

## (7) 平方开方法

配成 $a^2+b^2$ 或 $\alpha+\dfrac1\alpha$ 形式。

| 情形 | 配凑 |
| :-- | :-- |
| 倒数之和 $\alpha+\dfrac1\alpha$ | $\alpha^2+\dfrac1{\alpha^2}=\left(\alpha+\dfrac1\alpha\right)^2-2=\left(\alpha-\dfrac1\alpha\right)^2+2$；$e^{2x}+e^{-2x}=(e^x+e^{-x})^2-2$ |
| 线性组合 $a+b=c$ | $a^2+ab+b^2=(a+b)^2-ab=c^2-ab$ |
| 三式互推 | $a^2+b^2+c^2=(a+b+c)^2-2(ab+bc+ac)$；$a^2+b^2+c^2+ab+bc+ac=\dfrac12[(a+b)^2+(b+c)^2+(a+c)^2]$ |
| 三角倍角 | $1+\sin2\theta=(\sin\theta+\cos\theta)^2$；$1+\cot^2\theta=\csc^2\theta$（参见 [[附录 三角与代数补充]]） |
| 平方后简化 | $\sqrt{1+a}+\sqrt{1-a}=\sqrt{2+2\sqrt{1-a^2}}$；$\sqrt{2+\sqrt3}+\sqrt{2-\sqrt3}=\sqrt{4+2}=\sqrt6$ |

## (8) 特殊值法

令 $x=x_0$ 使欲求表达式与条件表达式产生联系。如 $f(x)=ax^3+bx^2+cx+d$：
$$
\begin{aligned}a+b+c+d&=f(1), & -a+b-c+d&=f(-1),\\[4pt] 3a+2b+c&=f'(1)\end{aligned}\ \Longrightarrow\ a+c=\tfrac12[f(1)-f(-1)],\ b+d=\tfrac12[f(1)+f(-1)]
$$

## (9) 因式分解法

$$a^2+ab+b^2=\dfrac{a^3-b^3}{a-b},\qquad a^2-ab+b^2=\dfrac{a^3+b^3}{a+b}$$

**适用场景**：遇 $\dfrac{a^3-b^3}{a-b}$ 型分式先约分（$=a^2+ab+b^2$）；分母含 $a^2\pm ab+b^2$ 时乘 $(a\mp b)$ 有理化（如 $\dfrac{1}{\sqrt[3]{x}-\sqrt[3]{a}}$ 型乘 $\sqrt[3]{x^2}+\sqrt[3]{xa}+\sqrt[3]{a^2}$ 化去分母根号）；或需引入立方差因子时反用。

（参见 [[附录 三角与代数补充]] 的立方和差与高次差。）

## (10) 整数幂和法

$$
\begin{aligned}
\sum_{i=1}^{n}i&=\dfrac{n(n+1)}2,\\[4pt]
\sum i^2&=\dfrac{n(n+1)(2n+1)}6,\\[4pt]
\sum i^3&=\left[\dfrac{n(n+1)}2\right]^2
\end{aligned}
$$

在放缩法中有一席之地。

> [!example] 2. 夹逼放缩
> 由 $\sin x<x<\tan x\ (0<x<1)$ 与 $\sum i^2$ 公式可估出 $\sum\dfrac{\sin\dfrac{i}{n^2}}{n}$ 类和的极限（**不是** $\dfrac1n\sum f(\dots)$ 形，不能用定积分定义，须放缩后夹逼）。

## (11) 三角公式法

$$a\sin x+b\cos x=\sqrt{a^2+b^2}\,\sin(x+\varphi),\quad \tan\varphi=\dfrac{b}{a}$$

（$\varphi$ 为向量 $(a,b)$ 的方向角。）

## (12) 共轭法

$A$ 与 $B$ 形式相似、代数运算结果简单，称为**共轭式**。见 $A$ 想 $B$ 并与之作运算：

| 共轭对 | 用途 |
| :-- | :-- |
| $\sqrt{a}+\sqrt b$ 与 $\sqrt a-\sqrt b$ | 分子有理化（根式求导、求极限） |
| $a+b$ 与 $a-b$ | 广义共轭 |
| $\sin x$ 与 $\cos x$ | $\sin^2+\cos^2=1$、$2\sin x\cos x=\sin2x$ |
| $a\sin x+b\cos x$ 与 $b\sin x-a\cos x$ | $(a\sin x+b\cos x)^2+(b\sin x-a\cos x)^2=a^2+b^2$ |
| $\cos ax\cos bx$ 与 $\sin ax\sin bx$ | 积化和差求高阶导数、原函数 |

> [!example] 3. 高阶导数的共轭
> $f(x)=\cos ax\cos bx$。法一（积化和差）：$f=\dfrac12[\cos(a+b)x+\cos(a-b)x]$，
> $$
> \begin{aligned}
> f^{(n)}&=\dfrac12\Bigl[(a+b)^n\cos\!\left((a+b)x+\dfrac{n\pi}{2}\right)\\[4pt]
> &\quad+(a-b)^n\cos\!\left((a-b)x+\dfrac{n\pi}{2}\right)\Bigr]
> \end{aligned}
> $$
> （不产生求和符号，最实用）。法二直接套莱布尼茨公式不可取（结果含求和号、实际无法用）。

## (13) 常用等式变形口诀

| 口诀 | 公式 |
| :-- | :-- |
| 加项减项 | $a=a+b-b$ |
| 除项乘项 | $a=a\cdot\dfrac bb$ |
| 取对数 | $a=e^{\ln a}$ |
| 1 的转化 | $1=\sin^2x+\cos^2x=e^{0}=\alpha^0\ (\alpha\ne0)$ |
| 创造 $a+\dfrac1a$ | $x^4+1=x^2\!\left(x^2+\dfrac1{x^2}\right)$ |

## 二、不等式变形

## (1) 抽象型基本不等关系

| 不等式 | 目标放缩方向 |
| :-- | :-- |
| $0\le a+\lvert a\rvert\le 2\lvert a\rvert$ | 处理绝对值 |
| $\lvert a\rvert=\lvert a-b+b\rvert\le\lvert a-b\rvert+\lvert b\rvert$ | 三角不等式 |
| $\lvert a-b\rvert=\lvert a-c+c-b\rvert\le\lvert a-c\rvert+\lvert c-b\rvert$ | 三个量的关系 |
| $a^2+b^2\ge2ab$ | 以 $ab$ 为目标 |
| $4ab\le(a+b)^2\le2(a^2+b^2)$ | 以 $(a+b)^2$ 为目标 |
| $\dfrac{a+b}{2}\ge\sqrt{ab}\ (a,b>0)$ | 以 $\sqrt{ab}$ 为目标 |
| $\dfrac{2}{\frac1a+\frac1b}\le\sqrt{ab}\le\dfrac{a+b}{2}\le\sqrt{\dfrac{a^2+b^2}{2}}\ (a,b>0)$ | 均值不等式链 |
| $(a_1b_1+a_2b_2)^2\le(a_1^2+a_2^2)(b_1^2+b_2^2)$ | 柯西不等式（向量点积 $\le\lvert\alpha\rvert\lvert\beta\rvert$） |

**柯西不等式积分形式**：
$$\left[\int_a^b f(x)g(x)\,dx\right]^2\le\int_a^b f^2(x)\,dx\cdot\int_a^b g^2(x)\,dx$$

## (2) 抽象型条件不等关系

| 条件 | 结论 |
| :-- | :-- |
| $0<a<1$ | $a>a^2$；$\sqrt{1-a}<1$；当 $a\ge\dfrac{\sqrt5-1}{2}$ 时 $\dfrac{1-a}{1+a}\le\dfrac{1-\sqrt{1-a}}{1+\sqrt{1-a}}$ |
| $ab=A$（$a,b>0$） | $a+b\ge2\sqrt A$ |
| $a+b=A$（$a,b>0$） | $ab\le\dfrac{A^2}{4}$，如 $x+(1-x)=1$ ⟹ $x(1-x)\le\dfrac14$ |
| $c\ge M$ | $a+b+c\ge a+b+M$（单调拼接） |
| $a_n>0$ 单调减 | $a_{n+1}\le\sqrt{a_n a_{n+1}}\le a_n$（把通项夹进邻项乘积的几何平均，放缩到乘积） |
| $a,b>0$ | $\dfrac{\sqrt a+\sqrt b}{\sqrt2}\le\sqrt{a+b}\le\sqrt a+\sqrt b$（逐步精细化，见书末汇总） |

## (3) 初等函数不等关系

| 不等式 | 备注 |
| :-- | :-- |
| $e^x\ge x+1$ | 等价 $e^{x-1}\ge x$；衍生 $e^x-1\ge x$、$e^x\ge ex$ |
| $\dfrac{x}{1+x}\le\ln(1+x)\le x\ (x>-1)$ | 泰勒展开可得；衍生 $\ln(1+n)\le n$、$\ln n<n$ |
| $e^x-\ln x>2$ | $e^x\ge x+1$ 与 $\ln x\le x-1$ 叠加（两处等号不同时成立） |
| $n!<n^n$，$\ln n!<n\ln n\ (n>1)$ | 由 $1\cdot2\cdots n<n\cdot n\cdots n$ |
| $\sin x<x<\tan x\ (0<x<\frac\pi2)$ | 几何比较法 |
| $\cos x<\dfrac{\sin x}{x}<1\ (0<x<\dfrac\pi2)$ | $\sin x<x$ 与 $x<\tan x$ 同除变形 |
| $x\ln x\ge-\dfrac1e\ (x>0)$ | $x\ln x$ 在 $x=\dfrac1e$ 取最小 |

## (4) 函数性态中的不等关系

| 性态 | 不等关系 |
| :-- | :-- |
| 极限保号性 | $\lim x_n=a\ne0$ ⟹ $n$ 足够大时 $\lvert x_n\rvert>\dfrac{\lvert a\rvert}{2}$ |
| 单调增 | $f(x)\ge f(x_0)\ (x>x_0)$；$(x-x_0)[f(x)-f(x_0)]\ge0$；如 $e^x\ge 1+x$（$\ln x$ 单调：$\ln e^x=x\ge\ln(1+x)$） |
| 单调减 + 积分 | $f$ 单调减 ⟹ $f(k+1)\le\int_k^{k+1}f(x)\,dx\le f(k)$ ⟹ $\sum$ 与 $\ln n$ 互推 |
| 凹凸性 | $f$ 凸 ⟹ $f\!\left(\dfrac{a+b}{2}\right)\le\dfrac{f(a)+f(b)}2$（琴生） |
| 积分中常见 | $\int_a^b f^2(x)\,dx\le\sqrt{(b-a)\int_a^b f^4(x)\,dx}$（柯西取 $g=f^2,\ h=1$） |

## (5) 消去法中的不等关系

| 情形 | 不等式 |
| :-- | :-- |
| $\sum\dfrac1{(2k-1)(2k+1)}$ 相消 | $=\dfrac12\!\left(1-\dfrac{1}{2n+1}\right)\to\dfrac12$ |
| 平方差 | $\sqrt{n+1}-\sqrt n=\dfrac1{\sqrt{n+1}+\sqrt n}$；更精确 $\dfrac1{2\sqrt{n+1}}<\sqrt{n+1}-\sqrt n<\dfrac1{2\sqrt n}$ |
| 级数部分和相消 | $a_n>0$ ⟹ $S_n>S_{n-1}$、$a_n=S_n-S_{n-1}$，估算 $a_n$ 界 |

## 方法论寄语

> [!quote] 张宇
> 数学考题的解题过程，本质上就是建立一座连接条件与结论的桥梁，搭建这座桥梁的每一步都是一个转化。无论等量关系、等价关系、不等量放缩、充分关系、必要关系，均可在形式上统称为**变形**。
> 把本附录反复实践、总结、再实践，达到**能背诵、能默写、能联想**的境界——解题将如**行云流水**，便能进入「用数学思考数学」的状态。

> [!tip] 学习提示
> 变形能力的提升，关键两件事：**方向对（科学的方法论）** + **量足（反复实践）**。本附录宜**结合各讲例题交叉研读**：求极限看换元/夹逼、求导数看共轭、求积分裂项、求级数错位相消、证不等式看函数性态与柯西/均值放缩。
