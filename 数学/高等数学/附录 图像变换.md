# 附录 图像变换

> [!abstract] 附录定位
> 对应张宇《基础30讲》高数分册附录1（图像变换）。函数图像的三类基本变换：**平移、对称、伸缩**，是第1讲函数图像、第2~5讲几何应用以及作图题的基础工具。

## 平移变换

| 原图 $y=f(x)$ | 变换后 | 方向 |
| :-- | :-- | :-- |
| $y=f(x+x_0)\ (x_0>0)$ | 沿 $x$ 轴**左移** $x_0$ | 「左加」 |
| $y=f(x-x_0)\ (x_0>0)$ | 沿 $x$ 轴**右移** $x_0$ | 「右减」 |
| $y=f(x)+y_0\ (y_0>0)$ | 沿 $y$ 轴**上移** $y_0$ | 「上加」 |
| $y=f(x)-y_0\ (y_0>0)$ | 沿 $y$ 轴**下移** $y_0$ | 「下减」 |

> [!tip] 记忆口诀
> **左加右减、上加下减**。$x$ 的变化写在括号内（作用于 $x$），$y$ 的变化写在括号外（作用于整体）。

## 对称变换

| 原图 $y=f(x)$ | 对称轴/中心 | 变换后 |
| :-- | :-- | :-- |
| 关于 $x$ 轴对称 | $x$ 轴 | $y=-f(x)$ |
| 关于 $y$ 轴对称 | $y$ 轴 | $y=f(-x)$ |
| 关于原点对称 | $(0,0)$ | $y=-f(-x)$ |
| 关于直线 $y=x$ 对称 | $y=x$ | $y=f^{-1}(x)$（反函数） |
| 保留 $x$ 轴及上方、把下方翻上 | $x$ 轴 | $y=\lvert f(x)\rvert$ |
| 保留 $y$ 轴及右侧、左侧镜像 | $y$ 轴 | $y=f(\lvert x\rvert)$ |

### 一般对称性的代数判别

把 $y=f(x)$ 写成隐式 $F(x,y)=f(x)-y=0$，则：

| 关系式 | 对称性 |
| :-- | :-- |
| $F(x,y)=F(-x,y)$ | 关于 $y$ 轴 $(x=0)$ 对称 |
| $F(x,y)=F(x,-y)$ | 关于 $x$ 轴 $(y=0)$ 对称 |
| $F(x,y)=F(-x,-y)$ | 关于原点 $(0,0)$ 对称 |
| $F(x,y)=F(y,x)$ | 关于 $y=x$ 对称 |
| $F(x,y)=F(2T-x,y)$ 或 $F(T+x,y)=F(T-x,y)$ | 关于 $x=T$ 对称 |
| $F(x,y)=F(x,2T-y)$ 或 $F(x,T+y)=F(x,T-y)$ | 关于 $y=T$ 对称 |
| $F(x,y)=F(2a-x,-y)$ | 关于点 $(a,0)$ 对称 |

> [!note] 一般情形 =「平移特殊情形」
> 后三行是前三行的「平移推广」：把对称轴/中心从坐标轴/原点平移到 $x=T$、$y=T$、$(a,0)$，要重视。

> [!example] 1. ✏️ 隐式对称判别示例
> - $F(x,y)=x^4-x^2-y^2$，$F(x,-y)=F(x,y)$ ⟹ 关于 $x$ 轴对称；
> - $F(x,y)=(1-x)^2-y^2$，$F(2-x,y)=F(x,y)$ ⟹ 关于 $x=1$ 对称；
> - $F(x,y)=x^3+y^3-3xy$，$F(y,x)=F(x,y)$ ⟹ 关于 $y=x$ 对称；
> - 摆线 $x=t-\sin t,\ y=1-\cos t$，满足 $y=1-\cos(2\pi-t)$ ⟹ 关于 $x=\pi$ 对称。

## 伸缩变换

| 原图 $y=f(x)$ | 变换后 | 几何效果 |
| :-- | :-- | :-- |
| $y=f(kx)\ (k>1)$ | 横坐标缩短到 $\frac1k$ | 横向**压缩** |
| $y=f(kx)\ (0<k<1)$ | 横坐标伸长到 $\frac1k$ | 横向**拉伸** |
| $y=kf(x)\ (k>1)$ | 纵坐标伸长到 $k$ 倍 | 纵向**拉伸** |
| $y=kf(x)\ (0<k<1)$ | 纵坐标缩短到 $k$ 倍 | 纵向**压缩** |

> [!tip] 谁变谁定方向
> 「$k$ 加在 $x$ 上→横变、$k>1$ 反而压缩」；「$k$ 加在 $f$ 上→纵变、$k>1$ 拉伸」。横纵规则相反，注意别记反。

---

## 综合：变换的可叠加性

平移、对称、伸缩可以**组合叠加**。常用模式：
1. $y=f(ax+b)$ ⟹ 先把 $x$ 缩放 $a$ 倍、再平移 $-\frac{b}{a}$（注意顺序：先伸缩再平移，或先提取 $a$ 再处理）。
2. 由 $y=f(x)$ 得 $y=\lvert f(kx+b)\rvert+c$ ⟹ 先对 $x$ 作 $k$ 伸缩、再平移 $\frac{b}{k}$（左移 $\frac bk$，见下方警示框）→ 再把 $x$ 轴下方的部分翻到上方、最后整体平移 $c$。

![[高数-图像变换.png|520]]
*图像变换总览：平移（左上）/ 对称（右上）/ 伸缩（左下）/ 关于 $y=x$ 的反函数对称（右下）*

> [!warning] $y=f(ax+b)$ 的平移量
> $y=f(ax+b)=f\bigl(a(x+\frac{b}{a})\bigr)$，故**左移 $\frac{b}{a}$** 个单位，而不是 $b$。化成 $f(a(x-x_0))$ 形式再判断方向最稳妥。
