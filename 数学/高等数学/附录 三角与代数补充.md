# 附录 三角与代数补充

> [!abstract] 📋 附录定位
> 通用附录：三角函数图像/恒等式与代数公式，配合各讲使用（不专属某讲次）。

## 📝 三角与反三角数图像

![[高数-三角与反三角图像.png|520]]

| 函数 | 定义域 | 值域 | 要点 |
| ---- | ------ | ---- | ---- |
| $\sin x$ / $\cos x$ | $\mathbb{R}$ | $[-1,1]$ | 周期$2\pi$；sin 奇、cos 偶 |
| $\tan x$ | $x\ne \frac{\pi}{2}+k\pi$ | $\mathbb{R}$ | 周期$\pi$；$(-\frac{\pi}{2},\frac{\pi}{2})$ 内单调增，奇 |
| $\cot x$ | $x\ne k\pi$ | $\mathbb{R}$ | 周期$\pi$；$(0,\pi)$ 内单调减，奇 |
| $\sec x=\frac{1}{\cos x}$ / $\csc x=\frac{1}{\sin x}$ | 同$\tan$/$\cot$ | $\lvert y\rvert\ge1$ | sec 偶、csc 奇；周期$2\pi$ |
| $\arcsin x$ | $[-1,1]$ | $\left[-\frac{\pi}{2},\frac{\pi}{2}\right]$ | 奇、单调增 |
| $\arccos x$ | $[-1,1]$ | $[0,\pi]$ | 单调减；$\arccos(-x)=\pi-\arccos x$ |
| $\arctan x$ | $\mathbb{R}$ | $\left(-\frac{\pi}{2},\frac{\pi}{2}\right)$ | 奇、单调增；$x\to\pm\infty$ 时 $\to\pm\frac{\pi}{2}$ |
| $\operatorname{arccot}x$ | $\mathbb{R}$ | $(0,\pi)$ | 单调减；$x\to+\infty\to0$、$x\to-\infty\to\pi$；$\operatorname{arccot}(-x)=\pi-\operatorname{arccot}x$ |

常用特殊值：
$$
\arcsin\dfrac12=\dfrac{\pi}{6},\quad \arcsin\dfrac{\sqrt2}{2}=\dfrac{\pi}{4},\quad \arcsin\dfrac{\sqrt3}{2}=\dfrac{\pi}{3};
\qquad \arctan\dfrac{1}{\sqrt3}=\dfrac{\pi}{6},\quad \arctan 1=\dfrac{\pi}{4},\quad \arctan\sqrt3=\dfrac{\pi}{3}
$$

> [!warning] ⚠️ 陷阱提示
> $\arcsin(\sin x)\ne x$（一般）
> $\sin(\arcsin x)=x$ 对 $x\in[-1,1]$ 恒成立；但 $\arcsin(\sin x)=x$ **仅当** $x\in[-\frac{\pi}{2},\frac{\pi}{2}]$，否则要先用周期/对称把角归位到主值区间，
> 如 $\arcsin(\sin 2)=\pi-2$。$\arctan(\tan x)$、$\arccos(\cos x)$ 同理，极限与化简题常挖这个坑。

## 📝 三角恒等式速查

| 类别 | 公式 |
| ---- | ---- |
| 平方关系 | $\sin^{2}x+\cos^{2}x=1$；$1+\tan^{2}x=\sec^{2}x$；$1+\cot^{2}x=\csc^{2}x$ |
| 和差角 | $\sin(A\pm B)=\sin A\cos B\pm\cos A\sin B$；$\cos(A\pm B)=\cos A\cos B\mp\sin A\sin B$ |
| | $\tan(A\pm B)=\dfrac{\tan A\pm\tan B}{1\mp\tan A\tan B}$ |
| 倍角 | $\sin 2x=2\sin x\cos x$；$\cos 2x=\cos^{2}x-\sin^{2}x=2\cos^{2}x-1=1-2\sin^{2}x$ |
| 降幂 | $\sin^{2}x=\dfrac{1-\cos 2x}{2}$；$\cos^{2}x=\dfrac{1+\cos 2x}{2}$（积分最常用） |
| 积化和差 | $\sin A\cos B=\dfrac{1}{2}[\sin(A+B)+\sin(A-B)]$；$\cos A\cos B=\dfrac{1}{2}[\cos(A+B)+\cos(A-B)]$ |
| | $\sin A\sin B=\dfrac{1}{2}[\cos(A-B)-\cos(A+B)]$ |
| 和差化积 | $\sin A+\sin B=2\sin\dfrac{A+B}{2}\cos\dfrac{A-B}{2}$；$\sin A-\sin B=2\cos\dfrac{A+B}{2}\sin\dfrac{A-B}{2}$ |
| | $\cos A+\cos B=2\cos\dfrac{A+B}{2}\cos\dfrac{A-B}{2}$；$\cos A-\cos B=-2\sin\dfrac{A+B}{2}\sin\dfrac{A-B}{2}$ |
| 反三角 | $\arcsin x+\arccos x=\dfrac{\pi}{2}$；$\arctan x+\operatorname{arccot}x=\dfrac{\pi}{2}$；$\arctan x+\arctan\dfrac{1}{x}=\dfrac{\pi}{2}\ (x>0)$ |
| 诱导公式 | 「奇变偶不变，符号看象限」：$\dfrac{k\pi}{2}\pm\alpha$ 中 $k$ 为奇数则函数名互变（$\sin\leftrightarrow\cos$，$\tan\leftrightarrow\cot$），符号取"把 $\alpha$ 视为锐角时原函数"的符号 |
| 倍角补充 | $\tan 2x=\dfrac{2\tan x}{1-\tan^{2}x}$；$\sin 3x=3\sin x-4\sin^{3}x$；$\cos 3x=4\cos^{3}x-3\cos x$ |
| 半角 | $\tan\dfrac{x}{2}=\dfrac{1-\cos x}{\sin x}=\dfrac{\sin x}{1+\cos x}$ |

## 📝 代数与阶乘补充

| 类别 | 公式 |
| ---- | ---- |
| 双阶乘 | $(2n)!!=2\cdot4\cdots(2n)=2^{n}\,n!$；$(2n-1)!!=1\cdot3\cdots(2n-1)$；$(2n)!!\,(2n-1)!!=(2n)!$ |
| 排列 | $A_n^{m}=n(n-1)\cdots(n-m+1)=\dfrac{n!}{(n-m)!}$（从 $n$ 起连乘 $m$ 个）；全排列 $A_n^{n}=n!$ |
| 组合 | $C_n^{m}=\dfrac{A_n^{m}}{m!}=\dfrac{n!}{m!\,(n-m)!}$；$C_n^{0}=C_n^{n}=1$（莱布尼茨公式、二项式定理的系数） |
| 组合恒等式 | $C_n^{m}=C_n^{n-m}$；$C_n^{m}+C_n^{m-1}=C_{n+1}^{m}$（帕斯卡）；$\sum\limits_{k=0}^{n}C_n^{k}=2^{n}$；$kC_n^{k}=nC_{n-1}^{k-1}$ |
| 二项式定理 | $(a+b)^{n}=\sum\limits_{k=0}^{n}C_n^{k}a^{n-k}b^{k}$ |
| 立方和差 | $a^{3}\pm b^{3}=(a\pm b)(a^{2}\mp ab+b^{2})$ |
| 高次差 | $a^{n}-b^{n}=(a-b)(a^{n-1}+a^{n-2}b+\cdots+b^{n-1})$；$n$ 奇：$a^{n}+b^{n}=(a+b)(a^{n-1}-a^{n-2}b+\cdots+b^{n-1})$ |
| 常用求和 | $\sum\limits_{i=1}^{n}i=\dfrac{n(n+1)}{2}$；$\sum i^{2}=\dfrac{n(n+1)(2n+1)}{6}$；$\sum i^{3}=\Bigl[\dfrac{n(n+1)}{2}\Bigr]^{2}$；$\sum\limits_{k=0}^{n-1}aq^{k}=a\cdot\dfrac{1-q^{n}}{1-q}$ |
| 均值不等式 | $\dfrac{2}{\frac1a+\frac1b}\le\sqrt{ab}\le\dfrac{a+b}{2}\le\sqrt{\dfrac{a^{2}+b^{2}}{2}}\ \ (a,b>0)$ |
