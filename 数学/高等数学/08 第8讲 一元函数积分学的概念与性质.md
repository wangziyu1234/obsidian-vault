# 第8讲 一元函数积分学的概念与性质

> [!abstract] 本讲定位
> 对应张宇《基础30讲》第8讲（一元函数积分学的概念与性质）。前半为原函数与不定积分，后半为定积分（黎曼积分）的精确定义、可积性与基本性质。本讲拆分为 4 个专题笔记（见导航），本文为**总览入口**。

## 🗂️ 分章导航

| 专题 | 覆盖内容 |
| :-- | :-- |
| [[08-1 不定积分的概念]] | 原函数、原函数族、不定积分的定义、不定积分与定积分的关系 |
| [[08-2 定积分的精确定义与性质]] | 黎曼积分定义（分割、积分和、ε-δ）、等分形式、可积条件、基本性质 |
| [[08-3 数列极限化定积分（等分形式专题）]] | 数列极限 → 定积分完整套路与例题（例 1–10）、上限非 $n$、带偏移 $\xi_i$ |

> [!tip] 学习路线
> 概念 → 定义 → 计算技巧 → 进阶：先读 08-1、08-2 打底，08-3 是数列极限化定积分的专项练习（常考），08-4 是必考的变限积分与反常积分判敛。

## 8.8 解题套路

先区分原函数存在与定积分存在 → 查可积性 → 用变限积分和积分性质 → 瑕点/无穷端逐段判敛。
