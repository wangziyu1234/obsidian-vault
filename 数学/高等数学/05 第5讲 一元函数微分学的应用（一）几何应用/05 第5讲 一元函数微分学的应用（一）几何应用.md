## 📋 本讲公式速查

| 项目 | 公式 / 判据 |
| :-- | :-- |
| 单调性 | $f'>0$ 单调增；$f'<0$ 单调减 |
| 极值 | ①$f'$ 在 $x_0$ 两侧变号；②$f'(x_0)=0$ 且 $f''(x_0)<0$ 极大 / $f''(x_0)>0$ 极小 |
| 凹凸 | $f''>0$ 下凸（凹弧向上）；拐点 = $f''$ 变号点 |
| 渐近线 | 水平 $\lim\limits_{x\to\pm\infty}f=b$；垂直 $\lim\limits_{x\to x_0}f=\infty$；斜 $k=\lim\frac{f}{x},\ b=\lim(f-kx)$ |
| 曲率 | $K=\frac{\lvert y''\rvert}{(1+y'^{2})^{3/2}}$，参数式 $K=\frac{\lvert\dot x\ddot y-\ddot x\dot y\rvert}{(\dot x^{2}+\dot y^{2})^{3/2}}$，曲率半径 $\rho=\frac{1}{K}$ |

## 🧮 5.11 解题套路

先定定义域与区间 → 列驻点/不可导点/二阶候选 → 判断变号 → 比较端点最值，区分极值与拐点。
