# 附录 矩阵运算公式速查

> [!abstract] 附录定位
> 逆矩阵、伴随矩阵、秩、分块、方阵幂的**核心公式速查**，含秩的六句口诀与 $AB=O$、$AB=C$ 的翻译；所有推导与例题见 [[02-1 矩阵运算与方阵的幂]]、[[02-2 伴随矩阵]]、[[02-3 矩阵的秩与典型例题]]。

## 可逆矩阵（逆矩阵）

**可逆的等价条件（全家桶）**

$A$ 可逆 ⟺ $\lvert A\rvert\ne0$ ⟺ $r(A)=n$（满秩）⟺ $A$ 的 $n$ 个行（列）向量线性无关 ⟺ $Ax=0$ 只有零解 ⟺ $Ax=b$ 有唯一解 ⟺ 特征值全不为 $0$ ⟺ $A$ 与 $E$ 等价 ⟺ $A$ 可表为初等矩阵之积。

**逆矩阵公式**

| 情形 | 公式 |
| :-- | :-- |
| 二阶 | $\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1}=\frac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$（主对角互换、副对角变号） |
| 伴随矩阵法 | $A^{-1}=\frac{A^{*}}{\lvert A\rvert}$（$A$ 可逆） |
| 初等变换法 | $(A\mid E)\xrightarrow{\text{行变换}}(E\mid A^{-1})$ |
| 分块对角 | $\operatorname{diag}(A,B)^{-1}=\operatorname{diag}(A^{-1},B^{-1})$ |
| 分块副对角 | $\begin{pmatrix}O&A\\B&O\end{pmatrix}^{-1}=\begin{pmatrix}O&B^{-1}\\A^{-1}&O\end{pmatrix}$ |

**逆矩阵性质**

| 公式 | 条件 |
| :-- | :-- |
| $(AB)^{-1}=B^{-1}A^{-1}$（穿脱原则） | $A,B$ 可逆 |
| $(A^{k})^{-1}=(A^{-1})^{k}$ | $A$ 可逆 |
| $(A^{T})^{-1}=(A^{-1})^{T}$ | $A$ 可逆 |
| $(cA)^{-1}=\frac{1}{c}A^{-1}$ | $c\ne0$，$A$ 可逆 |

## 伴随矩阵

以下按 $n\ge2$ 阶方阵讨论；凡含 $A^{-1}$ 或 $(A^{*})^{-1}$ 均要求 $A$ 可逆。

**核心公式**

$$
AA^{*}=A^{*}A=\lvert A\rvert E
$$

**伴随矩阵公式表**

| 公式 | 公式 |
| :-- | :-- |
| $A^{*}=\lvert A\rvert A^{-1}$（可逆时） | $\lvert A^{*}\rvert=\lvert A\rvert^{n-1}$ |
| $(A^{*})^{*}=\lvert A\rvert^{n-2}A$（$n\ge2$） | $(A^{k})^{*}=(A^{*})^{k}$ |
| $(A^{-1})^{*}=(A^{*})^{-1}=\frac{A}{\lvert A\rvert}$ | $(kA)^{*}=k^{n-1}A^{*}$ |
| $(A^{T})^{*}=(A^{*})^{T}$ | $A^{-1}=\frac{A^{*}}{\lvert A\rvert}$ |

**伴随矩阵的秩**

$$
r(A^{*})=\begin{cases}
n, & r(A)=n\\[2pt]
1, & r(A)=n-1\\[2pt]
0, & r(A)\le n-2
\end{cases}
$$

> 记忆口诀：「**满秩满、降一秩一、降二变零**」。

## 行列式运算（三易错）

| 运算 | 行列式变化 |
| :-- | :-- |
| $kA$（数乘整个矩阵） | $\lvert kA\rvert=k^{n}\lvert A\rvert$ |
| 某行（列）乘 $k$ | $k\lvert A\rvert$ |
| $A+B$ | $\lvert A+B\rvert\ne\lvert A\rvert+\lvert B\rvert$（**不满足分配律**） |
| $AB$ | $\lvert AB\rvert=\lvert A\rvert\lvert B\rvert$（满足） |
| $A^{T}$ | $\lvert A^{T}\rvert=\lvert A\rvert$ |
| $A^{-1}$ | $\lvert A^{-1}\rvert=\frac{1}{\lvert A\rvert}$ |
| $A^{*}$ | $\lvert A^{*}\rvert=\lvert A\rvert^{n-1}$ |

## 秩的不等式链

**基本性质**

| 公式 | 说明 |
| :-- | :-- |
| $0\le r(A)\le\min(m,n)$ | $A$ 为 $m\times n$ |
| $r(A)=r(A^{T})=r(A^{T}A)=r(AA^{T})$ | 实矩阵（$A^{T}A$ 与 $A$ 同秩） |
| $r(kA)=r(A)$（$k\ne0$） | 数乘不改变秩 |
| $r(PA)=r(A)$、$r(AQ)=r(A)$、$r(PAQ)=r(A)$ | 左乘、右乘可逆矩阵都不改秩 |
| $r(PA)=r(A)$（$P$ 列满秩）；$r(AQ)=r(A)$（$Q$ 行满秩） | 非方阵时只有单边成立；左乘要列满秩、右乘要行满秩 |
| $r(AB)\le\min(r(A),r(B))$ | 乘积秩不超过各因子秩 |
| $r(A+B)\le r(A)+r(B)$ | 和的秩不超过秩的和 |
| $r(AB)\ge r(A)+r(B)-n$ | Sylvester 不等式（$A$ 为 $m\times n$，$B$ 为 $n\times p$） |

> [!tip] 秩的六句口诀（比逐条记公式好背）
> 1. **越乘越小**：$r(AB)\le\min\{r(A),r(B)\}$；
> 2. **越拼越大**：$\max\{r(A),r(B)\}\le r(A\mid B)\le r(A)+r(B)$；
> 3. **可逆不变**：左乘、右乘可逆阵都不改秩；
> 4. **单边满秩也不变**：左乘要**列**满秩，右乘要**行**满秩（左列右行）；
> 5. **乘零收缩**：$AB=O\Rightarrow r(A)+r(B)\le n$（秩的和 $\le$ 相邻下标）；
> 6. **对角化后数非零**：$A$ 可相似对角化（含实对称）时，$r(A)=$ 非零特征值个数。

**分块秩公式**

| 公式 | 条件 |
| :-- | :-- |
| $r\begin{pmatrix}A&O\\O&B\end{pmatrix}=r(A)+r(B)$ | 分块对角 |
| $r\begin{pmatrix}A&O\\C&B\end{pmatrix}\ge r(A)+r(B)$ | 一般分块下三角 |
| $r(A)+r(B)\ge r(A\mid B)\ge\max(r(A),r(B))$ | 增广矩阵 |

**常用推论**

| 推论 | 说明 |
| :-- | :-- |
| $AB=O \Rightarrow r(A)+r(B)\le n$ | $B$ 的列都是 $Ax=0$ 的解 |
| $AB=O$ 且 $B$ 可逆 $\Rightarrow A=O$ | 由上条 + $r(B)=n$ |
| $r(A)=n \Rightarrow AB=AC \Rightarrow B=C$ | 列满秩可消去左边的 $A$（左逆） |
| $r(A)=m \Rightarrow BA=CA \Rightarrow B=C$ | 行满秩可消去右边的 $A$（右逆） |
| $r(A)=m \Rightarrow Ax=b$ 必有解 | 行满秩 |

> [!tip] $AB=O$ 的四重翻译（一条式子，四种说法）
> 1. **秩**：$r(A)+r(B)\le n$；
> 2. **方程组**：$B$ 的非零列向量**都是** $Ax=0$ 的解；
> 3. **特征**：$B$ 的非零列向量**都是** $A$ 的特征值 $0$ 的特征向量；
> 4. **正交**：$A$ 的行向量与 $B$ 的列向量**正交**（因为 $A$ 的行点乘 $B$ 的列 $=(AB)_{ij}=0$）。
>
> 反过来用：$A$ 的两个无关行向量可以求 $B$ 的一个列向量；$B$ 的两个无关列向量可以求 $A$ 的一个行向量。

> [!tip] $AB=C$ 的翻译（口诀「**左列右行**」）
> - $C$ 的**列**向量可由 $A$ 的**列**向量线性表示（$C_{:,j}=AB_{:,j}$）；
> - $C$ 的**行**向量可由 $B$ 的**行**向量线性表示（$AB=\sum_k A_{:,k}B_{k,:}$）。
> - 若 $A$ 可逆，则 $C$ 与 $B$ 的**列**向量组等价；若 $B$ 可逆，则 $C$ 与 $A$ 的**行**向量组等价。

## 分块矩阵

**分块求逆**

$A,B$ 为可逆方阵，阶数可不同；其他块维数相容，不要求两块可交换。

$$
\begin{pmatrix}A&O\\O&B\end{pmatrix}^{-1}=\begin{pmatrix}A^{-1}&O\\O&B^{-1}\end{pmatrix}
$$

$$
\begin{pmatrix}O&A\\B&O\end{pmatrix}^{-1}=\begin{pmatrix}O&B^{-1}\\A^{-1}&O\end{pmatrix}
$$

**三角分块求逆**（$A,B$ 可逆，阶数可不同、不必可交换）

$$
\begin{pmatrix}A&C\\O&B\end{pmatrix}^{-1}=\begin{pmatrix}A^{-1}&-A^{-1}CB^{-1}\\O&B^{-1}\end{pmatrix}
$$

$$
\begin{pmatrix}A&O\\C&B\end{pmatrix}^{-1}=\begin{pmatrix}A^{-1}&O\\-B^{-1}CA^{-1}&B^{-1}\end{pmatrix}
$$

记忆：对角块照常取逆；非对角块是「左逆 $\times$ 夹心 $\times$ 右逆」再**加负号**（右上、左下各一处）。

**分块伴随**（$A$ 为 $m$ 阶、$B$ 为 $n$ 阶，二者可逆）

$$
\begin{pmatrix}A&C\\O&B\end{pmatrix}^{*}=\begin{pmatrix}\lvert B\rvert A^{*}&-A^{*}CB^{*}\\O&\lvert A\rvert B^{*}\end{pmatrix}
$$

$$
\begin{pmatrix}A&O\\C&B\end{pmatrix}^{*}=\begin{pmatrix}\lvert B\rvert A^{*}&O\\-B^{*}CA^{*}&\lvert A\rvert B^{*}\end{pmatrix}
$$

记忆：**行列式交叉给**——每个对角块的伴随，乘的是**对方**块的行列式（$A^{*}$ 乘 $\lvert B\rvert$、$B^{*}$ 乘 $\lvert A\rvert$）；非对角块是「左伴随 $\times$ 夹心 $\times$ 右伴随」再加负号。

> 推导只用一条：$M$ 可逆时 $M^{*}=\lvert M\rvert M^{-1}$，而三角分块的行列式 $\lvert M\rvert=\lvert A\rvert\lvert B\rvert$、逆已在上方给出。

**分块乘法**

各左列块的宽度须等于对应右行块的高度，保持块内乘法顺序。

$$
\begin{pmatrix}A_1\\A_2\end{pmatrix}\begin{pmatrix}B_1&B_2\end{pmatrix}=\begin{pmatrix}A_1B_1&A_1B_2\\A_2B_1&A_2B_2\end{pmatrix}
$$

## 方阵幂 $A^{n}$（三种套路）

| 套路 | 适用场景 | 操作 |
| :-- | :-- | :-- |
| **秩 1 法** | $r(A)=1$，$A=\alpha\beta^{T}$ | $A^{n}=(\beta^{T}\alpha)^{n-1}A=(\operatorname{tr}A)^{n-1}A$；这是满秩分解 $A=BC$ 的极端情形：$B$ 列满秩、$C$ 行满秩（见 [[02-3 矩阵的秩与典型例题#🧩 2.7 矩阵的秩\|左乘要列满秩、右乘要行满秩]]） |
| **试算归纳** | 低阶、$A^{2},A^{3}$ 有规律 | 算 $A^{2},A^{3},\dots$ 找周期/递推 → 归纳 |
| **二项展开** | $A=B+C$ 且 $BC=CB$（常取 $A=kE+B$） | $A^{n}=\sum\binom{n}{m}k^{n-m}B^{m}$；$B$ 幂零时取前有限项 |

## 初等变换速查

方程组一栏的行变换均指对增广矩阵操作，**右端也必须一起变换**；倍乘仅允许 $k\ne0$。

| 变换 | 行列式 | 矩阵的秩 | 方程组 |
| :-- | :--: | :--: | :-- |
| 换两行 | 变号 | 不变 | 解不变 |
| 某行乘 $k\ne0$ | 乘 $k$ | 不变 | 解不变 |
| 倍加 | 不变 | 不变 | 解不变 |
| 列变换 | 允许（配合变号） | 求秩可混用 | 不直接保同解；须记录并还原变量 |

> **求秩**：行列变换可混用；**求逆**：$(A\mid E)\to(E\mid A^{-1})$ 只用行变换；**解方程组**：保持原变量直接求解时只用行变换；若作列变换，须记录 $Q$，并用 $x=Qy$ 还原原变量。
