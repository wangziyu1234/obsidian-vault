# 第1讲（二） 常用行列式与计算技巧

## 常用行列式

| 类型           | 结果                                                                                     |
| :------------- | :--------------------------------------------------------------------------------------- |
| 上/下三角、对角 | 主对角元之积 $a_{11}a_{22}\cdots a_{nn}$                                                 |
| 副对角（三角） | $(-1)^{\frac{n(n-1)}{2}}a_{1n}a_{2,n-1}\cdots a_{n1}$                                    |
| 主对角分块     | $\begin{vmatrix}A&O\\C&B\end{vmatrix}=\begin{vmatrix}A&D\\O&B\end{vmatrix}=\lvert A\rvert\lvert B\rvert$ |
| 副对角分块     | $\begin{vmatrix}O&A_m\\B_n&O\end{vmatrix}=(-1)^{mn}\lvert A\rvert\lvert B\rvert$          |
| 范德蒙德       | $\begin{vmatrix}1&\cdots&1\\x_1&\cdots&x_n\\\vdots&&\vdots\\x_1^{n-1}&\cdots&x_n^{n-1}\end{vmatrix}=\prod\limits_{1\le i<j\le n}(x_j-x_i)$ |
| 爪形           | 用斜爪消平爪（第 $j$ 列乘适当系数加到第 1 列），化三角                                    |
| 行和相等       | 各列加到第 1 列提出公因子，再倍加消元                                                     |
| "X" 型（箭靶型） | 主、副对角线上各 $a_i$ 与对应 $b_i$：偶阶 $D_{2k}=\prod\limits_{i=1}^{k}(a_i a_{2k+1-i}-b_i b_{2k+1-i})$；主副对角元素全相同（$a_i=a,b_i=b$）时 $D_{2k}=(a^2-b^2)^{k}$。奇阶需单独展开中间元。常用于二次型正定性判断 |

## 常用计算技巧

| 方法 | 适用场景 | 操作 |
| :-- | :-- | :-- |
| **化基本型（化三角/化分块）** | 结构规整的具体行列式，第一选择：先往"基本型"（三角 / 分块 / 已知公式型）上转化 | 行和相等 ⟶ 各列加第 1 列提公因子；爪形 ⟶ 斜爪消平爪；一般阵 ⟶ 倍加化零化上三角；展开后遇 $\begin{vmatrix}A&O\\C&B\end{vmatrix}$ 型分块 ⟶ 免展开直接套拉普拉斯（基本型清单见上方「常用行列式」表） |
| **递推法** | $n$ 阶行列式具有递推结构（相邻阶之间有关系），如三对角型 | 按首行（列）展开 → 得 $D_n = pD_{n-1}+qD_{n-2}$ → 解二阶递推方程得 $D_n$ 通式 |
| **加边法（升阶法）** | 除主对角元外各行（列）结构相同 | 在左上角加一行一列 $(1,\alpha_1,\dots,\alpha_n)$，其余行（列）利用新加入的 $1$ 消去规律结构 |
| **数学归纳法** | $D_n$ 猜想为某闭式 | 验证 $D_1,D_2$ + 假设 $D_{n-1}$ 成立 + 按首行展开代入递推关系推 $D_n$ |

> [!tip]
> 递推法最典型：三对角行列式 $D_n=a D_{n-1}-bc D_{n-2}$，求特征根 $r_1,r_2$ 后 $D_n=C_1r_1^n+C_2r_2^n$（$r_1\neq r_2$ 时），常数 $C_1,C_2$ 由 $D_1,D_2$ 确定。类似形式在特征多项式展开中也常出现。

**求特征方程的 $|\lambda E-A|$**（又名特征多项式展开）：二阶直接用 $|\lambda E-A|=\lambda^2-\operatorname{tr}(A)\lambda+|A|$；三阶用三阶公式；不需掌握 $n$ 阶行列式的完整逆序数定义。
若考题让求**代数余子式** $A_{ij}$ 而非行列式值，牢记 $A_{ij}=(-1)^{i+j}M_{ij}$ 先写余子式再冠符号。

**行列式计算方法总纲**（张宇第1讲总结，考试按此选方法）：

| 情况 | 首选方法 |
|:--|:--|
| 低阶（2~3 阶）无规律 | 直接展开/性质化简 |
| 高阶但有规律（每行元素相近、三对角、类对称等） | 找规律 → **公式**（范德蒙德、"12+1"型、$\begin{vmatrix}a&b&\cdots&b\\b&a&\cdots&b\\\vdots&&\ddots&\vdots\\b&b&\cdots&a\end{vmatrix}=(a+(n-1)b)(a-b)^{n-1}$ 等）；或递推/归纳 |
| 展开到"12+1"型（左下/右上一块为 0） | **不用再展开**，直接套分块公式 $\lvert A\rvert\lvert B\rvert$ |
| 抽象型（只给矩阵关系，不给具体元素） | 用性质（转置/倍加/拆行）与 $AB$ 型公式 $\lvert AB\rvert=\lvert A\rvert\lvert B\rvert$ |

> [!tip] 克拉默法则（行列式的收官应用，求解步骤见第 4 讲）
> 对方程组 $Ax=b$（$A$ 为 $n$ 阶方阵），当系数行列式 $D=\lvert A\rvert\ne0$ 时有**唯一解**
> $$
> \boxed{x_i=\dfrac{D_i}{D}}
> $$
> 其中 $D_i$ 是把 $D$ 的第 $i$ 列换成 $b$ 所得行列式。它属于行列式应用的经典场景，完整求解流程与例题见 [[04 线代第4讲 线性方程组]]（克拉默法则节）。
> **齐次方向（高频，张宇例1.13）**：$Ax=0$（$A$ 为 $n$ 阶方阵）有**非零解** $\iff \lvert A\rvert=0$（克拉默法则的逆否）。
> **推论（$AB=O$ 型）**：$AB=O$ ⟹ $B$ 的每一列都是 $Ax=0$ 的解 ⟹ $\lvert B\rvert\ne0$（$B$ 可逆）时 $B$ 的列线性无关 ⟹ $Ax=0$ 只有零解 ⟹ $A=O$——即 **$AB=O$ 且 $B$ 可逆 ⟹ $A=O$**；等价说法：$AB=O$ 时 $\lvert A\rvert$ 与 $\lvert B\rvert$ **至少一个为零**。

> [!note] 行列式表示的函数与方程
> 当 $a_{ij}$ 含变量 $x$ 或 $\lambda$ 时，$|A|$ 是该变量的 **多项式**：
> - 3 阶 $\Rightarrow$ 至多 3 次多项式；$n$ 阶 $\Rightarrow$ 至多 $n$ 次多项式（元素关于该变量为**一次**时；若某元素含 $x^2$ 等，次数可超 $n$）；**特征多项式** $\lvert\lambda E-A\rvert$ 必为 $n$ 次且**首一**（$\lambda$ 一次进入，最高次系数 1，来自主对角元之积）。
> - 求 $f(x+1)-f(x)$：只把含 $x$ 的那一列换成 $x+1$，**只有该列不同**才可用单列可拆性相减。
> - 作为函数，$|A|$ 也可求极限、导数、积分（如 $[f(x+1)-f(x)]'$、$\int[f(x+1)-f(x)]\,dx$）。
> - 特征方程 $|\lambda E-A|=0$ 即此类问题，根的重数由分解后判别（如 $\lambda^2-8\lambda+18-3a=0$ 用 $\Delta=0$ 定二重根）。
