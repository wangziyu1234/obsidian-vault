# 附录 二次型与正定判定速查

> [!abstract] 附录定位
> 二次型标准形、惯性定理、正定/负定/半定判定的**纯速查**。所有推导与例题见 [[06 线代第6讲 二次型]]。

## 二次型与矩阵表示

$$
f(x_1,\dots,x_n)=x^{T}Ax\qquad（A=A^{T}，\text{对称矩阵唯一确定}）
$$

> [!note] 二次型的核心：$A$ 必须是对称矩阵。非对称部分 $(A-A^{T})/2$ 在二次型中自动消去。

## 化标准形的方法

| 方法 | 保不保长度 | 变换矩阵 | 标准形系数 |
| :-- | :--: | :-- | :-- |
| **正交变换法** | 保 | 正交矩阵 $Q$（$Q^{-1}=Q^{T}$） | **特征值** |
| **配方法** | 不保 | 可逆矩阵 $C$（未必正交） | 不一定是特征值（但保持惯性指数） |
| **初等变换法** | 不保 | 列变换作用于整个 $\binom{A}{E}$；配套行变换只作用于上块，下块记录 $C$ | 不一定是特征值（保持惯性指数） |

三法分工：要特征值走正交变换；只要标准形走配方；要变换阵或抽象题走初等变换法。完整例题见 [[06 线代第6讲 二次型]]。

## 惯性指数速查

可逆线性变换化标准形后，正、负、零系数的数量分别为 $(p,q,n_0)$，都是合同不变量。

| 量 | 等价解释 |
| :-- | :-- |
| 正惯性指数 $p$ | 正标准形系数个数；正特征值个数（按重数） |
| 负惯性指数 $q$ | 负标准形系数个数；负特征值个数（按重数） |
| 零项数 $n_0$ | 零特征值个数（按重数）；$\dim\ker A$ |
| 秩 $r$ | $r=p+q$，且 $n_0=n-r$ |
| 符号差 $\sigma$ | $\sigma=p-q$ |

- 记号口径：$n$ 指矩阵阶数；“$n_0$”读作“n 零”，下标 $0$ 是**标记**，不表示 $n$ 取 $0$。三个量按重数计：$p=\#\{i:\lambda_i>0\}$、$q=\#\{i:\lambda_i<0\}$、$n_0=\#\{i:\lambda_i=0\}$。
- 已知秩与符号差：$p=\frac{r+\sigma}{2}$、$q=\frac{r-\sigma}{2}$。
- $f=\lVert Dx\rVert^2$ 时：$p=r(D)$、$q=0$；不能机械数平方式的个数。
- 所有顺序主子式非零时，数 $\Delta_k/\Delta_{k-1}$ 的正负（$\Delta_0=1$）；不能直接数正主子式的个数，也不能遇零删零。
- 规范形中正系数化为 $+1$、负系数化为 $-1$，零系数仍为0；系数大小可以变，数量不能变。

> [!warning] 零项与重数
> 零不算正或负，重特征值按重数计算；参数使某项从正变零时，正惯性指数减少，负惯性指数未必改变。正定要求 $p=n$，只知道 $p>0$ 或 $q=0$ 都不够。

完整概念与求法见 [[06-4-a 正负惯性指数与求法]]；重根、零主元、端点取舍见 [[06-4-b 惯性指数的参数与综合例题]]。

## 正定判定（五大充要条件）

$f=x^{T}Ax$ 正定（$x\ne0 \Rightarrow f>0$）**⟺** 任取其一：

| # | 条件 | 说明 |
| :-- | :-- | :-- |
| 1 | 特征值全 $>0$ | 计算 $\lvert\lambda E-A\rvert$ |
| 2 | 顺序主子式全 $>0$ | $D_k>0$（$k=1,2,\dots,n$） |
| 3 | 正惯性指数 $p=n$ | 配方法 / 正交变换法求标准形 |
| 4 | 合同于 $E$：$C^{T}AC=E$（$C$ 可逆） | 即 $A=D^{T}D$（$D$ 列满秩） |
| 5 | 平方和：$f=\lVert Dx\rVert^2$，$D$ 列满秩 | $r(D)=n$；方阵时等价于 $\det D\ne0$ |

**字母分工照教材**：变换矩阵写 $C$（一定可逆）；完全平方和的系数阵写 $D$（可以长方，但要求 $r(D)=n$）。

**正定必要条件（快速排除）**

- $a_{ii}>0$（主对角元全正）
- $\lvert A\rvert>0$

**正定常用结论**

| 结论 | 说明 |
| :-- | :-- |
| $A^{-1}$ 正定 ⟺ $A$ 正定 | 特征值取倒数 |
| $A^{T}$ 正定 ⟺ $A$ 正定 | 对称阵 $A^T=A$ |
| $aE+A$ 正定 ⟺ $a>-\lambda_{\min}$ | 特征值 $a+\lambda_i$ 全正 |
| $A,B$ 正定 ⟹ $A+B$ 正定 | 但 $AB$ 一般不正定（除非可交换） |
| $kA$ 正定（$k>0$） | 特征值乘 $k$ |

**正定判定步骤**

**① 先证 $A=A^{T}$**（正定的前提是对称矩阵）→ **② 再用五法中任一判正定**

> [!warning] 高频易错
> 负惯性指数 $q=0$ 不充分：例如 $A=\operatorname{diag}(1,0)$，$p=1<2$，非零向量 $(0,1)^T$ 使二次型为0，故不正定。
> - $A=D^{T}D$ 需 $D$ **列满秩**才正定；$D$ 为方阵时等价于可逆，否则存在零方向，只能非负而非正定。
> - $A,B$ 正定且 $AB=BA$ ⟹ $AB$ 正定（需可交换条件）

## 负定与半定

| 类型 | 充要条件 |
| :-- | :-- |
| **负定**（$x\ne0 \Rightarrow f<0$） | 奇数阶顺序主子式 $<0$，偶数阶 $>0$（即 $-A$ 正定） |
| **半正定**（此表指非负但不正定） | 特征值全非负且至少一个0；所有主子式非负且 $\det A=0$；可写 $A=D^TD$，其中 $D$ 为列不满秩（方阵时奇异）实矩阵 |
| **半负定** | $-A$ 半正定 |

## 合同判定

| 条件 | 说明 |
| :-- | :-- |
| 同阶实对称：$A\cong B$ ⟺ 正负惯性指数相同 | 充要 |
| 同阶实对称：$A\cong B$ ⟺ 特征值正负号分布相同 | 充要（不要求特征值相同） |

> **合同 ⟹ 等价**（$C^{T}AC=B$，$C$ 可逆 ⟹ $r(A)=r(B)$）；合同只在**对称矩阵**间讨论。
