# 附录 二次型与正定判定速查

> [!abstract] 附录定位
> 二次型标准形、惯性定理、正定/负定/半定判定、**化二次型为另一个二次型**的**纯速查**。所有推导与例题见 [[06 线代第6讲 二次型]]。

## 二次型与矩阵表示

$$
f(x_1,\dots,x_n)=x^{T}Ax\qquad（A=A^{T}，\text{对称矩阵唯一确定}）
$$

> [!note] 二次型的核心：$A$ 必须是对称矩阵。非对称部分 $(A-A^{T})/2$ 在二次型中自动消去。

## 化标准形的方法

| 方法 | 保不保长度 | 变换矩阵 | 标准形系数 |
| :-- | :--: | :-- | :-- |
| **正交变换法** | 保 | 正交矩阵 $Q$（$Q^{-1}=Q^{T}$） | **特征值** |
| **配方法** | 不保 | 可逆矩阵 $C$（未必正交） | 不一定是特征值（但保持惯性指数） |
| **初等变换法** | 不保 | 列变换作用于整个 $\binom{A}{E}$；配套行变换只作用于上块，下块记录 $C$ | 不一定是特征值（保持惯性指数） |

三法分工：要特征值走正交变换；只要标准形走配方；要变换阵或抽象题走初等变换法。完整例题见 [[06 线代第6讲 二次型]]。

## 惯性指数速查

可逆线性变换化标准形后，正、负、零系数的数量分别为 $(p,q,n_0)$，都是合同不变量。

| 量 | 等价解释 |
| :-- | :-- |
| 正惯性指数 $p$ | 正标准形系数个数；正特征值个数（按重数） |
| 负惯性指数 $q$ | 负标准形系数个数；负特征值个数（按重数） |
| 零项数 $n_0$ | 零特征值个数（按重数）；$\dim\ker A$ |
| 秩 $r$ | $r=p+q$，且 $n_0=n-r$ |
| 符号差 $\sigma$ | $\sigma=p-q$ |

- 记号口径：$n$ 指矩阵阶数；“$n_0$”读作“n 零”，下标 $0$ 是**标记**，不表示 $n$ 取 $0$。三个量按重数计：$p=\#\{i:\lambda_i>0\}$、$q=\#\{i:\lambda_i<0\}$、$n_0=\#\{i:\lambda_i=0\}$。
- 已知秩与符号差：$p=\frac{r+\sigma}{2}$、$q=\frac{r-\sigma}{2}$。
- $f=\lVert Dx\rVert^2$ 时：$p=r(D)$、$q=0$；不能机械数平方式的个数。
- 所有顺序主子式非零时，数 $\Delta_k/\Delta_{k-1}$ 的正负（$\Delta_0=1$）；不能直接数正主子式的个数，也不能遇零删零。
- 规范形中正系数化为 $+1$、负系数化为 $-1$，零系数仍为0；系数大小可以变，数量不能变。

> [!note]- 记号与排版口径（写笔记时用得上）
> - 行列式一律记 $|A|$（$\det A$）；长方阵没有 $|A|$，只能谈**列满秩** $r(A)=n$。
> - **定界符必须成对**：行内公式用单个定界符包裹，块级公式单独占行；美元号本身不是数学符号。
> - 表格单元格里画"夹住矩阵的竖线"必须写 `\lvert A\rvert`：直接写 `|` 会被 Markdown 当列分隔符，把公式拦腰截断；写成反斜杠加竖线则在 MathJax 里渲染成双竖线。

> [!warning] 零项与重数
> 零不算正或负，重特征值按重数计算；参数使某项从正变零时，正惯性指数减少，负惯性指数未必改变。正定要求 $p=n$，只知道 $p>0$ 或 $q=0$ 都不够。

完整概念与求法见 [[06-4-a 正负惯性指数与求法]]；重根、零主元、端点取舍见 [[06-4-b 惯性指数的参数与综合例题]]；字母分工与"何时该展开写 $A$"见 [[06-4-d 字母分工与D、A的取舍]]。

## 正定判定（五大充要条件）

$f=x^{T}Ax$ 正定（$x\ne0 \Rightarrow f>0$）**⟺** 任取其一：

| # | 条件 | 说明 |
| :-- | :-- | :-- |
| 1 | 特征值全 $>0$ | 计算 $\lvert\lambda E-A\rvert$ |
| 2 | 顺序主子式全 $>0$ | $D_k>0$（$k=1,2,\dots,n$） |
| 3 | 正惯性指数 $p=n$ | 配方法 / 正交变换法求标准形 |
| 4 | 合同于 $E$：$C^{T}AC=E$（$C$ 可逆） | 即 $A=D^{T}D$（$D$ 列满秩） |
| 5 | 平方和：$f=\lVert Dx\rVert^2$，$D$ 列满秩 | $r(D)=n$；方阵时等价于 $\det D\ne0$ |

**字母分工照教材**：变换矩阵写 $C$（一定可逆）；完全平方和的系数阵写 $D$（可以长方，但要求 $r(D)=n$）。

**正定必要条件（快速排除）**

- $a_{ii}>0$（主对角元全正）
- $\lvert A\rvert>0$

**正定常用结论**

| 结论 | 说明 |
| :-- | :-- |
| $A^{-1}$ 正定 ⟺ $A$ 正定 | 特征值取倒数 |
| $A^{T}$ 正定 ⟺ $A$ 正定 | 对称阵 $A^T=A$ |
| $aE+A$ 正定 ⟺ $a>-\lambda_{\min}$ | 特征值 $a+\lambda_i$ 全正 |
| $A,B$ 正定 ⟹ $A+B$ 正定 | 但 $AB$ 一般不正定（除非可交换） |
| $kA$ 正定（$k>0$） | 特征值乘 $k$ |

**正定判定步骤**

**① 先证 $A=A^{T}$**（正定的前提是对称矩阵）→ **② 再用五法中任一判正定**

> [!warning] 高频易错
> 负惯性指数 $q=0$ 不充分：例如 $A=\operatorname{diag}(1,0)$，$p=1<2$，非零向量 $(0,1)^T$ 使二次型为0，故不正定。
> - $A=D^{T}D$ 需 $D$ **列满秩**才正定；$D$ 为方阵时等价于可逆，否则存在零方向，只能非负而非正定。参见下一节的完整判据。
> - $A,B$ 正定且 $AB=BA$ ⟹ $AB$ 正定（需可交换条件）

## 转置乘积 $A^TA$（$D^TD$ 型的代表）

上面第 4、5 条的原型就是 $A^TA$。以下默认 $A$ 是 $m\times n$ **实**矩阵，$x\in\mathbb R^n$。

**① 三条基本性质**

| 性质 | 说明 | 出处 |
| :-- | :-- | :-- |
| $(A^TA)^T=A^TA$ | 恒为实对称矩阵，$A$ 不必是方阵 | [[02-1 矩阵运算与方阵的幂]] |
| $(A^TA)_{ij}=\alpha_i^T\alpha_j$ | 按列看是 **Gram 矩阵**：装了各列模长与两两夹角余弦 | [[02-1 矩阵运算与方阵的幂]] |
| $x^TA^TAx=\lVert Ax\rVert^2\ge0$ | **恒半正定**，任意 $m\times n$ 实矩阵都成立 | [[06-6-b 例题·范德蒙德型转置乘积正定\|P153 第25题]] |

> [!tip] 一句话贯穿
> **半正定是白送的，正定才需要额外条件**——而这个条件就是「$Ax=0$ 只有零解」。

**② 正定的核心判据（不要求方阵）**

$$
A^TA\ \text{正定}\iff Ax=0\ \text{只有零解}\iff r(A)=n\ (\text{列数})\iff A\ \text{列满秩}
$$

双向都通：正方向＝半正定加上取不到 $0$；反方向反证，若有 $x_0\ne0$ 使 $Ax_0=0$，则 $x_0^TA^TAx_0=0$，与正定矛盾。

**③ 推论与边界**

- $m<n$ 时**绝不正定**（$r(A)\le m<n$）；这正是 P153 第25题 $s>n$ 那一支。
- 方阵 $m=n$ 时：$A^TA$ 正定 $\iff$ $A$ 可逆 $\iff$ $\lvert A\rvert\ne0$。
- **不能换成任意对称阵**：$M=\operatorname{diag}(1,-1)$ 满秩、$Mx=0$ 只有零解，却因取 $x=(0,1)^T$ 得 $x^TMx=-1<0$ 而不正定。差的就是 $D^TD$ 型自带的半正定。

**④ 同解与四秩相等**

$$
Ax=0\ \text{与}\ A^TAx=0\ \text{同解}
$$

$$
r(A)=r(A^T)=r(A^TA)=r(AA^T)
$$

由此还得到必有解结论：$A^TAx=A^Tb$ 对任意 $b\in\mathbb R^m$ **必有解**（增广可写成 $A^T(A\mid b)$，秩被夹在两端），$r(A)=n$ 时唯一。详见 [[04-3 高频结论与证明#🔄 4.16 转置乘积与必有解的方程组\|4.16 节]]。

**⑤ 谱、迹与行列式**

$$
\lambda_i(A^TA)\ge0,\qquad \lambda_i(A^TA)=\sigma_i^2\ (\text{奇异值平方}),\qquad \text{正特征值个数}=r(A)
$$

$$
\operatorname{tr}(A^TA)=\sum_{i,j}a_{ij}^2=\sum_{i=1}^{n}\lVert\alpha_i\rVert^2
$$

$$
\lvert A^TA\rvert=\lvert A\rvert^2\ge0\quad(m=n)
$$

$A^TA$ 与 $AA^T$ 的**非零特征值连同重数完全相同**（$AB$ 与 $BA$ 共享非零谱，取 $B=A^T$）。

**⑥ 与列满秩的接口**（详见 [[02-3 矩阵的秩与典型例题#🧩 2.7 矩阵的秩\|秩篇的打包结论]]）

| $A$ | 等价说法 | 转置乘积的表现 |
| :-- | :-- | :-- |
| **列满秩** $r(A)=n$ | 列向量组无关 ⟹ 单射 | $A^TA$ 可逆且正定；有左逆 $L=(A^TA)^{-1}A^T$ |
| **行满秩** $r(A)=m$ | 行向量组无关 ⟹ 满射 | $AA^T$ 可逆且正定；有右逆 $R=A^T(AA^T)^{-1}$ |

**⑦ 补充速查（进阶，多为填空/选择陷阱）**

| # | 结论 | 说明 |
| :-- | :-- | :-- |
| 7.1 | 双视角：按列是 Gram 矩阵；按行则 $A^TA=\sum\limits_{i=1}^{m}r_ir_i^T$（$r_i^T$ 为 $A$ 的第 $i$ 行） | 行⟹行外积之和；列⟹列内积表 |
| 7.2 | Cauchy–Binet：$\lvert A^TA\rvert=\sum\limits_{\lVert S\rVert=n}(\det A_S)^2\ge0$（$m\ge n$） | 方阵时退化为 $\lvert A\rvert^2$；⟹ 存在 $n$ 阶非零子式 ⟺ 列满秩 ⟺ 正定 |
| 7.3 | 秩1：$A=\alpha\beta^T\ \Rightarrow\ A^TA=\lVert\alpha\rVert^2\beta\beta^T$ | 谱为 $\lVert\alpha\rVert^2\lVert\beta\rVert^2$（1 重）与 $0$（$n-1$ 重） |
| 7.4 | 投影矩阵（$A$ 列满秩）：$P=A(A^TA)^{-1}A^T$ | $P^T=P=P^2$，$\operatorname{tr}P=r(A)$，特征值 $1$（$r$ 个）与 $0$ |
| 7.5 | 特殊 $A$：对称⟹$A^TA=A^2$；正交⟹$A^TA=E$；对称幂等⟹$A^TA=A$ | 对称时 $A^2$ 恒半正定，$A$ 正定 $\iff$ $A^2$ 正定 |
| 7.6 | Hadamard：$\lvert A^TA\rvert\le\prod\limits_{i=1}^{n}\lVert\alpha_i\rVert^2$ | 等号 ⟺ 各列两两正交（或某列为零） |
| 7.7 | 谱范数（了解）：$\lVert A\rVert_2=\sqrt{\lambda_{\max}(A^TA)}$ | 与奇异值：$A^TA$ 的特征值 $=\sigma_i^2$ |

> [!note] 考纲边界
> 7.1–7.6 都在"知道即能用"的范围内，其中 **7.2、7.3 最值得背**（前者把"子式非零"与"正定"打通，后者见 [[05-1-2-a 秩1矩阵与伴随的谱]]）；7.7 与奇异值分解属数一/Numerical 范畴，数二不必深究。

> [!warning] 三条高频陷阱
> - **复数域要把转置换成共轭转置** $A^H$：$x^HA^HAx=\lVert Ax\rVert^2\ge0$
> ；写成 $A^TA$ 时 $x^TA^TAx$ 连实数都不是（$A=\begin{pmatrix}1&2+\mathrm i\\3-\mathrm i&4\end{pmatrix}$、$x=(1,\ \mathrm i)^T$ 得 $-4+18\mathrm i$），正定无从谈起。
> - **$A^TA$ 正定不能推出「$A$ 可逆」**——$A$ 长方时没有逆可谈，正确说法是「$A$ 列满秩」。
> - **看到 $A^TA=E$** 立刻读作「列向量标准正交」；但 $n<m$ 时 $A$ **不是**正交矩阵，只是某个子空间的一组标准正交基。

## 负定与半定

| 类型 | 充要条件 |
| :-- | :-- |
| **负定**（$x\ne0 \Rightarrow f<0$） | 奇数阶顺序主子式 $<0$，偶数阶 $>0$（即 $-A$ 正定） |
| **半正定**（此表指非负但不正定） | 特征值全非负且至少一个0；所有主子式非负且 $\det A=0$；可写 $A=D^TD$，其中 $D$ 为列不满秩（方阵时奇异）实矩阵 |
| **半负定** | $-A$ 半正定 |

## 合同判定

| 条件 | 说明 |
| :-- | :-- |
| 同阶实对称：$A\cong B$ ⟺ 正负惯性指数相同 | 充要 |
| 同阶实对称：$A\cong B$ ⟺ 特征值正负号分布相同 | 充要（不要求特征值相同） |

> **合同 ⟹ 等价**（$C^{T}AC=B$，$C$ 可逆 ⟹ $r(A)=r(B)$）；合同只在**对称矩阵**间讨论。

## 化二次型为另一个二次型

题型只有两类，区别在**题目允许用哪种变换**：

| 设问 | 变换类型 | 中间桥梁 | 变换阵 |
| :-- | :-- | :-- | :-- |
| 求**可逆** $P$，使 $P^{T}AP=B$ | 合同 | 各自化到**相同规范形** | $P=P_1P_2^{-1}$ |
| 求**正交** $Q$，使 $Q^{T}AQ=B$ | 正交（既相似又合同） | 各自化到**相同标准形** | $Q=Q_1Q_2^{T}$ |

**可逆解法（四步）**

1. 对 $A$ 用配方法或初等变换，得 $P_1^{T}AP_1=\Lambda$（只含 $0,\pm1$）；
2. 对 $B$ 同法，得 $P_2^{T}BP_2=\Lambda$（**必须是同一个** $\Lambda$）；
3. 由 $x=P_1z$、$y=P_2z$ 消去 $z$，得 $z=P_2^{-1}y$，故 $x=P_1P_2^{-1}y$；
4. 取 $P=P_1P_2^{-1}$，此时 $P^{T}AP=B$。

**正交解法（三步）**

1. 分别用正交变换把 $A$、$B$ 化成**相同**的标准形：$Q_1^{T}AQ_1=\Lambda=Q_2^{T}BQ_2$；
2. 由 $x=Q_1z$、$y=Q_2z$ 消去 $z$，得 $x=Q_1Q_2^{T}y$；
3. 取 $Q=Q_1Q_2^{T}$（正交阵之积仍是正交阵）。

> [!tip] 两条路子怎么选
> 题目只说「可逆矩阵」⟹ 走配方，快；
> 题目要求「正交矩阵」⟹ 必须走正交变换，因为标准形系数被钉成了特征值。
