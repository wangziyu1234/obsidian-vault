# 第3讲（一·2）线性表示、极大无关组与秩

> [!abstract] 本讲定位
> 从列向量模型理解可表、无关与张成；明确主元列回取和向量组等价的条件。

## 🔗 3.1 向量的基础概念（承接第 0 讲）

### 核心定义速览

| 概念 | 内容 |
| :-- | :-- |
| 向量 | 有序数组 $\alpha=(a_1,\dots,a_n)^{T}$，$n$ 为维数（定义与编码示例见 [[00 线代第0讲 线性代数入门]]） |
| 线性组合 | $k_1\alpha_1+\cdots+k_s\alpha_s$（$k_i$ 为组合系数） |
| 线性相关 | 存在**不全为零**的 $k_1,\dots,k_s$ 使 $k_1\alpha_1+\cdots+k_s\alpha_s=0$ ⟹ 张成空间维数 $<s$（有"冗余"向量） |
| 线性无关 | 只有 $k_1=\cdots=k_s=0$ 才使上式成立 ⟹ 每个向量都"有贡献" |

### 张成空间

一组向量的所有线性组合构成的集合 $\text{span}\{\alpha_1,\dots,\alpha_s\}$。如 $\alpha_1=(1,0),\alpha_2=(0,1)$ 的任意线性组合是 2 维平面内所有向量（所有点），称 $\alpha_1,\alpha_2$ **张成一个 2 维平面**。

### 线性表示（能 / 不能）

$$
\begin{aligned}
\text{能表示} &\iff \text{存在系数使 } k_1\alpha_1+\cdots+k_s\alpha_s=\beta\\
&\iff \beta\in\text{span}\{\alpha_1,\dots,\alpha_s\}\\
&\iff Ax=\beta\ \text{有解}\iff r(A)=r(A\mid\beta)
\end{aligned}
$$

$$
\text{不能表示}\iff \beta\ \text{不在张成空间}\iff r(A\mid\beta)=r(A)+1
$$

> [!tip] 一句入门
> 一个向量 $\beta$ **在** $\alpha_1,\dots,\alpha_s$ 张成的空间里 ⟺ 能表示；**不在** ⟺ 不能表示。$\alpha=0$ 相关、$\alpha\ne0$ 无关；单个非零向量、两个不成比例向量均无关；含零向量或含成比例向量的组必相关。（判别见 [[03-1-1 线性相关性七大判别定理]] 定理 5，举例见例 4。）

> [!note] 可表、唯一可表、生成组与基不是同一句话
> 设 $A=[\alpha_1,\ldots,\alpha_s]$，各列属于指定的实向量空间V。一个给定的 $\beta$ 可表示，当且仅当 $r(A)=r(A\mid\beta)$；它**唯一**可表示还需 $r(A)=s$。一旦有一组系数 $x_0$，全部系数为 $x_0+\ker A$。
>
> **生成组**要求V中每个向量都可表；**基**还要求生成组无关，等价于V中每个向量都唯一可表。$\dim\operatorname{span}(A)=r(A)$，不一定等于环境维数。
>
> 例如 $(e_1,e_1)$ 能表示 $e_1$ 但不唯一；只有 $e_1$ 的单向量组能唯一表示 $e_1$，却不是 $\mathbb R^2$ 的生成组。

## 🔗 3.2 线性相关性判定
![[线代-向量相关几何.png|520]]
*两向量共线 ⇒ 相关；不共线 ⇒ 无关（张成平面）*


$\boxed{k_1\alpha_1+\cdots+k_s\alpha_s=0}$ 有非零解 $\iff$ 相关；只有零解 $\iff$ 无关。

| 判定法 | 结论 |
| :----------------- | :--------------------------------------------------------------------- |
| 定义 | 存在**不全为零**的 $k_i$ 使 $\sum k_i\alpha_i=0$ ⟺ 相关；只有零解 ⟺ 无关 |
| 秩 | 相关 $\iff r(\alpha_1,\dots,\alpha_s)<s$；无关 $\iff r=s$ |
| 行列式（$s=n$ 时） | 相关 $\iff \lvert A\rvert=0$；无关 $\iff\lvert A\rvert\ne0$ |
| 个数超维数 | $n+1$ 个 $n$ 维向量**必相关** |
| 两个向量 | 相关 $\iff$ 成比例 |
| 三个三维向量 | 相关 $\iff$ **共面** $\iff \lvert A\rvert=0$（混合积为零） |
| 含零向量 | 必相关 |
| 含成比例向量 | 必相关 |

> [!note] 为什么会"必相关"——"个数超维数"背后的空间直觉
> $s$ 个 $n$ 维向量**至多张成 $n$ 维空间**。若向量个数超过维数（$s>n$），空间维数"装不下"这 $s$ 个向量，必然出现"躺平"的多余向量 ⟹ **必相关**。这是对 $n+1$ 个 $n$ 维向量必相关的理解，也呼应张宇的"张成空间"视角。

## 🔗 3.4 常用结论

### 相关性的传播与量纲

- **部分相关 ⟹ 整体相关**（逆否：整体无关 ⟹ 部分无关）。因为"相关"这一性质只会向"更多向量"传播——多余向量多了，不会变不相关。

- **添加分量（延长）**：无关组**延长**后仍无关；相关组**缩短**后仍相关。延长是加约束、更难相关；缩短是减约束、更易相关。

- $\alpha_1,\dots,\alpha_s$ 无关而 $\alpha_1,\dots,\alpha_s,\beta$ 相关 ⟹ $\beta$ 可由前者**唯一**线性表示。

- **以少表多，多必相关**：若 $\beta_1,\dots,\beta_t$ 可由 $\alpha_1,\dots,\alpha_s$ 表示且 $t>s$，则 $\beta$ 组相关。

> [!tip] 一句分辨：哪些性质"单向"、哪些给逆否
> 这里每条判定都可**双向**看（原命题 + 逆否）。上面 4 条的**逆否形式**正是考试偏爱用到的等价说法（对应 [[03-1-1 线性相关性七大判别定理]] 的定理 6/7/2/3），速查时以"逆否"作为切入点往往更快。

### 极大无关组与秩

- **极大无关组**（定义）：在 $\alpha_1,\dots,\alpha_s$ 中，若存在部分组 $\alpha_{i_1},\dots,\alpha_{i_r}$ 满足
  - ① 该部分组**线性无关**；
  - ② 向量组中**任一向量** $\alpha_i$ 都可由 $\alpha_{i_1},\dots,\alpha_{i_r}$ **线性表示**；
  则称该部分组是原向量组的**极大线性无关组**。

- **求法（列向量按列排）**：① 对矩阵A只作行变换求行最简形；② 找主元列编号，回到**原矩阵**取这些列，得到一组极大无关组；③ 非主元列在主元行上的值，才是它相对这组主元列的表示系数。若另选其他极大无关组，必须重新解表示方程，不能原样照读。

- **注意排列方向**：待研究向量按列排时用行变换保留原列关系；按行排时可转而用列变换。列变换会混合原列身份，不能做完后按同列号回取原列；例如 $[0,e_1]$ 变成 $[e_1,e_1]$ 后，第一列已不是原零列。

- **性质**：极大无关组**可能不唯一**，但所含向量**个数唯一**（$=$ 向量组的秩 $r$）；同一向量组的任意两个极大无关组**等价**；其余向量由极大无关组表示时**表示法唯一**。

- **判断**：「某无关部分组是极大无关组」只需再证**其余每个向量都可由它表示**（或该部分组个数恰为秩 $r$）。

- **特殊情形**：由**一个零向量**组成的向量组不存在极大无关组；一个本身**线性无关**的向量组的极大无关组就是它**自身**。

### 向量组等价

- **向量组等价**（定义）：两组向量（Ⅰ）$\alpha_1,\dots,\alpha_s$ 与（Ⅱ）$\beta_1,\dots,\beta_t$ 可**互相线性表示**，记作（Ⅰ）$=$（Ⅱ）。

- **判定 = 三秩相同**：
  $$
  r(\text{Ⅰ})=r(\text{Ⅱ})=r(\text{Ⅰ},\text{Ⅱ})
  $$
  即 $r(\alpha_1,\dots,\alpha_s)=r(\beta_1,\dots,\beta_t)=r(\alpha_1,\dots,\alpha_s,\beta_1,\dots,\beta_t)$。

- **等价关系**：是等价关系（**反身、对称、传递**；传递性如（Ⅰ）$=$（Ⅱ），（Ⅱ）$=$（Ⅲ）⟹（Ⅰ）$=$（Ⅲ））。

- **与极大无关组的关系**：向量组和它的**极大无关组是等价向量组**；两组向量等价 ⟺ 各自的**极大无关组等价**。

- **秩的关系**：等价的向量组**秩必相同**（逆否：秩不同必不等价）；但**秩相同 `⇏` 等价**（如 $\alpha=(1,0)$ 与 $\beta=(0,1)$ 秩同为 $1$，但 $r(\alpha,\beta)=2$、不能互相表示）。

- **易错辨析**：向量组等价 ≠ 矩阵等价——矩阵等价只需**秩相同**；向量组等价还要**并组秩相同**（如上，$r(\alpha,\beta)=2\ne r(\beta)=1$，故不等价）。

> [!note] 单向表示是整组每个向量都能表示
> B组可由A组表示，意指 $B=AC$，因此 $\operatorname{span}(B)\subseteq\operatorname{span}(A)$ 且 $r(B)\le r(A)$。两组等价，当且仅当秩相同且**一整组**可由另一组表示；只找到其中一个共同向量不够。
