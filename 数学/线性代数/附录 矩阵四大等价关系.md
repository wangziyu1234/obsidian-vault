# 附录 矩阵四大等价关系

> [!abstract] 附录定位
> 将**等价、相似、合同、正交相似**四大关系的定义、条件、不变量、判定、推论整理到一张表中，便于选填题快速查阅。各关系在后续章节有详细展开——[[03 线代第3讲 向量组]]（向量组等价）、[[05-2 实对称矩阵与求Aⁿ]]（相似判定与推论）、[[06 线代第6讲 二次型]]（合同与惯性指数）。

## 定义与核心条件

| 关系 | 记号 | 定义 | 矩阵要求 | 充要条件 |
| :-- | :-- | :-- | :-- | :-- |
| **等价** | $A\overset{=}{\sim}B$ | $PAQ=B$（$P,Q$ 可逆） | 同型（不要求方阵） | $r(A)=r(B)$ |
| **相似** | $A\sim B$ | $P^{-1}AP=B$（$P$ 可逆） | **方阵** | 实对称：特征值相同；一般：特征多项式相同 + 各阶主子式之和相同（必要非充分） |
| **合同** | $A\cong B$ | $C^{T}AC=B$（$C$ 可逆） | **方阵**（通常限对称） | 实对称：正负惯性指数相同 |
| **正交相似** | $A\overset{Q}{\sim}B$（$Q$ 正交） | $Q^{-1}AQ=Q^{T}AQ=B$ | **方阵** | 实对称：特征值相同（与相似等价） |

> [!tip] 一句话记忆
> **等价看秩、相似看特征值、合同看惯性指数、正交相似 = 相似 + 合同（实对称下）。**

## 强弱关系与包含链

$$A\overset{正交相似}{\sim}B \;\Longrightarrow\; A\sim B \;\Longrightarrow\; A\overset{=}{\sim}B$$

$$A\overset{正交相似}{\sim}B \;\Longrightarrow\; A\cong B \;\Longrightarrow\; A\overset{=}{\sim}B$$

> [!warning] 互不包含
> - **合同 $\not\Rightarrow$ 相似**：$A=E_2$ 与 $B=\begin{pmatrix}1&0\\0&4\end{pmatrix}$，合同（$C=\operatorname{diag}(1,2)$ 使 $C^TAC=B$）但不相似（特征值不同）。
> - **相似 $\not\Rightarrow$ 合同**（仅非对称矩阵可构造）：实对称时相似 $\Rightarrow$ 合同（特征值相同 ⟹ 惯性指数相同），故反例必须是非对称矩阵——但合同通常只在对称矩阵间讨论，实际考试中主要关注「合同 ⇏ 相似」。

## 不变量对比（必要条件速查）

| 不变量 | 等价 | 相似 | 合同 | 正交相似 |
| :-- | :--: | :--: | :--: | :--: |
| 秩 $r(A)$ | **保持** | **保持** | **保持** | **保持** |
| 行列式 $\lvert A\rvert$ | ✗ | **保持** | ✗ | **保持** |
| 迹 $\operatorname{tr}A$ | ✗ | **保持** | ✗ | **保持** |
| 特征多项式 | ✗ | **保持** | ✗ | **保持** |
| 正负惯性指数 | ✗ | ✗ | **保持** | **保持** |
| 特征值 | ✗ | **保持**（实对称充要） | ✗ | **保持** |
| 正交对角化能力 | ✗ | ✗ | ✗ | **保持**（实对称） |

> [!note] 等价标准形
> 任意 $A$（$m\times n$）都等价于 $PAQ=\begin{pmatrix}E_r&O\\O&O\end{pmatrix}$（$r=r(A)$）——这是**唯一的等价不变量：秩**。求 $P$ 使 $PA=B$ 的方法见 [[02-2 伴随矩阵]]。

## 判定方法对比

| 关系 | 判定方法 |
| :-- | :-- |
| **等价** | $r(A)=r(B)$（同型矩阵）；或 $A$ 经有限次初等行/列变换化为 $B$ |
| **相似** | ① 特征多项式相同（必要）；② 实对称 ⟺ 特征值相同（充要）；③ $A,B$ 均可对角化 ⟺ 特征值相同（充要）；④ $r(\lambda E-A)=r(\lambda E-B)$（所有 $\lambda$）（必要，精细） |
| **合同** | 实对称：正负惯性指数相同（配方法 / 正交变换法求标准形后比较 $p,q$） |
| **正交相似** | 实对称：特征值相同（充要）；正交对角化后 $Q_1^TAQ_1=Q_2^TBQ_2=\Lambda$ ⟹ $Q_2Q_1^T$ 即正交变换 |

## 推论与保持性质

| 关系 | 保持的运算 |
| :-- | :-- |
| **相似** | $A\sim B$ ⟹ $f(A)\sim f(B)$（任意多项式）、$A^{-1}\sim B^{-1}$（可逆时）、$A^{*}\sim B^{*}$、$A^{T}\sim B^{T}$（注意 $A^{T}$ 的传递用 $P^{T}$，不能与多项式共用 $P$） |
| **合同** | $A\cong B$ ⟹ $A^{T}\cong B^{T}$；$A$ 对称 ⟹ $B=C^{T}AC$ 仍对称 |
| **等价** | $PAQ=B$ 不保持特征值/行列式/迹，只保持秩 |
| **正交相似** | 同相似（因为正交相似是相似的特例），且额外保持长度/内积 |

## 实对称矩阵的特殊地位

> 实对称矩阵 $A$ 的四大关系**全部等价于特征值相同**：

$$A\sim B \;\iff\; A\cong B \;\iff\; A\overset{Q}{\sim}B \;\iff\; \text{特征值相同}$$

> 这是因为实对称矩阵**必可正交对角化**：$Q^TAQ=\Lambda$，而 $\Lambda$ 由特征值唯一确定。

## 向量组等价 vs 矩阵等价（高频易混）

| | 矩阵等价 $PAQ=B$ | 向量组等价（互相线性表示） |
| :-- | :-- | :-- |
| 判定 | $r(A)=r(B)$（同型） | $r(\text{Ⅰ})=r(\text{Ⅱ})=r(\text{Ⅰ},\text{Ⅱ})$ |
| 关系 | 等价关系（反身/对称/传递） | 等价关系（反身/对称/传递） |
| 注意 | 同型才谈等价 | 秩相同 ⇏ 等价（还需并组秩相同） |
