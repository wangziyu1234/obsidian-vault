# 附录 特征值与特征向量速查

> [!abstract] 附录定位
> 特征值变换表、特征多项式速算、对角化步骤、常用推论的**纯速查**。所有推导与例题见 [[05-1 特征值与相似对角化]]、[[05-2 实对称矩阵与求Aⁿ]]。

## 特征值变换表（选填最高频）

> $A$ 的特征值 $\lambda$、特征向量 $\xi$；$f$ 为多项式；$A$ 可逆时才有 $A^{-1},A^{*}$ 行。

| 矩阵 | 特征值 | 特征向量 |
| :-- | :-- | :-- |
| $A$ | $\lambda$ | $\xi$ |
| $kA$ | $k\lambda$ | $\xi$ |
| $A^{m}$ | $\lambda^{m}$ | $\xi$ |
| $f(A)$ | $f(\lambda)$ | $\xi$ |
| $A^{-1}$ | $\dfrac{1}{\lambda}$ | $\xi$ |
| $A^{*}$ | $\dfrac{\lvert A\rvert}{\lambda}$ | $\xi$ |
| $A^{T}$ | $\lambda$（特征值相同） | **不一定**（左特征向量） |
| $P^{-1}AP$ | $\lambda$ | $P^{-1}\xi$ |

> [!tip] 三条高频结论
> 1. **$AB$ 与 $BA$ 非零特征值相同**（含重数）：$\lvert\lambda E_m-AB\rvert=\lambda^{m-n}\lvert\lambda E_n-BA\rvert$（$m\ge n$）。
> 2. **$A$ 与 $A^{T}$ 特征值相同**（$\lvert\lambda E-A^T\rvert=\lvert\lambda E-A\rvert$），但特征向量一般不同。
> 3. **$f(A)=O$ ⟹ $\lambda$ 只能取 $f(\lambda)=0$ 的根**。

## 特征多项式速算

| 阶数 | 公式 |
| :-- | :-- |
| 二阶 | $\lvert\lambda E-A\rvert=\lambda^{2}-(\operatorname{tr}A)\lambda+\lvert A\rvert$ |
| 三阶 | $\lvert\lambda E-A\rvert=\lambda^{3}-(\operatorname{tr}A)\lambda^{2}+(A_{11}+A_{22}+A_{33})\lambda-\lvert A\rvert$（$A_{ii}$ 为二阶主子式） |
| $n$ 阶 | 按行/列展开 + 递推；或用特征值定义 $\det(\lambda I-A)$ 直接计算 |

> [!note] 特征多项式系数含义
> $\lvert\lambda E-A\rvert=\lambda^{n}-c_{1}\lambda^{n-1}+c_{2}\lambda^{n-2}-\cdots+(-1)^{n}c_{n}$，其中：
> - $c_{1}=\operatorname{tr}A$（迹 = 特征值之和）
> - $c_{n}=\lvert A\rvert$（行列式 = 特征值之积）
> - $c_{k}$ = 所有 $k$ 阶主子式之和

## 相似对角化

### 可对角化判定

| 条件 | 说明 |
| :-- | :-- |
| $n$ 个互异特征值 | **充分**，必可对角化 |
| 实对称矩阵 | **充分**，必可正交对角化 |
| $k$ 重特征值 $\lambda_i$ 满足 $n-r(\lambda_i E-A)=k_i$ | **充要**（每个特征值的几何重数 = 代数重数） |
| 存在 $k$ 重特征值但无关特征向量 $<k$ | **不可对角化** |

### 对角化三步法

1. **求特征值** $\lambda_1,\dots,\lambda_n$（含重数）
2. **求特征向量**：对每个 $\lambda_i$ 解 $(\lambda_i E-A)x=0$，取全部线性无关特征向量
3. **拼矩阵**：$P=(\xi_1,\dots,\xi_n)$，则 $P^{-1}AP=\Lambda=\operatorname{diag}(\lambda_1,\dots,\lambda_n)$（列与对角元**顺序对应**）

### 正交对角化（实对称矩阵）

1. 求特征值 → 2. 每个特征值求基础解系 → 3. **施密特正交化**（同一特征值的特征向量间）→ 4. 单位化 → 5. 拼 $Q$（正交矩阵），$Q^{-1}AQ=Q^{T}AQ=\Lambda$

## 相似判定速查

| 方法 | 适用 | 操作 |
| :-- | :-- | :-- |
| 特征值相同 | 实对称（充要）、一般（必要） | 计算 $\lvert\lambda E-A\rvert$ 比较 |
| $r(\lambda E-A)=r(\lambda E-B)$（$\forall\lambda$） | 一般矩阵（必要，精细） | 对每个特征值验证秩 |
| 均可对角化 + 特征值相同 | 充要 | 各自对角化后比较 $\Lambda$ |
| 各阶主子式之和分别相等 | 必要 | 计算 $c_k$ 系数 |

> [!warning] 常见陷阱
> - 特征值相同 + 秩相同 ⇏ 相似（还需几何重数相同）
> - $\operatorname{tr}A=\operatorname{tr}B$ 且 $\lvert A\rvert=\lvert B\rvert$ ⇏ 相似（二阶时特征多项式相同 ⟹ 相似，三阶及以上不成立）
