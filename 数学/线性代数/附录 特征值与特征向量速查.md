# 附录 特征值与特征向量速查

> [!abstract] 附录定位
> 特征值变换表、特征多项式速算、对角化步骤、二次方程型判据、实对称分解定理与「知一求二」、常用推论的**纯速查**。所有推导与例题见 [[05-1 特征值与相似对角化]]、[[05-2 实对称矩阵与正交对角化]]。

## 特征值变换表（选填最高频）

> $A\xi=\lambda\xi$ 且 $\xi\ne0$；$f$ 为多项式。$A^{-1}$ 行要求 $A$ 可逆；$A^*$ 的分式写法要求对应的 $\lambda\ne0$，不是说只有可逆矩阵才有伴随矩阵。

| 矩阵 | 特征值 | 特征向量 |
| :-- | :-- | :-- |
| $A$ | $\lambda$ | $\xi$ |
| $kA$ | $k\lambda$ | $\xi$ |
| $A^{m}$ | $\lambda^{m}$ | $\xi$ |
| $f(A)$ | $f(\lambda)$ | $\xi$ |
| $A^{-1}$ | $\frac{1}{\lambda}$ | $\xi$ |
| $A^{*}$ | $\frac{\lvert A\rvert}{\lambda}$ | $\xi$ |
| $A^{T}$ | $\lambda$（特征值相同） | **不一定**（左特征向量） |
| $P^{-1}AP$ | $\lambda$ | $P^{-1}\xi$ |

> [!note] 有零特征值时，伴随的谱用乘积写
> 若 $n\ge2$，$A$ 的特征值为 $\lambda_1,\ldots,\lambda_n$（计代数重数），则 $A^*$ 的特征值为
>
> $$
> \mu_i=\prod_{j\ne i}\lambda_j
> $$
>
> 此式对奇异矩阵也成立。推导和例子见 [[05-1-2-b 伴随矩阵的奇异情形与扰动法]]。

> [!tip] 三条高频结论
> 1. **$AB$ 与 $BA$ 非零特征值相同**（含重数）：$\lvert\lambda E_m-AB\rvert=\lambda^{m-n}\lvert\lambda E_n-BA\rvert$（$m\ge n$）。
> 2. **$A$ 与 $A^{T}$ 特征值相同**（$\lvert\lambda E-A^T\rvert=\lvert\lambda E-A\rvert$），但特征向量一般不同。
> 3. **$f(A)=O$ ⟹ $\lambda$ 只能取 $f(\lambda)=0$ 的根**。

> [!tip] 特征向量的组合：**同则仍成，异则不成**
> - **同一**特征值 $\lambda$ 的特征向量的任意非零线性组合仍是 $\lambda$ 的特征向量（$A(k_1\xi_1+k_2\xi_2)=\lambda(k_1\xi_1+k_2\xi_2)$）——所以一个特征值对应的解集是一整个子空间；
> - **不同**特征值的特征向量之和**一定不是**特征向量；
> - $k$ 重特征值**最多**有 $k$ 个线性无关的特征向量（几何重数 $\le$ 代数重数），只有取满 $k$ 个才可对角化。

## 特征多项式速算

| 阶数 | 公式 |
| :-- | :-- |
| 二阶 | $\lvert\lambda E-A\rvert=\lambda^{2}-(\operatorname{tr}A)\lambda+\lvert A\rvert$ |
| 三阶 | $\lvert\lambda E-A\rvert=\lambda^{3}-(\operatorname{tr}A)\lambda^{2}+(A_{11}+A_{22}+A_{33})\lambda-\lvert A\rvert$（$A_{ii}$ 为二阶主子式） |
| $n$ 阶 | 按行/列展开 + 递推；或用特征值定义 $\det(\lambda I-A)$ 直接计算 |

> [!note] 特征多项式系数含义
> $\lvert\lambda E-A\rvert=\lambda^{n}-c_{1}\lambda^{n-1}+c_{2}\lambda^{n-2}-\cdots+(-1)^{n}c_{n}$，其中：
> - $c_{1}=\operatorname{tr}A$（迹 = 特征值之和）
> - $c_{n}=\lvert A\rvert$（行列式 = 特征值之积）
> - $c_{k}$ = 所有 $k$ 阶主子式之和

## 特殊矩阵的特征值（"元素特点"的翻译）

| 矩阵长相 | 翻译 | 特征值 |
| :-- | :-- | :-- |
| 每行（或每列）和都是 $k$ | $A\mathbf{1}=k\mathbf{1}$ | $k$ 是一个特征值，$\mathbf{1}$ 是它的特征向量 |
| 元素全为 $1$ 的 $n$ 阶阵 $J$ | $J=\mathbf{1}\mathbf{1}^{T}$，秩 $1$ | $n,\ 0,\dots,0$ |
| $aE+bJ$ | $J$ 的平移加倍数 | $a+bn,\ a,\dots,a$ |

> [!tip] 两个立刻能用的推论
> - 每行和为 $k$ ⟹ $\lvert\lambda E-A\rvert$ 各行和都是 $\lambda-k$，各列加到同一列即得公因子 $(\lambda-k)$，特征方程**降一阶**；
> - $A$ 可逆且每行和为 $k\ne0$ ⟹ $A^{-1}$ 每行和为 $\dfrac1k$（因 $A^{-1}\mathbf{1}=\frac1k\mathbf{1}$）。

## 相似对角化

**可对角化判定**

| 条件 | 说明 |
| :-- | :-- |
| $n$ 个互异特征值 | **充分**，必可对角化 |
| 实对称矩阵 | **充分**，必可正交对角化 |
| $k$ 重特征值 $\lambda_i$ 满足 $n-r(\lambda_i E-A)=k_i$ | **充要**（每个特征值的几何重数 = 代数重数） |
| 存在 $k$ 重特征值但无关特征向量 $<k$ | **不可对角化** |

> [!tip] 二次方程型判据（好记好用）
> 若 $n$ 阶矩阵 $A$ 满足 $f(A)=O$，其中 $f(x)=(x-a)(x-b)$ 且 $a\ne b$（即 $(A-aE)(A-bE)=O$），则
> - $A$ 的特征值**只能是** $a$ 或 $b$；
> - $A$ **一定可相似对角化**；
> - 并且
>
> $$
> r(A-aE)+r(A-bE)=n
> $$
>
> 证明是两边夹：由 $(A-aE)(A-bE)=O$ 得 $r(A-aE)+r(A-bE)\le n$；又
>
> $$
> r(A-aE)+r(A-bE)\ge r\bigl[(A-aE)-(A-bE)\bigr]=r\bigl[(b-a)E\bigr]=n
> $$
>
> 两向夹住即得等号。
> 实例：$A^{2}-4A+3E=O$ ⟹ $r(A-E)+r(A-3E)=4$，且 $A$ 可对角化。

**对角化三步法**

1. **求特征值** $\lambda_1,\dots,\lambda_n$（含重数）
2. **求特征向量**：对每个 $\lambda_i$ 解 $(\lambda_i E-A)x=0$，取全部线性无关特征向量
3. **拼矩阵**：$P=(\xi_1,\dots,\xi_n)$，则 $P^{-1}AP=\Lambda=\operatorname{diag}(\lambda_1,\dots,\lambda_n)$（列与对角元**顺序对应**）

**正交对角化（实对称矩阵）**

1. 求特征值 → 2. 每个特征值求基础解系 → 3. **施密特正交化**（同一特征值的特征向量间）→ 4. 单位化 → 5. 拼 $Q$（正交矩阵），$Q^{-1}AQ=Q^{T}AQ=\Lambda$

> [!tip] 实对称矩阵的分解定理（反求 $A$ 用）
> 设 $\gamma_1,\dots,\gamma_n$ 为 $A$ 的**单位正交**特征向量、依次对应特征值 $\lambda_1,\dots,\lambda_n$，则
>
> $$
> A=\lambda_1\gamma_1\gamma_1^{T}+\lambda_2\gamma_2\gamma_2^{T}+\cdots+\lambda_n\gamma_n\gamma_n^{T}
> $$
>
> 特别的，$r(A)=1$ 时 $A=\operatorname{tr}(A)\,\gamma_1\gamma_1^{T}$。
> 用法：先拼特征值 $\lambda$，再拼特征向量的外积，**不必求 $P$ 与 $P^{-1}$**。

> [!tip] 实对称阵「知一求二」
> 已知某个特征值的特征向量 $\alpha_1$，求另一个**二重**特征值对应的两个正交特征向量：
> 1. 解 $\alpha_1^{T}x=0$（即 $a_1x_1+a_2x_2+a_3x_3=0$），得两个线性无关解；
> 2. 对这两个解做施密特正交化；
> 3. 单位化。
>
> 例：$\alpha_1=(1,1,1)^{T}$ 时取 $(1,-1,0)^{T}$、$(1,0,-1)^{T}$；施密特后第二个化为 $(1,1,-2)^{T}$（即原解减去在第一个上的投影再乘 $2$），再单位化。

## 相似判定速查

| 方法 | 适用 | 操作 |
| :-- | :-- | :-- |
| 特征值相同 | 实对称（充要）、一般（必要） | 计算 $\lvert\lambda E-A\rvert$ 比较 |
| $r(\lambda E-A)=r(\lambda E-B)$（$\forall\lambda$） | 一般矩阵（必要，精细） | 对每个特征值验证秩 |
| 两矩阵均可对角化 | 在此前提下，相似 ⇔ 谱相同 | 各自对角化后比较 $\Lambda$（计重数） |
| 各阶主子式之和分别相等 | 必要 | 计算 $c_k$ 系数 |

> [!warning] 常见陷阱
> - 特征值相同 + 秩相同 ⇏ 相似；几何重数相同也只是进一步的必要检查，不能当作任意阶矩阵的完整判据。
> - 迹与行列式相同仍不足；**二阶也不例外**。$E_2$ 与 $\begin{pmatrix}1&1\\0&1\end{pmatrix}$ 的特征多项式同为 $(\lambda-1)^2$，却不相似。
