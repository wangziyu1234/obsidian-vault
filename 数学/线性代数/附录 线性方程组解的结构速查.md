# 附录 线性方程组解的结构速查

> [!abstract] 附录定位
> 齐次/非齐次方程组解的判定、结构、求法、高频结论的**纯速查**。所有推导与例题见 [[04 线代第4讲 线性方程组]]。

教材依据：[[27张宇基础30讲线代.pdf#page=123|第4讲，书内 pp.116–132]]（PDF pp.123–139）。

## 解的判定

| 方程组 | 判定条件 |
| :-- | :-- |
| $Ax=0$（$n$ 元） | 只有零解 ⟺ $r(A)=n$；有非零解 ⟺ $r(A)<n$（方阵 ⟺ $\lvert A\rvert=0$） |
| $Ax=b$ | 无解 ⟺ $r(A)<r(A\mid b)$；唯一解 ⟺ $r(A)=r(A\mid b)=n$；无穷解 ⟺ $r(A)=r(A\mid b)<n$ |

> [!tip] 含参数方程讨论步骤
> **方阵**可先算 $\det A$：非零时唯一解；为零时逐一代入参数值，比较 $r(A)$ 与 $r(A\mid b)$。非方阵直接行化简讨论。

## 解的结构

#### 齐次方程组 $Ax=0$

$$
\boxed{x=k_{1}\xi_{1}+\cdots+k_{n-r}\xi_{n-r}}
$$

- 基础解系 $\xi_1,\dots,\xi_{n-r}$ 含 $n-r(A)$ 个线性无关解
- **基础解系三条件**：① 每个 $\xi_i$ 是解；② 线性无关；③ 个数 $=n-r(A)$

#### 非齐次方程组 $Ax=b$

$$
\boxed{x=\eta^{*}+k_{1}\xi_{1}+\cdots+k_{n-r}\xi_{n-r}}
$$

- 特解 $\eta^{*}$ + 齐次通解
- $\eta_1,\eta_2$ 是 $Ax=b$ 的解 ⟹ $\eta_1-\eta_2$ 是 $Ax=0$ 的解

#### 系数和结论（抽象题高频）

设 $\eta_1,\dots,\eta_m$ 均为同一非齐次方程组 $Ax=b$ 的解，且 $b\ne0$，则 $\sum k_i\eta_i$：

| 条件 | 结论 |
| :-- | :-- |
| $\sum k_i=0$ | 是**齐次解**（$Ax=0$ 的解） |
| $\sum k_i=1$ | 仍是**非齐次解**（$Ax=b$ 的解） |
| 其余 | 两者皆非 |

> 由 $A\sum k_i\eta_i=(\sum k_i)b$ 一步得。

## 求基础解系标准步骤

1. 对 $A$ 做**初等行变换**化为**行最简形**
2. 确定**自由变量**：$n-r(A)$ 个非主元列对应的变量
3. 依次令每个自由变量 $=1$、其余 $=0$，回代解出主元变量 → 得 $n-r(A)$ 个基础解向量
4. 齐次通解 $=$ 这些向量的线性组合

## 非齐次特解快速求法

行化简后令**全部自由变量 $=0$**，回代得特解 $\eta^{*}$。

## 行列变换与解的关系

- **行变换**：保留任意对应部分列的相关性和原系数；增广矩阵整行变换后，原方程组同解。
- **列变换**：保留任意对应部分行的相关性和原系数；若 $C=AQ$，解 $Cy=b$ 后须用 $x=Qy$ 还原。
- **共同点**：秩、全体行及全体列是否相关都不变；这不等于“对应部分组不变”或“原解向量不变”。

总表、证明和反例见 [[04-4 行列变换、线性相关性与解的关系]]。

## 高频结论

| # | 结论 | 说明 |
| :-- | :-- | :-- |
| 1 | $A^{T}Ax=A^{T}b$ 必有解 | 增广矩阵为 $A^T(A\mid b)$，其秩被夹在 $r(A^TA)=r(A)$ 与 $r(A)$ 之间 |
| 2 | $A$ 列满秩（$r(A)=n$）时 $AB=AC \Rightarrow B=C$ | 类消去律（$Ax=0$ 只有零解） |
| 3 | $AB=O \Rightarrow r(A)+r(B)\le n$ | $B$ 的列都是 $Ax=0$ 的解 |
| 4 | $r(A)=m$（行满秩）$\Rightarrow Ax=b$ 必有解 | 增广矩阵行向量仍无关 |
| 5 | $Ax=0$ 与 $A^{T}Ax=0$ 同解 | $\Rightarrow r(A)=r(A^{T}A)$（实矩阵） |

> [!warning] 伴随矩阵的列不能全拿来当基础解系
> 若 $r(A)=n-1$（$n\ge2$），取 $A^*$ 的**任意一列非零列**即可作为 $Ax=0$ 的基础解系；此时 $r(A^*)=1$，所有列一起取通常线性相关。
> 逐步证明见 [[04-3 高频结论与证明]]。

## 同解与公共解

| 类型 | 判定/求法 |
| :-- | :-- |
| **同解**（齐次） | $Ax=0$ 与 $Bx=0$ 同解 ⟺ $r(A)=r(B)=r\begin{pmatrix}A\\B\end{pmatrix}$ |
| **同解**（非齐次） | $Ax=b$ 与 $Bx=c$（均有解）同解 ⟺ 增广矩阵去掉全零行后行最简形相同 ⟺ $r(A\mid b)=r(B\mid c)=r\begin{pmatrix}A&b\\B&c\end{pmatrix}$ |
| **公共解** | 联立 $\begin{cases}Ax=0\\Bx=0\end{cases}$ 求解；或把一通解代入另一方程组解参数 |
| **解的包含** | $Bx=0$ 的解均为 $Ax=0$ 的解 ⟺ $A=CB$ ⟺ $r\begin{pmatrix}A\\B\end{pmatrix}=r(B)$ |

## 克拉默法则

方阵 $A$ 且 $D=\lvert A\rvert\ne0$ 时，唯一解 $\boxed{x_i=\frac{D_i}{D}}$（$D_i$：把 $D$ 的第 $i$ 列换成 $b$）。

> **齐次方向**：$Ax=0$（$A$ 为 $n$ 阶方阵）有非零解 ⟺ $\lvert A\rvert=0$。
> **$AB=O$ 推论**：$AB=O$ 且 $B$ 可逆 $\Rightarrow A=O$；若 $A,B$ 是同阶方阵，$AB=O$ 时两者行列式至少一个为零。
