# 第4讲 解题套路与例题索引

> [!abstract] 本页定位
> 全章方法收尾：把第4讲的六条做题路线各挂上对应例题，**套路与例题双向可查**。定理与证明见 [[04-3 高频结论与证明]]，题型入口见 [[04-2 典型例题#🗂️ 题型导航|题型导航]]。

## 🧮 4.24 解题套路

1. **具体方程**：行化简 → 判相容 → 找自由变量 → 写特解与齐次方向 → 代回。
   （例题：[[04-1-1 解的结构与基础解系#🧮 4.4 跟着一个教材示例走到通解|教材示例]]、[[04-2 典型例题#✏️ 四道热身自测|热身3]]）
2. **含参方阵**：行列式找降秩候选值 → 每个候选值检查增广矩阵，不能跳过无解分支。
   （例题：[[04-2-1 含参数方程组#✏️ 4.8 教材例4.8：有两个不同解|教材例4.8]]、[[04-2 典型例题#✏️ 四道热身自测|热身2]]）
3. **抽象通解**：用已知关系构造解 → 验无关 → 验个数 $n-r(A)$ → 加一个特解。
   （例题：[[04-2-2 已知解与列向量关系#🧩 4.9 教材例4.9：由已知解构造通解|教材例4.9]]、[[04-2-2 已知解与列向量关系#🔤 4.10 教材例4.10：把列向量关系翻译成解|教材例4.10]]、[[04-2-2-a 由通解反推列向量与行元素和#✏️ 教材例4.11（书内 p.127）：由通解反推列向量的表示关系|教材例4.11]]）
4. **公共解**：联立；有现成通解时，先考虑代入以减少未知参数。
   （例题：[[04-2-3 公共解与同解方程组#🔗 4.11 公共解：同时满足两组方程|教材例4.12]]）
5. **同解**：证明互相包含；若一组只是多了几条方程，就检查旧通解是否自动满足新增方程。
   （例题：[[04-2-3 公共解与同解方程组#⚖️ 4.12 同解：加入新方程后没有丢解|教材例4.13]]、[[04-2-3 公共解与同解方程组#✏️ 4.13 教材例4.14：用已有特解证明同解|教材例4.14]]、[[04-2-6 增添齐次方程的参数条件|P125 第14题]]）
6. **行列变换**：先分清“秩不变”“关系系数不变”和“同解”；若列变换后求得新变量的解，按记录的可逆矩阵还原。
   （例题：[[04-4 行列变换、线性相关性与解的关系#✏️ 例1：列关系没变，但行关系的系数变了|例1]]、[[04-4 行列变换、线性相关性与解的关系#✏️ 例2：秩不变，指定的两列却由无关变成相关|例2]]）

> [!tip] 套路和例题的双向对照
> 每条套路都挂了例题；反过来，[[04-2 典型例题#🗂️ 题型导航|题型导航]]里每道题也标了它用第几条套路。例题缺哪一条，就回到对应小节补练。
