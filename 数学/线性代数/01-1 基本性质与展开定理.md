# 第1讲（一） 基本性质与展开定理

## 基本性质

| 性质         | 内容                                                                       |
| :----------- | :------------------------------------------------------------------------- |
| 转置         | $\lvert A^{T}\rvert=\lvert A\rvert$                                        |
| 换行（列）   | 对换两行，行列式**变号**                                                   |
| 数乘         | 某一行乘 $k$ → 行列式乘 $k$；整个矩阵乘 $k$：$\lvert kA\rvert=k^{n}\lvert A\rvert$ |
| 拆分         | 某一行是两组数之和 → 可拆成两个行列式之和（**只拆一行**）                   |
| 倍加         | 某行加上另一行的 $k$ 倍，行列式**不变**                                     |
| 乘积         | $\lvert AB\rvert=\lvert A\rvert\lvert B\rvert$（同阶方阵；但 $\lvert A+B\rvert\ne\lvert A\rvert+\lvert B\rvert$！） |
| 相关推论     | 两行相同或成比例 → $=0$；有一行全零 → $=0$                                  |

---

## 展开定理

按第 $i$ 行展开：$\boxed{\lvert A\rvert=\sum\limits_{j=1}^{n}a_{ij}A_{ij}}$（$A_{ij}=(-1)^{i+j}M_{ij}$ 为代数余子式）。

**异乘变零**：某行元素乘**另一行**的代数余子式之和为零：$\boxed{\sum\limits_{j}a_{ij}A_{kj}=0\ (i\ne k)}$。

**求 $\sum k_j A_{ij}$ 型套路**：把 $A$ 的第 $i$ 行换成 $(k_1,\dots,k_n)$ 后的新行列式。

> [!tip] 张宇口诀（余子式 / 代数余子式线性组合）
> - **大 $A$ 配小 $a$，逆用展开式**：当组合系数 $(k_1,\dots,k_n)$ 恰好等于 $A$ 的第 $i$ 行 $(a_{i1},\dots,a_{in})$ 时，$\sum_j k_j A_{ij}=\sum_j a_{ij}A_{ij}=|A|$。
> - **大 $A$ 配小 $k$，$k$ 把小 $a$ 吃**：当组合系数与第 $i$ 行元素**不一致**时，把第 $i$ 行元素**替换**成 $(k_1,\dots,k_n)$ 后求新行列式即为答案。
> - 若题目给的是**余子式** $M_{ij}$ 组合，先用 $M_{ij}=(-1)^{i+j}A_{ij}$ 化成代数余子式 $A_{ij}$ 的组合再套上面两条。
> - 若某行系数与组合系数**整行相同**则该项按"异乘变零"取 $0$，不必算。

**拉普拉斯展开（按多行/多列展开）**：取第 $i_1<\cdots<i_k$ 行与第 $j_1<\cdots<j_k$ 列交叉处的 $k$ 阶子式 $M$，
及其代数余子式 $A=(-1)^{(i_1+\cdots+i_k)+(j_1+\cdots+j_k)}\overline M$（$\overline M$ 为划去这些行、列后余下的 $n-k$ 阶子式），则
$$
\lvert A\rvert=\sum M\cdot A\ \ (\text{对全部 }k\text{ 阶子式求和})
$$

> [!tip] 用法
> 最常用的是**按含零最多的行/列先化出"$\begin{vmatrix}A&O\\C&B\end{vmatrix}$"型分块**，直接得 $\lvert A\rvert\lvert B\rvert$。
> 这就是拉普拉斯展开的特例（主对角分块公式 $\begin{vmatrix}A&O\\C&B\end{vmatrix}=\lvert A\rvert\lvert B\rvert$、
> 副对角分块公式 $\begin{vmatrix}O&A_m\\B_n&O\end{vmatrix}=(-1)^{mn}\lvert A\rvert\lvert B\rvert$ 均由它导出）。
> 考试很少要求按任意 $k$ 行展开，记住分块特例即可。
