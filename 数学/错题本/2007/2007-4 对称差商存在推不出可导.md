# 2007 数二第 4 题：对称差商存在，推不出可导

> [!abstract] 错题定位
> **错因**：本题选 A（本次反馈只说"选的 A"，没说明当时怎么排除的 D）。A 其实是**真命题**：$f(x)/x$ 有有限极限 ⟹ $f(x)=x\cdot\frac{f(x)}{x}\to0$，再由 $f$ 在 0 连续得 $f(0)=0$。四个命题里唯一错的是 D。
> **答案**：D。
> 原题与完整推导见 [[2007年考研数学二答案与解析#一、选择题（1～10）|2007.4 解析]]——**一律不抄**。

#### ❌ 我卡在哪

> [!warning] 选了 A；其实 A、B、C 都能推出来，D 才是假的
> 1. **A 为什么真**：$f(x)/x$ 有有限极限 $L$（题注"极限存在"指有限的两侧极限），于是 $f(x)=x\cdot\dfrac{f(x)}x\to 0\cdot L=0$；又 $f$ 在 0 连续，故 $f(0)=\lim\limits_{x\to0}f(x)=0$。**$f(0)=0$ 是必然结论**，不是额外交代的条件，所以 A 没说错。
> 2. **D 为什么假**：把分子换成 $f(x)-f(-x)$ 之后，函数里**偶的部分被相减消掉了**（偶函数满足 $f_{\text{偶}}(x)=f_{\text{偶}}(-x)$），差商只剩下奇部分的信息；可 $f'(0)$ 要看整条曲线在 0 两侧的斜率。反例取到最小：$f(x)=|x|$ 时分子恒为 0、比值恒为 0（极限存在），但左右导数分别是 $-1$ 与 $1$，不可导 ⟹ D 假。
> 3. **本次反馈没说明当时的想法**：只说了"选的 A"。如果当时是把 D 当成了"可导的等价条件"（把对称差商当成导数定义），要把这一点补进这里；如果卡在 A 的"分子趋于 0"那一步，重点看下面第 ①、② 条。

> [!note] 机制：对称差商只看函数的"奇部"
> 把 $f$ 拆成偶部与奇部：
>
> $$e(x)=\frac{f(x)+f(-x)}2,\qquad o(x)=\frac{f(x)-f(-x)}2,\qquad f=e+o .$$
>
> 两种差商分别是
>
> $$\frac{f(x)-f(-x)}{x}=\frac{2o(x)}x,\qquad \frac{f(x)+f(-x)}x=\frac{2e(x)}x .$$
>
> 奇函数天然满足 $o(0)=0$，所以"$\dfrac{f(x)-f(-x)}x$ 极限存在"等价于**奇部 $o$ 在 0 可导**——它完全看不到偶部 $e$。而真正的导数 $f'(0)=e'(0)+o'(0)$ 要求两者都在 0 可导。$|x|$ 恰好是纯偶的（$e=|x|$、$o\equiv0$）：对称差商恒为 0，函数却在 0 有尖点。**要推翻 D，只需找一个在 0 不可导的偶函数。**

#### ✅ 纠正的关键一步

> [!tip] 第一手只有一句：极限存在 ⟹ 分子必须趋于 0
> **A、B 共用这一手**：若 $\dfrac{g(x)}x$ 在 $x\to0$ 时有**有限**极限 $L$，则
>
> $$\lim_{x\to0}g(x)=\lim_{x\to0}x\cdot\frac{g(x)}x=0\cdot L=0 .$$
>
> 取 $g(x)=f(x)$，配连续性得 $f(0)=0$（A 真）；取 $g(x)=f(x)+f(-x)$，由连续性 $g(x)\to2f(0)$，又必须为 0，得 $f(0)=0$（B 也真）。
>
> **C 的正当理由**：A 已给出 $f(0)=0$，于是
>
> $$f'(0)=\lim_{x\to0}\frac{f(x)-f(0)}x=\lim_{x\to0}\frac{f(x)}x=L,$$
>
> 导数存在且等于 $L$——**普通差商才是导数的定义式**。
>
> **D 的反例（记牢）**：
>
> $$f(x)=|x|:\qquad \frac{f(x)-f(-x)}x\equiv0\ \text{极限存在},\qquad f'_-(0)=-1\ne1=f'_+(0).$$
>
> **口诀**：**"分母是 $x$、分子趋于 0 就能读出点值；把 $f(x)-f(-x)$ 当差商，等于闭着眼只看奇部——偶部的尖点被藏起来了。"**
