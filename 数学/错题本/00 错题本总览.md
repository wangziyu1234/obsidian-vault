# 错题本总览

> [!abstract] 本页定位

## 🎯 今天先做

包含今天到期与逾期的题，按到期先后排列。点击题目开始复习。

```dataview
TABLE WITHOUT ID link(file.path, file.name) AS "题目", topic AS "专题", dateformat(min(pending.due), "MM-dd") AS "到期", choice(min(pending.due) < date(today), "逾期 " + string(round((date(today) - min(pending.due)).days)) + " 天", "今天") AS "提醒"
FROM #错题
WHERE file.folder != "templates" AND type = "mistake" AND (mastery = 1 OR mastery = 2)
FLATTEN list(filter(file.tasks, (t) => !t.completed AND startswith(t.text, "错题复习") AND t.due)) AS pending
WHERE length(pending) > 0 AND min(pending.due) <= date(today)
SORT min(pending.due) ASC, year ASC, no ASC
```

*打开题目勾选当前一轮，也可以在下方「完整排期」直接勾选。提醒会保留到你打勾为止。*

## 🗂️ 全部错题

按需要展开；勾掉当前一轮后，总览自动显示下一条未完成的日期。

> [!note]- 尚未掌握 · 查看全部题目与下次日期
> ```dataview
> TABLE WITHOUT ID link(file.path, file.name) AS "题目", topic AS "专题", choice(mastery = 0, "已挂起", choice(mastery = 1, "待练习", "待巩固")) AS "状态", choice(mastery = 0, "—", choice(length(pending) = 0, "本轮已完成", dateformat(min(pending.due), "MM-dd"))) AS "下次复习"
> FROM #错题
> WHERE file.folder != "templates" AND type = "mistake" AND mastery < 3
> FLATTEN list(filter(file.tasks, (t) => !t.completed AND startswith(t.text, "错题复习") AND t.due)) AS pending
> SORT mastery ASC, min(pending.due) ASC, year ASC, no ASC
> ```

> [!note]- 暂时挂起 · 想重新拿回的分
> 准备重新练时，告诉我题号，恢复后续四轮复习；也可以自行用「记录本次复习」记录表现并恢复排期。
>
> ```dataview
> TABLE WITHOUT ID link(file.path, file.name) AS "题目", topic AS "专题", cause AS "原因"
> FROM #错题
> WHERE file.folder != "templates" AND type = "mistake" AND mastery = 0
> SORT year ASC, no ASC
> ```
>
> 弃题前先问：这题的方法，换一道选择题还会不会用？

> [!note]- 完整排期 · 可直接勾选本次复习
> 次日、第 3 天、第 7 天、第 30 天提前排好。复习没问题就勾当前一轮；后续提醒保留，不必运行快捷命令。
>
> ```tasks
> not done
> path includes 数学/错题本
> description regex matches /^错题复习/
> has due date
> sort by due
> ```

## 📈 复盘统计

每周看一次：哪些错因反复出现，哪些专题还需要回到讲次补基础。

> [!note]- 按错因看 · 常见卡点
> ```dataview
> TABLE WITHOUT ID c AS "错因", length(rows) AS "题数"
> FROM #错题
> WHERE file.folder != "templates" AND type = "mistake"
> FLATTEN cause AS c
> GROUP BY c
> SORT length(rows) DESC
> ```
>
> 一道题可有两个主因，因此各类题数相加可能超过收录总数。

> [!note]- 按专题看 · 知识点分布
> ```dataview
> TABLE WITHOUT ID topic AS "专题", length(rows) AS "题数", round(average(rows.mastery), 1) AS "平均掌握"
> FROM #错题
> WHERE file.folder != "templates" AND type = "mistake"
> GROUP BY topic
> SORT length(rows) DESC
> ```
>
> 掌握度：0 挂起 · 1 待练习 · 2 待巩固 · 3 已掌握。勾选表示本次已复习，全部勾完也不会自动归档。

## 🛠️ 排期检查

> [!warning]- 检查日期或重复 · 正常情况下没有待处理项
> ```dataview
> TABLE WITHOUT ID link(file.path, file.name) AS "题目", length(pending) AS "待办数", length(filter(pending, (t) => t.due)) AS "有效日期数"
> FROM #错题
> WHERE file.folder != "templates" AND type = "mistake"
> FLATTEN list(filter(file.tasks, (t) => !t.completed AND startswith(t.text, "错题复习"))) AS pending
> WHERE length(pending) > 4 OR length(filter(pending, (t) => t.due)) != length(pending) OR length(unique(pending.due)) != length(pending) OR any(pending, (t) => contains(t.text, "当天")) OR ((mastery = 0 OR mastery = 3) AND length(pending) > 0) OR review != null
> SORT year ASC, no ASC
> ```
>
> 四轮全部勾完、没有待办是正常状态。误勾时取消勾选即可；日期异常或重复任务交给我核对。
