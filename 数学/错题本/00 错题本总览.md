# 错题本总览

> [!abstract] 本页定位
> 错题本的**索引页与看板**：自动列出到期未做、尚未掌握、错因与专题分布，手写索引只保留题目导航。
>
> 复习后打开当前错题卡，用 **QuickAdd: 记录本次复习** 记录表现；操作与字段说明见 [[01 错题本使用规范]]。

## 📊 看板

> [!note] 看板自动读取卡片
> Dataview 按 `#错题` 标签和 `type: mistake` 收题，排除模板；下次日期只读取正文中尚未完成的「错题复习」任务的 `📅` 到期日。以下是普通 Dataview 查询，无须开启 JavaScript 查询。

### 待复习（到期且尚未掌握）

```dataview
TABLE year AS 年份, no AS 题号, topic AS 专题, cause AS 错因, task.due AS 到期日, mastery AS 掌握
FROM #错题
WHERE file.folder != "templates" AND type = "mistake" AND (mastery = 1 OR mastery = 2)
FLATTEN file.tasks AS task
WHERE !task.completed AND startswith(task.text, "错题复习") AND task.due AND task.due <= date(today)
SORT task.due ASC, year ASC, no ASC
```

> [!note] 先看到期日，再记录本次表现
> 到期日早于今天就是逾期；补做前一直保留，补做后再按实际完成日安排下一次。表格为空且下方「排期异常」也为空，才表示当前没有到期任务。
>
> 不必在看板上直接勾框。打开卡片，用 [[01 错题本使用规范#✅ 复习完了怎么标|记录本次复习]] 一次完成记录、排期和掌握度更新。

### 尚未掌握（全部，含还没到期的）

```dataview
TABLE year AS 年份, no AS 题号, topic AS 专题, cause AS 错因, mastery AS 掌握, min(pending.due) AS 下次复习
FROM #错题
WHERE file.folder != "templates" AND type = "mistake" AND mastery < 3
FLATTEN list(filter(file.tasks, (t) => !t.completed AND startswith(t.text, "错题复习") AND t.due)) AS pending
SORT mastery ASC, min(pending.due) ASC, year ASC, no ASC
```

`mastery: 0` 是主动挂起，没有下次日期；`1/2` 应各有一个待办。此表保留逾期日期，避免把欠下的复习隐藏成空白。

### 排期异常（进行中的题没有有效待办，或待办重复）

```dataview
TABLE year AS 年份, no AS 题号, mastery AS 掌握, length(pending) AS 待办数, length(filter(pending, (t) => t.due)) AS 有日期数
FROM #错题
WHERE file.folder != "templates" AND type = "mistake" AND (mastery = 1 OR mastery = 2)
FLATTEN list(filter(file.tasks, (t) => !t.completed AND startswith(t.text, "错题复习"))) AS pending
WHERE length(pending) != 1 OR length(filter(pending, (t) => t.due)) != 1
SORT year ASC, no ASC
```

这里正常应为空。若误点了复习任务的方框，撤销误勾后用「记录本次复习」操作；若发现重复待办或日期损坏，先核对卡片正文，避免漏掉实际记录。

### 跳过挂起（`mastery: 0`，主动放弃、不排复习节点）

整题跳过、**本轮不打算拿分**的题挂在这里。准备重新开始时，先做题，再在当前卡片调用「记录本次复习」，即可恢复正常排期。弃题判据见 [[01 错题本使用规范|使用规范]]。

```dataview
TABLE year AS 年份, no AS 题号, topic AS 专题, cause AS 错因, file.mtime AS 最后改动
FROM #错题
WHERE file.folder != "templates" AND type = "mistake" AND mastery = 0
SORT year ASC, no ASC
```

> [!warning] 0 档 = 明确挂起，卡片与链接保留
> 弃之前先问：「**这题的方法，换一道选择题还会不会用？**」常用方法应留下继续练；即使放弃技巧型证明，也先写出能拿过程分的那一步。

### 按错因统计

```dataview
TABLE length(rows) AS 题数
FROM #错题
WHERE file.folder != "templates" AND type = "mistake"
FLATTEN cause AS c
GROUP BY c
SORT length(rows) DESC
```

### 按专题统计

```dataview
TABLE length(rows) AS 题数, round(average(rows.mastery), 1) AS 平均掌握
FROM #错题
WHERE file.folder != "templates" AND type = "mistake"
GROUP BY topic
SORT length(rows) DESC
```

> [!tip] 两张统计表怎么用
> 某个 `cause` 连续两周居首 → 回去补对应讲次；某个 `topic` 的题数多而平均掌握低 → 那个专题要系统重过。字段取值见 [[01 错题本使用规范#🏷️ 字段与标签约定|字段与标签约定]]。

### 复习待办（Tasks 汇总）

只汇总带到期日的「错题复习」任务；本栏供查看排期，**复习后请打开卡片使用「记录本次复习」**，这样表现与下次日期会一并保存。

```tasks
not done
path includes 数学/错题本
description regex matches /^错题复习/
has due date
sort by due
```
