# 错题本总览

> [!abstract] 本页定位
> **把每一次错，变成下一次会。** 先完成到期复习，再按需要回看专题与旧题。

[[#🎯 今天先做|今日复习]] · [[#🗂️ 全部错题|全部错题]] · [[#📈 复盘统计|复盘统计]] · [[#📚 按年份找题|年份索引]] · [[01 错题本使用规范|使用指南]]

> [!note|review-metrics] 复习进度
> ```dataview
> TABLE WITHOUT ID length(filter(rows, (p) => (p.mastery = 1 OR p.mastery = 2) AND any(p.file.tasks, (t) => !t.completed AND startswith(t.text, "错题复习") AND t.due AND t.due <= date(today)))) AS "今日待复习", length(rows) AS "已收录", length(filter(rows, (p) => p.mastery = 2)) AS "待巩固", length(filter(rows, (p) => p.mastery = 3)) AS "已掌握"
> FROM #错题
> WHERE file.folder != "templates" AND type = "mistake"
> GROUP BY true
> ```

> [!tip] 复习后的一个动作
> 打开错题 → **Ctrl+P** → **记录本次复习** → 选择表现。下次日期自动安排，无须提前勾框。

## 🎯 今天先做

包含今天到期与逾期的题，按到期先后排列。点击题目开始复习。

```dataview
TABLE WITHOUT ID link(file.path, file.name) AS "题目", topic AS "专题", dateformat(task.due, "MM-dd") AS "到期", choice(task.due < date(today), "逾期 " + string(round((date(today) - task.due).days)) + " 天", "今天") AS "提醒"
FROM #错题
WHERE file.folder != "templates" AND type = "mistake" AND (mastery = 1 OR mastery = 2)
FLATTEN file.tasks AS task
WHERE !task.completed AND startswith(task.text, "错题复习") AND task.due AND task.due <= date(today)
SORT task.due ASC, year ASC, no ASC
```

*清单为空时，可到下方「排期检查」确认没有遗漏，再挑一道旧题自测。*

## 🗂️ 全部错题

按需要展开；复习状态与日期会随记录自动更新。

> [!note]- 尚未掌握 · 查看全部题目与下次日期
> ```dataview
> TABLE WITHOUT ID link(file.path, file.name) AS "题目", topic AS "专题", choice(mastery = 0, "已挂起", choice(mastery = 1, "待练习", "待巩固")) AS "状态", dateformat(min(pending.due), "MM-dd") AS "下次复习"
> FROM #错题
> WHERE file.folder != "templates" AND type = "mistake" AND mastery < 3
> FLATTEN list(filter(file.tasks, (t) => !t.completed AND startswith(t.text, "错题复习") AND t.due)) AS pending
> SORT mastery ASC, min(pending.due) ASC, year ASC, no ASC
> ```

> [!note]- 暂时挂起 · 想重新拿回的分
> 准备重新练时，先做题，再打开卡片运行「记录本次复习」。
>
> ```dataview
> TABLE WITHOUT ID link(file.path, file.name) AS "题目", topic AS "专题", cause AS "原因"
> FROM #错题
> WHERE file.folder != "templates" AND type = "mistake" AND mastery = 0
> SORT year ASC, no ASC
> ```
>
> 弃题前先问：这题的方法，换一道选择题还会不会用？

> [!note]- 完整排期 · 查看所有下次待办
> 这里用来查日期；记录复习请使用快捷命令。
>
> ```tasks
> not done
> path includes 数学/错题本
> description regex matches /^错题复习/
> has due date
> sort by due
> ```

## 📈 复盘统计

每周看一次：哪些错因反复出现，哪些专题还需要回到讲次补基础。

> [!note]- 按错因看 · 常见卡点
> ```dataview
> TABLE WITHOUT ID c AS "错因", length(rows) AS "题数"
> FROM #错题
> WHERE file.folder != "templates" AND type = "mistake"
> FLATTEN cause AS c
> GROUP BY c
> SORT length(rows) DESC
> ```
>
> 一道题可有两个主因，因此各类题数相加可能超过收录总数。

> [!note]- 按专题看 · 知识点分布
> ```dataview
> TABLE WITHOUT ID topic AS "专题", length(rows) AS "题数", round(average(rows.mastery), 1) AS "平均掌握"
> FROM #错题
> WHERE file.folder != "templates" AND type = "mistake"
> GROUP BY topic
> SORT length(rows) DESC
> ```
>
> 掌握度：0 挂起 · 1 待练习 · 2 待巩固 · 3 已掌握。

## 🛠️ 排期检查

> [!warning]- 检查遗漏或重复 · 正常情况下没有待处理项
> ```dataview
> TABLE WITHOUT ID link(file.path, file.name) AS "题目", length(pending) AS "待办数", length(filter(pending, (t) => t.due)) AS "有效日期数"
> FROM #错题
> WHERE file.folder != "templates" AND type = "mistake" AND (mastery = 1 OR mastery = 2)
> FLATTEN list(filter(file.tasks, (t) => !t.completed AND startswith(t.text, "错题复习"))) AS pending
> WHERE length(pending) != 1 OR length(filter(pending, (t) => t.due)) != 1
> SORT year ASC, no ASC
> ```
>
> 误勾待办时先撤销，再使用「记录本次复习」；发现重复任务或损坏日期，先核对卡片。
