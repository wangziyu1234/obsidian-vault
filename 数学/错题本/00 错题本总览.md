# 错题本总览

> [!abstract] 本页定位
> 错题本的**索引页与看板**：做真题时错的题一题一篇（收在下方的年份子文件夹里），这里只负责"看"——自动列出到期未做、尚未掌握、错因与专题分布，外加一张手写索引方便按年份扫一眼。
>
> **怎么录、字段怎么填、复习怎么标、交给 AI 怎么发 → 全部搬到 [[01 错题本使用规范]]**，本页不再重复。

## 📊 看板

> [!note] 查询用标签而不是文件夹
> 下面几张表一律用 `FROM #错题`（而不是 `FROM "数学/错题本"`），并按 `file.folder != "templates"` 把模板排除。**好处：以后再挪文件夹、加年份子目录，看板都不用改**；只要错题篇带了 `#错题` 标签就会被收进来（模板自带该标签，所以才有那条排除）。

### 待复习（`review` 里已到期且未掌握）

```dataview
TABLE year AS 年份, no AS 题号, kind AS 题型, topic AS 专题, cause AS 错因, min(filter(review, (d) => d <= date(today))) AS 到期日, mastery AS 掌握
FROM #错题
WHERE file.folder != "templates" AND type = "mistake" AND mastery < 3 AND any(review, (d) => d <= date(today))
SORT review ASC
```

> [!warning] 这张表空着 = **今天没有到期的复习节点**，不是坏了
> 查询条件只有一句"有没有 `review` 日期 $\le$ 今天"。当天那一档做完后就把该日期从 `review` 里删掉，于是下一个节点变成明天——**当天做完后，这张表当天必然是空的**，要到明天才会重新有内容。
>
> - 想确认看板有没有失效：看下面的「**尚未掌握（全部）**」——只要它列出了原题，就说明查询一切正常；
> - `到期日` 那一列比今天早多少天，就是欠了多少天的债，详见
>   [[01 错题本使用规范#✅ 复习完了怎么标（三处，缺一看板不刷新）|复习标注规则]] 里「`review` 不会自动顺延」的说明。

### 尚未掌握（全部，含还没到期的）

这张**永远有内容**（只要有 `mastery < 3` 的错题），用来代替上面那张判断看板是否正常工作：

```dataview
TABLE year AS 年份, no AS 题号, topic AS 专题, cause AS 错因, mastery AS 掌握, min(filter(review, (d) => d >= date(today))) AS 下次复习, length(review) AS 剩余节点
FROM #错题
WHERE file.folder != "templates" AND type = "mistake" AND mastery < 3
SORT review ASC
```

> [!note] 「剩余节点 = 0」= 该题是跳过的（`mastery: 0`），还没排任何复习节点
> 这张表收 `mastery < 3` 的全部错题，所以跳过的题也在里面；它没有 `review` 日期，于是「下次复习」为空、「剩余节点」为 `0`。具体怎么办见下面那张「跳过挂起」。

### 跳过挂起（`mastery: 0`，主动放弃、不排复习节点）

整题跳过、**本轮不打算拿分**的题挂在这里（目前主要是**证明题**）。**它们不进上面的「待复习」**（`review` 是空的），但会一直留在清单上：哪天决定要了，把 `mastery` 改成 1 并按当天 / 次日 / +3 / +7 / +30 排满节点，就转入正常复习流程。规则与「哪些能弃、哪些不能弃」的判据见 [[01 错题本使用规范|使用规范]]里 `mastery: 0` 那一段。

```dataview
TABLE year AS 年份, no AS 题号, topic AS 专题, cause AS 错因, file.mtime AS 最后改动
FROM #错题
WHERE file.folder != "templates" AND type = "mistake" AND mastery = 0
SORT year ASC, no ASC
```

> [!warning] 0 档 = 明确放弃，不是"忘了"，也不是"删除"
> 这张表的作用是**让你看得见自己主动丢了哪些分**。弃题本身没问题——目标分不上 130 时，技巧型证明题的性价比确实低——但两条底线要守住：一是弃之前用一句判据过一下「**这题的方法，换一道选择题还会不会用？**」；二是**那个"白送的一步"仍然要写**（如"零点定理给出至少一个零点"），过程分按步给，一行也是分。

### 按错因统计

```dataview
TABLE length(rows) AS 题数
FROM #错题
WHERE file.folder != "templates" AND type = "mistake"
FLATTEN cause AS c
GROUP BY c
SORT length(rows) DESC
```

### 按专题统计

```dataview
TABLE length(rows) AS 题数, round(average(rows.mastery), 1) AS 平均掌握
FROM #错题
WHERE file.folder != "templates" AND type = "mistake"
GROUP BY topic
SORT length(rows) DESC
```

> [!tip] 两张统计表怎么用
> 某个 `cause` 连续两周居首 → 回去补对应讲次；某个 `topic` 的题数多而平均掌握低 → 那个专题要系统重过。字段取值的完整说明见 [[01 错题本使用规范#🏷️ 字段与标签约定|字段与标签约定]]。

### 复习待办（Tasks 汇总）

在任意错题里写 `- [ ] 2026-10-05 复盘` 这类待办即可被下面这段收上来：

```tasks

path includes 数学/错题本

```
