# 错题本总览

> [!abstract] 本页定位
> 做真题时的错题，**一题一篇**收在本目录（文件名 `年份-题号 关键词`）。本页是本子说明、字段约定与自动看板；每题正文套 `templates\错题模板.md`（Templater / QuickAdd 可直接套）。

## 🧭 使用流程

1. **做卷时标记**：在当年解析页对应题号旁加一行
   > 错题：2025-19 二次型参数
   这样从真题页能直接跳进错题本，不必回头翻。
2. **建篇**：用 QuickAdd / Templater 套 `templates\错题模板.md`，文件名写 `年份-题号 关键词`（如 `2025-19 二次型参数`）。
3. **填四块**（顺序就是复盘顺序）：
   - 原题（题干可截图，图片放 `附件\`，正文用 `![[图.png|430]]`）；
   - **我当时怎么错的**——写清卡在哪一步、被什么带偏（只抄正确答案等于白做）；
   - 正确解法（每步独立公式块）；
   - 同类与变式：讲次笔记链接、教材例、下次要盯的三个点。
4. **排复习**：frontmatter 的 `review` 写当天、次日、第 3 天、第 7 天、第 30 天；`mastery` 从 1 涨到 3 就归档。
5. **每周看一次看板**（下方）：待复习清单 + 错因统计。某个错因连续两周居首，就回去补对应讲次。

## ✅ 复习完了怎么标（三处，缺一看板不刷新）

| 位置 | 怎么改 | 作用 |
| :-- | :-- | :-- |
| 正文「复习记录」 | 在该行**点一下方框**，把未完成勾成完成 | Tasks 自动补 `✅ 日期`，形成复盘日志 |
| frontmatter `review` | **删掉已完成的那个日期**，只留未来的 | 看板查询是 `any(review, d <= today)`，不删就永远显示"待复习" |
| frontmatter `mastery` | 1 → 2（会做但不熟）→ 3（稳） | `mastery: 3` 后彻底移出待复习，视为归档 |

> [!warning] `review` 里的日期只能**删除**，不能划掉或加注
> `review` 是 YAML 日期列表，Dataview 靠类型判断到期。写成 `~~2026-09-18~~`、`2026-09-18(已做)` 都会变成普通字符串，**看板行为不可预料**。做完一次就把那一个日期删掉，其余日期保持原样。

> [!note] 勾的是"动作"，`mastery` 才是"掌握"
> **打勾 ≠ 做对**。勾框记录的是"这一档复习动作完成"，所以**做错也该打勾**——做对做错交给 `mastery` 表达。两个理由：一是只有先勾掉、再删日期，看板才不会一直催；二是"没做对所以不敢勾"会让日期越积越多，最后干脆不看错题本。
>
> `mastery` 才是掌握度，宁低勿高：
>
> | 值 | 判定标准 |
> | :-- | :-- |
> | 1 | 还做不对，或必须看答案才能走完 |
> | 2 | 不看答案能做对，但慢、要靠"提醒自己关键点"才不出错 |
> | 3 | 一看就会，能讲清当时为什么错，**连续两次通过** → 归档 |
>
> **这次又错了怎么办**：照样打勾 + 删掉本次日期，在那行写明"新错法是什么"，`mastery` 退回 1，并把剩余日期按"明天、+3、+7"从今天起重排（30 天节点保留）。

复盘时在勾好的那一行后面补一句当时表现，比只打勾有用：

```
- [x] 2026-09-17 当天重做 ✅ 2026-09-17 —— 一次做对，但提示自己落笔前先看问号左边
- [x] 2026-09-18 次日    ✅ 2026-09-18 —— 还是漏 dx，直到想起"问 dy 就写系数×dx"才对
```

> [!tip] 一句话记住
> **勾框是留痕、删日期是排下次、涨 `mastery` 是归档**；只勾框不动 frontmatter，看板会一直催你。
>
> 另外：`review` 是**写死的日期，不会自动顺延**——漏做只会在「待复习」里一直显示（看 `到期日` 列就是欠债天数），不会帮你把后面的节点往后挪，详见下方「待复习」表下的说明。

## 🏷️ 字段与标签约定

| 字段 | 取值 | 说明 |
| :-- | :-- | :-- |
| `type` | `mistake` | 看板查询靠它筛，别写成别的 |
| `year` / `no` | 如 `2025` / `19` | 题号按当年试卷编号 |
| `kind` | 选择 / 填空 / 解答 | 便于看哪类题丢分 |
| `topic` | 对齐 [[考研数学二目录]] 的专题名 | 如「二次型」「一元函数微分学」 |
| `cause` | 概念不清 / 方法不会 / 计算出错 / 审题失误 / 时间不够 | 每次只标 1–2 个主因 |
| `mastery` | 1（刚错）→ 2（会做但不熟）→ 3（稳） | 到 3 就从待复习里消失 |
| `review` | 日期列表 | 到期的题会出现在「待复习」表 |

> [!tip] 错因只标主因
> 一道题常同时有审题和计算问题，但**先记最致命的那一个**。都记等于都没记，统计也失去意义。

## 📊 看板

### 待复习（`review` 里已到期且未掌握）

```dataview
TABLE year AS 年份, no AS 题号, kind AS 题型, topic AS 专题, cause AS 错因, min(filter(review, (d) => d <= date(today))) AS 到期日, mastery AS 掌握
FROM "数学/错题本"
WHERE type = "mistake" AND mastery < 3 AND any(review, (d) => d <= date(today))
SORT review ASC
```

> [!warning] 不复习不会自动顺延
> `review` 是一串**写死的日期**，错过就错过：查询只判断"有没有已到期的日期"，所以**漏做不会把后面的 D3/D7/D30 推后**，只是这条一直留在表里，`到期日` 那一列会越来越早——它就是你的"欠债天数"。
>
> 补做时有两条路，选一条即可：
>
> - **补做、后续节点不动**（省事）：把漏掉的那个日期从 `review` 里删掉，其余日期保持不变；
> - **整体后移一轮**（彻底追不上时用）：以补做当天为新起点重排还没做的日期，例如拖到 9-20 才补 D1，则把剩余日期改成次日、+3、+7、+30。
>
> 判断"现在该做哪一档"，看正文「复习记录」里**第一个没打勾的行**。

### 按错因统计

```dataview
TABLE length(rows) AS 题数
FROM "数学/错题本"
WHERE type = "mistake"
FLATTEN cause AS c
GROUP BY c
SORT length(rows) DESC
```

### 按专题统计

```dataview
TABLE length(rows) AS 题数, round(average(rows.mastery), 1) AS 平均掌握
FROM "数学/错题本"
WHERE type = "mistake"
GROUP BY topic
SORT length(rows) DESC
```

### 尚未掌握的题（`mastery` 小于 3）

```dataview
LIST
FROM "数学/错题本"
WHERE type = "mistake" AND mastery < 3
SORT mastery ASC, year DESC
```

### 复习待办（Tasks 汇总）

```tasks

path includes 数学/错题本

```

## 🤝 交给 AI 建篇时怎么发

原题与标准解法不用抄——库里就有整卷试题与解析。你只要发**题号 + 你当时怎么错的**，我按模板建篇、排复习日期、挂好链接并提交。

最小格式（一题一段，多题连着发也行）：

```
2025 数二 19
我错在：把行元素之和当成特征值之和，直接写了 3,3,3
卡点：没注意题设给了二重特征值 1
（可选）耗时 12 分钟 / 是蒙对的
```

我会做这些事：

1. 从 `YYYY年考研数学二试题.md`、`…答案与解析.md` 取原题与标准解法（逐步公式块）；
2. 按 `templates\错题模板.md` 建 `数学\错题本\YYYY-NN 关键词.md`，填 `year/no/kind/topic/cause/mastery/review`（复习日期自动排当天、次日、第 3/7/30 天）；
3. 在当年解析页对应题号旁补一行 `> 错题：同名错题页`；
4. 到讲次笔记里找同型例题挂「同类与变式」，跑一遍校验后提交。

> [!tip] 两件只有你能提供的信息
> - **当时的想法**：哪怕一句「我以为…」「没看出…」「算到一半慌了」都比标准解法值钱；
> - **是否蒙对**：蒙对的题也建议收（标 `cause: 审题失误`、`mastery: 1`），这类题二刷最容易翻车。
>
> 错因标签我先按五类给初判，拿不准会写 `cause: [待确认]`，你一句话我就改。
