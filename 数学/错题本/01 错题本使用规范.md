# 错题本使用规范

> [!abstract] 本页定位
> 新建错题卡时填清当时错法；复习后只运行一次 **QuickAdd: 记录本次复习**。脚本保存表现、更新掌握度并安排下一次，看板见 [[00 错题本总览]]。
>
> 每题正文套 `templates/错题模板.md`。一题一篇，按年份放进 `数学/错题本/YYYY/`；根目录只留总览和本页，新年份有第一题时再建文件夹。

## 🧭 使用流程

1. **做卷时标记**：在当年解析页的题号旁加一行 `> 错题：`，后接该错题页的 wikilink，便于从解析直接跳转。
2. **建篇**：套 `templates/错题模板.md`，文件名写 `年份-题号 关键词`，如 `2025-19 二次型参数`。
3. **填四块**：abstract 写一句错因和答案；「我卡在哪」保留当时的错误想法；「纠正的关键一步」记录纠正这一处的公式与提醒；「同类与变式」链接讲次与同型真题。
4. **排第一轮**：普通新错题设 `mastery: 1`，正文只留一个当天到期的「错题复习」任务；整题跳过、主动挂起的设 `0`，不排待办。
5. **复习后记录**：打开该卡片运行「记录本次复习」，按真实表现选择结果。每周扫一次看板的待复习、跳过挂起与错因统计。

> [!warning] 原题与完整解法一律不抄
> 库里已有整卷试题与解析，错题卡只写解析页里没有的东西：**我卡在哪、纠正这一处的关键一步、下次要盯什么**。答案留在 abstract，便于对答案。
>
> 学习正文以 60~80 行为目标；复习历史随使用增长，**不要为了压行数删除历史或挤密公式**。删减优先顺序：备选解法 → 重抄的原题 → 方法补充说明 → 同卷相邻题链接。**「我卡在哪」永远保留，细节不删。**

## ✅ 复习完了怎么标

1. **打开当前错题卡**，按 `Ctrl+P`，搜索并运行 **QuickAdd: 记录本次复习**。
2. 选择 **仍做不对／提示后做对／独立做对**。
3. 可选写一句备注，如「仍漏初值」「独立完成，用时 8 分钟」；没有补充就留空。
4. 脚本一次写入完成记录、更新 `mastery`、安排唯一的下次任务。满足归档条件时，再由你明确选择是否归档。

> [!tip] 日常只做这一个操作
> 不用另改日期列表，也不用回索引改数字。**不要先手动勾框再运行命令**；命令会完成这一步。操作完成后看板自动读取新记录。
>
> 如果刚同步到另一台设备、命令还未出现，重载 QuickAdd 或重启 Obsidian 后再搜索。命令脚本位于 `templates/scripts/review-mistake.js`。

正文示例：

```markdown
- [x] 错题复习（当天） ✅ 2026-10-05 —— 提示后做对：仍漏初值
- [ ] 错题复习（次日） 📅 2026-10-06
```

`✅` 后是实际完成日期，`📅` 后是待办的到期日。**完成记录永久保留；尚未完成的复习任务只保留一条。**

| 内容 | 唯一维护位置 |
| :-- | :-- |
| 过去做过什么、表现如何 | 正文「复习记录」里的完成项与备注 |
| 下次什么时候复习 | 一条未完成任务的 `📅` 日期 |
| 当前掌握程度 | frontmatter 的数字属性 `mastery` |
| 总览看板与 Tasks 汇总 | 自动读取以上内容 |
| 手写索引 | 题号与考点导航，复习后不用修改 |

> [!note] 旧记录继续留着
> 过去勾选过的任务保留原文字、完成日期和复盘说明。**旧打勾只能说明做过，不能推断为独立做对**，因此不会凭旧勾选自动达成归档条件。
>
> 原来的 `review` 日期列表已取消；今后不要再添加。旧计划里还没完成的多个未来节点合并为一个下次任务，其后的日期等实际复习后再排。

### 下次日期怎么排

| 本次表现 | 掌握度 | 下次安排 |
| :-- | :-- | :-- |
| 仍做不对 | `1` | 实际完成日 +1 天，回到次日阶段 |
| 提示后做对 | `1` | 实际完成日 +1 天，回到次日阶段 |
| 独立做对 | `2` | 沿 D0 → D1 → D3 → D7 → D30 前进 |
| 达到归档条件并明确选择归档 | `3` | 不再留待办，历史保留 |

独立做对的相邻间隔依次是 **1、2、4、23 天**，都从本次实际完成日计算。阶段名「当天／次日／第 3 天／第 7 天／第 30 天」表示复习进度；漏做后不再硬套最初建卡日。第 30 天阶段完成但暂不归档，30 天后再测一次。

例如：原定 10 月 4 日做「第 3 天」，实际 10 月 5 日独立完成，则下一次「第 7 天」排到 **10 月 9 日**；若提示后才做对，则回到次日阶段，排 **10 月 6 日**。

> [!note] 逾期与同日补记
> 漏做时任务保持逾期，看板持续显示；实际补做后才重排下一次，不用把积欠的多个节点在同一天逐个补勾。
>
> 同一天补充记录不会变成两次隔日通过。记录结果应与实际表现一致，提示后完成就选「提示后做对」。

### 掌握度与归档

| `mastery` | 判定标准 |
| :-- | :-- |
| `0` | 整题跳过／主动挂起，本轮不打算拿这几分 |
| `1` | 仍做不对，或需要答案／提示才能完成 |
| `2` | 能独立做对，继续练熟或验证保持情况 |
| `3` | 连续两次在**不同日期**明确记录为独立做对，并由你选择归档 |

**归档由你决定。** 命令仅在满足条件时提供归档选项；你仍可选择继续复习。归档时移除下次待办，保留全部完成记录、卡片及链接。旧有归档说明也保留。

归档或挂起的题再次练习后，直接调用「记录本次复习」即可恢复排期；再错就退回 `1`。`mastery` 保持数字属性，不要改成文本。

### 跳过挂起怎么用

- 新收整题跳过的题设 `mastery: 0`，不创建复习待办；已有卡片挂起时只移除未来待办，保留历史。
- 不进入到期清单，但总览「跳过挂起」一直列出；0 档是明确选择，卡片不删。
- 决定重新练时，做完题再调用「记录本次复习」；若暂时不写卡，至少在解析页留 `> 错题：跳过（原因）`。
- 每周扫一次挂起清单，判断是否需要收回。

> [!tip] 弃题前问一句：这题的方法，换一道选择题还会不会用？
> 数二里能弃的是部分靠灵感的技巧型证明，**常用方法仍要练**。
>
> | 情形 | 处理 |
> | :-- | :-- |
> | **可弃**：需要自行构造辅助函数／反证的技巧型证明，如 2000.16 | `mastery: 0`，不排待办，`cause: 主动放弃` |
> | **慎弃**：外壳是零点定理、变上限积分求导、保序性、单调性的题 | 留在 1 档；这些方法在选择、填空、计算题里同样考 |
> | **底线**：先写出能直接得到的那一步，如由积分条件结合零点定理说明至少一个零点 | 过程分按步给，一行也是分 |
>
> 判据：**换一道选择题还会用到的方法，不该随整题一起放弃。**

## 🏷️ 字段与标签约定

| 字段 | 取值 | 说明 |
| :-- | :-- | :-- |
| `type` | `mistake` | 看板只收错题卡 |
| `year` / `no` | 如 `2025` / `19` | 题号按当年试卷编号 |
| `kind` | 选择 / 填空 / 解答 | 题型 |
| `topic` | 对齐 [[考研数学二目录]] 的专题名 | 专题统计使用 |
| `cause` | 概念不清 / 方法不会 / 计算出错 / 审题失误 / 时间不够 / 主动放弃 | 只标 1–2 个主因；主动放弃用于挂起 |
| `mastery` | 数字 `0 / 1 / 2 / 3` | 复习命令更新；归档需明确选择 |
| `tags` | 必须含 `错题` | 看板按标签收题 |

> [!tip] 错因只标主因
> 一道题可能同时有审题和计算问题，先记最致命的一个。拿不准时先保留具体错法，再核对分类。

## 🩺 交卷前的三秒自检（全是机械动作，不是技巧）

> [!warning] 2000 年三次错都出在这一类
> 11 题漏写 $+C$、14 题把 $\lvert\cos t\rvert$ 的周期看成 $2\pi$、18 题 $\int x^4$ 忘了给指数 $+1$ 且代入时又搞错一次——**都不是"不会"，是动作没走完**。

固定动作，做完题花半分钟过一遍：

1. **积分**：指数是否比原来 **$+1$**、系数是否 $\frac{1}{n+1}$、不定积分是否补了 $+C$；
2. **代上限**：**别急着代 $r$**——先把 $r$ 留在外面，让两项幂次对齐；代入的幂次必须与积分结果一致（$\frac{x^5}{5}$ 代出 $r^5$，不能"统一按 $x^2$ 代"）；
3. **同类项合并**：提出常数后各项应是**同一个量纲/幂次**（旋转体的两项都该是 $r^5$）；不一致 ⟹ 一定错；
4. **公式限定**：体积带 π、面积不带；周期函数先确认**最小正周期**（$\lvert\cos t\rvert$ 是 $\pi$ 不是 $2\pi$）；
5. **代值验证**：取个最简单的参数（如 $a=1$）看正负与量级——体积、面积**不可能为负**；
6. **答题完整**：回读题干问句——问"何时最大/最大是多少"，就必须有求导和最值两步；问「曲线方程为____」要写**带等号的方程**（$y=\dots$），别只填右边的表达式。
7. **几何对象对位**：点斜式 $y-y_0=k(x-x_0)$ 落笔前先抄下 $(x_0,y_0)$ 并填空，写完把该点代回验一遍；**切线＝导数、法线＝负倒数**，写完回读题干确认问的是哪个。

> [!tip] 一句话
> 「不会」靠讲次笔记补；「漏动作」只能靠交卷前这半分钟。

## 🤝 交给 AI 建篇时怎么发

原题与标准解法库里已有，只要发**题号 + 当时怎么错的**，我按模板建篇、排首次待办、挂链接并提交。

```text
2025 数二 19
我错在：把行元素之和当成特征值之和，直接写了 3,3,3
卡点：没注意题设给了二重特征值 1
（可选）耗时 12 分钟 / 是蒙对的
```

我会做这些事：

1. 从当年试题与答案解析核对原题和标准解法，错题卡里只链接。
2. 在年份目录建 `YYYY-NN 关键词.md`，填写 `year/no/kind/topic/cause/mastery`；正常新卡只创建一个当天到期的「错题复习」任务，不添加 `review`。
3. 在解析页题号旁补该卡片的 wikilink，找已有同型例题挂「同类与变式」，并在总览补题号导航。
4. 运行 `python .scripts/check-mistake-cards.py`，检查字段、小节、日期和唯一待办；再对改动笔记运行 `.scripts/check-notes.ps1`，确认结构、公式配对与链接后提交。

> [!tip] 两件只有你能提供的信息
> **当时的想法**：一句「我以为……」「没看出……」都比重抄标准解法有用。**是否蒙对**：蒙对的题也建议收，先设 `mastery: 1`，按实际错因分类。
