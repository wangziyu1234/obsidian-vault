# 错题本使用规范

> [!abstract] 本页定位
> 错题本的**操作手册**：一题一篇放哪个文件夹、新建时填什么、复习完改哪三处、字段取值是什么、把题丢给 AI 时怎么发。**看板在 [[00 错题本总览]]**，本页不看数据，只讲规矩。
>
> 每题正文套 `templates\错题模板.md`（Templater / QuickAdd 可直接套）；模板里自带 `#错题` 标签，看板就靠这个标签收题，见 [[00 错题本总览#📊 看板|看板说明]]。

> [!note] 一题一篇，按年份分文件夹（2026-09-18 起）
> 错题篇一律放进 `数学\错题本\年份\`：2000 年的题进 `数学\错题本\2000\`，文件名仍是 `2000-4 斜渐近线截距漏项` 这种 `年份-题号 关键词`；根目录只留 `00 错题本总览.md`（索引）与本页（规范）。新年份**有第一篇错题时再建文件夹**，不必预先建空目录。
>
> **看板不用改**：查询按 `#错题` 标签收（带 `file.folder != "templates"` 排除模板），不论题在根目录还是子文件夹都收得到。链接也照旧——Obsidian 的 wikilink 认文件名，不认路径，移进子文件夹后 `[[2000-4 斜渐近线截距漏项]]` 照样跳得到。

## 🧭 使用流程

1. **做卷时标记**：在当年解析页对应题号旁加一行
   > 错题：2025-19 二次型参数
   这样从真题页能直接跳进错题本，不必回头翻。
2. **建篇**：用 QuickAdd / Templater 套 `templates\错题模板.md`，放进**年份子文件夹**（如 `数学\错题本\2025\`），文件名写 `年份-题号 关键词`（如 `2025-19 二次型参数`）。
3. **填四块**（顺序就是复盘顺序，**全篇控制在 60~80 行**）：
   - abstract：一句话错因 + **答案**（供复习时对答案）；
   - **❌ 我卡在哪**——写清卡在哪一步、被什么带偏（**全篇唯一不可替代的内容，细节全留**）；
   - **✅ 纠正的关键一步**——只给纠正这一处的一个公式 + 一句口诀；
   - 同类与变式：讲次与专题链接、同型真题、下次要盯的点（压成一行）。

> [!warning] 原题与完整解法一律不抄（长期遵守，2026-09-19 定）
> 库里已有整卷试题与解析，再抄一遍只会把错题本变成讲义。**错题篇只写解析页里没有的东西**：我卡在哪、纠正这一处的关键一步、下次要盯什么。目标篇幅 **60~80 行**。
>
> 唯一例外：**答案要留在 abstract 里**，这样复习时能直接对答案，不必跳页。
>
> 删减时的取舍顺序（先删这些）：备选解法／第二种走法 → 原题整块 → 方法的补充说明 → 同卷相邻题链接。**「我卡在哪」永远不删**。
4. **排复习**：frontmatter 的 `review` 写当天、次日、第 3 天、第 7 天、第 30 天；`mastery` 从 1 涨到 3 就归档。**整题跳过、没动笔的（`mastery: 0`）不排节点**，先挂进总览页的「跳过挂起」，规则见下方「`mastery` 才是掌握度」那一段。
5. **每周扫一次看板**（[[00 错题本总览|总览页]] 最上方）：待复习清单 + 错因统计。某个错因连续两周居首，就回去补对应讲次。

## ✅ 复习完了怎么标（三处，缺一看板不刷新）

| 位置 | 怎么改 | 作用 |
| :-- | :-- | :-- |
| 正文「复习记录」 | 在该行**点一下方框**，把未完成勾成完成 | Tasks 自动补 `✅ 日期`，形成复盘日志 |
| frontmatter `review` | **删掉已完成的那个日期**，只留未来的 | 看板查询是 `any(review, d <= today)`，不删就永远显示"待复习" |
| frontmatter `mastery` | 1 → 2（会做但不熟）→ 3（稳） | `mastery: 3` 后彻底移出待复习，视为归档 |

> [!warning] `review` 里的日期只能**删除**，不能划掉或加注
> `review` 是 YAML 日期列表，Dataview 靠类型判断到期。写成 `~~2026-09-18~~`、`2026-09-18(已做)` 都会变成普通字符串，**看板行为不可预料**。做完一次就把那一个日期删掉，其余日期保持原样。

> [!note] 改了数值就是改了属性：面板与源码都行
> `mastery`、`review` 就是笔记顶部的**属性（Properties）**，两种改法等价：
>
> - **属性面板**（最快）：`mastery` 直接点数字改成 `2`／`3`；`review` 是列表，悬停某一条日期点 `✕` 即可删掉它、需要时点 `+` 补新日期；
> - **源码**：直接编辑 YAML 里的 `mastery: 1` 与 `review: [...]`，适合一次改多条、或要精确控制格式时用。
>
> **一个警告**：在属性面板里**不要把这几个属性的类型改成"文本"**。`mastery` 一旦变成字符串，看板里的 `mastery < 3` 这种数字比较就会失效；`review` 的类型也要保持"列表"。类型不对时，最省事的修复是直接改源码或用模板重建。

> [!note] 勾的是"动作"，`mastery` 才是"掌握"
> **打勾 ≠ 做对**。勾框记录的是"这一档复习动作完成"，所以**做错也该打勾**——做对做错交给 `mastery` 表达。两个理由：一是只有先勾掉、再删日期，看板才不会一直催；二是"没做对所以不敢勾"会让日期越积越多，最后干脆不看错题本。
>
> `mastery` 才是掌握度，宁低勿高：
>
> | 值 | 判定标准 |
> | :-- | :-- |
> | 0 | **跳过／主动放弃**——整题没动笔，本轮不打算拿这几分（典型是数二的证明题） |
> | 1 | 还做不对，或必须看答案才能走完 |
> | 2 | 不看答案能做对，但慢、要靠"提醒自己关键点"才不出错 |
> | 3 | 一看就会，能讲清当时为什么错，**连续两次通过** → 归档 |
>
> **这次又错了怎么办**：照样打勾 + 删掉本次日期，在那行写明"新错法是什么"，`mastery` 退回 1，并把剩余日期按"明天、+3、+7"从今天起重排（30 天节点保留）。

> [!note] `mastery: 0`（跳过／主动放弃）怎么用——**不排复习节点，但清单里一直留着**
> 「跳过」和「做错」是两种不同的欠账：做错的题你已经走过一遍、缺的是某一步；跳过的题**连第一步都没写**。0 档单列：
>
> - **不排复习节点**：`review` 留空。**本轮不打算拿这几分，复习它只是白占名额。**
> - **不进「待复习」，但一定进「跳过挂起」**：总览页有一张专收 `mastery: 0` 的表（它在「尚未掌握（全部）」里也会出现，`剩余节点 = 0` 就是"还没开始"）。**0 档不是"忘了"，是"明确放弃"**，所以留在清单上随时能回看。
> - **想收回就回收**：哪天决定要了，把 `mastery` 改成 1，按"当天、次日、+3、+7、+30"排满节点即可。
> - **不写卡也要留痕**：至少在解析页那行写 `> 错题：跳过（原因）`。
>
> 一句话：**0 档 = 挂起，不是删除。**

> [!tip] 弃题前问一句：**这题的方法，换一道选择题还会不会用？**
> 数二里"证明题"是个筐，**能弃的只是其中靠灵感的技巧题**，别把筐里那些别处照考的方法一起倒掉：
>
> | 情形 | 处理 |
> | :-- | :-- |
> | **可弃**：需要自己**构造辅助函数 / 反证**的技巧型证明（如 2000.16 反设只有一个零点、再造 $g=f(\cos x-\cos c)$） | `mastery: 0`，不排节点，`cause: 主动放弃` |
> | **慎弃**：外壳是**零点定理、变上限积分求导、保序性、单调性**的题 | 留 1 档——这些方法在选择题 / 填空题 / 计算题里同样考（变限积分求导见 2020.1、2026.6；零点个数见 2015.19） |
> | **底线**：弃之前先把那一步**白送的**写掉（如"由 $\int_0^\pi f=0$ 知 $f$ 有正有负 ⟹ 零点定理给出至少一个零点"） | 过程分按步给，一行也是分 |
>
> 判据一句话：**这题的方法，换一道选择题还会不会用？会 → 不该进 0 档。**
>
> 一句话：**0 档 = 挂起，不是删除。**每周扫一次「跳过挂起」，挑一条补掉。

> [!note] 归档怎么写（`mastery: 3`）
> 判为"已会"的题：`mastery` 改成 3，并把「⏱️ 复习记录」的勾选框换成一行归档说明，例如：
>
> ```
> > **2026-09-19 归档（mastery: 3）**：方法全会，错在机械动作；对策见本页「交卷前的三秒自检」。
> ```
>
> 归档后看板自动排除（两个查询都带 `mastery < 3`），但**卡片与各处链接一律保留**——它是"为什么会有那张自检清单"的证据。二刷再犯同类错，按上面的规则退回 1 重排。

复盘时在勾好的那一行后面补一句当时表现，比只打勾有用：

```
- [x] 2026-09-17 当天重做 ✅ 2026-09-17 —— 一次做对，但提示自己落笔前先看问号左边
- [x] 2026-09-18 次日    ✅ 2026-09-18 —— 还是漏 dx，直到想起"问 dy 就写系数×dx"才对
```

> [!tip] 一句话记住
> **勾框是留痕、删日期是排下次、涨 `mastery` 是归档**；只勾框不动 frontmatter，看板会一直催你。
>
> 另外：**`review` 是写死的日期，不会自动顺延**——漏做只会在「待复习」里一直显示（看 `到期日` 列就是欠债天数），不会帮你把后面的节点往后挪。补做时二选一：
>
> - **补做、后续节点不动**（省事）：把漏掉的那个日期从 `review` 里删掉，其余日期保持；
> - **整体后移一轮**（彻底追不上时）：以补做当天为新起点重排还没做的日期。

## 🏷️ 字段与标签约定

| 字段 | 取值 | 说明 |
| :-- | :-- | :-- |
| `type` | `mistake` | 看板查询靠它筛，别写成别的 |
| `year` / `no` | 如 `2025` / `19` | 题号按当年试卷编号 |
| `kind` | 选择 / 填空 / 解答 | 便于看哪类题丢分 |
| `topic` | 对齐 [[考研数学二目录]] 的专题名 | 如「二次型」「一元函数微分学」 |
| `cause` | 概念不清 / 方法不会 / 计算出错 / 审题失误 / 时间不够 / 主动放弃 | 每次只标 1–2 个主因；`主动放弃` 专配 `mastery: 0`，用来统计"我故意丢了多少分" |
| `mastery` | 0（跳过未做）→ 1（刚错）→ 2（会做但不熟）→ 3（稳） | `3` 归档；`0` 不排复习节点，进总览页「跳过挂起」 |
| `review` | 日期列表 | 到期的题会出现在「待复习」表 |
| `tags` | 必须含 `错题` | **看板靠这个标签收题**，别删 |

> [!tip] 错因只标主因
> 一道题常同时有审题和计算问题，但**先记最致命的那一个**。都记等于都没记，统计也失去意义。

## 🩺 交卷前的三秒自检（全是机械动作，不是技巧）

> [!warning] 2000 年三次错都出在这一类
> 11 题漏写 $+C$、14 题把 $\lvert\cos t\rvert$ 的周期看成 $2\pi$、18 题 $\int x^4$ 忘了给指数 $+1$ 且代入时又搞错一次——**都不是"不会"，是动作没走完**。

固定动作，做完题花半分钟过一遍：

1. **积分**：指数是否比原来 **$+1$**、系数是否 $\frac{1}{n+1}$、不定积分是否补了 $+C$；
2. **代上限**：**别急着代 $r$**——先把 $r$ 留在外面，让两项幂次对齐；代入的幂次必须与积分结果一致（$\frac{x^5}{5}$ 代出 $r^5$，不能"统一按 $x^2$ 代"）；
3. **同类项合并**：提出常数后各项应是**同一个量纲/幂次**（旋转体的两项都该是 $r^5$）；不一致 ⟹ 一定错；
4. **公式限定**：体积带 π、面积不带；周期函数先确认**最小正周期**（$\lvert\cos t\rvert$ 是 $\pi$ 不是 $2\pi$）；
5. **代值验证**：取个最简单的参数（如 $a=1$）看正负与量级——体积、面积**不可能为负**；
6. **答题完整**：回读题干问句——问"何时最大/最大是多少"，就必须有求导和最值两步；问「曲线方程为____」要写**带等号的方程**（$y=\dots$），别只填右边的表达式。
7. **几何对象对位**：点斜式 $y-y_0=k(x-x_0)$ 落笔前先抄下 $(x_0,y_0)$ 并填空，写完把该点代回验一遍；**切线＝导数、法线＝负倒数**，写完回读题干确认问的是哪个。

> [!tip] 一句话
> 「不会」靠讲次笔记补；「漏动作」只能靠交卷前这半分钟。

## 🤝 交给 AI 建篇时怎么发

原题与标准解法不用抄——库里就有整卷试题与解析（见上方「填四块」的篇幅约定，全篇 60~80 行）。你只要发**题号 + 你当时怎么错的**，我按模板建篇、排复习日期、挂好链接并提交。

最小格式（一题一段，多题连着发也行）：

```
2025 数二 19
我错在：把行元素之和当成特征值之和，直接写了 3,3,3
卡点：没注意题设给了二重特征值 1
（可选）耗时 12 分钟 / 是蒙对的
```

我会做这些事：

1. 从 `YYYY年考研数学二试题.md`、`…答案与解析.md` 取原题与标准解法（逐步公式块）；
2. 按 `templates\错题模板.md` 建 `数学\错题本\YYYY\YYYY-NN 关键词.md`（年份文件夹不存在就新建），填 `year/no/kind/topic/cause/mastery/review`（复习日期自动排当天、次日、第 3/7/30 天）；
3. 在当年解析页对应题号旁补一行 `> 错题：同名错题页`；
4. 到讲次笔记里找同型例题挂「同类与变式」，跑一遍校验后提交：
   - `python .scripts/check-mistake-cards.py`（查错题卡：必备字段、四个小节是否齐全、`复习记录`与 `review` 是否对得上、篇幅 60~90 行）；
   - `.scripts/check-notes.ps1`（全库笔记校验）。

> [!tip] 两件只有你能提供的信息
> - **当时的想法**：哪怕一句「我以为…」「没看出…」「算到一半慌了」都比标准解法值钱；
> - **是否蒙对**：蒙对的题也建议收（标 `cause: 审题失误`、`mastery: 1`），这类题二刷最容易翻车。
>
> 错因标签我先按五类给初判，拿不准会写 `cause: [待确认]`，你一句话我就改。
