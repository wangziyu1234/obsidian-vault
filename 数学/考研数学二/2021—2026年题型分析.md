# 2021—2026 年数二题型总结分析

> [!abstract] 本页定位
> 2021 年新大纲实施（10 选择＋6 填空＋6 解答，满分 150）以来共 6 套卷、132 道题、900 分。本页把每题**逐题归入板块**、统计分值、找出六年不变的规律，并把每个高频考点**落到具体方法**，用来排复习优先级。
> 逐题原文见 [[考研数学二目录#年份目录|年份目录]]；考点口径沿用 [[考研数学二目录#专题目录与题量|专题目录]]。

### 5.2 一元微分学（年均 31 分，含全部证明题）

| 考点 | 识别信号 | 具体方法 | 真题 |
| :-- | :-- | :-- | :-- |
| 导数定义 | 给可导性＋极限式，求 $f'(x_0)$ | 把极限凑成 $\frac{f(x_0+\square)-f(x_0)}{\square}$，系数据此读出；有 $f(\mathrm e^{x^2})=3f(1+\sin^2x)$ 型条件就分别展开 | 2022.17、2024.2、2025.18 |
| 参数方程·隐函数求导 | $\begin{cases}x=x(t)\\y=y(t)\end{cases}$ 或 $F(x,y)=0$ | 一阶 $\frac{\mathrm dy}{\mathrm dx}=\frac{y_t'}{x_t'}$，二阶 = 一阶结果再对 $t$ 求导再除 $x_t'$；隐函数用两边微分或 $-\frac{F_x}{F_y}$ | 2021.12、2022.12、2023.14、2025.14 |
| 高阶导数 | 求 $f^{(n)}(x_0)$、$f^{(5)}(1)$ | 泰勒展开比对系数（最快）⟹ 莱布尼茨公式 ⟹ 部分分式逐项求导 | 2021.5、2024.14 |
| 切·法·渐近线·曲率 | 求切线/法线/渐近线/曲率圆 | 切线 $y-y_0=f'(x_0)(x-x_0)$，法线斜率 $-\frac1{f'}$；渐近线三类（竖直/水平/斜：$k=\lim\frac fx$、$b=\lim(f-kx)$）；曲率 $K=\frac{\lvert y''\rvert}{(1+y'^2)^{3/2}}$，曲率圆在凹侧 | 2021.18、2023.1/14、2024.11、2025.12、2026.13 |
| 单调·极值·拐点 | "有几个零点""无极值但有拐点""解有界" | $f'$ 定号判单调，$f'=0$ 且变号判极值；$f''=0$ 且变号判拐点；零点个数 = 单调区间 + 端点极限符号，含参就按参数分区间讨论 | 2021.2/4、2022.3、2023.7、2025.2、2026.5 |
| 证明：中值定理 | 结论含"存在 $\xi$ 使 $f'(\xi)=\dots$" | 把结论凑成 $[F(x)]'=0$ 用罗尔（辅助函数 = 结论里的式子积分回去）；两个中值点就折半区间用两次拉格朗日或柯西；含 $f''$ 用泰勒；含 $\int$ 用变限积分求导或积分中值 | 2022.21、2023.21 |
| 证明：不等式·误差界 | 证 $f\le\dots$、$\left\lvert\int f-\dots\right\rvert\le\dots$ | 移项造差函数 $h$ 证 $h'\ge0$；凸性 $f''\ge0$ ⟹ 中点值 ≤ 积分平均；插值误差写带余项泰勒再估计 | 2024.21、2025.21 |

### 5.5 常微分方程（年均 15.5 分）

| 考点 | 识别信号 | 具体方法 | 真题 |
| :-- | :-- | :-- | :-- |
| 一阶方程类型识别 | 一阶 $y'=\dots$ | 可分离（能写成 $g(y)\mathrm dy=f(x)\mathrm dx$）⟹ 齐次 $y'=\varphi(\frac yx)$ 令 $u=\frac yx$ ⟹ 一阶线性 $y'+P(x)y=Q(x)$ 套公式 ⟹ 全微分 $P\mathrm dx+Q\mathrm dy=0$ 且 $P_y=Q_x$ | 2024.13、2025.15 |
| 可降阶 | 二阶缺 $y$ 或缺 $x$ | 缺 $y$：令 $p=y'$；缺 $x$：令 $p=y'$ 并把 $y$ 当自变量（$y''=p\frac{\mathrm dp}{\mathrm dy}$） | 2026.21 |
| 二阶常系数 | $y''+ay'+by=f(x)$ | 特征方程 $r^2+ar+b=0$ 三情形写通解；非齐次特解按 $f(x)$ 设（$\mathrm e^{\lambda x}P_m$、三角）；"解有界/积分收敛" ⟹ 特征根实部条件 | 2021.15、2022.14、2023.4、2025.3 |

## 六、六年不变的六条规律

1. **线性代数固定 32 分、位置也固定**：选择第 8、9、10 题（15 分）＋填空第 16 题（5 分）＋解答第 22 题（12 分），六年零变化。解答题三年一轮：相似对角化（2021、2023）→ 二次型（2022、2024）→ 合同/正交变换（2025）与向量组（2026）。
2. **解答题 17～21 全是高数**（58 分），其中**二重积分年年一道**（2021.21、2022.19、2023.20、2024.17、2025.20、2026.17）；若二重积分落到第 17 题就是 10 分。
3. **第 21 题＝证明题的常驻席位**：2022—2025 连续四年（凸性充要条件、中值定理、插值误差界、割线斜率单调）；2021、2026 换成计算题。
4. **反常积分年年考**（2021.11、2022.5、2023.6、2024.7、2025.3/11、2026.11）——正对应 2021 大纲新增的"收敛的比较判别法"：**新增大纲要求往往立刻变高频**。
5. **多元微积分是最大板块**：六年 193 分（21.4%，年均 32 分），解答题 11 道；"多元极值"在 2023—2026 连续四年出现。
6. **客观题 80 分、每题 5 分**：概念型"命题真假判断"选择题六年出现 8 次（2022.1/3、2024.4/7、2025.4/7、2026.5/10），考的全是概念的边界条件。

## 七、已经消失或降格的题型

- **纯物理建模解答题（雪堆／冷却／注水型）：六年 0 次**。最近两次是 2020.21（面积比建模）与 2015.20（牛顿冷却）；物理应用只剩 5 分小题。
- **弧长与旋转曲面面积**：2021.19、2022.18、2023.12 三次后消失，2024—2026 改考"旋转体体积"（2024.19、2026.20）。
- **形心、静水压力、质心**：六年 0 次（2013.21、2014.13、2020.12 之后再未出现）。
- **极限单独作解答题**：只有 2021.17 一次，此后极限都藏在小题里。
- **泰勒公式证明显式考法、多中值点证明**：六年 0 次（2024.21 的插值误差与梯形误差界是另一种新面孔）。
- **老题型并未全死**：2023.17（切线截距 ⟹ 微分方程 ⟹ 切线与两轴三角形面积最小）与 2001.16、2017.21 同型——"几何条件 ⟹ 方程 ⟹ 最值"这条线一直有效，只是换了包装。
