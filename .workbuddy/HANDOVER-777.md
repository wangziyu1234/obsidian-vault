## 三、⚠️ Read 工具串页坑（2026-09-25 实测，第6章录入时集中爆发）

- **现象**：`Read` 图片会回送别的已读图（页码不符、张冠李戴），并行多图读几乎必错；单读也可能回送旧图，同一文件连续读可一直卡在同一张旧图上。
- **对策（有效组合）**：
  1. **一次消息只 Read 一张图**；
  2. **读完立即核对图内页脚/题号**，不符就当没读；
  3. 换名重渲染（新前缀 / 新 dpi / 新目录都试过，**新 dpi+新名字**组合最稳，如 `_pdf3\pXXX.jpg` dpi148/155）；
  4. 交付不可靠时改用 **RapidOCR 分段 OCR 文件本身**（第7章即用 `_ocr_batch7.py` 批量 OCR 47 页打底，公式密集处再读图互证——7-4/7-7/7-20 差分方程下标等都是读图抓回的）；
  5. **每读成功一页立刻 Write/Edit 落盘**，防上下文压缩丢失。
- 页码地面真值：`_probe_rows5.py`/OCR 页脚 = 书内页，PDF = 书内页 + 6（两册一致）。
