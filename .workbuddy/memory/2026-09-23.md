## 用户习惯：偏好图像直觉解题（答疑，未改笔记）
- 追问「能不能靠感觉大致走向、看凹凸形状」。答复口径（以后同问照此答）：
  - **走向/符号/极值/单调 = 可以靠草图**，且是严谨的（由零点重数 + 首项系数唯一决定）。
  - **凹凸/拐点 = 不能靠手感**：拐点个数由 $f''$ 零点的**重数**决定，重数肉眼读不出（铁证：$y=x^{4}$ 与 $y=x^{5}$ 在原点附近都"平得像直线"，前者 0 个拐点、后者 1 个）。
  - 折中规则（已写进 05-2 tip）：草图只取两个**可数**的量——极值点数 $m$、次数 $n$，用 $m-1\leqslant\text{拐点数}\leqslant n-2$ 夹；夹住即确定，夹不住必须求 $f''$ 或用个数公式。夹不住的例子：$y=x^{4}+x$（$m=1$、上界 2、实际 0）、$y=x^{5}$（$m=0$，下界失效、实际 1）。
  - 另一条分界：**题目给的图**（如 2001.10 给 $f$ 图选 $f'$ 图）是已知条件，可严谨读；**自己手画的草图**只能按夹逼规则用。
