## 表格源码风格（长期遵守）
- **表格一律紧凑**：`| a | b |` + `| :-- | :-- |`，不按列宽补空格。理由：用户「横向珍惜」偏好 + 避免 git 出现大段纯空白 diff。
- 根因：Obsidian 源码模式下**编辑过的表格会被自动按列宽对齐**（核心编辑器行为，无开关）——不是插件，已确认 `obsidian-linter` 装的但 `lintOnSave/lintOnFileChange=false` 且 0 条规则开启。所以只有被编辑过的表才变宽。
- 工具 `.scripts\normalize-md-tables.py`（`--check` 只报告）：按未转义 `|` 切分（兼容表格内 `\|` 转义）；分隔行保留 `:-:` / `:--:` 的对齐语义，只压过长横杠；**只在确有对齐空格时才重写**，避免无意义 diff。

## 频域特征点速算（2026-09-26 立，用户明确口径）
- **三个频率**：$\omega_0=\frac1{\sqrt{T_1T_2}}$（落轴点，不带零点）· $\omega_g$=穿越频率（$\varphi=-180°$，判稳/幅值裕度；777 记 $\omega_g$，教材与 05-4-3、05-3-7 记 $\omega_x$，同一量）· $\omega_c$=截止频率（$|G|=1$，相角裕度）。**别再用 $P=T_1T_2$、$T=T_1+T_2$、$X$ 这类中间记号**，一律用 $K,T_1,T_2,\tau$ 直写；只保留 $\tau_c=\frac{T_1T_2}{T_1+T_2}$。
- 分页：`05-3-8 双惯性系统特征点速算`（§5.3.2.9，248 行）、`05-3-9 单惯性系统特征点速算`（§5.3.2.10）、`附录 z变换与离散化速查`（第7章）；附录 幅相曲线速查 的 (3) 只留指针。
- **关键结论**：双惯性两道门限 $\tau_c$（Ⅰ 型有无穿越点）与 $T_1+T_2$（Ⅱ 型，可稳需 $\tau>T_1+T_2$）；单惯性 $\tau\ne T$ 时**永不落轴** → 无 $\omega_g$、$h=\infty$，ν=2 判稳 ⟺ $\tau>T$；典型Ⅰ型 $KT=0.5$ → $\zeta=0.707$、$\omega_c\approx0.455/T$、$\gamma\approx65.5°$。
- 777 的 $\omega_c$ 是**渐近值**（分段线性按折点取），与精确解可差 10%+，引用时注明。
