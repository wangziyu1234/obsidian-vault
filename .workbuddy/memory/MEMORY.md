## 错题本机制（数学/错题本/）
- 按年份放子文件夹：`数学\错题本\YYYY\YYYY-NN 关键词.md`；根目录只留 `00 错题本总览`（索引＋看板）与 `01 错题本使用规范`。新年份**有第一篇错题时再建文件夹**。挪目录用 `git mv`，wikilink 认文件名不认路径。
- 看板查询一律用标签 `FROM #错题` + `WHERE file.folder != "templates"`（模板自带 `#错题`，靠 folder 条件排除）。**「待复习」当天做完后必然空表，是正常现象**；判断看板是否失效看常驻表「尚未掌握（全部）」。
- 一题一篇，`type: mistake`，字段 `year/no/kind/topic/cause/mastery/review`，模板 `templates\错题模板.md`。**复习三处联动**：正文勾框（Tasks 自动补 ✅ 日期）＋ frontmatter `review` 删已完成日期 ＋ `mastery` 1→2→3。
- **`mastery` 五档**：`0` 跳过/主动放弃 → `1` 刚错 → `2` 会做但不熟 → `3` 稳。`0` 档 `review: []` 不排节点，进总览「跳过挂起」表，配 `cause: 主动放弃`；**`review` 只有 0 档允许为空**（`check-mistake-cards.py` 已同步）。
- **弃题判据**：可弃 = 需自造辅助函数/反证的技巧型证明；慎弃 = 零点定理/变上限积分求导/保序性/单调性外壳的题；底线 = **弃题也要写到"免费的那一步"**。一句话：这题的方法换一道选择题还会不会用？
- `review` 是写死的日期不自动顺延；补做二选一：删漏掉的日期，或以补做日重排剩余。
- 小失误（漏 `+C` 之类收尾漏动作）不算原错因复发 ⟹ `mastery` 提到 2、复习日期不动；只有原错因复发才退 1 重排。
- ⚠️ 新文案别写「待补」二字（check-notes.ps1 占位符检查会报「待修」）。
- 建篇后在当年解析页题号旁补 `> 错题：[[同名错题页]]`，总览索引表加一行。

## 批量脚本的坑（多次踩实，写脚本前必读）
- **批量写文件禁止 `文本.replace('\n', 变量)`**（行尾变量被覆盖会把文件撑爆）：一律按行列表组装 `'\r\n'.join(lines)`，写盘前断言行数、写盘后重读核对。
- 判断行尾必须**二进制读**（文本模式 universal newlines 会把 \r\n 悄悄转 \n）：`nl = '\r\n' if b'\r\n' in open(p,'rb').read() else '\n'`；写完复查裸 LF 为 0。
- 别用 bash 双引号包 Python 单行脚本（Git Bash 吃反斜杠）：脚本写 `.workbuddy/_x.py` 再跑。
- 拆分/替换用**占位符两趟法**；切片若已含标题行别再手写一遍（会报小节号重复）；PowerShell 5 无三元运算符。
- 脚本要能重跑：命中已完成就 print('SKIP')。
- 改 method 页的考点速记块必须**按行内容匹配**定位（不许按行号）；块内每条 ≤200 字符，写时就量。
- 「缩进 3 空格」在父项是 `1. ` 时是正确对齐，不是错。
