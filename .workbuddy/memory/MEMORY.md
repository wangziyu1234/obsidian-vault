## 批量脚本的坑（多次踩实，写脚本前必读）
- **批量写文件禁止 `文本.replace('\n', 变量)`**（行尾变量被覆盖会把文件撑爆）：一律按行列表组装 `'\r\n'.join(lines)`，写盘前断言行数、写盘后重读核对。
- 判断行尾必须**二进制读**（文本模式 universal newlines 会把 \r\n 悄悄转 \n）：`nl = '\r\n' if b'\r\n' in open(p,'rb').read() else '\n'`；写完复查裸 LF 为 0。
- 别用 bash 双引号包 Python 单行脚本（Git Bash 吃反斜杠）：脚本写 `.workbuddy/_x.py` 再跑。
- 拆分/替换用**占位符两趟法**；切片若已含标题行别再手写一遍（会报小节号重复）；PowerShell 5 无三元运算符。
- 脚本要能重跑：命中已完成就 print('SKIP')。
- 改 method 页的考点速记块必须**按行内容匹配**定位（不许按行号）；块内每条 ≤200 字符，写时就量。
- 「缩进 3 空格」在父项是 `1. ` 时是正确对齐，不是错。

## 拆分与合并套路
- **留标题、搬内容**：被移走内容的小节标题留在方法篇，外部 `#锚点` 链接就不用改；改完 grep 旧文件#旧锚点 确认 0。

- **入口模式**（原文件名不动改成总览）：反向链接零改动；拆前 grep 确认无 `[[文件#锚点]]` 引用。
- 合并两页：以覆盖更全的为存续页 → 重复小节留一份 → 重排编号 → 删被并页 → **改写全部反向链接**（grep 确认 0 残留）。
