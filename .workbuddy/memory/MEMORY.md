# 项目约定（D:\obsidian 知识库）

## 错题本机制（数学/错题本/）
- **按年份放子文件夹**（用户 2026-09-18 要求，commit `5bd66bb`）：`数学\错题本\YYYY\YYYY-NN 关键词.md`，如 `2000\2000-4 斜渐近线截距漏项.md`；根目录只留两篇：`00 错题本总览.md`（索引＋看板）与 `01 错题本使用规范.md`（流程/字段/复习标注/AI 口径），2026-09-18 从总览拆出（commit `e89737c`）。新年份**有第一篇错题时再建文件夹**，不预建空目录。
- 移目录不用改链接：Obsidian wikilink 认文件名不认路径；Dataview 的 `FROM "数学/错题本"` 与 Tasks 的 `path includes 数学/错题本` **都递归子文件夹**，看板照旧。用 `git mv` 移（保留历史）。
- **看板查询一律用标签 `FROM #错题` + `WHERE file.folder != "templates"`**（2026-09-18 改）：不再依赖文件夹路径，以后挪文件夹/加年份子目录都不用改查询。`#错题` 由 `templates\错题模板.md` 自带，模板本身靠那条 folder 排除掉（模板的 frontmatter 也是 `type: mistake`，不排除会混进统计）。
- **「待复习」表空着是正常现象，不是坏了**：查询条件是"有没有 `review` 日期 ≤ 今天"，当天那一档做完就把该日期删掉，于是下一个节点变成明天——**当天做完后当天必然空**。为此看板里另放了一张常驻表「尚未掌握（全部，含还没到期的）」，带 `下次复习` 与 `剩余节点` 两列，用来一眼判断看板是否真的失效。
- 一题一篇 `年份-题号 关键词.md`，`type: mistake`，字段 `year/no/kind/topic/cause/mastery/review`，模板在 `templates\错题模板.md`。
- **复习状态三处联动**：正文「复习记录」勾框（Tasks 自动补 `✅ 日期`）＋ frontmatter `review` 删掉已完成日期 ＋ `mastery` 1→2→3（3 归档）。
- **`review` 是写死的日期，不自动顺延**：漏做只让看板的「到期日」列一直偏早，不会推动后续节点。补做二选一：删掉漏掉的日期（后续不动）；或以补做日为起点重排剩余日期。
- 「待复习」查询条件：`type="mistake" AND mastery<3 AND any(review, d<=today)`。
- 建篇后要在当年解析页对应题号旁补 `> 错题：[[同名错题页]]`，并在总览手写索引表加一行。
