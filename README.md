## 📊 内容概览

### 数学二：先概念，再计算与证明

**高等数学**按15讲组织：

- **01–02**：函数、极限、连续与数列。
- **03–07**：导数、微分、几何应用、中值定理、泰勒与变化率。
- **08–12**：积分概念、计算、几何/物理应用与积分不等式。
- **13–15**：多元微分、二重积分、微分方程。
- **14类附录**：基础工具、图像、积分速查、曲线曲面与教材对照；较长附录按主题分层。

**线性代数**沿“矩阵与行列式 → 向量与方程组 → 特征值 → 二次型”复习：

- **第4讲**保留细颗粒知识点导航；**第5讲**按“定义与求法 → 性质 → 相似判定 → 对角化与反求矩阵 → 实对称正交对角化”分层。
- **第6讲**按 6.1→6.15 的教材顺序命名，覆盖合同与相似、配方法、标准形与惯性定理、正交变换与正定判定。
- 每篇都是“理论 + 例题 + 习题”；同解、相似、合同等关系单独辨析。

**数二真题**提供27套试卷及独立答案解析。专题目录按主考点整理607道题，交叉练习另列，不重复计入题量。

**错题本**一题一篇，记原题、当时错在哪、正确解法与同类变式，并用 Dataview 与 Tasks 自动筛出待复习与未掌握的题；复习节奏 D0/D1/D3/D7/D30，字段与错因标签见 [[数学/错题本/00 错题本总览|错题本总览]]。

## 🪶 阅读与笔记约定

**适合纵向阅读，而不是把公式挤进一行。**

- 先定位摘要，再看方法、证明和例题；所有跨文导航使用 wikilink。
- 推导用青色说明框，例题用紫色，技巧用绿色，易错点用橙色。
- 多主题长文保留原名作总览入口；**同一道题的题目、图、推导及多解法保持完整**。
- 完整单题可用 `single-exercise: true` 豁免250行告警，其余结构、公式、链接仍须检查。
- 错题一题一篇（`YYYY-NN 关键词`，`type: mistake`），错因与复习记录写在 frontmatter 里，便于看板汇总。
- 命名、页头、LaTeX和修改流程详见 [[AGENTS]]；本文不重复全部细则。

> [!tip] 在 Obsidian 中阅读

## 🔍 校验脚本

```powershell
# 指定学科
.\.scripts\check-notes.ps1 -Dir "数学\高等数学"

# 指定一篇笔记
.\.scripts\check-notes.ps1 -File "控制理论\现代控制理论\01 状态空间表达式.md"

# 全库结构扫描
```

脚本检查链接、公式配对、标题结构、编号和篇幅等机械问题。**数学正确性、定理前提、教材题设和图文一致性仍须人工重推**，不能以脚本通过代替内容审校。

## 🔄 Git 同步

Remotely Save负责多端同步，Git负责可追溯的版本兜底。工作分支为 `main`，远程为 `origin`。

```powershell
git status --short

# 只列本轮确认完成的路径；以下以首页为例
git add -- "README.md"
git diff --cached --stat
git commit -m "docs: 更新知识库导航"
git push origin main
```

- **提交前缀**：`fix:` 修错 · `docs:` 补内容 · `refactor:` 调结构 · `chore:` 杂项。
- **并行编辑**：不要用全量暂存把其他任务的未完成修改带入提交。
- **同步异常**：旧版覆盖或图片消失时，先比对磁盘内容与Git哈希，再从已确认版本定点恢复；不要凭文件名批量删除副本。
- **远程仓库**：`git@github.com:wangziyu1234/obsidian-vault.git`。
