## 📊 内容概览

### 数学二：先概念，再计算与证明

> [!note]- 数学二内容与复习方式
> **高等数学**按15讲组织：
>
> - **01–02**：函数、极限、连续与数列。
> - **03–07**：导数、微分、几何应用、中值定理、泰勒与变化率。
> - **08–12**：积分概念、计算、几何/物理应用与积分不等式。
> - **13–15**：多元微分、二重积分、微分方程。
> - **15类附录**：基础工具、图像、积分与换元速查、曲线曲面与教材对照；较长附录按主题分层。
>
> **线性代数**沿“矩阵与行列式 → 向量与方程组 → 特征值 → 二次型”复习：
>
> - **第4讲**保留细颗粒知识点导航；**第5讲**按“定义与求法 → 性质 → 相似判定 → 对角化与反求矩阵 → 实对称正交对角化”分层。
> - **第6讲**文件名即阅读顺序（06-1 → 06-9，对应教材小节 6.1–6.15），覆盖合同与相似、配方法、标准形与惯性定理、正交变换与正定判定。
> - 每篇都是“理论 + 例题 + 习题”；同解、相似、合同等关系单独辨析。
>
> **数二真题**提供27套试卷及独立答案解析。专题目录按主考点整理607道题，交叉练习另列，不重复计入题量；[[数学/数二题型分析（2021—2026）|近年题型分析]]与[[数学/数二证明题保底（2016—2026）|证明题保底]]另给出复习优先级与落笔动作。
>
> **错题本**一题一篇，链接原题与解析，保留当时错法、关键一步与同类变式。当天整理就算复盘，预排次日、第 3 天、第 7 天、第 30 天四轮复习；没问题自己勾掉当前轮，有问题直接告诉 AI。看板保留到期和逾期提醒，四轮全勾后显示本轮完成。掌握度只按明确反馈更新，**QuickAdd: 记录本次复习** 保留为可选记录工具。
>
> 字段取值、复习怎么标、交给 AI 怎么发见 [[数学/错题本/01 错题本使用规范|错题本使用规范]]，看板与索引见 [[数学/错题本/00 错题本总览|错题本总览]]。

## 🪶 阅读与笔记约定

> [!note]- 排版约定与阅读方式
> **适合纵向阅读，而不是把公式挤进一行。**
>
> - 先定位摘要，再看方法、证明和例题；所有跨文导航使用 wikilink。
> - 推导用青色说明框，例题用紫色，技巧用绿色，易错点用橙色。
> - 多主题长文保留原名作总览入口；**同一道题的题目、图、推导及多解法保持完整**。
> - 完整单题可用 `single-exercise: true` 豁免250行告警，其余结构、公式、链接仍须检查。
> - 错题一题一篇（`YYYY-NN 关键词`，`type: mistake`），错因与最近明确掌握度写在 frontmatter，四轮复习任务及完成历史留在正文；看板读取最早的未完成任务，保留逾期提醒。

## 🔄 Git 同步

> [!note]- 同步方式与提交命令
> Remotely Save负责多端同步，Git负责可追溯的版本兜底。工作分支为 `main`，远程为 `origin`。
>
> ```powershell
> git status --short
>
> # 只列本轮确认完成的路径；以下以首页为例
> git add -- "README.md"
> git diff --cached --stat
> git commit -m "docs: 更新知识库导航"
> git push origin main
> ```
>
> - **提交前缀**：`fix:` 修错 · `docs:` 补内容 · `refactor:` 调结构 · `chore:` 杂项。
> - **并行编辑**：不要用全量暂存把其他任务的未完成修改带入提交。
> - **同步异常**：旧版覆盖或图片消失时，先比对磁盘内容与Git哈希，再从已确认版本定点恢复；不要凭文件名批量删除副本。
> - **远程仓库**：`git@github.com:wangziyu1234/obsidian-vault.git`。
