## 📐 笔记规范（摘要）

详见 `AGENTS.md`，要点：

- **文件命名**：`NN 第N章（第N讲） 描述.md`；附录不带数字前缀；拆分专题 `NN-x 描述.md`
- **文件头**：frontmatter（create/modify/tags）→ 返回行 `> 返回目录：[[目录]]` → `# H1` → `> [!abstract] 本讲定位`
- **小节**：`## 图标 X.Y 标题`（连续不重号）；每章末 `## X.N 解题套路`
- **LaTeX**：行内 `$…$`、块级 `$$…$$`（必须成对）；`\begin/\end`、`\left/\right` 配对
- **wikilink**：跨文引用一律 `[[ ]]`；跨目录用短路径 `[[控制理论/现代控制理论/01 状态空间表达式|别名]]`
- **图片**：`![[文件名.png|尺寸]]`，正文图 `|430`、速查大图 `|520`
- **拆分**：文件 >250 行按入口模式拆（原文件留总览 + `NN-x` 专题）；当前全库无 >250 行文件

## 🔍 校验脚本

`.scripts/check-notes.ps1` —— 对标 AGENTS.md 检查清单的全库校验：

```powershell
.\.scripts\check-notes.ps1                    # 全库扫描
.\.scripts\check-notes.ps1 -Dir 数学          # 只看某目录
.\.scripts\check-notes.ps1 -File "数学\高等数学\11….md"  # 只看单文件
```

检查项：断链、LaTeX 配对、小节编号重复/跳号、H1 唯一、abstract 位置、附录无 H3、超长文件（>250 行）、占位符、空链接、图片命中。
